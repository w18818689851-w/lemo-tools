## 三、「语言版本」功能版块（核心交付）

### 设计：**一份内容文件 = 一个语言版本**

片子代码**不认识语言**，只认识内容文件里的 `"lang"` 字段。它驱动四件事：

| 驱动什么 | 英文 | 中文 |
|---|---|---|
| 字体（罗马体角色 / 手写体角色） | Bodoni Moda / Pinyon Script | `"Bodoni Moda", "Noto Serif SC"` / LXGW WenKai |
| 字距（拉丁要拉开、汉字天然紧排） | title 0.16 | title 0.30（两字标题需要更开） |
| 圆窗编号前缀 | `FIG.` → `FIG. 1 · THE FLOWER` | `图` → `图 1 · 花` |
| 配音 | `en-gb` / `bm_fable` / 0.92 | `cmn` / `zm_yunjian` / 0.95 |

### 组件

```
core/lang/
  lang.mjs         语言注册表：LANGS{en,zh} + langOf(C) + fontsToLoad(L) + isCJK(s)
  fonts-zh.css     中文默认字体表（思源宋 + 霞鹜文楷）
  fonts/           两个 woff2 子集（1.25MB + 0.79MB，各含 3500 个一级汉字）+ OFL 授权原文
```

**两层结构**（关键设计）：
- `core/lang` 提供**每种语言的通用默认字体**；
- **内容文件可以覆盖** —— 风格要换自己的中文黑体，只在自己 content 里写 `"fonts": {...}`，**不用改注册表**。
  （这一条是字体智能体提出「共享目录里放的是铜版画挑的字体，对无衬线风格是错的」之后补上的。）

### 用法

```sh
# 英文版（与改动前逐字节一致：不传 --lang）
node lemo-make.mjs engraving --film film_coffee --q content=content_coffee.json

# 中文版：一条命令
node lemo-make.mjs engraving --film film_coffee --lang zh --q content=content_coffee.json
#   → 语言版本 zh → 内容文件 content_coffee.zh.json
#   → 渲染与事件**两侧**都换成该文件（只送一侧会让事件表停在另一种语言，
#     cuecheck 会拿同一份错事件核成"通过"——这是与 --film 完全同型的坑）
```

**加一种语言**＝在 `LANGS` 加一条 + 加字体表 + 写 `content_<片名>.<code>.json`。**影片代码一行不用改。**

## 四、为了中文，改了什么（都带证据）

| # | 问题 | 处置 |
|---|---|---|
| 1 | 风格只有拉丁字体 ⇒ 中文是豆腐块 | 引入 OFL 中文字体：**思源宋 SC**（罗马体角色）+ **霞鹜文楷**（手写体角色），按**一级字 3500 字**子集化 |
| 2 | 子集含 ASCII ⇒ 会抢走拉丁 | 罗马体角色写成**字体栈** `"Bodoni Moda", "Noto Serif SC"`（Bodoni 有字形就用 Bodoni，缺字才回落） |
| 3 | `plate.js` 的 `FONTS` 是写死的常量 | 加 `setFonts()` / `setFontSpec()`；**纯拉丁路径 MD5 逐字节不变**（`d2403637243f55aee94776f25c91b379`） |
| 4 | `wrapLines` 按空白分词 ⇒ 中文整句永不换行 | 补中文**逐字断行 + 基本禁则**（行首禁标点、行尾禁开引号） |
| 5 | 引擎**无条件给 font 值加引号** ⇒ 字体栈被拼坏、Chromium 静默回落 | 修（这个 bug 是字体栈能生效的前提） |
| 6 | `build.sh` 的派生行把 `lang='en-gb'` **写死** | 改成读内容里的 `voice.lang`（英文缺省行为逐字节不变，已 `diff` 核对） |
| 7 | `asr_check` 对中文**不可用**（离线 whisper 实测 9/9 全 DIFF，且不归一化「十/百/千」） | 音频脚本对 CJK 语言**主动跳过并说明原因**，而不是刷一屏假警告掩盖真失败 |
| 8 | 四位年份会被 TTS 读成「一千五百五十四」 | 中文文案里的四位年份**一律写汉字**（一五五四年），计数仍用汉字（六到十一个月、六百年） |
| 9 | 内容文件必须**同时存在于两份库**（配音派生与 `subs.py` 都在 WSL 跑） | 已同步；这是跨文件系统那一类缺陷的第 5 次出现 |

## 五、已知限制（如实列出）

> **① 与 ② 已于本轮内修掉**，下面保留「问题 → 修法 → 结果」，因为这两条都是**先发现、再修、再验证**的。

### ① 中文断行会在两字词中间断 —— **已修**

- **问题**：只做了逐字断行 + 基本禁则，没做分词。`白色，五瓣，闻起来像茉莉。只开两天。` 断成 `…像茉` / `莉。只开两天。`（拆开「茉莉」）；`成熟转红，要六到十一个月。` 末行只剩「月。」。
- **修法**：用 `Intl.Segmenter`（Chromium 内置 ICU 中文分词）把同一个词的字黏成一个 unit，**只在 unit 之间断行**；两行时枚举所有 unit 边界取 `max(左,右)` 最小者（平手优先落在标点后），三行以上时末行只剩 1 个 unit 就把上一行末尾拉下来。`Intl.Segmenter` 不存在时自动降级为逐字断行，不抛错。
- **结果**（coffee 片真实参数 size 27 / maxW 320）：
  | | 修前 | 修后 |
  |---|---|---|
  | note1 | `…闻起来像茉` / `莉。只开两天。` | **`白色，五瓣，闻起来` / `像茉莉。只开两天。`** |
  | note2 | `…要六到十一个` / `月。` | **`成熟转红，要六` / `到十一个月。`** |
  | note3 | `…平面相抵。咖` / `啡豆是种子。` | **`两粒种子，平面相抵。` / `咖啡豆是种子。`** |
  - **自动化词完整性检查：拆词数 2 → 0**；拉丁路径 11 例 0 差异；**英文成片 MD5 `d2403637243f55aee94776f25c91b379` 逐字节不变**
- **残留**：`Intl.Segmenter` 也非最优（「六到十一个月」被切成 `六/到/十/一个/月`，整句仍会被断开）。要彻底解决需领域词典，判断不值得。

### ② 原创性审计器对中文的判据 —— **已修（但我的原始判断有一半是错的）**

- **我原先的判断**：「n-gram 与重合率两条判据都按空白分词，中文整句被当成一个词，两条都失效」。
- **实际核查结果（智能体读了 `lib/originality.mjs:82-88` 的 `tokenize()` 并实测）**：
  - **n-gram 那条本来就是字符级**（CJK 逐字 push），5 字阈值就是「连续 5 个字相同」—— **我的判断在这条上是错的**。
  - **真正坏的是重合率那条**：中文没有词表可去虚词，实际是**字符集合**重合率，却仍挂着拉丁的 0.6 阈值 → **独立写作的同题材中文实测 0.722 被误判为抄**。
- **修法**：加 `NARRATION_OVERLAP_MAX_CJK = 0.75` + CJK 专用 `overlapTokens()`（不去虚词）；报告标题/阈值/detail 三处都写明「最长公共连续**字**串」「**字符集合**重合率」，明说与拉丁的实词重合率**不是同一个指标**。
- **结果**：中文版真实对照 **11 通过 / 0 失败 / 0 无法判定**；反向验证「中文 vs 它自己」→ 20 字连续、100%、退出码 1（证明 CJK 分支真的开火，不是判据失效）；测试 34 → **42 条全绿**，英文路径逐字节不变。
- **新增盲区（已写进审计器的人工复核清单）**：**跨语言照译**（把英文旁白逐句翻成中文）判不出来 —— 这是设计使然（文件头原则 3：判据抓不到的事就该出现在人工清单里，而不是让报告显示一片 ✅ 让人以为没有风险）。

### 其余限制

3. **标题后的句点是拉丁习惯**：中文版显示为「咖啡.」，不是「咖啡。」。
4. **中文配音是离线 Kokoro**，音色一般（库文档自己就这么写：「离线可用，音色一般」）。要更自然需走 `tts_zh.py`（edge-tts，**要联网**），本轮的硬规则是本地渲染、不联网，所以没用。
5. **中文子集覆盖一级字 3500 字**：超出这个范围的生僻字（人名、古地名）会缺字。加字要重新子集化。
6. **中文版的 `asr_check` 已主动跳过**：离线 whisper 对中文实测 9/9 全 DIFF（相似度 0.20–0.57），且它的 norm 不归一化「十/百/千」，含多位数字的行即使转写正确也会 FAIL ⇒ 只会刷一屏假警告、掩盖真正的失败。所以音频脚本按 `lines.json` 的 `lang` 判定并**明确跳过 + 说明原因**。
