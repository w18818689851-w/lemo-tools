# 瑞士动态排版（`swiss-motion`）· 风格制作 Skill

## 1. 风格说明

**是什么**：一部「国际主义排版风格被做成了动效」的片子——**模块网格、一种字体、一种信号色**，运动像印刷机一样精确。平面纸、黑字与黑条、一种很浅的灰、以及唯一一种饱和的信号色；每个元素都吸附到网格上，每次运动都落在拍点上，**什么都不回弹**。它的魅力是**严谨中的唯一例外**——整幅画面服从一套系统，于是唯一不服从的那个元素就变成了角色（`STYLE.md:6-11`、`lib/style-dna/swiss-motion.md:11`）。

**不是什么**（最容易做错的邻居风格）：不是 keynote（没有渐变、发光、设备渲染图）；不是歌词视频的动感字（**词不飞不转不弹**）；不是数据可视化（条块作为图形有质量，而不是被画出的数量）；不是包豪斯基本形状的仿作（`STYLE.md:13`）。

**什么时候用它**：品牌识别 / 活动 / 设计教育——尤其适合「系统本身在讲故事」的主题。产品发布 → 规格表在网格上组装、然后一个功能冲破网格；公司历史 → 每个十年是加到同一张海报上的一条规则；爱情故事 → 两个红元素在两套不同的网格上，片子结束于其中一个离开它的网格（`DEMO.md:28`）。

**一句话内核**：**吸附落拍 + 只有两种曲线 + 唯一信号色**——这三条骨架不能拆（`STYLE.md:103-109`、`DEMO.md:18-28`）。

**边界**：这个风格**撑不起**有机、手作、情绪化、抒情的内容。它没有质感（无渐变 / 无阴影 / 无粒子 / **无颗粒**，mux grain 0）、没有表情、没有运镜的「情绪」。**画面里只能有一个信号色**，任何「多色品牌」的题材都会被压成单色。它也不能承载抽象概念——只说**能被排到网格上的东西**（`lib/style-dna/swiss-motion.md:50`）。此外它禁止照抄任何历史海报的构图（不从 Müller-Brockmann 搬同心圆或扇形版式）、禁止用 Helvetica 或 Akzidenz 字体文件、禁止在海报上写真实机构名（`STYLE.md:4`、`STYLE.md:157-159`）。

## 2. 画面构图

- **镜头数与画幅**：24 fps，1920×1080（16:9）。样本片 1056 帧 / 44.0s。画面网格是 **12 列、两侧边距约 96 px、栏距 24 px（列宽 122 px）、基线 24 px**（`film.js:11`、`DEMO.md:79`）。
- **画面可当「跨页」**：左页（列 1–6）= **程序**（巨大数字、规则文本、技术注释），右页（列 8–12）= **作品**（海报 706×1008，比例 0.70 ≈ 瑞士世界开本）。这是本风格最典型的构图（帧 f03/f06/f08/f10 全是这个跨页）。
- **主体位置与占比**：**极端尺度对比**是核心——规则数字约 **980 px 字号 / 700 px 字高**，底部与海报下沿对齐；技术注释只有 **19 px**。两者同框（帧 f08：巨大的 `3` 与右下角三行小注）（`DEMO.md:82`）。
- **负空间 / 留白**：**大块白是版面的一部分**（`STYLE.md:34`）。帧 f01 开场几乎全是空页，只有一条红线和左侧三条极浅的竖条（网格正在长出）。
- **图层叠放顺序**（从底到顶）：① 页底色 `#EAE9E5` → ② 网格线（三种浅灰：在页 `#CFCEC9` / 建造中 `#C9C8C2` / 在纸 `#E2E1DC`）→ ③ 纸块 `#FFFFFF`（海报）→ ④ **第二声部**：压在黑色元素下的**浅灰条**（不引入第二种颜色就得到纵深）→ ⑤ 黑字与黑条 `#111111` → ⑥ **信号红 `#E30613`**（全片只有一件东西是红的）→ ⑦ 覆盖式文字（黑压红 = 叠印 overprint）。
- **安全区**：字幕**不是底部的条**，而是版面的一部分——坐在当前构图里**某一列的起点**（跨页时固定在左页第 1 列）；技术注释在角落（模块尺寸、计数、小节计数器 `bar 04.3`）。
- **本风格不能出现的构图**：居中对称的 UI 式版式（必须**齐左、右不齐** flush left / ragged right）；任何不在网格线上的元素（**唯一的例外**除外）；渐变 / 发光 / 阴影 / 粒子 / 颗粒；照抄 Müller-Brockmann 的同心圆或扇形版式。

### 在 9:16（产品默认）下的表现

本风格**已适配 9:16**：`FILM_META.aspects = ['16:9','9:16']`（`film.js:27`），`renderFilm` 从 `opts.W/opts.H` 调 `layout(W,H)`（定义 `film.js:246-258`，调用点 `film.js:417`）重排整个版面——① 12 列画面网格随帧宽拉伸（`FM/FG/FC × fx`，`film.js:248`），**12 列永远铺满整幅**；② 字号 / 线宽 / 巨大数字这类尺寸按紧轴 `S = min(fx,fy)` 缩放（巨大数字 `NUM_SIZE = round(700*S/NUM_ASC)`，`film.js:249`；技术注释 19 px → `19*S`，`film.js:293`、`film.js:298`；陈述句 76 px → `bigSize*S`，`film.js:69-72`）；③ 机位（海报中心 `cx/cy` 与缩放 `s`）随帧走（`film.js:250-257`），**海报永远落在画面里**。

1080×1920 实测（`S = 0.5625`）：**不裁切、无黑边**，核心的**左右跨页保住了**——左页的规则文字与巨大数字（锚在底部 `1044*fy`，`film.js:270`）在，右页的**海报（706×1008）也完整可见**；海报墙那一镜（37.4s）五张海报仍并排铺满宽度。代价是整幅版面按 `S` 缩到 0.5625×：巨大数字从约 700 px 高缩到约 394 px、技术注释缩到约 11 px（19×0.5625）、陈述句缩到约 43 px（76×0.5625），画面上下各留出大片页色空白。信息完整度与 16:9 一致（跨页的「因 / 果」两半都在），只是**字号更小、版面更空**。

## 3. 配色体系

| 角色 | 色值 | 用途 | 来源 |
|---|---|---|---|
| 页 | `#EAE9E5` | 全片主底（很浅的暖灰） | `film.js:6-9`、`DEMO.md:81` |
| 纸 | `#FFFFFF` | 海报底（纯白，与页拉开一档） | `DEMO.md:81` |
| 墨 | `#111111` | 字与条块 | `DEMO.md:81` |
| 信号（红） | `#E30613` | **全片唯一**的饱和色，红 = 主角 | `DEMO.md:81` |
| 网格线（在页） | `#CFCEC9` | 网格线常态 | `film.js:6-9` |
| 网格线（建造中） | `#C9C8C2` | 网格正在长出时的线色 | `film.js:6-9` |
| 网格线（在纸） | `#E2E1DC` | 压在白纸上的网格线 | `film.js:6-9` |
| 第二声部（浅灰条） | `#CFCEC9` | 压在黑条下的浅灰条（贝斯声部） | `DEMO.md:81`、`DEMO.md:90` |
| 字幕（派生通路） | 字 `#111111` / 描边 `#FFFFFF` | 深字压在浅页上 | `lib/dub-styles.json#swiss-motion.subtitle` |

- **明度 / 对比规则**：**只有一件东西承载信号色**，这就让它成为主角；**也是唯一被允许不精确的东西**（`STYLE.md:26`）。允许**叠印**（黑字压信号色，帧 f14/f17/f19 里 `neue musik` 黑字压在红圆上）。深浅两档纸（`#EAE9E5` 页 / `#FFFFFF` 纸）是唯一的「层次」手段——**没有阴影**。
- **禁止出现的颜色**：**不能加第二个信号色**（信号色可以是红 / 橙 / 群青 / 绿，按题材选一个就锁死，`STYLE.md:28`）。禁止任何渐变、任何带明度过渡的填充、任何颗粒噪点。
- **同一画面最多几个色相**：**实际上是单色相**——墨黑 + 浅灰 + 纸白 + 唯一信号色。**任何时刻画面里最多出现一个彩色**。

## 4. 转场规则

- **镜头之间怎么切**：允许的转场只有四种——**划像（wipe）、刀切（knife cut）、相机运动、重排（re-flow）**；**绝不溶解**（`STYLE.md:63`、`lib/style-dna/swiss-motion.md:103`）。
- **有没有叠化 / 闪白 / 擦除 / 定格**：**没有叠化、没有淡入淡出**。入场**必须是划像或 clip 揭示，绝不是 fade**（`STYLE.md:42`）。两种本风格独有的「删减」转场：① **刀切**——一条 **2 px** 的线在 **1/16 音符**内穿过元素，然后元素在 **1/8 音符**内垂直塌缩到它的中线（`DEMO.md:48`）；② **重排**——涟漪按**到因的距离排序**，从最近的开始，每次两个单位、走在十六分音符上（`STYLE.md:44`、`DEMO.md:49`）。
- **硬切点怎么定**：**运动时值是音符时值**（120 BPM：1/8 = 0.25s、1/16 = 0.125s、1 拍 = 0.5s、1 小节 = 2.0s）。一次吸附**提前一个音符时值起步、落在拍点上**：`snap(t, t1, d=E8)`（`ease.js:18-21`）。★ **视觉起点必须落在整帧上**（24 fps 下 0.25s 的整数倍），落在帧之间的起点会闪烁（`STYLE.md:96`）。
- **转场时长与缓动**：**只有两种曲线**——吸附用精确缓动 `cubic-bezier(.7,0,.2,1)`；**线性**只用于正在被画出的线、播放头、以及那个**例外**。**没有过冲、没有弹簧、没有回弹**（`STYLE.md:40`）。样本关键时刻表：`circleIn=20.0 / pageOut=24.5 / fly0=24.5 / land=26.0 / reflow=26.125 / gridOff=27.5 / rot=30.0（旋转 1.5 拍）/ labels=30.5 / sweep=32.0 / wall=37.0 / cut=39.0 / home=40.0`（`film.js:19-23`）。
- **绝对不要的转场**：溶解 / 淡入淡出等 UI 式转场；任何元素的淡入；回弹 / 弹簧 / 过冲；无来由的运镜。★ 另外：**旋转与标注不能同时进行**（会读成噪音），必须「先旋转 1.5 拍 → 停住 → 网格线 → 标签 → 播放头 → 扫过」（`DEMO.md:103`）。

## 5. 字幕样式

| 项 | 值 |
|---|---|
| 字体 | 全片**一种字族**，OFL 新怪诞（样本 **Archivo** 可变字体，字重 400–800）；字幕与正文字族相同，只换字重与字号 |
| 字号（相对画面宽 / 高） | **字幕是版面的一部分，字号随构图变**：跨页镜头里第一句是 **30 px Medium 灰色导语**，其余是 **76 px Bold 陈述**；非规则句（`Perfect. And a little dull.`）用 Regular 字重。技术注释 **19 px Medium**，海报标题 **120 px Bold**（`DEMO.md:94-96`）。**派生通路**取类别默认 `fontSizeFactor: 0.03148`（36 px @1080 高，≈ 画面高 3.15% / 画面宽 1.77%） |
| 颜色 / 描边 / 阴影 | 字 `#111111`、描边 `#FFFFFF`（`subtitleOutline`）、`outlineFactor: 0`、`bold: true`；**无阴影、无底条**（`subtitleBack: #00000000`） |
| 位置 / 安全边距 | **坐在当前构图里某一列的起点**（跨页时 = 左页第 1 列；其他镜头 = 该镜头第 1 列、或作品标题基线、或海报墙下方像博物馆展签）。**派生通路**：`marginLFactor: 0.07037`、`marginVFactor: 0.16019`、`align: 1` |
| 单行字数上限 / 最多行数 | 口播单句实测 **9–45 字符**（最短 `Only one.` = 9，最长 `Same five rules. A different song every time.` = 45）。**一句一个规则**，>45 字符会盖过一个乐句 |
| 出现与消失方式 | **逐词 clip 揭示**（不是整行淡入）：每个词按 **whisper 词时间戳**从基线下方升起（1/16 音符）、向上翻走（1/8 音符）。停留 ≥ `max(1.8s, 语音时长 + 0.6s)`，**并在 `tools/subs.py` 里 assert**（`STYLE.md:35`、`DEMO.md:47`、`DEMO.md:94`） |

- **字幕与旁白的关系**：字幕是**旁白的版面化呈现**。旁白是一位冷静的设计讲师在念一套程序：**第二人称祈使 + 现在时、规则式短句**。Kokoro `af_sarah`，speed 1.0（它的 3–8 kHz 辅音能量约为 `af_kore` 的 7 倍，所以更清脆，`DEMO.md:74`）。样本 8 条行 + 1 条 `l5b`（`Only one.`），实测语音时长 0.792–2.786s。
- **本风格特有的字幕禁忌**：① **绝不做底部的字幕条**——那是别的风格（`STYLE.md:35`）；② 不能整行淡入，必须**逐词 clip 揭示**；③ 不能用第一人称抒情与内心独白；④ 不用网络口播腔、感叹号堆叠、营销话术；⑤ 不长复合句（一句一个规则）；⑥ **抽象概念不当主语**（只说能被排到网格上的东西）；⑦ 数字口播必须写进 `asr` 字段做校对（样本 `"asr": "Rule 1, …"`）。

## 6. BGM / 音效特征

- **配乐**：**Motorik / krautrock，120 BPM，A 多利亚**（不是通用钢琴弦乐铺底）。★ **每加一条规则就加一件乐器**，这本身就是一次清晰的 build：① 只有 hi-hat → ② + 全套 motorik 鼓组（`drum_kit`：kick 在 1、3、3&；snare 在 2、4；闭镲八分）→ ③ + `electric_bass` 八分根音脉冲 → ④ + numpy 锯齿琶音十六分（带开合滤波）→ ⑤ + `glockenspiel`（钟琴）被一个柔和 numpy 方波主音加倍（`DEMO.md:55-60`）。
- **★ 图与乐共享同一个数据文件**：`score.json`（`bpm / key / cols / midi / stiff / final`）——**列 → 音高、行 → 起点、长度 → 时值、`bleed` → 出血**。「海报就是乐谱」在代码里是真的，不是做出来的效果（`DEMO.md:63`、`score.json:22`）。样本实测扫过的 8 个起点与预期值误差 **0.04–3.31 ms**（出片日志 `sweep_onset_error_ms`），远小于「≤ 5 ms」的验收线。
- **拟音（foley）**：**跟印刷材料走，干、近、不加混响**——铅字 clack（金属瞬态 + 3.3 / 5.1 kHz 共振 + 木质托盘低频）、钢尺划线「嘶」、裁纸刀（带通扫频上升 + 金属 snick）、纸铺 / 纸滑、数字「咚」（每级一次）、条块吸附咔哒、红圆落地（**58 Hz 毡垫闷响**）。★ **那个例外是唯一会「唱」的元素**：一条跟随它位置的滑音（`STYLE.md:70-71`、`DEMO.md:64-73`）。
- **旁白处理**：人声压缩，**比音乐高 ≥ 6 dB**；音乐在人声下 **duck ≈ −10 dB**（demo 实际 `1 − 0.68·vad`，闪避包络**提前 80 ms 压下、释放 250 ms**）（`mix.py:89-96`）。
- **响度目标**：`−14 LUFS`。成片实测 **I: −14.0 LUFS / LRA 4.4 LU / Peak −1.3 dBFS**（ebur128），同一条链里 astats 印 **−1.334716 dBFS**（出片日志第 165-168 行）。★ 本风格走 **`core/render/mux.sh`**（不是 demo 副本），该脚本的 loudnorm TP 目标是 **−1.7**（比交付目标 −1.2 低 0.5 dB，是**留给 AAC 编码的余量**），判据改用同一条 `-af` 链里 astats 的 6 位小数读数（`core/render/mux.sh:5-11`）。
- **静音策略**：静默是「**一切在下拍上硬停**」，下一个吸附读起来就像一个事件（`STYLE.md:72`）。样本：**打破那一小节撤掉鼓组**（落位时回来）；揭示前加**一小节近乎无声**（贝斯踏板 + 四分音符滴答）；揭示期间只留 kick + bass + melody 让每个音都听得见。实测 `l5b`（Only one.）那一段拟音为 **−180.0**（完全静音），30–32s 段落 mix −29.3 dB（出片日志第 144、151 行）。

## 7. 素材偏好

- **需要什么素材**：① **布局系统**——画面网格（`film.js` 的 `FM/FG/FC/fx()`）+ 作品网格（`PW/PH/PMX/CW/RH/NC`）+ **「行列意味着什么」这个设计决定**；② **共享数据文件** `score.json`；③ 台词 `lines.json`（每条 `{id, t, text, asr?, voice, speed}`）；④ 调色板 `film.js` 的 `C`（page/paper/ink/red/grid/pgrid/bass/mute/col/wall）；⑤ 规则表 `RULES` 与 `NOTES`；⑥ 一种 OFL 新怪诞字体（多字重，**画前必须 `document.fonts.load`**）；⑦ 音效事件 `buildEvents()`。
- **不需要什么素材**：**不需要任何实拍、照片、贴图、视频素材**。整片由 Canvas2D 平面绘制。**也不要有任何质感素材**——无渐变贴图、无阴影、无粒子、无颗粒（`STYLE.md:19`）。
- **取景 / 质感 / 比例偏好**：条与块是**平面矩形**；同一单元的相邻格**合并成一条**，接缝处**多画 1 px**（抗锯齿会露细线，尤其旋转 / 缩放后）；海报比例 0.70（瑞士世界开本）；齐左、右不齐；大留白；一切在网格线上。★ **模块尺寸必须让元素有质量**——样本先试过 12 个半音列，条只有 43 px 宽，海报看起来像数据图表；改成 **7 列 × 91 px + 16 行 × 40 px** 才对（`DEMO.md:80`）。
- **可替代方案**（缺素材时怎么降级而不破风格）：① 缺 Archivo → 换任何 OFL 新怪诞（Inter / Schibsted Grotesk / Instrument Sans），但**绝不换 Helvetica / Akzidenz**，也**不能混用两个字族**；② 缺钟琴 / 贝斯音源 → 用合成音替代，但**「每加一条规则加一件乐器」的层次结构不能省**；③ 缺字体加载 → 必须先 `document.fonts.load` 再画，否则首帧会用回退字体导致宽度测量错误；④ 缺 whisper 词时 → 退化为整行 clip 揭示（**不能退化成淡入**）。

## 8. 镜头节奏

| 项 | 值 |
|---|---|
| 单镜时长 | 由关键时刻表定（`film.js:19-23`）；最长的锁死跨页镜头约 4–5s，打破镜头只占 1 小节（2.0s） |
| 全片时长 | **44.0s**（样本片，`film.js:5` 的 `DUR=44`）。文档给 **30–60s** 区间，情绪弧见 `DEMO.md:30` |
| 镜头数 | 8 个段落（开场锁死全画幅 → 建规则锁死跨页 ×4 → 打破 → 揭示旋转 → 尺度揭示海报墙 → 回到主角与片尾卡） |
| 信息投放节拍 | **120 BPM**：1 拍 = 0.5s、1/8 = 0.25s、1/16 = 0.125s、1 小节 = 2.0s（`ease.js:18`） |

- **加速 / 减速点**：**减速**在打破段（鼓组退出，全片唯一一次线性、不吸附的运动，中途还停一个八分音符「回头看一眼」）与揭示前的一小节近乎无声；**加速**在重排段（涟漪按距离、每次两个单位、走在十六分音符上）与海报墙拉远段。
- **动画节奏（关键）**：**平滑 24 fps，没有步进**——这个风格是**数字精确**，不是手作（`STYLE.md:46`）。大数字用 `steps(t, a, b, 4)` **分 4 级升起**（「一格一格」）；网格线**按十六分音符逐个长出**；网格线在打破段**延伸出页面**（系统比作品更大）。
- **留白与静音的位置**：开场 0–2s 几乎空页（只有一条红线和正在长出的网格，日志 `section_rms_dbfs "0-2": -60.8`）；30–32s 揭示前近乎无声（`-27.4` dB）；结尾 40–44s 回落到 −22.8 dB。
- **★ 那个例外**：一个元素**线性、不吸附**地打破网格——它**边飞边长大**，中途停一个八分音符，旁边的坐标读数从 `col 5.00 row 0.00 · on grid` 变成红色的 `off grid` 并出现非整数（甚至负数）的值（帧 f14 右侧可见红字 `off grid`，`DEMO.md:50`、`film.js:486-498`）。

## 10. 编排规则

- **内容文件字段契约**（`content_fields`）：布局系统 = 画面网格（`FM/FG/FC/fx()`）+ 作品网格（`PW/PH/PMX/CW/RH/NC`）+「行列意味着什么」；`score.json` 的 `bpm/key/cols/midi/stiff/final`；`lines.json` 每条 `{id, t, text, asr?, voice, speed}`（样本 8 行 `af_sarah`）；`film.js` 的 `C` 调色板与 `RULES` / `NOTES`；一种 OFL 新怪诞字体；`buildEvents()`（`lib/style-dna/swiss-motion.md:165-176`）。
- **事件词汇表**（`type` → 消费者，共 10 类）：`knife`（裁纸刀 / 刀切删元素）、`rule`（钢尺划线，网格线长出）、`clack` / `clackBig`（铅字 clack，文字落位 / 换字体）、`paper`（纸铺上）、`thunk`（大数字每级升起）、`slide`（纸面滑动 = 重排）、`snap`（条块吸附）、`thump`（红圆落地 / 进场）、`tick`（犹豫抖动 / 标签）、`swish`（旋转 / 拉远的呼啸）、`voice{id}`（人声，mix.py 从 `voices/<id>.wav` 读）。全部由 `film.js:502-532` 的 `ev.push` 产生，`core/render/events.mjs` 序列化成 `events.json`（本次 146 条）。
- **时间线契约**：`ease.js` 提供时间原语（`BPM/BEAT/E8/E16/BAR`、`cubicBezier`、`E`、`snap`、`lin`、`steps`、`track`）。`film.js` 导出 `W/H/DUR/C/fx/PW/PH/px/py/T`、`setScore/setWords/setLines`、`subs()`、`flight/circleState/posterMatrix`、`renderFilm(g, t, opt)`（`opt.nosub` 关字幕、`opt.poster` 出海报版片尾）、`buildEvents()`。`main.js` 加载字体、`score.json`、`lines.json` 与 whisper 词时（`tools/words.py`），暴露 `window.READY / window.render(t) / window.DUR / window.EV`。
- **新增画面元素怎么接入**：文本一律走 `font(g, weight, size, fam)`（≥90 px 自动 −2.2% 字距）+ `revealText(g, s, x, y, size, p, q)`（从基线下方 clip 揭示、向上翻走）；条块用 `rectOf(c, r, first, last, bar)` + `g.fillRect`（同单元相邻格多画 1 px 消除接缝）；网格线用 `gridState(t)` + `drawPosterGrid/drawGridExt`；机位用 `posterMatrix(t)`（由 `CAM = track([...])` 驱动）；吸附 / 线性 / 分级一律用 `ease.js` 的 `snap/lin/steps/track/E`。
- **换主题时要改哪些文件**：① `demo/score.json`（**先写它**——它同时是配乐与「海报即乐谱」的数据源：列 → 音高、行 → 起点、长度 → 时值、`bleed` 出血）；② `demo/film.js` 的布局系统与 `RULES` / `NOTES`（重写规则文本与注释）；③ `demo/film.js` 的 `C` 调色板（换信号色，**只换一个**）；④ `demo/lines.json`（重写旁白 + `asr` 数字校对字段）；⑤ `demo/voices/`（重新 TTS 声线）；⑥ `demo/film.js` 的 `T` 关键时刻表与 `CAM = track([...])`（重排镜头与拍点）；⑦ 字体族（换 OFL 新怪诞，**全片仍只能一种**）；⑧ `demo/music/score.py` 的乐器加层顺序。**不用改**：`ease.js` 的两种曲线与 `snap/steps/track` 原语、`film.js` 的 `revealText` / 刀切 / 涟漪 / 网格线生长算法。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里是**派生条目**（`derived: true`，`derivedFrom: palette@lib/dub-visual.json / category-default(caption-row) / contrast-rule(WCAG)`）。生效参数：`palette`（bg `#EAE9E5`、bg2 `#FFFFFF`、fg `#111111`、accent `#E30613`、subtitle `#111111`、subtitleOutline `#FFFFFF`、subtitleBack `#00000000`）、`bgRecipe`（gradient + `texture: none` + vignette 0.08）、`subtitle`（SimSun、`fontSizeFactor 0.03148`、`marginVFactor 0.16019`、`marginLFactor 0.07037`、`outlineFactor 0`、`bold: true`、`align: 1`）、`title.fontSizeFactor 0.12`、`overlay.chapterCards: false` / `accentRule: true` / `progressBar: true`、`motion.subtitleFadeIn: 0` / `chapterTransition: "cut"`。**★ 注意 `notes` 的诚实说明**：本条的**字幕字号与位置不是从 STYLE.md 抽的**——STYLE.md §4 只给了字幕**形态**（坐在某一列起点、逐词 clip 揭示）而**没给 px 值**，所以通路取的是**类别默认**（caption-row：36 px、下边距 173 px、左边距 86 px、描边 0 px）。字幕颜色由 WCAG 从底色 `#EAE9E5` 推得（亮底 → 深字）。`motion.subtitleFadeIn: 0` 是对的（本风格字幕**从不淡入**）。但 **`overlay.progressBar: true` 在 STYLE.md 里找不到对应依据**——本风格的「进度」是由网格线生长、小节计数器 `bar 04.3` 与播放头承载的，不是一个进度条。知识库更新时应优先用代码抽取值替换本条的派生值（`lib/dub-styles.json#swiss-motion.notes`）。

## 11. 当前短板与避坑要点

### 已知缺陷
- **9:16 曾不可用（★ 2026-10-04 已修，原记「架构级缺陷」）**：原记「无 `aspects` 声明，产品默认 9:16 导出会丢右侧 43.75%、右页（列 8–12 的海报 706×1008）整块被切，观众只看到左页」。**2026-10-04** 已改造 `styles/swiss-motion/demo/film.js`：导出 `NATIVE`、声明 `FILM_META.aspects = ['16:9','9:16']`（`film.js:27`），并把顶层几何全部移进 `layout(W,H)`（`film.js:246-258`）——12 列网格随帧宽拉伸、尺寸按紧轴 `S` 缩放、机位（含海报中心与缩放）随帧走。**16:9 逐字节未变**（`fx=fy=S=1` 时每个表达式退化成设计值）；9:16 实测跨页与海报墙都不再被切（见第 2 节子段）。
- **派生通路的字幕字号 / 位置不是从 STYLE.md 抽的**：STYLE.md §4 只给形态、未给 px，通路取的是**类别默认**（caption-row：36 px / 下边距 173 px / 左边距 86 px）。这不是「抽取」，是「套默认」，知识库更新时应优先替换。
- **派生通路 `overlay.progressBar: true` 无风格依据**：STYLE.md 里没有进度条这个元素；本风格的「进度」由网格线生长、小节计数器 `bar 04.3` 与播放头承载。
- **派生通路字体是 SimSun**（面向中文文案），与 demo 的 **Archivo** 不同。字幕几何一致，但气质差异明显——本风格「全片一种新怪诞」的骨架在中文通路里被换成了宋体。
- **派生条目是近似值**：`notes` 明说配色来自 `lib/dub-visual.json` 的 palette（demo 代码抽取），字幕颜色由 WCAG 推得。知识库更新时应优先用代码抽取值替换。
- **成片真峰值 −1.3 dBFS（astats −1.334716）**，相对交付上限 −1.2 dBTP 只余 0.13 dB 余量。本次**未触发告警**（阈值按 astats 6 位小数判定），但余量偏薄，后续加内容时容易越线。
- **配乐 `score.py` 输出 `dur: 44.5s` 而画面 44.0s**：音频比画面长 0.5s，由 `-shortest` 裁掉（`MUX_OK 4991543 src_frames=1056 out_frames=1056` 帧数一致）。这是设计如此，但换主题时要留意别让音频短于画面——那样才会触发 mux 的补静音分支。

### 素材缺口
- **必须自带 whisper 词时**：字幕是**逐词 clip 揭示**，依赖 `tools/words.py` 产出的词级时间戳。缺这一环就只能退化成整行揭示，风格的一半（「每个词落在它自己的时间上」）就没了。
- **字体必须随 demo 复制**：样本用 Archivo 可变字体（400–800 五个字重），缺字重会导致字重层级塌陷（19 px Medium / 76 px Bold / 120 px Bold 的对比就没了）。
- **拟音全部程序合成**：铅字 clack、钢尺划线、裁纸刀、纸铺、数字咚、条块吸附、58 Hz 毡垫闷响都是合成的，比真采样略薄；样本没有现成采样库。
- **海报墙的「其他作品」是同一套程序生成的变体**，没有独立的作品库——想要「一个程序很多产出」的尺度揭示，只能靠参数化生成。

### 能力限制
- **原生 16:9（已适配 9:16，见第 2 / 9 节）**；只能 Canvas2D（无 WebGL 需求，但也没有任何质感能力——这是风格要求）。
- **只能一个信号色**：任何多色品牌 / 多彩数据的题材都会被压成单色，这是硬约束不是缺陷。
- **禁止淡入**：所有入场必须是划像或 clip 揭示。这在工程上意味着**不能用透明度动画做入场**，对实现有真实约束。
- **视觉起点必须落在整帧上**（24 fps 下 0.25s 的整数倍），落在帧之间的起点会闪烁（`STYLE.md:96`）。
- 抽象概念不能当主语：内容必须能**被排到网格上**。

### 踩过的坑（本机实测）
- **12 列看起来像图表**：网格模块必须让图形元素**有质量**。样本先试过 12 个半音列，条只有 43 px 宽、海报像数据图表；改成 7 列 × 91 px + 16 行 × 40 px 才对（`DEMO.md:80`、`DEMO.md:101`）。
- **「更好」的构图并不明显更好**：四组小阶梯 → 一个散乱版面**说服力不够**。修法：**一条主对角线 + 长 / 短节奏、红元素放到约 2× 尺度、元素出血出纸边、字压红圆（黑压红）**——**仅仅把正确版面倾斜是不够的**（`DEMO.md:102`、`STYLE.md:91`）。
- **旋转揭示需要「停」**：旋转与标注同时进行读成噪音。顺序必须是「旋转（1.5 拍）→ 停住 → 网格线 → 标签 → 播放头 → 扫过」（`DEMO.md:103`）。
- **合并的条在旋转 / 缩放后露接缝**（相邻矩形的抗锯齿）→ 在格子相接处**多画 1 px**（`DEMO.md:104`）。
- **标签与页眉重叠** → 在旋转镜头前把 caption row 藏起来（`DEMO.md:105`）。
- **whisper 会拆词或并词**（「type face」），且 `asr_check` 会把第一个词报在 **−0.6s**（填充）→ 按**字母**对齐并把时间**钳到 0**（`tools/words.py`、`DEMO.md:106`）。
- **字幕停留规则（≥ 语音 + 0.6s 且 ≥ 1.8s）有两条差 2 ms 没过** → `tools/subs.py` 里**断言**它，靠微调起始时间修掉（`DEMO.md:107`）。
- **海报墙的切割必须跟着那条红线走**：在**屏幕空间**里从红线进入的那一侧开始收缩墙板（`DEMO.md:108`）。
- **墙上的其他海报与主画面共享相机矩阵** → 只在海报墙那一镜画它们，否则它们会以 ±786 px 的偏移**泄漏到其他镜头**里（`DEMO.md:109`、`STYLE.md:94`）。
- **Canvas 的 `letterSpacing` 也会影响 `measureText`** → 宽度必须在**设好字体之后**再算（`DEMO.md:110`、`STYLE.md:95`）。
- **开场那条红线的入场是划像不是淡入**——这是风格硬规则，实现时不要图省事用 alpha。
