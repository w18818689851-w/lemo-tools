## 1. 风格说明

**是什么**：给成年人看的 2D 电视动画——**会沸腾的均匀粗深色描边**、**平涂 + 硬边阴影块（无渐变）**、**大白眼 + 小瞳孔**、**有弹性的嘴**、又丑又可爱的生物，以及**被当成家里破烂用的科幻硬件**。喜剧是**对白驱动**的：像即兴的闲聊、抢话、尴尬停顿、反应镜头、不断升级，最后一个反转收尾。类型的引擎是「**一个极小的日常目标，用荒谬巨大的科幻手段去追**」——谁能解决任何事，就用它去干一件鸡毛蒜皮的事，然后有人为它付出情绪代价（`STYLE.md:6-8`）。

**不是什么**（最容易做错的邻居风格）：不是**给孩子看的卡通**（要冷幽默、长停顿、干笑点）；不是**日式动画**（不要闪亮的眼睛、不要华丽特效）；不是**矢量说明片**（线要 boil，绝不能是静态干净的矢量线）；也不是**中西部卡通**或**橡皮管**——那两类没有「一个世界一套配色 + 对白驱动的双人反差」这套骨架（`STYLE.md:10`）。

**什么时候用它**：内容里有一个**极小目标 + 荒谬手段**的落差、一对**反差搭档**（老手 vs 新人、AI vs 用户、家长 vs 青少年），或者一个可以**平行世界化**的选题（产品的各个版本、你本可以有的几段职业、同一座城的五个年代）（`STYLE.md:83-91`、`style.json#uses`）。

**一句话内核**：**笑点在两个反应的差里**——死鱼眼与惊慌各给一个反应镜头，荒谬图像之后必跟一个反应特写。

**边界**：撑不起**严肃纪实**内容（体裁天生在拆台）；**长段独白 / 书面解说**（对白必须短、必须能被抢话）；**细腻写实质感**（平涂 + 粗描边 + 12fps 步进）；**没有「日常小事 × 巨大手段」落差的纯抒情**内容（那更适合 `watercolor` / `ink-wash`）。

**版权红线（不可让步）**：绝不复刻任何既有作品的角色、剪影、配色组合、名字、口头禅、打嗝梗、logo，或某个传送枪的外观；自创卡司、道具与传送装置；**不要在片子里或文档里写出源类型的作品名**，一句「inspired by adult-swim-era sci-fi sitcom cartoons」足矣（`STYLE.md:12-14`）。

## 2. 画面构图

- **镜头数与画幅**：demo 57.5s / 8 个节拍（冷开场 → 传送门 + 片名 → 果冻宇宙 → 马克杯宇宙 → 三连蒙太奇 → 可疑地正常的宇宙 → 回家 + 冷场反转 → 片尾卡），全片 **1380 帧 @24fps**、原生 **1920×1080（16:9）**；**已适配 9:16**（`FILM_META.aspects = ['16:9','9:16']`，`film.js:20`）（`DEMO.md:19-28`、`style.json`）。
- **主体位置与占比**：**中景双人**是基本镜头——两位主角一左一右占画面下半，脸要大（大白眼是笑点的载体）；蒙太奇段落**每个世界用同一个取景**（搭档在左、生物在右），让「只有世界在变」（`DEMO.md:39`）。**极小的日常物件**（空咖啡壶、马克杯）在冷开场走**插入极端特写 + 慢推**，它的荒谬细节就是笑点本身。
- **负空间 / 留白**：留白由**平色带天空与大面积平涂墙**承担（天空是平色带，不是渐变，`toon.js:151-154`）；房间内部（实验室）用黑板、时钟、架子上的瓶罐 / 书填住背景，避免空。**底部约 170px 是字幕带，脸不许进**（`STYLE.md:40`）。
- **图层叠放顺序**（从底到顶）：平色带天空 / 背景墙 → 中景道具（柜台、黑板、家具）→ 生物 / 大物件 → 两位主角（`toon.js` 的矩阵栈，世界坐标搭建）→ 传送门（**全片唯一发光物**，带平半透明色 wash 罩住场景）→ 屏幕图形（VT323 世界标签，逐字打出）→ 字幕（说话人气泡 + 白字黑边）→ 片名卡 / 片尾卡（`worlds.js:17-56`、`main.js:370-441`）。
- **安全区**：字幕**底部居中**、说话人气泡在左；世界标签在**左上角**（`DIMENSION J-9 EVERYTHING IS JELLY` 那种 VT323 小牌）；**脸不进底部 170px**、世界标签不压脸；生物若被柜台 / 家具挡住，必须仍露出**脸和上半身**（demo 就把柜台后的生物往前挪过，`DEMO.md:94`）。
- **本风格不能出现的构图**：溶解 / 叠化；把脸放进字幕带；世界标签压到脸；**静态干净的矢量线**（线必须 boil）；把线宽随景别放大（线宽在屏幕空间恒定，近景是「重画」不是「放大」，`STYLE.md:18`）。

**在 9:16（产品默认）下的表现**：本风格**已适配 9:16**——`FILM_META.aspects = ['16:9','9:16']`（`film.js:20`），`main.js` 按**视口**调 `toon.js` 的 `setFrame(W,H)`（`toon.js:12`，导出 `FX/FY/S = min(fx,fy)`）重排版面：相机 `cam()` 把「设计帧 → 当前帧」的**等比装入**（`×S` + 居中偏移）折进变换（`film.js:48`），舞台世界坐标**不再**单独乘 `FX/FY`；屏幕空间的家什按轴拉伸 / 按紧轴缩放——说话人气泡 + 白字字幕（字号 `50*S`、底边 `H-92*FY`、描边 `11*S`，`film.js:412-438`）、世界标签（`70*FX / 62*FY`、线宽 `7*S`，`film.js:388`）、片名卡 / 片尾卡（`W/2 … 190*FY`、`×S`，`film.js:439-486`）、传送门 wipe 铺满 `W×H`（`film.js:379`）。1080×1920 实测（`S = 0.5625`）：**不裁切、无黑边**，整幅 1920×1080 设计帧等比落入画面中部，上下留边用**该世界的天空 / 地面色**填满（不是黑，`film.js:487`）；字幕与气泡完整在框内、贴底居中；蒙太奇段「搭档在左、生物在右」**两边都在**（不再丢生物）、中景双人的**右位角色不再被切**。16:9 逐字节未变（`FX=FY=S=1` 时每个表达式退化成它替换掉的那个数字，三帧 md5 与改造前完全一致）。

| 片尾卡底 | 深紫 + 暗化的传送门 | 收尾 | `DEMO.md:68` |

- **明度 / 对比规则**：**一个世界一套配色，3–5 色**，与上一个世界在**色相和明度上都尽量不同**，让观众**只靠颜色就能读出「我们跳了」**（`STYLE.md:29`）。**描边色与眼白永远不变**，其余一切可换；**辉光色只属于传送装置**，任何世界的其它东西都不许用它（`STYLE.md:30-31`）。
- **填充规则**：只有**平涂色**；阴影是**裁在填充内、朝背光侧的硬边深色块（每形体一块）**；辉光是 **1–2 圈平半透明环，不是渐变**；天空是平色带（`toon.js:117-130,151-154`）。
- **禁止出现的颜色 / 用法**：任何**渐变**（填充与天空都不许）；把辉光色用到非传送装置上；给不同世界复用同一套配色（会让「跳跃」读不出来）；「酸绿 + 黏液滴落 + 摇晃泡泡字」这套组合**在片名上要避开**——它读起来像某个特定作品（`STYLE.md:39`）。
- **同一画面最多几个色相**：**3–5 个**（该世界的整张调色板），另加永远在场的墨色描边与眼白。

## 4. 转场规则

- **镜头之间怎么切**：**硬切**是主力（对白剪辑、反应镜头、插入特写都靠硬切）；**世界之间走传送门的漩涡擦除**——冲向传送门 → 全屏漩涡 wipe（擦除瞬间闪一层**浅绿**）→ 下一个世界从漩涡里打开（`main.js:361-368`、`STYLE.md:63,70`）。demo 的 wipe 时刻：**12.85 / 20.9 / 28.4 / 29.4 / 30.4 / 31.4 / 36.05 秒**（`story.js:33`）。
- **有没有叠化 / 闪白 / 擦除 / 定格**：有**漩涡擦除**与**硬切**；有**甩镜**（两张脸之间，用于重叠的争吵 / double take）；有**对静止双人极慢推入**（冷场）；**没有溶解 / 叠化**（`STYLE.md:70`）。
- **硬切点怎么定**：时间挂在 **120 BPM** 上，**1 拍 = 0.5s**；**每个音乐 cue 的第一拍就是它的剪辑点**（`story.js:1-6,66`、`DEMO.md:45`）。三连蒙太奇是「两次慢的错误答案，然后**一秒一个世界、按拍切、同一个拒绝词**」——三段世界各只占 **1.0s**（`story.js:33`、`style-dna/scifi-toon.md:81`）。
- **转场时长与缓动**：传送门开门带**轻微过冲（~12%，back-ease ~0.3s）**；**弹性过冲要温和**——demo 用库里的 `spring` 时曾过冲到 **~135% 把演员吞掉**（`main.js:31`、`DEMO.md:93`）。wipe 本身走每帧平滑（24fps）。
- **绝对不要的转场**：**溶解 / 叠化**；把脸放进字幕带或让世界标签压到脸；用硬切音乐 cue 却**不切它的混响尾巴**（那就不是死寂，`STYLE.md:77`）。

## 5. 字幕样式

| 项 | 值 |
|---|---|
| 字体 | **Baloo 2 ExtraBold**（圆润重体无衬线，约 **50 px**）——让它看起来像卡通自己的字幕；世界标签用 **VT323**（复古终端）逐字打出；片名用 **Bungee**（厚重块字）；片尾卡风格名用终端字体（`STYLE.md:37`、`DEMO.md:62,67-68`） |
| 字号（相对画面宽 / 高） | 字幕 **~50 px**（1920×1080 上约 **2.6% 画面宽 / 4.6% 画面高**）；`dub` 条目 `fontSizeFactor 0.0463`（≈50px @1080 高）与此一致；片名 `dub` 给 `fontSizeFactor 0.09` |
| 颜色 / 描边 / 阴影 | **白字 + ~11 px 黑描边**，像卡通字幕本体；左侧带一枚**说话人气泡**，用该角色的颜色、**描边也会 boil**（`STYLE.md:37`、`main.js:401-419`） |
| 位置 / 安全边距 | **底部居中**；**脸不进底部约 170px**；世界标签在左上角、不压脸（`STYLE.md:40`） |
| 单行字数上限 / 最多行数 | 超过 **~1300 px** 自动**折成两行**；**重叠的台词会堆叠**，较旧的一条**变暗到约 70%**（`main.js:394-419`） |
| 出现与消失方式 | 旁白停留 **≥ max(1.8s, 语音 + 0.6s)**；快对白用 **max(audio + 0.35s, 0.9s + 字符数 / 17)**；在**世界切换处**与**静音拍之前**切断，让静音在**干净的画面上**演（`STYLE.md:38`、`main.js:385-392`） |

- **字幕与旁白的关系**：本风格几乎**没有旁白**，全是**对白**——两把声音一来一回，字幕跟着对白走，并带**说话人气泡**标明是谁在说。`.srt` 由 demo 自带 `srt.mjs` 从同一份 `story.js` / `lines.json` 数据导出（`DEMO.md:82`、`build.sh:12`）。
- **本风格特有的字幕禁忌**：不许长段独白 / 书面解说（对白要短、要能被抢话）；不许解释笑点（喜剧靠反应镜头，不靠字幕说明）；不许把脸放进字幕带；不许在字幕或片名里写出源类型的作品名。

## 6. BGM / 音效特征

- **配乐**：**全合成，不需要采样**——一条**特雷门琴**式主音（正弦 + 少量二三次谐波、连奏滑音约 **70 ms**、起音后约 **150 ms** 淡入颤音、弹簧混响）压在**模拟贝斯 + 方波琶音 + 复古鼓机**上；小调式与半音线条适合主主题（`STYLE.md:74`、`score.py:1-5`）。demo 主主题在 **D 小调**，半音下行 **D–A–B♭–A–E–F–E–E♭–D**；**120 BPM 让剪辑咬在半秒拍上**（`DEMO.md:45`）。
- **每世界一套类型 cue**：**一个宇宙一条动机，各是一条独立 cue，第一拍就是剪辑点**——果冻 = 弹跳大号 + 摇晃主音 + 滑哨；马克杯 = 刷子摇摆爵士 + 颤音琴；蒙太奇 = 四踩脉冲上的 **1 秒 stingers**；可疑地正常的世界 = 电梯 bossa（Karplus–Strong 尼龙弦）；释然 = 温暖 Rhodes + 特雷门「aah」；惊慌 = 上升颤音弦乐（`DEMO.md:46`、`STYLE.md:75`）。
- **拟音（foley，全合成）**：传送门系列（**开**：低频 boom + 下扫噪声 + 上升漩涡；**嗡鸣**；**关**：贴近的 fwump；每次擦除的**漩涡 whoosh**；suck）；pop / boing（吐出与落地）；生物系列 glorp / squish / wetblink；吸管 slurp、牙齿 chomp、鸽子 coo、商店铃、气泡 bloop、眨眼 blip、遥控 click-beep（`mix.py:34-85`、`DEMO.md:48`）。
- **旁白处理 / 配音**：**两把对比声音**——死鱼眼天才 = Kokoro `am_onyx`、speed **0.82–0.9**、轻度饱和 + **约 180 Hz 抬升**做沙哑；紧张者 Gary = Kokoro `am_eric`、speed **1.1–1.15**、存在感提升；生物 = Kokoro `af_sky` **升 +7 半音**说一两个词。人声走 **RMS 配平 + 压缩 + 短早反射（约 9–67 ms 五次抽头）**，让它落在同一个房间里（`DEMO.md:49`、`voice.py:25-29`、`mix.py:140-144`）。选角方法是**生成测试句、量中位 f0 与音高方差**（`DEMO.md:85`）。
- **响度目标**：**−14 LUFS**（母带），音乐在对话下**闪避约 −7 dB**（`mix.py:149-150`、`STYLE.md:79`）。本次成片 mux 实测 **I −14.0 LUFS / LRA 5.4 LU（`ebur128`）/ 真峰值 −1.59 dBTP（`loudnorm` `input_tp`，4× 过采样）**（`logs/scifi-toon.log:143-146`）。**交付真峰值上限**：`−1.2 dBTP`（项目级交付线；`STYLE.md` / `style-dna` 未给 dBTP 目标，`STYLE.md:79` 只写 master −14 LUFS）—— 真峰值在交付线内（余量 0.39 dB）、未削波。此前本节写的「Peak −1.6 dBFS」是 `ebur128` 的 1 位小数读数（口径不对），已改为 `input_tp` 口径；`astats` 采样峰值 −1.590988 是下界。
- **静音策略**：**静音就是包袱**——在**揭示处**（果冻宇宙的插入特写）和**冷场处**（「decaf」之后 **2s+**）**硬切音乐、连混响尾巴一起切**，只留房间底噪（日光灯嗡、钟表滴答、冰箱）（`STYLE.md:77`、`DEMO.md:47`）。**冷场要一块干净的画面**（`main.js:386`）。

## 7. 素材偏好

- **需要什么素材**：几乎**不需要外部素材**——所有画面都是 `toon.js` 矢量引擎用矩阵栈 + 形状原语在**世界坐标**里画出来的（`STYLE.md:107`）。要产出的是：**`story.js`**（唯一时间真值：`DUR` / `ANIM_FPS` / `q(t)` / `BEAT` / `VO{}` / `SHOTS[]` / `WIPES[]` / `TAGS[]` / `T{}` / `CUES[]`）；**`lines.json`**（`{id, who, text, sub?, voice, speed, pitch?, cut?, asr?}`）；**卡司**（用 `chars.js` 的参数化眼 / 嘴 / 手 + 面条肢体搭，每个主角一个荒谬服装点子）；**每个世界一个函数**（`worlds.js` 的 `xxxWorld(t, o)` + 3–5 色配色 + 可选生物 + 一条配乐 cue）；**传送门**（复用 `portal(cx,cy,r,t,{open,sx,spin})`）；字体 Baloo 2 / VT323 / Bungee（OFL）。
- **不需要什么素材**：不需要照片、实拍、3D 资产包、AI 生成图；不需要渐变 / 辉光滤镜（辉光是平半透明环，且只给传送门）；**绝不需要、也不许使用**参照作品的角色、剪影、配色组合、名字、口头禅、logo 或某个传送枪的外观（`STYLE.md:12-14`）。
- **取景 / 质感 / 比例偏好**：**描边屏幕空间恒定**（先变换到屏幕坐标再描边，`toon.js:131-134`）；**line boil**：每条轮廓按 ~7px 重采样、沿法向低频噪声位移幅度 ~**1.7px**、**12fps 在 3 张 boil 画间循环**；**一切都沸腾**，包括保持姿势与背景——**静帧永不死**（`toon.js:27-30,80-110`）。角色 **12fps（q = 拍两格）**，镜头 / 传送门 / 飞行道具 / 转场 **24fps**（`STYLE.md:44`）。
- **可替代方案**（缺素材时怎么降级而不破风格）：画不出原创卡司就**减少角色、复用同一套参数化脸与肢体**，但**绝不能**换成平滑插画或去掉 boil；没有 Baloo 2 就用**任何圆润重体无衬线 + 白字黑边**，但**绝不能**用衬线或细体；传送门画不出疙瘩边缘就**简化旋臂数**，但**绝不能**放弃「全片唯一发光物」这条约束；配乐做不出特雷门就用**任何正弦主音 + 滑音**，但**绝不能**换成有采样的现成音乐（会立刻破掉「合成、不需要采样」的口径）。

## 8. 镜头节奏

| 项 | 值 |
|---|---|
| 单镜时长 | 对白镜头 4–8s；果冻 / 马克杯跳跃各 6–8s；**三连蒙太奇每个世界只占 1.0s**；冷场 4–5s；回家段 12–16s；片尾卡 4–5s（`DEMO.md:19-28`） |

| 信息投放节拍 | 挂在 **120 BPM（1 拍 = 0.5s）** 上，**每个 cue 的第一拍就是剪辑点**；世界切换点 WIPES = 12.85 / 20.9 / 28.4 / 29.4 / 30.4 / 31.4 / 36.05 秒 |

- **表演细节（本风格的「运动」其实是「表演」）**：保持姿势做小变化（**眼皮抽动、瞳孔滑动、咽口水、汗珠**）；空闲生命 = 呼吸（**±1% 挤压**）+ 由说话响度驱动的点头；每个手势前有**预备**；落地有**衰减余弦挤压（~22%）**、飞出门时**拉伸**、「被吸进」= 朝门心缩放同时拉伸；口型由音频驱动（**RMS 张开 + 频谱质心宽窄，24 Hz** 采样到 12fps 绘制时刻，尖叫夸张到 **嘴 ×1.5–1.9**）；**神经质抖动** = 12fps 的 **3–6 px** 随机偏移 + 发抖瞳孔，幅度随惊慌增长（`STYLE.md:45-50`、`main.js:15-74`）。

## 10. 编排规则

- **内容文件字段契约**：**`story.js` 是唯一时间真值**，导出——`DUR`（57.5）/ `ANIM_FPS`（12）/ `q(t)`（拍两格）/ `BEAT`（0.5）；`VO{}`（`{id: 秒}` 对白起点）；`SHOTS[]`（`[起, 止, 名, 宇宙]` 镜头表）；`WIPES[]`（`[tc, 半宽]` 传送门擦除）；`TAGS[]`（`[起, 止, 编号, 描述, 底色, 字色]` 世界标签）；`T{}`（关键时刻）；`CUES[]`（配乐 cue，`t0` = 第一拍）。另有 `lines.json`：`{id, who, text, sub?, voice, speed, pitch?, cut?, asr?}`。**画面、字幕、拟音、配乐 cue 全从 `story.js` 导出，改时间只改这一处**（`style-dna/scifi-toon.json#asset_contract`、`DEMO.md:81`）。
- **事件词汇表**（`events()` → `mix.py` / `score.py`，本次导出 **112 条**）：`vo{id}` / `cue{...}`（人声 / 配乐 cue）；`amb{w,d}`（世界环境床 lab / jelly / mug / normal / teeth / pigeon / vasks）；`plip` / `squeak` / `tic` / `gulp` / `cloth` / `click`（小动作音）；`portalOpen` / `portalHum{d}` / `portalClose` / `portalWhoosh` / `suck` / `whooshBig`（传送门系列）；`pop` / `boing` / `slam` / `thud`（弹 / 弹跳 / 摔 / 闷响）；`gurgle` / `glorp` / `slide` / `squish` / `wetblink` / `slurp{d}`（湿滑系列）；`page` / `lick` / `chomp` / `coo` / `swish`；`shopbell` / `cupSet` / `bloop` / `blip` / `wheee{d}` / `gulpPortal` / `tOpen`（`main.js:474-513`）。
- **时间线契约**：页面契约暴露 `window.render(t)` / `window.DUR` / `window.EV` / `window.SUBS`；**字体在 render 前预载**（`main.js:515-516`）。字幕在 `WORLD_CUTS` 处与**静音拍之前**切断（`main.js:386-390`）；折行阈值 1300px（`main.js:394-400`）。
- **新增主体怎么接入**：**新增一个角色** = 用 `toon.js` 的矩阵栈 + 形状原语在**世界坐标**里搭，脸用 `chars.js` 的 `eye` / `mouth` / `hand`，肢体用 `noodle`，描边自动走屏幕空间 boil 并保持恒定线宽；**新增一个世界** = 在 `worlds.js` 加一个 `export function xxxWorld(t, o)`，给它一套 3–5 色配色（与上一个世界在**色相和明度上都尽量不同**）、一个可选生物、一个配乐 cue；**新增一个传送门** = 复用 `worlds.js` 的 `portal(cx,cy,r,t,{open,sx,spin})`（`style-dna/scifi-toon.md:184-188`）。
- **换主题时要改哪些文件**：**改 3 组**——(1) `story.js`（`DUR` / `VO` / `SHOTS` / `WIPES` / `TAGS` / `T` / `CUES`）与 `lines.json`（对白脚本）；(2) 卡司与道具（`chars.js` 的 `PAL` 与角色骨架、`worlds.js` 的每个世界函数与生物）；(3) `music/score.py` 的动机与各世界 cue（它读 `story.js` 的 `CUES`，所以**改世界数 / 改 BPM 都会自动跟着走**）。`toon.js`（矢量引擎 / boil / 恒定线宽）/ `voice.py` / `asr.py` / `mix.py` 的**引擎层不动**——这是本风格最关键的复用机制：**换故事、卡司、世界与配色，渲染引擎与声音管线不变**。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里是 `derived:true` 条目，`derivedFrom:["palette@lib/dub-visual.json","subtitle-px@STYLE.md §4","contrast-rule(WCAG)"]`。**能生效的参数**：`palette`（bg `#f4f1ea`、bg2 `#e8f0e0`、fg `#3a3340`、accent `#e8392b`、subtitle `#3a3340`、subtitleOutline `#FFFFFF`、subtitleBack `#00000000`）、`bgRecipe`（type **gradient**、stops `#f4f1ea→#e8f0e0`、texture **paper**、vignette 0.08）、`subtitle`（fontFamily **DengXian**、fontSizeFactor 0.0463、marginVFactor 0.14537、marginLFactor 0.06019、outlineFactor **0.01019**、bold **true**、align 2）、`title`（fontSizeFactor 0.09）、`overlay`（**chapterCards false**，其余 false）、`motion`（subtitleFadeIn 0、chapterTransition **cut**）。⚠ 该条目**无法承载本风格最核心的「一个世界一套配色」**，且字体与描边口径与 `STYLE.md §4` 不一致，详见第 11 节。

## 11. 当前短板与避坑要点

### 已知缺陷
- **★ `demo/mix.py` 的 `nz(d)` 与 `core/audio/sfx.py` 的 `t_(d)` 取整口径不一致，曾让整条音频链挂掉、本风格一直出不了片**：`mix.py` 的 `nz(d)` 原写作 `int(d * SR)`（**截断**），而 `sfx.py` 的 `t_(d)` 用 `int(round(d * SR))`（**四舍五入**）——当 `d*SR` 的小数部分 ≥ .5 时两者差 **1 个样本**，`portal_hum()` 直接抛
  `ValueError: operands could not be broadcast together with shapes (158400,) (158399,)`，`mix.py` 崩掉、音频链整条挂掉（编排器注释里登记为「demo 自身 bug」）。**2026-10-03 已把 `nz` 改成 `rng.standard_normal(len(t_(d)))`（按 `t_` 的实际长度取，长度从此按构造保证一致）**（现源码 `mix.py:20` 带注释「与 t_() 同长度（按构造保证）」、`sfx.py:9` 带注释「与 noise() 同样取整，避免长度差 1 相乘报错」）。本次出片是该修复**之后**的成功运行——日志显示 TTS 2/2、`voice.py`、`score.py`、`mix.py`（`MIX_OK 11040044`）全部跑通（`logs/scifi-toon.log:32-134`）。**教训**：跨模块合成音频时，长度必须**按同一个取整口径**构造（更稳的做法是直接按目标数组长度取，而不是各自 `int(d*SR)`）。
- **`.srt` 未在本次重新生成**：混流阶段明确告警「本 demo 没有本次新生成的字幕源 —— `.srt` 沿用仓库里已提交的旧文件，未重新生成」（`logs/scifi-toon.log:29-30,140`）。虽然 `demo/srt.mjs` 存在，但本次成片里的字幕轨**用的是仓库旧 `.srt`**，与本次画面 / 对白是否逐字对齐**未经验证**。

### 素材缺口
- **每个世界都要为新主题重画**：`worlds.js` 的每个 `xxxWorld()` + 它的 3–5 色配色 + 生物，是人力最重的一块；卡司的 `chars.js` 骨架（`vask` / `gary`）也要为新角色重写。
- **字体只有 demo 那一套**：Baloo 2 ExtraBold（字幕）、VT323（世界标签）、Bungee（片名），`fonts/` 下为 OFL 子集；没有第二套字面，也没有粗 / 斜变体。
- **配乐只有 demo 那一套 cue**：`music/score.py` 的动机与各世界类型 cue（大号 / 摇摆爵士 / bossa / 特雷门）是为这个题材写的；换主题要重写动机，且必须保证「一个世界一条 cue、第一拍是剪辑点」这个结构约束。

### 能力限制
- 平涂 + 粗描边 + 12fps 步进，**做不了写实质感**；细腻表情只能靠参数化的眼 / 嘴 / 眉与「表演细节」（眼皮抽动、瞳孔滑动、汗珠）。
- 体裁天生在**拆台**，做不了严肃纪实或庄重抒情。
- 对白必须短、必须能被抢话，**做不了长段独白或书面解说**。
- 生物必须**非语言**（只用音效），否则片子就不再是两位主角的对白。
