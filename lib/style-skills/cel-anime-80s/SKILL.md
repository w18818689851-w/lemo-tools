## 1. 风格说明

**是什么**：**四层叠出来的画面，缺一层就不像**（`STYLE.md:8-12`）——①**喷枪柔边背景**（加载时一次画好：天空渐变、喷枪云、带绘制光源的建筑，并配一张随色版滑动的**发光版**，之后只做平移）；②**赛璐璐 cel**（角色 / 载具 / 道具：平涂 + **硬边**阴影月牙 + **硬边**高光月牙 + **彩色**描线，绝不纯黑，以 12 或 8 fps 步进）；③**光**（背光 `透過光`：招牌、灯、片名字母**透过**画面发光，光斑与 halation）；④**播放**（一盘 80 年代末录像带在显像管电视上：色度渗色、扫描线、RGB 光栅、荧光辉光、四角压暗、淡噪声）。

**不是什么**（最容易做错的邻居风格）：不是**现代数字动画**（圆眼大虹膜、网格腮红）；不是**矢量剪贴画**（等宽黑线、形状内渐变）；不是**胶片拷贝的仿作**（没有片门抖动、灰尘、划痕、套色错位——**这是磁带不是胶片**，`STYLE.md:14`、`DEMO.md:51`）。

**什么时候用它**：适合 MV、游戏预告、怀旧题材、城市夜景/竞速/追逐叙事、伪片头字幕。`style.json:11-15` 给的适用面是 Music videos / Game trailers / Nostalgia。

**一句话内核**：**巨大的手绘世界里的小个子平涂英雄**——用多层景片与光带扫过制造运动，在峰值处敢于**冻结**成一张手绘静止画（`STYLE.md:81`、`STYLE.md:45`）。

**边界**：这个风格**撑不起**纪录片式解说（它是**对白驱动**，不是旁白）、长句与书面语、抽象概念主题、以及任何需要「清晰可读的图表/数据」的内容。它也没有现代动画的萌系表情——脸是 80 年代的正剧脸（`STYLE.md:20`）。

## 2. 画面构图

- **镜头数与画幅**：样片 59.0s / **1416 帧 @24fps**，`story.js` 的 `SHOTS`（`[起,止,名]`）逐镜切分，所有剪辑点**对齐 116 BPM 的小节**（1 拍 = 0.5172s、1 小节 = 2.069s，`style-dna/cel-anime-80s.md:72`）。画幅按 `STYLE.md:26` 是**完整 16:9 剧场比例**（4:3 pillarbox 也合法，作为 OVA 观感）。
- **主体位置与占比**：偏爱**剪影、背光与速度语法**。多层景片升降越过一张高景片时，前景层动得更快（视差）；侧向跟拍用 **3–4 层视差**；后视驶入**伪 3D 峡谷**（`STYLE.md:55-57`）。cel 必须在景片上**读得清**（`style-dna/cel-anime-80s.md:110`）。
- **负空间 / 留白**：**画面下方约 120 px 必须留空**给字幕（`STYLE.md:67`）。大特写时靠**背光/风挡/护目镜**遮住最难画的正脸——样片把骑手正面藏在茶色风挡后，只露护目镜与头发，让头灯光斑撑住镜头（`DEMO.md:33`）。
- **图层叠放顺序**（从底到顶）：背景色版（柔边喷枪）→ 背景发光版（滑动）→ 湿地面反射（色版的翻转模糊拉丝版）→ cel 层（平涂 + 硬边阴影/高光 + 轮廓光 + 彩线）→ 光斑/速度线/雨等 fx → **CRT 后期（泛光/调色/字幕/扫描线/光栅/压暗）**（`STYLE.md:18-26`）。
- **本风格**不能**出现的构图**：cel 在景片上看不清；占掉下方约 120 px 字幕区；用**真的三维运动**代替多层景片与光带（`style-dna/cel-anime-80s.md:110`）；正面全脸大特写（最难画，能躲就躲）。

**★ 2026-10-04：已支持多比例（页面外壳等比装入）**。本风格是**最不适合逐处改写**的一类——17 文件 / 2438 行、逐镜**绝对坐标** + 多层景片视差 + WebGL2 CRT 多 pass，漏改一处**静默错位**。所以改造**只碰一个页面外壳文件** `demo/index.html`：影片本体仍按**固定设计帧 1920×1080** 画（一字未改），当前帧（= 渲染视口）不是 1920×1080 时，把**整张设计帧等比装入**（contain）并居中，留边露出页面底色 `#1f2446`（`dub-styles.json#cel-anime-80s` 的 `palette.bg`，夜景靛蓝——本片 CRT 底色是深蓝紫，用**深色**留边而不是纯黑）。声明在 `demo/film.js`（`FILM_META.aspects`，控制台按源码文本探测）。`FILM_META.aspects = ['16:9','9:16','3:4','4:3','1:1']`。★ **只包唯一的上屏画布 `#gl`**；离屏画布由 `cel.js` 的 `document.createElement('canvas')` 造、从不入 DOM，外壳碰不到它们。

- **16:9 逐字节不变**：1920×1080 时外壳**完全不碰 DOM**（不建包装层、不设 transform、不改底色）。实测改造前 vs 改造后 3 帧 **md5 逐字节相同**；**同会话往返**（1920×1080 → 1080×1920 → 1920×1080）亦 **md5 逐字节相同**（CRT 多 pass **未**引入时间相关状态）。**证据强度：最强（跨进程 + 同会话往返都逐字节一致）。**
- **9:16 不裁切**：整幅画面（多层景片、速度线、CRT 四角压暗）与底部对讲字幕**全部在画面内**（实测：改后 9:16 vs 16:9 中心裁切 SSIM **0.51–0.76**，vs 理想等比装入 SSIM **0.945–0.985**）。**字幕不再落在黑边上**——它随设计帧一起缩放，仍在画面内。
- **已知代价**：① 竖屏下有效画面只占 **1080×607**，景片视差与侧向跟拍的速度感按紧轴缩到 **0.5625×**（构图未重排成竖版）；② **CRT 扫描线 / 色度渗色 / 四角压暗是「设计帧内」的全屏层，不进上下留边**——实测留边 **YMIN = YMAX = 38（`#1f2446`，完全平的深靛蓝，无扫描线）**，画面内 YMIN 4 / YMAX 198（扫描线在）；③ 其它比例同理（3:4 / 4:3 / 1:1 已声明）。
- **没有做的**：这是**等比装入**，不是**重排**——景片横向布局、字幕安全区（距底 96 px）与 CRT 四角压暗都没有按竖屏口径重算（见第 11 节）。

- **色指定（色指定 = colour model）规则**：以**白天标准色**为基准，按 lit / shadow / line **分别乘色**推出其他套；另有**背光剪影套**（暗紫 + 暖轮廓光）。样片实测乘子：夜景 lit ×[.78,.74,1.0]、shadow ×[.58,.52,.92]；黎明 lit ×[1.04,.9,.84]（`DEMO.md:48`、`pal.js:35-41`）。
- **明度 / 对比规则**：**背景带渐变与空气感，cel 是平涂、少色、高饱和**——对比就来自这四层的差异（`STYLE.md:30`）。**皮肤每套色指定单独给色**，否则把白天皮肤乘一层色会让脸在霓虹下发粉（`STYLE.md:32`）。
- **禁止出现的颜色**：**纯黑描线**（描线一律是填充色的深版本：皮肤暖深棕、头发深紫，**只有硬道具近黑**，`STYLE.md:18`）；cel 形状内部**不许有渐变**（唯一例外：峰值处一张 harmony 手绘静止画，`STYLE.md:18`）；**不许用品牌名或真实作品的招牌**（招牌只用通用词：BAR / CAFE / 喫茶 / ホテル / カラオケ，`DEMO.md:49`）。
- **同一画面最多几个色相**：夜景 5 个（靛蓝/深紫/洋红/青/窗金）为上限；cel 本身只占其中 2–3 个 + 主角强调色 1 个。

## 4. 转场规则

- **镜头之间怎么切**：**在强拍（小节）上硬切**，所有剪辑点对齐 116 BPM 网格（`style-dna/cel-anime-80s.md:72`）。
- **有没有叠化 / 闪白 / 擦除 / 定格**：**没有数字溶解或划像**（`STYLE.md:67`）。允许的转场**必须来自媒介本身**：①强拍硬切；②**白闪**；③**冲击帧**（2 帧反转或单色剪影叠在辐射线上，然后给结果，`STYLE.md:45`）；④在**与磁带相关的拍点**上用**跟踪噪声**（几帧撕裂、滚动带、垂直跳，`STYLE.md:26`）。另有两个可选的磁带点缀：**开机亮线**（点 → 线 → 画面）与**跟踪噪声**（`STYLE.md:26`）。
- **硬切点怎么定**：挂在 **116 BPM、4/4 的小节网格**上。样片关键时刻：eyesOpen 7.75s / 片名 bar(5)=10.345s / 报警 bar(13)=26.90s / 全静音 cutout bar(15)+3 拍=32.59s / 跳跃 bar(16)=33.10s / 落地 bar(18)=37.24s / 按 PLAY bar(21)+0.5 拍 / 发射上摇 bar(22)=45.52s / 片尾 bar(26)=53.79s（`style-dna/cel-anime-80s.md:78`）。
- **转场时长与缓动**：硬切 0 帧；白闪与冲击帧各 2 帧；跟踪噪声几帧。**峰值用「一拍冻结」**——辐射速度线 → 一拍冻结 + 白闪 → 冲击帧 → 手绘静止画慢摇 → 冲击帧 → 落地（`DEMO.md:28`）。
- **绝对不要的转场**：数字溶解 / 划像（`style-dna/cel-anime-80s.md:110`）；胶片式瑕疵（片门抖动、灰尘、划痕、套色错位）——**与「磁带」设定矛盾**（`style-dna/cel-anime-80s.md:161`）。

## 5. 字幕样式

| 项 | 值 |
|---|---|
| 字体 | **Barlow Semi Condensed 600**（半窄无衬线）；片名另用 **Dela Gothic One** 写片假名行、**Kanit** 写 tagline（均 OFL，`DEMO.md:63`） |
| 字号（相对画面宽 / 高） | **54 px**（1080p 下；归一化约画面宽 2.81%）；片名字号更大、斜体 chrome |
| 颜色 / 描边 / 阴影 | 普通句 **奶黄 `#fff0a0`** + **9 px 深描边** + 柔阴影；**对讲句青色 `#8ff4ff`** + 方框 `● BASE` 标签 |
| 位置 / 安全边距 | 距画面**底边 96 px**；画面下方约 120 px 必须留空 |
| 单行字数上限 / 最多行数 | 单行；样片单句 **17–41 字符**（约 3–8 英文词） |
| 出现与消失方式 | 停留 ≥ max(语音 + 0.6s, **1.9s**)；下一句出现时上一句**让位**（`hud.js:4-8`） |

- **字幕与旁白的关系**：字幕是**录在带子上**的——在调色之后、**CRT 管线内**合成，所以字幕本身也带扫描线与色度渗色（`STYLE.md:26`、`STYLE.md:37`）。**两个说话人用两种颜色区分**：少女 `af_bella` 用奶黄，无线电调度员 `am_michael` 用青色 + `● BASE` 方框标签（`DEMO.md:57`）。
- **本风格特有的字幕禁忌**：①不许把字幕排除在 CRT 后期之外（会像贴上去的现代字幕）；②不许占掉下方约 120 px 安全区以外的构图空间（cel 会读不清）；③不许用旁白式解说文案——这是**两人对话**，信息密度低、口语、有来回（`style-dna/cel-anime-80s.md:48-51`）。

## 6. BGM / 音效特征

- **配乐**：原创 **city pop / 合成器放克 / 动画片头流行**，numpy 合成（`music/score.py`）。**116 BPM、E♭ 大调**，maj7 / 9 度和声，J-pop「王道进行」**IVM7–V7–iii7–vi7**；音色：FM 电钢琴（DX7 式 1:1 载波 + 14:1 钟形瞬态）、slap 贝斯（拇指 + 八度 pop）、门限混响军鼓、合成铜管 stab、合唱 16 分吉他切音、弦乐垫、可唱的 lead hook、FM 钟闪烁；**最后一段副歌升半音**（`DEMO.md:37`）。
- **配乐与画面的结构耦合**：配乐**逐段对齐 `story.js` 的镜头**——冷开场下的前奏、给引擎轰油留的 fill bar、片名落在**铜管重音**上、蒙太奇下的主歌、预副歌 build、**跳跃前一拍真静音**、手绘静止画上的副歌、落地的重音、片尾卡上的终止和弦。**卡带化（diegetic twist）**：舱内磁带播放时配乐被**带通成卡带音质**一小节，随后随升调打开到全频（`DEMO.md:39`）。
- **拟音（foley，全部合成）**：引擎按**转速曲线**合成（谐波锯齿堆叠 + 点火抖动 + 带通排气脉冲，**腾空时低通变远**）、雨底 + 随机雨滴、湿路胎噪、风、吊桥警铃、对讲机 squelch、撞击闷响、金属刮擦 + 火花、磁带咔哒、按键 + 马达、火箭点火与轰鸣；**磁带点缀有自己的闷响 / 嗡声 / 嘶声**（`DEMO.md:41`、`mix.py:23-57`）。
- **旁白处理**：**英配动画感**的短句，两个说话人（`af_bella` 少女 / `am_michael` 调度员）。调度员走**带通 380–2800 Hz + 饱和 + squelch**（`mix.py:111-124`）。混音：**先限幅再压缩 TTS**；人声按 RMS 比闪避后的音乐高约 **10 dB**（音乐 duck ~9 dB ≈ −0.64 线性），引擎与环境再让 **3 dB**（duck2 ~−0.3），**副歌比前奏响 4–6 dB**（`style-dna/cel-anime-80s.md:140`）。
- **响度目标**：`−14 LUFS`（两遍 loudnorm，`linear=true`，`DEMO.md:88`）。本次成片实测 `mix peak 0.97 / rms −13.08 dB`（`logs/cel-anime-80s.log:84`）；成片 mux 步骤只输出 `MUX_OK`、**未打印 I / LRA / Peak**（`logs:118`），故出片时无法在管线内自证。**2026-10-03 离线复测（`loudnorm`）**：成片 **I = −14.08 LUFS / LRA 4.10 LU / 真峰值 −3.12 dBTP**（判据 = `input_tp`，4× 过采样）——相对 −14 LUFS 目标偏 **0.08 LU**、真峰值**远低于 −1.2 dBTP 交付线、未削波**，即**响度目标实测达标**。音频链在本次运行中**真实跑过**：TTS 产出 8 行配音（d1 2.749s … g4 1.368s，`logs:37-50`）、ASR 校对 8/8 OK、`score.py` 出 116 BPM 配乐、`mix.py` 出 `MIX_OK`（`logs:36-106`）。
- **静音策略**：**真正的静音用在最大变化之前**——`cutout`（bar15 第 4 拍 → bar16）**全静音一拍 + 白闪**，紧接冲击帧与副歌；那一拍真空让跳跃读起来更狠。**静默里保留环境（雨/引擎），只把音乐撤掉**（`style-dna/cel-anime-80s.md:84`）。实测 section RMS：intro −15.5 / title −11.2 / verse −13.6 / **cutout −19.9** / chorus −11.5 / lofi −14.1 / keych −11.2 / end −16.2 dB（`logs/cel-anime-80s.log:98-105`）。

## 7. 素材偏好

- **需要什么素材**：不需要任何实拍或现成素材——**全部由代码生成**（numpy、Canvas 2D、WebGL；无采样、无素材图，`DEMO.md:61`）。需要的是：①**喷枪柔边背景景片**（每个场景一张色版 + 一张配套**发光版**，加载时一次画好）；②用 `cel.js` 原语画出的 **cel 主体**（角色 / 载具 / 道具）；③一套**色指定**（白天标准色 + 夜景 / 黎明 / 背光剪影的乘子）；④一张**人设表（model sheet）**——先建先审，之后每一镜都从**同一个头部函数**画（`STYLE.md:20`）；⑤**8 行短台词**（两人对话）。
- **不需要什么素材**：不需要照片、实拍、3D 模型、贴图；不需要胶片颗粒 / 片门抖动 / 划痕（与磁带设定冲突）；不需要品牌招牌。
- **取景 / 质感 / 比例偏好**：质感来自**四层对比**——背景柔边渐变 vs cel 硬边平涂；描线 2–3 px（1080p），**大特写缩到 0.45–0.8×**；cel 内部**无渐变**。**湿地面** = 色版的翻转 + 模糊 + 拉丝 + 波纹带，再用波纹带压暗。移动景片加约 **16 px 横向拖影**以抗频闪（`STYLE.md:22`）。
- **可替代方案**（缺素材时怎么降级而不破风格）：缺复杂背景时，用**更少的景片层**（2 层而非 4 层）但仍保留「喷枪柔边 + 发光版」这一对——四层的**对比关系**比层数重要。缺人设表时，至少保证**每一镜从同一头部函数画**，否则脸会飘。缺合成音源时用 FM 合成替代，但**保留 116 BPM 网格、maj7/9 和声与「卡带化」手法**。

## 8. 镜头节奏

| 项 | 值 |
|---|---|
| 单镜时长 | 无固定值；由 `story.js` 的 `SHOTS` 决定，切点对齐 116 BPM 小节（1 小节 = 2.069s） |
| 全片时长 | **59.0s**（`style.json` 记 dur 59.0；`DUR = 59.0s`，1416 帧 @24fps） |
| 镜头数 | 样片约 11 段：冷开场升降 → 物件插入 → 决心大特写 → 片名 → 动势蒙太奇（4 镜）→ 障碍（2 镜）→ 峰值（5 步）→ 黎明释放 → 交接 → 尾声 → 片尾卡（`DEMO.md:20-31`） |
| 信息投放节拍 | 挂在 **116 BPM、4/4**：1 拍 = 0.5172s、1 小节 = 2.069s（`style-dna/cel-anime-80s.md:72`） |

- **动画步进（本风格最核心的节奏规则）**：**角色「拍两格」= 12 fps**；**表演（眨眼 / 睁眼 / 口型 / 手势）「拍三格」= 8 fps**；**镜头 / 光扫 / 光斑 / 雨「拍一格」= 24 fps**（`STYLE.md:42`）。**绝不要把镜头也做成 12 fps 步进**——会读成抖动（`style-dna/cel-anime-80s.md:166`）。
- **循环与减速点**：头发与布料是**旅行正弦驱动的飘带**，**4 张一循环**（平静时 6 张）；弹跳 = 12 fps 的几像素抖动（`STYLE.md:43`）。**移动光而不是画**：彩色光带以 `source-atop` 扫过静止的 cel（`STYLE.md:44`）。
- **留白与静音的位置**：**峰值冻结**——一张手绘静止画 + 慢摇，只有循环在动（`STYLE.md:46`）；跳跃前**一拍真静音**（`cutout` 段 −19.9 dB，`logs:101`）；快眨眼只用一个 8 fps 的闭眼画；睁眼三张画；口型 3–4 个形状 @8 fps，落在**保持的表情**上（`STYLE.md:47`）。

## 10. 编排规则

- **内容文件字段契约**：本风格**没有单独的内容 JSON**——台词由 `story.js` 的 **`VO` 数组**驱动（`style-dna/cel-anime-80s.md:175-183`）。字段：`id`（如 `d1`..`d4`、`g1`..`g4`）、`t`（出现时刻，秒）、`who`（`'D'` = 调度员走无线电 / 青色 + BASE 标签；`'G'` = 少女）、`text`（单行台词，实测 17–41 字符、全片 8 行）。语音时长由 `voices/dur.json` 提供（缺省回退 = 文本长度 × 0.07）。时间点、镜头表、片尾署名都在 `story.js`。
- **事件词汇表**：`main.js` 的 `events()` 产出，`type` 有 `squelch`/`tapeclick`/`rev{v}`/`crton`/`launch`/`whoosh{v}`/`spray{d}`/`bell{v}`/`clunk`/`twist`/`impact`/`wind{d}`/`land`/`scrape{d}`/`grab`/`button`/`tapenoise{d}`/`motor{d}`/`ignite`/`roar{d}`/`vo{id}`（完整表见 `style-dna/cel-anime-80s.md:205-227`）；`vo{id}` 里 `d*` 走 radio 滤波。
- **时间线契约**：`story.js` 导出 `BPM`(116) / `BEAT` / `BAR` / `bar(n)` / `beat(n)` / `DUR`(59.0) / `q12(t)` / `q8(t)` / `qc12(t)`（量化到 1/12s、1/8s）/ `T` / `VO` / `SHOTS`(`[起,止,名]`) / `shotAt(t)`。`main.js` 导出 `render(t)`（`const fr = Math.round(t*24)`）、`window.EV` / `window.DUR` / `window.POST` / `window.READY`；`shots.js` + `scenes1–4.js` 每镜一个函数，从 `main.js` 的 `SHOTS_FN` 分派。
- **新增主体怎么接入**：一个新主体 = 用 `cel.js` 的原语画（`style-dna/cel-anime-80s.md:190-196`）：`path(pts, closed, tension)`（折点 `[x,y,1]` = 折角，Catmull-Rom → 贝塞尔平滑）；`cel(g, pts, {f, s, so, h, ho, rim, l, lw, sh, hi})` 一次画出「平涂 + 硬边阴影月牙（`so` 朝光源偏移）+ 硬边高光月牙（`ho`）+ 轮廓光（`rim`）+ 彩色描线（`l`）」；头发/围巾用 `ribbon(spine, width)` + `flutter(...)` 生成飘带；头部参考 `head80.js`（颅骨球心 (0,0) 半径 80、眼中心 +22、鼻底 +54、嘴 +74、下巴 +114，导出 `EXPR` 与正面 / 3-4 / 侧面三种画法）。**颜色一律从 `pal.js` 的色指定取，不要硬编码**，否则换时间带会崩；**大特写时把 `LWK.k` 调小**让描线变细。
- **换主题时要改哪些文件**：①`story.js`（BPM 网格 / 镜头表 `SHOTS` / 台词 `VO` / 片尾署名）；②`shots.js` + `scenes1–4.js`（逐镜函数）；③`bg.js`（新背景景片 + 发光版）；④`pal.js`（新色指定乘子）；⑤`head80.js` / `rider.js` / `hands.js`（新角色）；⑥`music/score.py` 的段落结构（须与新镜头对齐）。**注意**：`style-dna/cel-anime-80s.md:186` 明确警告——换 `VO` 重跑只是「验证引擎能重排」的技术检查，**不是做片子的方式**。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里走 `lib/dub-styles.json#cel-anime-80s`，该条目**标记为派生条目**（`derived:true`，`derivedFrom: palette@lib/dub-visual.json / subtitle-px@STYLE.md §4 / contrast-rule(WCAG)`）。生效参数：`palette.bg #fff0c0` / `fg #141414` / `accent #C9006A` / `subtitle #141414` + `subtitleOutline #FFFFFF`、`bgRecipe.type solid` + `texture scanlines`（★ 2026-10-03 更正：原记 `cel`，不是本项目的合法 texture 枚举；当前配置为 `scanlines`） + `vignette 0.08`、`subtitle.fontFamily DengXian` / `fontSizeFactor 0.04907` / `marginVFactor 0.08889` / `marginLFactor 0.06019` / `outlineFactor 0.00593` / `bold true` / `align 2`、`title.fontSizeFactor 0.09` / `showRole false`、`overlay.chapterCards true` / `accentRule false`、`motion.subtitleFadeIn 0` / `chapterTransition cut`。**注意其 notes 自陈「不是逐行手抽」**，且 `palette.fg` 曾缺失、由底色明暗反推——知识库更新时应优先用 demo 代码抽取值替换派生值。

### 素材缺口
- 字体依赖 demo 自带的 `demo/fonts/`：**Dela Gothic One**（片假名）、**Kanit**（tagline）、**Barlow Semi Condensed**（字幕），均 OFL；通路条目因本机无这些字体退回 `DengXian`，**字形与样片不同**。

### 能力限制
- **禁止纯黑描线**：描线必须是填充色的深版本，只有硬道具近黑（`STYLE.md:18`）。
- **cel 内部禁止渐变**（唯一例外：峰值处一张 harmony 手绘静止画）。
- **禁止真三维运动**：只能用多层景片 + 光带扫过制造运动（`style-dna/cel-anime-80s.md:110`）。
- **禁止胶片瑕疵**（片门抖动、灰尘、划痕、套色错位）——与磁带设定矛盾。
- **禁止镜头做 12 fps 步进**（会读成抖动）。
- 题材上是**对白驱动**的短叙事：撑不起纪录片式解说与长句。
