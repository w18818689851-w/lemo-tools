## 1. 风格说明

**是什么**：中国皮影戏。一幅被油灯照亮的白棉布，布前是**透光的染色驴皮剪影**。整幅画面只有一条公式：**画面 = 色调映射(灯光场 × 驴皮透射率 × 布纹)**（`gl.js:36-37`）——一切亮度来自灯，一切暗来自皮片的叠加，**镂空的孔才是最亮的地方**。皮影是关节连缀的刻皮片，用**可见的线铆钉**连接、被**细竹杆**操纵（颈杆 + 两根手杆），永远侧身、永远在布的同一侧表演。这是**活体剧场，不是定格动画**：幕布随灯呼吸，皮影在手里发颤，松动的部件在铆钉上摆（`STYLE.md:6-10`）。

**不是什么**（最容易做错的邻居风格）：不是剪影动画（silhouette animation，只有全黑轮廓，没有镂空透光、没有染色、没有铆钉关节）；不是红纸窗花（这里是**背光透射**的驴皮，不是正面受光的红纸，没有剪刀、没有折纸）；不是彩色玻璃（没有铅条，皮件会移动与重叠）；不是平面矢量剪贴画；不是 3D（层永远平行于布面，纵深靠灯与虚焦）。**绝不**照抄任何真实的皮影纹样、人物造型、旋律或录音，也**绝不在片中点名它们**（`STYLE.md:4`）。

**什么时候用它**：神话与民间传说、文化遗产、节庆；适合讲**一个古老的灾祸与救赎**，或任何可以用「灯的数量」直接映射张力的题材（`style.json` uses: Myths & folklore / Heritage / Festivals）。

**一句话内核**：**灯就是世界——亮度由亮着的灯数决定，暗由皮片叠加决定。**

**边界**：撑不起快节奏喜剧（锣鼓先行、一记大锣定生死，靠的是留白不是密度）；撑不起需要正面脸与细腻表演的题材（皮影永远侧身、脸是镂空空脸，**表情永不改变**，情绪只能靠头角度与身体倾斜）；撑不起明亮的日间实景（一切颜色都被灯染暖，夜戏 = 关灯而**绝不加蓝**）；也撑不起大量文字信息。

## 2. 画面构图

- **镜头数与画幅**：样本 **13 个镜头**（`story.js:29-33` SHOTS：house / suns / land / enter / liang / draw / second / volley / last / heal / truck / back / end），原生 **1920×1080（16:9）**，画布由 WebGL2 承载（`demo/index.html`）；**已适配 9:16**（`FILM_META.aspects = ['16:9','9:16']`，`demo/film.js:10`，由 `gl.js` 的幕布合成着色器把整张设计帧**等比装入**当前帧）。
- **主体位置与占比**：**皮影永远侧身**，布面**大部分留白**。英雄段用中景跟拍；连射段用**锁死全景**（完全不动），让观众数得清九级变暗；抉择段用中近景——英雄在左、空天在中、最后一颗太阳在右（f16 ≈36.3 s，`DEMO.md` Shots）。
- **负空间 / 留白**：留白是主角之一。f08（≈18.1 s 焦土横移）、f16（≈36.3 s 抉择）里布面上半部几乎全空，只有皮影与一颗太阳；「空布」本身就是「停顿、呼吸」的镜头语言（`STYLE.md:66`）。
- **图层叠放顺序**（从底到顶）：黑场（戏台房间）→ 透射率画布（每片驴皮 = 一张预渲染的透射率贴图，用 `multiply` 画，**重叠自然变暗**，镂空孔保持透明）→ 灯光场 L（每盏灯 = 宽叶瓣 σ≈700 px + 紧核心 σ≈120 px，核心/叶瓣亮度比约 6:1）→ `hdr = L × T × cl × (.62 + .38·ed) × expo` → 色调映射 `c = 1 − exp(−hdr)` → 前景层 F（黑漆木框、台口、模糊的观众后脑、前景立柱）以 `c = F.rgb + c·(1 − F.a)` 叠上 → 暖辉光（三级降采样金字塔，阈值 0.72，染色 `(1,.82,.6)`）→ **暖暗角（向棕 `(.7,.47,.25)` 走，绝不向灰）** → 饱和度 ×1.1 + 柔和 S 曲线 + 轻颗粒（`gl.js:14-40,56,62`）。
- **安全区**：**推近时镜头必须夹在幕布矩形内，不出黑边**（`film.js:149` 有专门的夹紧逻辑）；推镜**永远推框中心**，只有俯冲进灯焰时才围绕灯（`STYLE.md:72,104`）。字幕题板牌高 70 px，底边距画面底 **58 px**，居中。
- **本风格不能出现的构图**：正对镜头的脸、正面全身（皮影永远侧身）；把皮影放到布外或被裁掉的构图；以**边缘灯**为中心做推镜（会把人物推出画面）；把镂空纹样画成放射状花瓣或锯片（鱼鳞、云头、联珠、锦纹都有固定走向，不能乱转）。

**在 9:16（产品默认）下的表现**：本风格**已适配 9:16**——`FILM_META.aspects = ['16:9','9:16']`（`demo/film.js:10`）。影片模块 `film.js` 把 gl 画布对齐到**视口**（`film.js:29` `glcv.width/height = innerWidth/innerHeight`），`gl.js` 的幕布合成着色器把整张 **1920×1080 设计帧等比装入**当前帧（`fit = min(W/1920, H/1080)`，contain、居中）：取样坐标 `uvT = uv*uvk + uvb`（`gl.js:24`）、幕布坐标 `q` 改按设计帧像素换算（`gl.js:26-27`）、设计帧外的上下留边填**剧场暗色** `letterCol = (0.07,0.043,0.027)`（`gl.js:54`，读作「暗的戏台房间」，不是灰、不是黑边）。**世界坐标（幕布坐标）不变**——取景、夹紧（`film.js` 的 `camAt`）与摆位仍是设计帧口径，皮影**不会被二次缩放**。1080×1920 实测（`fit = 0.5625`）：**不裁切**，整幅设计帧（含黑漆木框、台口、观众后脑、字幕题板）完整落在画面中部（约 607 px 高、上下各留约 656 px 剧场暗色）；f16 的「英雄在左 / 空天在中 / 太阳在右」三分布**三块都在**（不再丢右侧的太阳），字幕题板随设计帧一起装入、**完整可见不被裁**（8.16 s 与 46.24 s 两帧实测）。代价是**版面偏空**：竖幅里戏台只占中段一条横带、上下大片暗色——这是「横向戏台装进竖幅」的必然结果，不是缺陷。16:9 逐字节未变（1920×1080 时 `fit = 1`、`uvk = 1`、`uvb = 0`、`fitOne = 1`、`inFrame = 1`，每个表达式都退化成它替换掉的那个数字；三帧 md5 与改造前完全一致）。

- **明度 / 对比规则**：**所有颜色都是透射的**——染料在过滤暖灯光，所以**没有任何东西比灯更亮**，每一个色相都偏暖。**孔是最亮的值**（镂空 = 零密度 = 全透），**重叠是最暗的值**。亮度来自**灯的数量，不是后期调色**：`expo = 1.75 / √(亮着的灯数)`（十盏灯 ≈ 一盏灯的 3 倍），夜戏 = **关灯**（灯数变少），**绝不加蓝**。必须读得清的细片（弓弦、箭杆、文字）一律用**深色**——浅色薄片在亮布上会消失（`STYLE.md:30-35`）。
- **同一画面最多几个色相**：**3–5 种饱和染料 + 生皮 + 墨**，上限不可突破；示例色组：**court**（朱红 + 赭石 + 石绿）、**river**（靛 + 玉 + 一点赭石）、**harvest**（火橙 + 金 + 一点绿）。
- **禁止出现的颜色**：任何「被灯照亮后仍然冷」的颜色；夜戏里的蓝；过曝处的**灰**角（暗角必须走棕）；把皮影画成没有厚薄、没有透光变化的平涂色块。

## 4. 转场规则

- **镜头之间怎么切**：**硬切**，切点挂在 100 BPM 网格上（1 拍 = 0.6 s，1 小节 = 2.4 s；`story.js:29-33` 的 SHOTS 全部对齐 `T` 里的关键时刻）。**一记大锣 = 一个决定性切换**。
- **允许的转场**（必须来自戏台 / 皮影本身）：① **灯一盏盏暗下去**；② **虚化的前景立柱横扫过画面**（样本从幕后绕回时用，「truck right as a blurred foreground pillar wipes the frame」）；③ **一个皮件在光里被揭起来**（揭条 / 抬走）；④ **闪到暖白**（`fadeCol ≈ [1,.82,.55]`）；⑤ **绕到幕后**（`mir = −1`，画面左右翻，同一套透射率画布镜像着看）。另外「亮相」用 **几帧的急推（crash zoom）压在锣上**——打击乐变成了摄影机运动（`film.js:157`）。
- **转场时长与缓动**：皮件「按上布」= 从 2.6 倍缩到 1 倍、模糊 34 px → 0，历时 **0.55 s**；「离布」= 放大 1.9 倍、加 30 px 模糊、淡出，历时 **约 0.9 s**；灯「亮起」有过冲（到 1.5 倍）再回落，灯「熄灭」在 **0.35 s** 内收掉（`DEMO.md` Motion numbers）。
- **绝对不要的转场**：**通用叠化（crossfade）**；数字转场（像素化、故障、扫光）。

| 单行字数上限 / 最多行数 | **单行**，牌宽 = 22（左内距）+ 46（印）+ 20（间隔）+ 文字实测宽 + 36（右内距）。样本 6 句英文，最长 69 字符；中文口径为 **8–16 字短句** |
| 出现与消失方式 | **上滑 18 px / 0.22 s** 入场（`hud.js` 的 `slide`），无淡出；显示到「语音 + 0.8 s」且 ≥ 1.8 s，**截到下一句前 0.3 s**；最后一句截到 `clap2 − 0.15`（`tools/cues.py`） |

- **字幕与旁白的关系**：字幕是说书人的题板，就是旁白的逐句转录。样本 6 句落在 7.45 / 12.30 / 22.35 / 25.20 / 37.75 / 45.20 s（`shadow-puppet.srt`）。**字幕、页面 `main.js` 的 `SUBS`、SRT 三处必须同源**——都用 `tools/cues.py` 的同一规则算（`style-dna/shadow-puppet.md:336-338`）。
- **本风格特有的字幕禁忌**：不许网络梗、流行语、emoji、颜文字；不许长定语从句、书面化长句、并列排比堆叠；不许第一人称吐槽或旁白自我吐槽；不许现代专有名词、时间戳、数字梗；不许形容词堆砌（「美轮美奂」「震撼人心」）；不许解释性元叙述（「接下来我们看」）。句首习惯用：`很久以前……` / `那时候……` / `只见……` / `可……` / `后来……` / `于是……` / `就为……`。

**文案+风格通路的底衬落地**：STYLE.md §4 声明「a storyteller’s placard (narrow dark-lacquer board, thin gold line)」，但「文案+风格」通路原先只走 `BorderStyle=1`（只画描边与阴影、不画底盒；盒填充字段 `OutlineColour` 被当作描边色用），这层底衬从未画出来。现已切到 `BorderStyle=3`（不透明底盒：盒填充色改用 `OutlineColour`、`Outline` 变为盒内边距，`BackColour` 仍只作阴影色——box 模式下 `Shadow=0`，故该阴影不绘制），渲染参数固定为 `BorderStyle=3`、盒内边距 `Outline=10`（1080 高基准）、`Shadow=0`、盒填充色 `OutlineColour=#122E160E`（AARRGGBB，落盘 ASS 为 `&H120E162E`）。`Shadow=0`：`BorderStyle=3` 下 ASS 的阴影是一份与底盒几乎完全重叠的整盒副本，会把半透明底衬二次压暗（实测 `hd-2d` 的对比度由 6.00 掉到 3.18）；置 0 后底衬的不透明度如实生效，也与检查器的单层合成模型一致。**底衬色与字色取自 demo 的真实实现**：该风格 `STYLE.md §4` 明确规定了底衬与字色的深浅取向（见上方原句），而此前配置正好相反；现已把 `palette.subtitle` 与 `subtitle.plateColor` 一起换成 demo 那一对。字色 `#f3e2bf` 与该底衬 `#122E160E` 的 WCAG 对比度 **11.16**。

## 6. BGM / 音效特征

- **配乐：锣鼓先行，不是钢琴与弦乐**（锣鼓经思路）。乐器：大锣「哐」（击后 0.4 s 音高下滑 2–3.5 半音）、小锣「台」（击后 0.12 s 上扬）、钹、板鼓（高硬「哒」）、堂鼓（心跳与滚奏）、木鱼、低音垫（contrabass / cellos，很弱）。**弓弦与吹管**：板胡（erhu 采样加亮 + 鼻音共振峰 + 可变速滑音），**苦音**（ku-yin：fa↑ = +5.4 半音、si↓ = +10.5 半音，用于灾祸）与**欢音**（huan-yin：D E F# A B，用于英雄与回春）；唢呐感（oboe + 饱和 + 1.2–3 kHz 共振峰）**全片最多一次**。样本 12 段 cue 按戏剧顺序排：开场滚奏 → 一灯一击、逐渐加速 → 灾祸下的心跳鼓 → 急急风滚奏冲进亮相 → 亮相大锣 → 快长锤一箭一锣 → **硬停**（≤30 ms，含混响尾）→ 一声极轻小锣（决定）→ 柔和板胡主题 → 锣刮转场 → 收板大锣长尾（`DEMO.md` Score structure；`music/score.py:273-275`）。
- **拟音（按材料分层）**：醒木（硬木拍桌）、划火柴（噼啪 + fwoomp）、点灯 fwoomp（音高随灯序号升）、竹杆碰布（短脆高频）、驴皮离布 flap、干皮翻动、皮鞋步、弓弦（基频 196 Hz 轻微上滑）、箭飞行 whoosh、箭中皮 thwack、捏灯芯（噗 + 嘶）、乌拍翅四声、火噼啪、热的低嗡、水、幕后房间底噪、呼吸（`style-dna/shadow-puppet.md:216-235`）。
- **旁白处理**：说书人，短句，**小剧场混响**（`mix.py:13-17`）。**闪避规则**：音乐 **12 dB**（250 ms 包络 × 1.6）、拟音 4 dB、环境 5 dB；**每句旁白必须比床（音乐 + 拟音 + 环境）高 ≥ 12 dB 才算过**。样本实测：L1 13.1 / L2 13.4 / **L3 11.9** / L4 12.0 / L5 21.2 / L6 20.2 dB（`_distill/logs/shadow-puppet.log:109-114`）。
- **响度目标**：`−14 LUFS`（两遍 loudnorm，TP `−1.2`）；**颗粒 2**。**实测成片 `−14.0 LUFS / LRA 7.4 LU / 真峰值 +1.43 dBTP`**（I/LRA 见 `logs/shadow-puppet.log:125-126`；真峰值口径 = `loudnorm` 的 `input_tp`，4× 过采样，**超 −1.2 dBTP 交付线 2.6 dB、已实际削波**，见第 11 节）。 ★ **2026-10-03 已修**：成片已用 `scripts/fix-truepeak.mjs` 音频重混（`-c:v copy`，视频流逐字节未变），真峰值 +1.43 dBTP → **−1.60 dBTP**、已在 −1.2 dBTP 交付线内（达标）；原 +1.43 dBTP 记录保留为历史。
- **静音策略**：**静场是真实存在的一段，而且是硬停**。整条伴奏被 gate 硬切为 0（锣鼓 / 唢呐在 34.8 s 之后永远清零，**连长尾一起切**），只留灯芯噼啪与弓弦；静场里至多一声极轻的小锣（36.9 s）。**实测 34.83–36.85 s 的 RMS 是 −199.6 dB**（真静音，判定 OK），另外收板前醒木留空 50.5–50.7 s 的 RMS 是 −240.0 dB（`logs/shadow-puppet.log:92-93`；`mix.py:144`）。静场里最多允许一个声音：一口气、一声轻敲、一记嘶响。

## 7. 素材偏好

- **需要什么素材**：① 一套「刻皮件」模块——每个可动部件 = 一张**透射率贴图**（由 `carve.js` 的 `piece(box, draw, opt)` 预渲染）+ 一个关节（父片局部坐标）+ 一个铆钉；角色至少 **8–12 片**（样本英雄 11 片 + 箭壶 + 弓 + 两根翎子），头放大 **约 1.2 倍**、头饰占全身约 **1/4**，袖子与躯干用**不同染料**；② 三根操纵杆锚点（颈杆 + 两根手杆）+ 两段 IK 手臂链 + 预模拟的摆动物（翎子 / 流苏）；③ 刻皮词汇库（鱼鳞缝、云头卷、联珠/梅花、菱形锦纹、古钱纹、水波纹、回纹、山纹地层、锥形裂缝、火舌）；④ 景片（山、地面条、树、河条、房子、火、烟）；⑤ 灯光场参数；⑥ 锣鼓经配乐与按材料合成的拟音；⑦ 8–16 字短句旁白。
- **不需要什么素材**：实拍视频、照片贴图、粒子系统（火 / 烟 / 水**都是刻好的皮件插在杆上，靠换片与抖动演出，绝不用粒子**）、3D 模型、任何真实皮影的纹样或造型拷贝。
- **取景 / 质感偏好**：皮影永远侧身，布面大片留白；质感来自**镂空与透光**（孔最亮、叠加最暗、刻得越密透光越多）、**驴皮质感**（可平铺 512² 纹理以 `multiply` 乘上皮片，再用 `destination-in` 还原原 alpha 让镂空孔保持透明）、**刻线**（暗色 1.5–2.4 px 勾外轮廓与分区线）、**铆钉**（关节处一个深色小圈 + 浅色线结，画在透射率画布的世界坐标上）、**布纹**（`sin × sin` 经纬被噪声扭曲 + 纤维噪点 + 大尺度疏密斑 + 四边略暗）。
- **可替代方案**（缺素材时怎么降级而不破风格）：缺纹样库就**只保留 3 种最基础的刻法**（鱼鳞、云头卷、古钱纹）——**宁可少，也不能把纹样画成放射状花瓣或锯片**；缺锣鼓采样就用**纯合成**的大锣（噪声 + 指数衰减 + 音高下滑）+ 板鼓（短噪声爆发 + 高 Q 带通）+ 堂鼓；缺板胡就用任何**明亮、带鼻音共振峰**的弓弦音色，但要保留「苦音 / 欢音」两套音阶；缺景片就**减少元素、加大留白**——「布面大部分留白」本来就是风格的一部分，不是缺陷。

- **运动质量**：**皮影与镜头都是 24 fps 连续运动**；**只有被换的效果皮件（火、水）是 12 fps 抖动**。**手抖**：每个皮影带几像素的慢频抖动（≈3 px / 0.018 rad），紧张时振幅放大到 **1.8 倍**；腿、翎子、流苏是**预模拟的阻尼摆**（120 Hz 预模拟保证确定性），越紧张摆得越狠。**身法走的是戏曲phrasing**：碎步跑 → 跳 → 下蹲 → **在打击乐重音上定住姿势约 1 s**（只有松动部件在颤）→ 转头。**脸永不改变**，态度 = 头角度 + 身体倾斜（抬头 = 决心，低头 = 悲伤）。**绝不移动的是**：布、木框；**绝不形变的是**：皮件只能绕铆钉转、沿杆滑、或被换掉（`STYLE.md:44-51`）。

- **留白与静音的位置**：**静场 34.83–36.85 s**（2.02 s，实测 RMS −199.6 dB），落在最后一箭与回春之间；收板前醒木留空 50.5–50.7 s。抉择段「中近景空布」本身也是留白——用布面的空当表达「停顿、呼吸、抉择前的静」。

## 10. 编排规则

- **内容文件字段契约**（`story.js` 是唯一真值）：`DUR`（54.4）、`BEAT` / `BAR`（0.6 / 2.4）、`T`（每个关键时刻的秒数，含 clap / match / lampOn / titleIn / titleSet / titleOut / sun0 / flares / hot / burn0 / burn1 / flames / run0 / run1 / hop / liang / lookUp / draw1 / rel / fly / last0 / lastDraw / stop / lower0 / lower1 / softGong / heal0 / river / canopy / heal1 / pull0 / truck0 / cutBack / truck1 / bow / clap2 / endIn / end）、`KILL`（被射顺序，样本 `[6,1,3,7,2,8,4,9,5]`，**sun 0 留下**）、`hitT(i) = rel[i] + fly[i]`、`VO[]`（`{id, t, text}`，id 为 L1..L6）、`SHOTS[]`（`[起, 止, 名]`）+ `shotAt(t)`。页面契约：`window.READY` / `window.render(t)` / `window.DUR` / `window.EV` / `window.T` / `window.SUBS`（`main.js`）。
- **事件词汇表**（`type` → `mix.py` 里的声音）：`clap` 醒木（硬木拍桌）、`match` 划火柴（噼啪 + fwoomp）、`ignite` 点灯（fwoomp）、`flare` 灯亮（fwoomp，音高随序号升）、`rodtap` 竹杆碰布（短脆高频）、`liftoff` 皮件离布（flap）、`creak` 木头/皮革吱呀、`twang` 弓弦（196 Hz 轻微上滑）、`arrow` 箭飞行（whoosh）、`hit` 箭中皮（thwack）、`snuff` 捏灭灯芯（噗 + 嘶）、`crowflap` 乌拍翅（四声）、`bowease` 收弓（两声吱呀）、`step` / `hop` / `land`、`crack` / `crackle` / `fireup` / `heat` 火、`water` / `wind` / `cloth` / `room` / `breath` 环境、`vo{id}` 旁白（读 `voices/<id>.wav`）。
- **时间线契约**：`story.js` 导出 `DUR/BEAT/BAR/T/KILL/hitT/VO/SHOTS/shotAt`；**所有模块禁止各写一份时间**。`core/render/events.mjs` 从 `story.js` 生成 `events.json`，`mix.py` 与 `music/score.py` 都读它。**字幕区间**：`t1 = t + max(1.8, dur[id] + 0.8)`；若有下一句则 `t1 = min(t1, 下一句 t − 0.3)`；最后一句截到 `clap2 − 0.15`。**字幕、页面、SRT 三处必须同源**。
- **新增主体怎么接入**：新人物 / 新物 = 一个「刻皮片模块」，必须提供：① 每个可动部件 = 一张透射率贴图（`carve.js` 的 `piece(box, draw, opt)` 预渲染）+ 一个关节 + 一个铆钉；② 至少 8–12 片；③ 头放大约 1.2 倍、头饰约占全身 1/4；④ 袖子与躯干用不同染料；⑤ 画的时候用 `multiply`，镂空用 `destination-out`（**先设 `fillStyle = '#000'`，fill alpha 决定挖多少**）；⑥ 导出三根操纵杆锚点 + 两段 IK 手臂链 + 可选的预模拟摆件。**景片** = 刻好的皮件，幕布大部分留白。
- **换主题时要改哪些文件**：① `demo/lines.json`（8–16 字短句旁白，**同音词写 `asr` 别名字段**）；② `demo/story.js` 的 `DUR/BEAT/BAR/T/KILL/VO/SHOTS`（**时间线先写，再写 cue 表**）；③ `demo/houyi.js` / `poses.js`（主角的刻皮片模块与关键姿势）；④ `demo/scenery.js` / `suns.js`（景片、山、地面条、河条、树、房子、火、太阳）；⑤ `demo/stage.js` / `backstage.js`（木框、观众、立柱、幕后剪影）；⑥ `demo/music/score.py`（换主题，但保留「锣鼓先行 + 一记大锣定生死 + 静场硬切」）；⑦ `demo/mix.py` 的材料拟音映射。**可整体换**：主题、人物、场景、染料组（上限 3–5 饱和色 + 生皮 + 墨）、开场、结尾、镜头路径、节奏，甚至换另一种戏曲打击乐（潮州锣鼓、十番）——但**「锣鼓先行、一记大锣定生死、静场硬切」的规则不变**。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里能生效的参数是 `palette`（bg `#f4ead2` / bg2 `#2b170d` / fg `#1a100a` / accent `#b3261b`）、`bgRecipe`（gradient + `paper` 纹理 + `backlit-leather` + vignette 0.08）、`subtitle`（SimSun / 0.04167 / marginV 0.14537 / marginL 0.06019 / 无描边 / 加粗 / 居中）、`title.fontSizeFactor 0.09`、`overlay` 全部关闭、`motion.subtitleFadeIn = 0.1` + `chapterTransition = cut`。**注意**：`lib/dub-styles.json#shadow-puppet` 是 `derived: true` 的**派生条目**（配色来自 `lib/dub-visual.json` 的代码抽取，字幕 px 来自 STYLE.md §4，字幕色由 WCAG 规则反推），且模板通路**拿不到** WebGL2 的灯光场 × 透射率 × 布纹合成、镂空透光、铆钉与手抖——**这些是本风格的命门**。走 dub 通路时本风格的还原度会明显低于走 `demo/build.sh`。

## 11. 当前短板与避坑要点

### 已知缺陷
- **十灯全亮时布面被推到大面积近白**：`expo = 1.75/√10 ≈ 0.55`，f06（≈13.6 s，焦土段十灯全亮）里上半幅几乎全白，太阳的**刻火舌**、山的**山纹地层**、地面条的**回纹与古钱孔**都只剩很淡的轮廓，擦到 `STYLE.md:17`「more lamps bleach the frame **but keep it readable**」与 `STYLE.md:100`「过曝处出灰角」的边界。这是亮度模型本身的可读性上限，不是渲染 bug。
- **片尾暖白闪衰减慢于片尾牌到位**：f23（≈52.1 s）里镂空字牌「SHADOW PUPPETRY」被 `fadeCol (1,.82,.55)` 漂白成**浅底深字**、几乎读不出，直到 f24（54.4 s）才恢复成**深底金字**。转场闪白与片尾牌的时序需要错开。
- **旁白与床的间隔有两句压线**：`STYLE.md:81` 的硬规则是「每句旁白比床高 **≥ 12 dB**」，实测 **L3（Then came Hou Yi, the archer.）只有 11.9 dB**、L4 是 12.0 dB（`logs/shadow-puppet.log:111-112`）。L3 严格来说没过线，会让「按锣」的节奏被旁白糊住。`DEMO.md` 也记录过同类问题：一句本来通过 whisper 独测的旁白，混进音乐后糊成「shadow place」——**遇到这种情况应该改句子，而不是去调混音**。
- **dub 通路的字幕位置与 demo 差约 6 个百分点**：demo 的题板底边距画面底 **58 px（5.4%）**、牌心约在画面高 **91.4%**；dub 的 `marginVFactor 0.14537` 是**距底 14.5%**。模板通路会把题板推到明显更高的位置，破坏「贴在台口下沿」的剧场感。
- **dub 通路会丢掉题板的全部装饰**：`subtitleOutline` 是 `#00000000`（全透明）、`fontFamily` 回退 **SimSun**、`subtitleFadeIn 0.1`（demo 是上滑 18 px / 0.22 s）——细金线、朱红「说」字印、漆面渐变与上滑动作全部丢失，只剩一行加粗文字。
- **文档与本次实际跑通的旁白口径不一致**：`lib/style-dna/shadow-puppet.md:40-44` 与 `STYLE.md:39` 描述的是「说书人、口播 6 句、每句 8–16 字中文短句」，但本次成片实际用的 `demo/lines.json` 是**6 句英文**（Kokoro `am_michael`，speed 0.86–0.88）。所以成片是**英文旁白 + 中文「说」字印的题板**。这是一处真实的口径分叉，换主题时按目标语言重写 `lines.json` 即可，但要知道文档描述的是中文口径。

### 能力限制
- **横竖差异大**：已适配 9:16（`FILM_META.aspects = ['16:9','9:16']`，`demo/film.js:10`），但本风格是**横向展开**的（横移讲广度、锁死全景数变暗、左右分立对峙），竖幅下戏台只占中段一条横带、上下留大片剧场暗色——**信息完整但版面偏空**（详见第 2 节子段）。

### 踩过的坑（本机实测）
- **本风格自带 `demo/tools/mux.sh` 副本，原先有两处问题**：① 编码器硬写成 `libx264`（CPU 编码，违反「合成渲染走本地 GPU」的硬规则）；② 缺「音频比画面短时补静音」——音频比画面短时 `-shortest` 会切掉最后一帧，编排器的守卫会判 `MUX_FAIL 帧数不符`（同类问题实测发生在 backrooms：渲染 1433 / 成片 1432）。
- **2026-10-03 的最小外科回灌**：用 `D:/lemo-tools/scripts/patch-style-mux.mjs` 把 `core/render/mux.sh` 的这两处修好回灌到本 demo 的副本（`patch-style-mux.mjs:37-47` 里 `shadow-puppet` 条目为 `{slug:'shadow-puppet', crf:22}`）。**只换了两件事**：① 编码器跟随 `LEMO_VENC`（`h264_nvenc` 走 GPU，否则回退 libx264）；② 音频短于画面时 `apad=whole_dur = 画面长度 + 1/24 s`（多补一帧，让 `-shortest` 切不到末帧）。**shadow-puppet 自己的 CRF 22 完整保留**（它本来就没有 `-tune grain`），没有动。
- **补丁本次真的生效了**：日志 `[6]` 打出了 `mux.sh: note: audio (54.400000 s) shorter than video (54.415039 s); padding to 54.456706 s (one frame past, so -shortest cannot clip)`，随后 `MUX_OK 36065489 src_frames=1306 out_frames=1306`——**帧数一致**（`logs/shadow-puppet.log:127-128`）。如果没有这条补静音，54.400 s 的音轨会切掉 54.415 s 视频的末帧，帧数就会变成 1305。
