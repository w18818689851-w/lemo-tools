# 孔版印刷（`risograph`）· 风格制作 Skill

> **用途**：选定本风格后，**优先读这份文档**作为核心参考。
> **目标不是逐帧复刻样本**，而是**对齐风格特质、复用它的制作思路 / 视觉元素 / 编排手法**。

## 1. 风格说明

**是什么**：一部看起来**一张一张印在孔版印刷机上**的动画。孔版机一次只印一个颜色，每个颜色是一块自己的模板（版）、自己的滚筒、自己的半透明油墨；这一条事实就决定了全部外观：2–3 块半透明专色叠印在暖白纸上，网点半调、墨粒、套色永远对不齐，形状是平涂色块与剪影、**没有描边**（`STYLE.md:6-16`）。

**不是什么**（最容易做错的邻居风格）：不是「平面矢量图 + 噪点滤镜」——每个颜色都必须来自一块版；不是 CMYK 波普半调（没有印刷色、没有 keyline）；不是丝网印刷海报（Riso 墨是半透明带颗粒的，不是不透明实地）。**绝不**出现 Riso 品牌、logo 或机器外观，油墨名只作颜色参考（`STYLE.md:16`）。

**什么时候用它**：独立品牌、zine、生活方式、城市日常、音乐、青年题材；适合讲「平凡的一天里颜色一点点回来」这类温柔观察式的题材（`style.json` uses: Indie brands / Zines / Lifestyle）。

**一句话内核**：**一次只印一个颜色，世界在每个转折点获得一块新墨。**

**边界**：撑不起快剪强节拍的动作片、撑不起高信息密度的数据长图（半调会把细节糊成一团泥）、撑不起写实人物特写（平涂剪影没有面部表演）。也撑不起需要精确对位的字幕/UI 叠加——本风格的套色错位是刻意的。

## 2. 画面构图

- **镜头数与画幅**：样本 11 个镜头，设计帧 **16:9（1920×1080）**，绝对像素构图（`demo/draw.js:3` 写死 `W=1920, H=1080`）；**已支持多比例**（`demo/film.js` 的 `FILM_META.aspects` = 16:9 / 9:16 / 3:4 / 4:3 / 1:1），经**页面外壳等比装入**实现（见下）。
- **主体位置与占比**：一条地平线 + 一块大平场或圆盘 + **一个小人**；小人的头要压在**画面里最平的那块颜色**上（`STYLE.md:33`）。人物极小——f05 里骑车人只占画面高约 1/6，天空占掉上半幅。
- **负空间 / 留白**：大量纸白与实地墨。天空是**空的大色块**，专门留给片名（`DEMO.md` 镜 2：片名印在空天上，2.0 刷出、5.4 撤下）。
- **图层叠放顺序**（从底到顶）：暖白纸 `#F6F1E6` → 各版网点/实地墨（每版独立位移 + 微旋转）→ 角色的**纸白挖空描边**（halo 4–5 px，12 次环形压印）→ 角色本体 → 字幕纸白挖空条 → 字幕文字（`draw.js:11-22`；`film.js:306-315`）。
- **安全区**：字幕条居中于画面下方 y≈1000 px（画面高 92.6%），挖空条宽 = 文字实测宽 + 64 px，半径 6 px；主体不得压住字幕带；边缘 5% 内不放关键形状（套色错位会把它推出去）。
- **每区域最多两块版、最多一块作淡色**——三块半调叠在一处就是一团泥（`STYLE.md:29-30`）。
- **本风格不能出现的构图**：满幅三块半调叠印；居中大特写（剪影没有面部信息）；对称硬边框与 keyline；任何形式的渐变（只能有分级网点带）。

**★ 2026-10-04：已支持多比例（页面外壳等比装入）**。本风格有约 **700 处绝对像素字面量**（位置/尺寸混写），逐处改「哪个是位置、哪个是尺寸」会漏、且漏了**静默错位**；所以改造**只碰一个页面外壳文件** `demo/index.html`：影片本体仍按**固定设计帧 1920×1080** 画（一字未改），当前帧（= 渲染视口）不是 1920×1080 时，把**整张设计帧等比装入**（contain）并居中，留边露出页面底色 `#F6F1E6`（`demo/riso.js` 的 `PAPER [246,241,230]`，也就是本片的**纸白**——Riso 画面本就是「墨印在纸上」，**留黑会读成完全不同的东西**）。声明在 `demo/film.js`（`FILM_META.aspects`，控制台按源码文本探测）。`FILM_META.aspects = ['16:9','9:16','3:4','4:3','1:1']`。

- **16:9 逐字节不变**：1920×1080 时外壳**完全不碰 DOM**（不建包装层、不设 transform、不改底色）。实测改造前 vs 改造后 3 帧 **md5 逐字节相同**；**同会话往返**（1920×1080 → 1080×1920 → 1920×1080）亦 **md5 逐字节相同**。**证据强度：最强。**
- **9:16 不裁切**：整幅画面（含片名、横移主体、字幕条）**全部在画面内**（实测：改后 9:16 vs 16:9 中心裁切 SSIM **0.13–0.28**，vs 理想等比装入 SSIM **0.947–0.958**）。
- **已知代价**：① 竖屏下有效画面只占 **1080×607**，画面按紧轴缩到 **0.5625×**——**网点（周期 7 px）随之缩到 ≈3.9 px**，放大看局部出现轻微混叠/拍频，但**未形成大面积摩尔纹带**（实测 vs 理想等比装入 SSIM 仍 0.95+）；② 上下留边是**纸白纯色**（实测留边 YAVG=241 = `#F6F1E6`），与画面纸张同色、肉眼无缝——**这正是必须留纸白的原因**；③ 其它比例同理（3:4 / 4:3 / 1:1 已声明）。
- **没有做的**：这是**等比装入**，不是**重排**——横移镜头没有改成纵向推入（见第 11 节）。

## 3. 配色体系

| 角色 | 色值 | 用途 | 来源 |
|---|---|---|---|
| 纸白（底） | `#F6F1E6` | 纸张底色、挖空、描边光晕、字幕条底 | `demo/riso.js:11` `PAPER=[246,241,230]`（`STYLE.md:40` 文档写作「around #F4EEE2」） |

| 版 2 · 黄 | `#FFE800` | 第二块版（面包店到场）；叠蓝成绿 | `demo/riso.js:9` / `STYLE.md:43` |
| 版 3 · 荧光粉 | `#FF48B0` | 第三块版（公园/鸽群）；叠蓝成紫、叠黄成橙红 | `demo/riso.js:10` / `STYLE.md:43` |
| 字幕字 | `#0078BF`（样本） / `#3D5588`（dub 通路） | 印在一块版上的字 | `DEMO.md` End card；`lib/dub-styles.json#risograph` |
| 字幕条底 | `#F4EEE2` | 零墨纸白挖空条 | `STYLE.md:49` |

- **明度 / 对比规则**：墨是**乘算**的（`col *= mix(vec3(1.), uInk[i], c)`，`riso.js:104`），所以两墨相交必变暗、三墨接近黑。**纸白也是颜色**（挖空、高光、字幕底）。皮肤只用最浅一块版的淡色——饱和色的网点打在皮肤上像出疹子（`STYLE.md:41`、`DEMO.md` 坑）。
- **禁止出现的颜色**：CMYK 四色印刷色、不透明实地墨（无颗粒感）、纯白 `#FFFFFF`（纸必须暖）、任何渐变。同一区域**最多两个色相**（两块版）。
- **同一画面最多几个色相**：全片最多 3 个专色 + 纸白；单镜头单区域 ≤ 2 块版（一块可作淡色）。满叠印（三版同时最浓）**只在最该给的那一下**用一次。

## 4. 转场规则

- **镜头之间怎么切**：**按拍硬切**为主。120 BPM、1 小节 = 2 s，所以切点基本落在**偶数秒**上（`DEMO.md` Arc）。
- **允许的转场**：① **叠印生长**——一块墨的形状长过整个画面，把下面的一切变成混合色，再缩成下一场的关键形状（样本 24–26 s：粉圆从车筐长出来吞掉画面，再缩成河上的大太阳，`DEMO.md` 镜 7）；② **滚筒刷墨**——一道移动的偏浓墨带把一块版从左到右揭示出来（样本开场：蓝版滚过车把与车铃，`DEMO.md` 镜 1）；③ **形状匹配剪辑**——靠一块平形状的形延续到下一场；④ 每版有 gate（是否上机）与 sweep（揭示推进边缘）。
- **硬切点怎么定**：对齐拍点（偶数秒）与重音。套色「跳点」`KICKS` 在 2 / 5.5 / 8 / 12 / 16 / 20 / 24 / 30 / 31 / 36 / 38 s，幅度 4–14 px（`film.js:13-14`）。
- **转场时长与缓动**：kick 在 ≈0.25 s 内衰减、带轻微振铃；drift 在一次「停住」里漂开至多 ≈25 px，在强拍上「咔」地套准（样本 28.0 s，`film.js:45-50`）。
- **绝对不要的转场**：交叉溶解（cross-dissolve）、柔和的数字擦除、每帧抖动的套色（会闪、会撑爆体积，`STYLE.md:75,102`）。印品不淡出——标题靠刷墨到场或在拍上硬上，**靠硬切离场**。

| 项 | 值 |
|---|---|
| 字体 | 样本：Jost 500–700（字幕）/ Bricolage Grotesque 800（片名）；dub 通路回退 **DengXian**（本机无前两者，`lib/dub-styles.json#risograph`） |
| 字号（相对画面高） | 样本 **42 px ≈ 3.9% 画面高**；dub 通路 `fontSizeFactor 0.04` → **43 px ≈ 4.0%**（`STYLE.md:49` 声明 40–46 px） |
| 颜色 / 描边 / 阴影 | 字印在**一块版**上（样本蓝 `#0078BF`；dub 通路为对比度改用 `#3D5588`），**无描边、无阴影**（`outlineFactor: 0`）；底是零墨**纸白挖空条** `#F4EEE2`，半径 6 px，边缘会沾上套色错位的彩色毛边 |
| 位置 / 安全边距 | 居中，条心 y≈1000 px（画面高 92.6%）；dub 通路 `marginVFactor 0.145`（距底 14.5%）、`marginLFactor 0.06` |
| 单行字数上限 / 最多行数 | **1 行，绝不折行**；英文 30–60 字符（≈6–12 词），中文 14–30 字。挖空条宽 = 文字实测宽 + 64 px（`STYLE.md:49`） |
| 出现与消失方式 | **硬上硬下**（`subtitleFadeIn: 0`）——印品不淡出。停留 ≥ `max(1.8 s, 语音时长 + 0.6 s)`，并被下一句起点 − 0.05 s 截断，最晚 36 s（`film.js:29-33`、`tools/subs.py:8`） |

- **字幕与旁白的关系**：字幕就是旁白的**逐句转录**，一句对一条；5 句落在 5.6 / 9.0 / 21.7 / 28.3 / 32.8 s（`risograph.srt`）。
- **本风格特有的字幕禁忌**：不许把颜色、版数、印刷术语写进字幕——**颜色靠画面说，不靠旁白解释**；不许营销腔、感叹号堆叠、网络口播腔；一句里不许塞两个以上信息点或两个并列从句（`style-dna/risograph.md:48-52`）。

**文案+风格通路的底衬落地**：STYLE.md §4 声明「a paper-white knockout strip (zero ink, small radius)」，但「文案+风格」通路原先只走 `BorderStyle=1`（只画描边与阴影、不画底盒；盒填充字段 `OutlineColour` 被当作描边色用），这层底衬从未画出来。现已切到 `BorderStyle=3`（不透明底盒：盒填充色改用 `OutlineColour`、`Outline` 变为盒内边距，`BackColour` 仍只作阴影色——box 模式下 `Shadow=0`，故该阴影不绘制），渲染参数固定为 `BorderStyle=3`、盒内边距 `Outline=10`（1080 高基准）、`Shadow=0`、盒填充色 `OutlineColour=#00F4EEE2`（AARRGGBB，落盘 ASS 为 `&H00E2EEF4`）。`Shadow=0`：`BorderStyle=3` 下 ASS 的阴影是一份与底盒几乎完全重叠的整盒副本，会把半透明底衬二次压暗（实测 `hd-2d` 的对比度由 6.00 掉到 3.18）；置 0 后底衬的不透明度如实生效，也与检查器的单层合成模型一致。**底衬色为回退值**：demo 侧底衬（demo band [0,0,0] 黑色底块）与该风格配置的 `palette.subtitle` 字色 #3D5588 对比度不足（<3.0），故改用该风格自身的地色/辅色（palette.subtitleBack #F4EEE2）；字色 #3D5588 与该底衬的 WCAG 对比度 **6.37**。

## 6. BGM / 音效特征

- **配乐**：原创轻 **bossa nova**，D 大调，**120 BPM**（1 小节 = 2 s），numpy 合成（`demo/music/score.py` + `music/bell.py`）。**分层像分版**：一块墨 = 尼龙吉他独奏 → +黄版 = 沙锤、rim clave、轻刷鼓组（车铃当打击乐）→ +粉版 = 立式贝斯 + 口哨旋律 → 满叠印 = +颤音琴。拉远镜头时乐器一件件离场（颤音琴→口哨→贝斯→打击乐），片尾只剩吉他 + 一个持续的 Dmaj9（`DEMO.md` Score structure）。
- **拟音（foley）清单**：**机器是标志**——进纸「唰」+ 滚筒「咔嚓—咚」（在每块版到场时响，按版左右摆 pan）、马达嗡、纸落到纸堆（39.5 s）；车铃（两个非谐分音 ≈2.1 / 3.4 kHz，每次 5 快击）、飞轮 tick、刹车 squeal；面包壳 crunch（密集微小带通咔哒）；鸽群振翅（短带通噪声爆发）+ 咕咕（300–400 Hz 滑音）；水拍（`DEMO.md` Foley；`mix.py:23-25,81-87,114`）。
- **旁白处理**：Kokoro `am_adam`，speed 0.95，5 句短句；放松、口语、贴近的男声；**音乐在人声下闪避约 −8 dB**（`mix.py:145`）。
- **响度目标**：`−14 LUFS`；**交付真峰值上限**：`−1.2 dBTP`（项目级交付线，`STYLE.md` 未额外声明更严上限）。**实测成片 `I −14.4 LUFS / LRA 4.0 LU（ebur128）`**（`_distill/logs/risograph.log:173-174`）；**真峰值 −0.76 dBTP**（`loudnorm` `input_tp`，4× 过采样）—— **超 −1.2 dBTP 交付线 0.44 dB，真峰值为负、未削波**。混流走本风格副本 `styles/risograph/demo/tools/mux.sh`（两遍 loudnorm，**`TP=-1.2`**，`tools/mux.sh:3,5,9`）。 ★ **2026-10-03 已修**：成片已用 `scripts/fix-truepeak.mjs` 音频重混（`-c:v copy`，视频流逐字节未变），真峰值 −0.76 dBTP → **−1.96 dBTP**、已在 −1.2 dBTP 交付线内（达标）；原 −0.76 dBTP 记录保留为历史。
  ★ 2026-10-04 多比例重渲后复测（2026-10-05）：当前入库成片真峰值 **−3.11 dBTP**（`loudnorm input_tp`，4× 过采样）、`I = −14.4 LUFS`（`ebur128`）、`LRA 4.0 LU`（`ebur128`）——−1.96 属重渲前版本。
- **静音策略**：**第 1 小节完全没有音乐**（只有进纸、滚筒、车铃）；**26–28 s 一个完整静音小节**——混响尾被切掉，只留水声、鸟与一声远处的教堂钟（26.3 s），配对一次套色漂移；28.0 s 的「咔」套准把全乐队带回来（`film.js:45-50`；`STYLE.md:82`）。**成片 mux 不加颗粒**（颗粒在印里），`grain = 0`。

## 7. 素材偏好

- **需要什么素材**：① 用「分版浓度」画出来的角色与场景（街道、面包店、公园、河岸、正上方俯拍码头、印刷机、车铃特写，`scenes.js` / `scenes2.js`）；② 一套原创配乐脚本（numpy）+ 拟音合成脚本（`mix.py`）；③ 字体（Bricolage Grotesque 800 / Jost 500–700，`demo/fonts/`）；④ 5 句以内的短旁白文案（`lines.json`）。
- **不需要什么素材**：实拍视频、照片贴图、任何带真实印刷品牌或插画师角色/构图/配色的参考图（`STYLE.md:4` 明确「copy none of their characters, compositions or palettes」）。
- **取景 / 质感 / 比例偏好**：宽幅横移、静止大全景、锁定构图、正上方俯拍；质感来自网点（1080p 周期 **7 px**、网角 **15°/0°/75°**、阈值 smoothstep ±0.07、密度 ≥0.9 印实地）+ 墨粒（阈值上 ±0.08 噪声、噪声 >0.93 处漏白 ×0.75、走纸方向条纹 ×10 拉伸、墨浓度 `k = 0.80 + 0.14·streak + 0.08·blot`、纸纤维 ±1.5%、沸腾 35%）（`DEMO.md` Palette & props）。
- **可替代方案**（缺素材时怎么降级而不破风格）：没有 Bricolage / Jost 就换任意**重黑体**做片名、几何无衬线做字幕（dub 通路就是这么退到 DengXian 的）；没有原创配乐就用**干、暖、lo-fi** 的现成曲并保证「每块新版进一件乐器」的分层逻辑；场景缺一个地点就**合并两个地点**，但必须保留「每块版 = 一个转折点」的因果——宁可少一个镜头，也不要让一块版无故到场。

## 8. 镜头节奏

| 项 | 值 |
|---|---|
| 单镜时长 | 2–8 s，均值 ≈3.6 s（最短 2 s 的开场特写与片名镜；最长 8 s 的面包店横移） |

## 10. 编排规则

- **内容文件字段契约**：`window.render(t)` / `window.DUR` / `window.EV` / `window.SUBS` / `window.READY`（`main.js:14-15,56`）。绘制层契约：`ink(b,y,p)` 三版浓度 → 颜色串、`over(fn)` 只加墨不挖空（叠印）、`layer(fn, halo)` 角色纸白挖空描边、`S.mask` 全局版遮罩（`draw.js:1-2,24-32`）。
- **事件词汇表**（`EV` → `mix.py`）：`drum{plate}` 版到场（进纸「唰」+ 滚筒「咔嚓—咚」，按版摆 pan）、`bell{n,gain}` 车铃、`titlehit` 片名印上、`doorchime` / `church`、`catch` / `snap` / `crunch`、`flock` / `flap` / `land` / `coo` / `peck`、`whoosh` / `brake`、`paperout` / `paperland`、`amb{kind,t1}` 环境床、`ride{t1,v}` 车轮区间、`vo{id}` 人声（`style-dna/risograph.md:199-213`）。
- **时间线契约**：`film.js` 是**唯一时间真相**——`DUR` / `SHOTS` / `EV` / `KICKS` / `plates(t)` 全从它导出；字幕区间由 `setLines` 与 `tools/subs.py` 用**同一规则**算出，`t1 = min(下一句起点 − 0.05, max(t + 语音时长 + 0.7, t + 1.8), 36)`（`film.js:8-33`、`tools/subs.py:8`）。改时间只改一处。
- **新增主体怎么接入**：用分版浓度画（普通绘制 = 挖空，`over()` = 叠印）；角色必须包在 `layer(fn, halo)` 里以获得纸白描边。**新增一块版** = 在 `INK` 里给一个专色 + 在 shader 里占一个通道（R/G/B）+ 给它一个网角。一套骨骼用 **2 骨 IK** 出所有姿势（`draw.js:60-83`）。**新增一个镜头** = 在 `SHOTS` 加一行 + 在 `SHOT` 对象里加一个绘制函数（`film.js:9-12,69-292`）。
- **换主题时要改哪些文件**：① `demo/lines.json`（旁白文案，5 句以内短句）；② `demo/film.js` 的 `SHOTS` / `EV` / `KICKS` / `DUR` 与各 `SHOT.*` 绘制函数（叙事结构与时间线）；③ `demo/rider.js` / `scenes.js` / `scenes2.js`（主体与场景，全部改成新主题的分版浓度画法）；④ `demo/riso.js` 的 `INK` / `PAPER`（换墨色，2–3 块）；⑤ `demo/music/score.py`（换配乐，但保留「每块新版进一件乐器」的分层逻辑）；⑥ `demo/mix.py` 的拟音映射（把「机器拟音」换成新主题的标志性拟音）。**不可换**的三件事：分版浓度画布（通道 = 版）、叠印相乘混色、套色错位 + 网点。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里能生效的参数是 `palette`（bg `#F6F1E6` / bg2 `#0078BF` / fg `#3D5588` / accent `#FF48B0`）、`bgRecipe.texture = halftone`、`subtitle`（DengXian / 0.04 / marginV 0.145 / marginL 0.06 / 无描边 / 加粗 / 居中）、`title.fontSizeFactor 0.09`、`overlay.accentRule = true`、`motion.subtitleFadeIn = 0` + `chapterTransition = cut`。**注意**：模板通路拿不到 WebGL2 分版印刷 shader，叠印与套色错位会丢失，只能靠 `halftone` 纹理近似——走 dub 通路时本风格的还原度会明显低于走 `demo/build.sh`。

## 11. 当前短板与避坑要点

### 已知缺陷
- **字体回退**：样本字幕用 Jost 500（42 px）、片名用 Bricolage Grotesque 800（190 px），**本机两套都没有**；dub 通路回退到 DengXian（`lib/dub-styles.json#risograph` notes）。片名的「Riso 双印」重黑体气质在模板通路里会掉一半。
- **字幕字色偏离样本**：样本字幕印在蓝版上是 `#0078BF`，dub 通路为满足对比度 ≥4.5 改成 `#3D5588`（同风格第三套墨组的 Federal Blue）。这是**有意修正**，但确实与成片抽帧（f05/f19/f21 的蓝版字）不完全一致。
- **部分镜头违反「头压在最平的色块上」**：f09 骑车人叠在带窗格与门廊的立面上、f13 叠在鸽群与绿地上，主体与网点/窗格打架，剪影读起来比样本吵。
- **响度略偏**：实测 `−14.5 LUFS`（目标 `−14`，偏 0.5 LU，可接受）；但 `LRA 5.4 LU` 远低于 loudnorm 目标 11 LU，说明全片动态范围比设定窄——静音小节与满乐队之间的落差被 loudnorm 的线性增益压平了一些。
- **成片真峰值超交付线 0.44 dB（本次新补记）**：真峰值 **−0.76 dBTP**（`loudnorm` `input_tp`，4× 过采样；`STYLE.md` 未声明更严上限，按项目线 −1.2 dBTP 判）。真峰值为负 ⇒ **未削波**，属『仅超线』。根因在下游 AAC 编码余量——本风格副本 `tools/mux.sh` 是 core 版副本，其 loudnorm 目标仍写死 `TP=-1.2`（`tools/mux.sh:3,5,9`），未采用 core 的 `LN_TP=-1.7`；按 AGENT-BRIEF 取 −2 档后**减半 = −1**（项目级既有缺陷，非本风格音频链所致），`audio 19→18`（理由见 `_distill.json.audioScoreBasis`）。注意 `astats` 采样峰值 −1.107324 比真峰值低 0.35 dB，只看它会把这条判成达标。（★ 2026-10-05 复测当前入库成片 `astats` 采样峰值 = **−3.106276 dBFS**；原记 −1.107324 属重渲前版本。） ★ **2026-10-03 已修**：成片已用 `scripts/fix-truepeak.mjs` 音频重混（`-c:v copy`，视频流逐字节未变、帧数与时长不变），真峰值 −0.76 dBTP → **−1.96 dBTP**，已在 −1.2 dBTP 交付线内；音频评分回补 +1（见第 10 节）。
  ★ 2026-10-04 多比例重渲后复测（2026-10-05）：当前入库成片真峰值 **−3.11 dBTP**（`loudnorm input_tp`）——−1.96 属重渲前版本。
- **`-tune grain` 在 GPU 路径上不生效**：回灌后的 `tools/mux.sh` 在 `LEMO_VENC=h264_nvenc` 分支用 `-cq 20`，**不带 `-tune grain`**（那是 libx264 的选项）；只有回退到 libx264 时才用 `crf 16 -tune grain`。也就是说 GPU 编码时网点/墨粒的保真度依赖 `-cq 20` 的高码率，而非 grain 调优。
- **`-tune grain` 之外的编码代价**：`DEMO.md` Build notes 记录，逐帧套色抖动 + 逐帧走纸条纹会把 x264 推到 900 MB；改成「每镜头固定偏移 + 重音 kick + 切口换纸噪」后 crf 16 `-tune grain` 约 280 MB。本次成片 70.6 MB 是因为走的是 nvenc。
- **字幕底衬色为回退值**：目前用风格自身地色/辅色替代（回退原因见第 5 节）；若要完全对齐 demo，需先统一 `palette.subtitle` 与 demo 的 `textColor`。

- **`demo/tools/mux.sh` 原先把编码器硬写成 `libx264`**（CPU 编码，违反「合成渲染一律走本地 GPU」的硬规则），**且缺「音频比画面短时补静音」**——音频比画面短时 `-shortest` 会切掉最后一帧，编排器的守卫会判 `MUX_FAIL 帧数不符`（同类问题实测发生在 backrooms：渲染 1433 / 成片 1432）。
- **2026-10-03 的最小外科回灌**：用 `D:/lemo-tools/scripts/patch-style-mux.mjs` 把 `core/render/mux.sh` 的这两处修好回灌到本 demo 的副本（`patch-style-mux.mjs:37-47` 里 `risograph` 条目为 `{slug:'risograph', crf:16, tune:true}`）。**只换了两件事**：① 编码器跟随 `LEMO_VENC`（`h264_nvenc` 走 GPU，否则回退 libx264）；② 音频短于画面时 `apad=whole_dur = 画面长度 + 1/24 s`（多补一帧，让 `-shortest` 切不到末帧）。**risograph 自己的 CRF 16 + `-tune grain` 完整保留**，没有动。补丁脚本是**幂等**的（先 `normalize()` 还原再打），并且要求同时写 WSL 与 Windows 两份、各自 `sh -n` 语法检查通过。

- **挖空描边层忘了复制画布变换**：缩放镜头会把主体画错尺度（`STYLE.md:104`、`draw.js:12`）。
- **主色里不含第一块版**：单色帧里会出现一个「飘着的头」——毛衣和裤子必须都含蓝版（`DEMO.md` 坑）。
