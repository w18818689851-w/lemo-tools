## 1. 风格说明

**是什么**：一部「金色细线在暖黑漆面上自己画出来」的 1930 年代海报电影。画面由**描金关键线（gline）+ 硬边喷枪体积（airbrush）**构成，一切围绕一条**垂直中轴**组织：太阳纹是背景、阶梯拱是画框、仪表盘是进度条、灯泡招牌是一次揭示。运动是**机械且对称**的——东西从中轴向两侧展开、门沿接缝裂开、灯按点数一盏盏亮起（`STYLE.md:6-10`）。

**不是什么**（最容易做错的邻居风格）：不是金箔幻灯片（东西必须会动、有体积）、不是**新艺术 Art Nouveau**（没有鞭形曲线和花卉）、不是平面矢量海报（体积必须喷绘并带金边）、也不是 60 年代间谍片头（没有平涂色块上的人物剪影）（`STYLE.md:10`）。

**什么时候用它**：需要「隆重、精确、有仪式感、有刻度」的内容——产品/品牌发布、周年庆典、邀请函、酒店与展会、城市与建筑题材。demo 是一封赶在午夜前送达的信（`style.json:9`）。

**一句话内核**：把一个「有截止时刻的盛事」翻译成「计数的光 + 门槛之门 + 承载情节的仪表盘」。

**边界**：这个风格**撑不起**内心独白、抒情与抽象概念；也不适合快节奏碎片化口播、现代网络腔、或需要写实人物/自然风光的题材。它只讲能被画成金色图形的东西（`style-dna/art-deco.md:50-54`）。

## 2. 画面构图

- **镜头数与画幅**：demo 共 1401 帧 / 24fps（≈58.4s），原生 **1920×1080 / 16:9**（`_distill/logs/art-deco.log:38,81`）；**已适配 9:16**（`FILM_META.aspects = ['16:9','9:16']`，`demo/film.js:20`）。
- **主体位置与占比**：**中轴是构图里唯一不能动的东西**（`STYLE.md:45`）。主角常在中轴或近中轴，情绪峰值时占 ≥1/3 画幅高度（`STYLE.md:63`）。
- **负空间 / 留白**：暖黑漆面本身就是负空间，靠金线与辉光「刻」出形体；画面通常上 1/3 为建筑/招牌、下 1/3 为地板透视或字幕卡。
- **图层叠放顺序**（从底到顶）：暖黑底（`#0d0b09`）→ 太阳纹/阶梯拱等结构母题 → 建筑与场景（真一点/两点透视）→ 人物 → 描金线与光扫 → 字幕卡 → 颗粒。
- **安全区**：字幕卡中心 y≈990px（`film.js:118-129` 的 cy 990），卡宽上限 1500px，压在画面下方；主体不进入最下 12% 以免被卡遮。
- **本风格**不能**出现的构图**：中轴漂移的斜构图；无来由的运镜；用平面缩放冒充推拉（透视必须真的变，`STYLE.md:19`）。

**在 9:16（产品默认 1080×1920）下的表现**：本风格**已适配 9:16**——`FILM_META.aspects = ['16:9','9:16']`（`demo/film.js:20`），`frame.js` 导出 `NATIVE`（`frame.js:15`）与 `setFrame(w,h)`（`frame.js:17`），由 `main.js` 按视口尺寸调用（`main.js:7-8`）派生 `W/H/FX/FY/S = min(fx,fy)`（`frame.js:18`）。★ 本片的「版面」是**满幅 16:9 画面、没有画框/片门**（对比 silent-film 的 4:3 片门）：布景是真一点/两点透视的房间（`engine/cam.js` 的针孔相机 + `shots_kitchen.js` 与 `scenes/stairs.js` 各自的像素级投影器），原生视场下**已经竖直填满画面**、中景以上没有可露出的几何——所以 9:16 的正解不是「重排」，而是**整幅等比装入 + 同色留白**：`renderFilm` 先把整帧铺成影院黑 `#050403`（`demo/film.js:107`），再 `clip` 到设计帧矩形（`demo/film.js:112`）、施加 `transform(S,0,0,S, bx, by)`（`demo/film.js:113`）——**所有绘制代码仍在 1920×1080 坐标系里写，一行未改**，所以**中轴对称**（`STYLE.md:45`「中轴是构图里唯一不能动的东西」）**逐像素保留**。字幕是**当前帧的家什**（画在变换之外）：中心 x 随帧宽、基线 `990 × FY`、字号 `40 × S`、卡宽 `1500 × S`（`demo/film.js:145-151`）。1080×1920 实测（`S = 0.5625`）：整幅 **1080×607.5 居中**（上下各 656 px 影院黑，与画面边缘的暗角同色、接得上），**不裁切、不变形，中轴与全部金线/招牌/塔身完整**；字幕**完整可见、未被裁**（实测 t=8.76「Good evening, America! …」与 t=49.62「Right on time. Happy New Year…」两句整句可读、居中落在画面下方）。与「16:9 中心裁切」的 SSIM 实测 **0.50 / 0.57 / 0.57**（`≈1` 才说明是裁切）⇒ 确为**等比装入**而非裁切。**代价**：16:9 画面在竖屏上只占画面中部约 **31.6%** 面积，上下大片影院黑（本风格底色本来就是暖黑，留白接得住）。

## 3. 配色体系

|---|---|---|---|
| 底（暖黑漆面） | `#0d0b09` | 全片地面，最深 `#060504` | `DEMO.md:59` · `deco.js:16-31` |
| 底（夜空） | `#0a0e16` → 地平线祖母绿 `#10231f` | 屋顶/城市夜空 | `DEMO.md:59` |

| 强调（唯一色） | burgundy `#8E1B2E` | 主角制服——全片唯一大饱和面 | `DEMO.md:61` |
| 宝石副色 | emerald `#1D6B57` | 扇形、门板、夜 | `DEMO.md:61` |
| 纸/手套/光 | ivory `#F2E8D5` | 信、手套、地毯 | `DEMO.md:61` |
| 字幕 | 象牙白 `#F2E8D5`（产品通路取 `#FFFFFF`） | 字幕卡文字 | `STYLE.md:34` · `dub-styles.json#art-deco` |
| 字幕底 | 漆面黑 ~88%（`#B3000000` 叠底） | 字幕卡底条 | `STYLE.md:34` · `dub-styles.json#art-deco` |

- **明度 / 对比规则**：三常量——暖黑地、金线金属、象牙白；**一个饱和强调色只留给主角/故事追随的那件东西**，它是唯一大饱和面，任何宽景里眼睛都能找到它；冷宝石色只做次级面、面积绝不与强调色竞争（`STYLE.md:22-28`）。
- **禁止出现的颜色**：中性灰黑（必须是暖黑）、三位 hex（会破坏调色，曾把祖母绿扇子变蓝紫，`DEMO.md:97`）；禁止第二个大饱和色相。
- **同一画面最多几个色相**：金 + 暖黑 + 象牙白为基，最多再进 **1 个**强调色相（+可选 1 个宝石副色，面积很小）。

## 4. 转场规则

- **镜头之间怎么切**：全部用**机械/建筑本身**的转场——**对称裂开**（出画帧变两片铰在外缘的门扇，从接缝甩开）、**旋转门擦除**（玻璃翼扫过）、**门扇合拢**（电梯门在实时画面上滑合落成片尾卡）、**形状匹配剪辑**（圆→圆、射线→射线）（`STYLE.md:47-63`、`film.js:41-89`）。
- **有没有叠化 / 闪白 / 擦除 / 定格**：有擦除（旋转门）与裂开，**绝无通用溶解/淡入淡出**（`STYLE.md:63`）。
- **硬切点怎么定**：挂在 116 BPM 网格上（1 拍=0.5172s，1 小节=2.069s），转场落在命名同步点 `T`（`timeline.js:35-43`）。
- **转场时长与缓动**：门扇展开用 **eio（ease-in-out）缓动，约 0.35–0.5s**；灯泡点火带 ~1.6× 过冲、约 0.18s 落定（`STYLE.md:42`、`style-dna/art-deco.md:87`）。
- **绝对不要的转场**：通用溶解/淡入淡出；无来由的运镜；让中轴漂移的滑动（`STYLE.md:63`）。

| 颜色 / 描边 / 阴影 | 象牙白 `#F2E8D5`；**双层金关键线**做卡框；无黑描边（`STYLE.md:34`） |
| 位置 / 安全边距 | 居中，卡中心 y≈990px；产品通路 `marginVFactor` 0.14537、`marginLFactor` 0.06019（`film.js:118-129`、`dub-styles.json#art-deco`） |
| 单行字数上限 / 最多行数 | 卡宽上限 1500px，**最多两行**；每行口播 ≤ 4.5s（`style-dna/art-deco.md:16`） |
| 出现与消失方式 | **从中心展开**（与标题、转场同一套系统）：提前 0.05s 上、滞后 0.25s 下；停留 `max(1.8s, 语音时长+0.6s)`（`style-dna/art-deco.md:34`） |

- **字幕与旁白的关系**：字幕卡带**扬声器图标**（播音员=金色丝带麦，主角=酒红药丸帽），一卡一说话人（`DEMO.md:68`）。旁白是 1930 年代电台播音员腔，数字（楼层/时钟/年份）自己承担情节（`STYLE.md:35`）。
- **本风格特有的字幕禁忌**：不用黑描边、不用现代无衬线粗口播字、不用逐字弹出；卡必须是「阶梯端头 + 双金线」的漆面条，不能是普通圆角矩形。

**文案+风格通路的底衬落地**：STYLE.md §4 声明「Subtitle card: a lacquer bar (~88 % black) with stepped ends」，但「文案+风格」通路原先只走 `BorderStyle=1`（只画描边与阴影、不画底盒；盒填充字段 `OutlineColour` 被当作描边色用），这层底衬从未画出来。现已切到 `BorderStyle=3`（不透明底盒：盒填充色改用 `OutlineColour`、`Outline` 变为盒内边距，`BackColour` 仍只作阴影色——box 模式下 `Shadow=0`，故该阴影不绘制），渲染参数固定为 `BorderStyle=3`、盒内边距 `Outline=10`（1080 高基准）、`Shadow=0`、盒填充色 `OutlineColour=#1F060504`（AARRGGBB，落盘 ASS 为 `&H1F040506`）。`Shadow=0`：`BorderStyle=3` 下 ASS 的阴影是一份与底盒几乎完全重叠的整盒副本，会把半透明底衬二次压暗（实测 `hd-2d` 的对比度由 6.00 掉到 3.18）；置 0 后底衬的不透明度如实生效，也与检查器的单层合成模型一致。该色值取自 demo 的 band 真实实现（demo band rgba(6,5,4,0.88)）；字色 #FFFFFF 与该底衬的 WCAG 对比度 **20.25**。

## 6. BGM / 音效特征

- **配乐**：**1920–30 年代交响爵士**（不是 60 年代大乐队）。乐器：步态/音乐会钢琴、单簧管（颤音、变速重采样长滑音）、弦乐（震音/上行冲刺/拨弦）、弱音小号、长号与萨克斯组、行走拨弦贝斯、鼓刷→鼓棒、管钟、竖琴滑音、班卓琴、木琴、钢片琴。节奏型：狐步 / 查尔斯顿 / 探戈 / 火炬歌谣 / 新闻片号角（`STYLE.md:67`）。
- **拟音（foley）清单**：黄铜咔哒、青铜牌当啷+铁链、铁楼梯踏步、大理石鞋跟、银托盘、木门+弹簧吱呀、纸的扑动、刀闸「chunk」+灯丝嗡鸣、继电器滴答、电梯叮、香槟塞；**每个点亮的字母 = 一次刀闸 chunk + 灯丝嗡鸣**（`DEMO.md:52`）。
- **旁白处理**：播音员走**五个声学空间**（街角喇叭→桌上收音机→楼梯间 PA→厨房收音机→现场麦），让观众听见主角在靠近声源；乐队在 30 楼做**距离自动化**低通（街上 2.5kHz → 门厅 1.2kHz → 爬楼逐步打开 → 屋顶全频且干）（`DEMO.md:50-51`、`mix.py:29-48`）。
- **响度目标**：`−14 LUFS`（实测 −14.0 LUFS / LRA 3.6 LU，`_distill/logs/art-deco.log:95-97`）；**真峰值上限**：`−1.2 dBTP`（mux.sh 交付判据）。本次成片**真峰值 −1.17 dBTP**（口径 = `loudnorm` 的 `input_tp`，4× 过采样）——与 −1.2 dBTP 交付线**擦线、超 0.03 dB**（测量/编码噪声量级，故 mux 未告警）。日志里的 `Peak: -1.2 dBFS`（ebur128 1 位小数）与此一致；而 `log:98` 的 `Peak level dB: -1.388914` 是 `astats` 的**采样峰值**、不是真峰值，**不能**当作真峰值引用。 ★ **2026-10-03 已修**：成片已用 `scripts/fix-truepeak.mjs` 音频重混（`-c:v copy`，视频流逐字节未变），真峰值 −1.17 dBTP → **−1.54 dBTP**（★ 2026-10-05 重渲后实测）、已在 −1.2 dBTP 交付线内（达标）；原 −1.17 dBTP 记录保留为历史。
- **静音策略**：静默是「最重一声之前的清场」——钟敲 XII 后只留风声与飘落的信，下一个声音就是全片最重要的一声（第一记钟）；第 12 记钟后留一拍屏息再进 tutti（`STYLE.md:71`、`DEMO.md:53`）。

## 7. 素材偏好

- **需要什么素材**：全部由引擎程序化绘制，**不需要外部实拍/图库**。需要：剧本节拍表（每拍标「门槛/截止时刻/计数揭示/被解锁之物」）、台词 `lines.json`、时间网格 `timeline.js`、调色板、招牌文本、数字道具（楼层号/时钟/年份徽章）（`style-dna/art-deco.md:172-181`）。
- **不需要什么素材**：不需要真实海报版式、真实建筑、角色、字体设计或旋律（**参考只借语法，不复制**，`STYLE.md:4`）。
- **取景 / 质感 / 比例偏好**：真一点透视（mode-7 地板）+ 针孔相机两点透视；金线要「暗刻线+金主线+细高光」三层，体积要「硬边+喷绘+受光侧金边」。
- **可替代方案**（缺素材时怎么降级而不破风格）：没有角色时走「无人建筑 + 仪表盘承载情节」；没有原创配乐时至少保住「计数网格」——每个视觉揭示落在拍点上，并保留一层材料拟音（刀闸/继电器/钟）。

## 8. 镜头节奏

| 项 | 值 |
|---|---|
| 单镜时长 | 由 `timeline.js` 的 `SEC` 段表驱动；demo 约 10 个段落，从开场 3s 钩子到 4.4s 片尾卡 |
| 全片时长 | demo **58.4s**（`style.json:17`）；用例区间 30–60s（`style-dna/art-deco.md:35`） |
| 镜头数 | 1401 帧 @24fps（`log:38,81`）；`SHOTS` 表定义逐镜 |
| 信息投放节拍 | 116 BPM（1 拍 0.5172s）；楼梯段 16 拍加速到 138 BPM；STRIKE1=35.86s 起 12 声钟每声 1 拍（`timeline.js:3-16`） |

- **加速 / 减速点**：楼梯（Charleston）是加速段；高潮后 tutti 是全曲第一次完整奏出主题，是情绪顶点；片尾卡放慢。
- **留白与静音的位置**：钟敲 XII 后（`OUT OF ORDER` 反应后两次滴答、12 记钟后一拍屏息），静默总落在**最重要声音之前**（`DEMO.md:53`）。
- **人物 vs 镜头帧率**：人物**走二拍（12fps）**、镜头/光/灯泡/描线走一拍（24fps）；镜头若走二拍会读成卡顿（`STYLE.md:39`）。

## 10. 编排规则

- **内容文件字段契约**（`content_fields`）：`lines.json` 每条 `{id, text, voice, speed, pitch?, sub?, asr?}`；单行口播 ≤4.5s；人声分 `radio`（`bm_fable`，speed 0.96–1.02）与 `boy`（`am_puck`，speed 0.86、pitch +4）两类（`style-dna/art-deco.md:96`、`lines.json`）。
- **事件词汇表**：`shot{name}`（镜头切换，供声音分层）、`vo{id}`（人声，mix.py 从 `voices/<id>.wav` 读）；动作拟音按材料（黄铜/青铜/铁/银/木/纸/刀闸/继电器/电梯叮/烟花哨）由 `mix.py` 按 `T` 的命名时刻生成（`style-dna/art-deco.md:99`）。
- **时间线契约**：`timeline.js` 导出 `BPM/B/BAR/K_BPM`、段表 `SEC`、命名同步点 `T`、台词起点 `LINES`；`film.js` 导出 `renderFilm(g,t,Q)`、`DUR`、`SHOTS`（`[t0,t1,fn,name]`）、`TR`、`subs()`、`events()`；页面契约 `window.READY / window.render(t) / window.DUR / window.EV`（`style-dna/art-deco.md:98`）。
- **新增主体怎么接入**：任意路径走 `D.drawShape(g, pts, {color, halo, trail, glints, part})`（喷绘金填充或 `color` 单色 + 金关键线 + 可选太阳纹光晕/速度线尾/闪光）；母题用 `sunburst / archFrame / fan / fishScale / chevrons / sparkle / speedLines`；招牌用 `B.buildSign(text)` → `B.drawSign(g, sign, x, y, scale, {lit})`；镜头用 `cam.js` 的 `makeCam` + `cardTransform`（`DEMO.md:103-120`）。
- **换主题时要改哪些文件**：① `demo/timeline.js`（BPM/段表/同步点/台词起点）；② `demo/lines.json`（文案+音色）；③ `demo/film.js` 的 `SHOTS/TR/subs`（镜头与转场编排）；④ `demo/scenes/*`（场景）；⑤ `demo/chars.js`（人物，或删掉走无人版）；⑥ `music/score.py` 与 `mix.py` 的 cue 表；⑦ 调色板里唯一的强调色。**引擎（`engine/deco.js`/`type.js`/`bulbs.js`/`cam.js`）不用改**。
- **与 `dub.mjs` 通路的关系**：本风格在「文案+风格」通路里能生效的参数是 `palette`（bg `#0d0b09` / accent `#c9a24b` / 字幕底 `#B3000000`）、`bgRecipe`（`#0d0b09`→`#0a0e16` 渐变 + vignette 0.35）、`subtitle`（`fontSizeFactor` 0.03796、`marginVFactor` 0.14537、bold）、`title`（`fontSizeFactor` 0.1）、`overlay.accentRule=true`；`chapterCards/lowerThird/progressBar` 均关闭（`dub-styles.json#art-deco`）。**注意该条为 `derived:true` 派生值**，不是逐行手抽。**字体口径**：通路按 `lib/dub-styles.json._notes[5]` 的约定把 `subtitle.fontFamily` 填成**本机真实存在的字体** —— 本条是 `DengXian`（等线）；本节第 5 行点名的 Josefin Sans / Limelight / Poiret One / Italiana **本机都没有**（OFL，只在 `styles/art-deco/demo/fonts/` 里），故字形观感与样片**有差**（等线是几何无衬线，接近但不等于 Josefin Sans）。

- 本风格**全程序化绘制，无外部素材缺口**；唯一缺口是「新主题需要的原创交响爵士配乐」——若无法产出原创谱，需退化为通用爵士 bed，会削弱「音乐就是情节」这一核心。

### 能力限制

- 鱼鳞母题易读成砖墙，必须逐行下移半圆、叠压上一行、再加内弧（`STYLE.md:91`）。

### 踩过的坑（本机实测）

- 门扇压在「平涂内景」上会读成空白帧——现在只画门扇、合在实时画面上（`DEMO.md:94`）。
