## 1. 风格说明

**是什么**：一个从背后打光的**层叠纸雕灯箱**（纸雕灯 / shadow box lightbox）。6–9 张剪纸卡纸叠在一个浅盒子里（腔体 `0.56 × 0.33 m`、深 `0.16 m`），暖光透纸，窗和月亮从孔洞里烧出来，每一层把柔和影子投到后面那一层。屏幕上的一切只能是三样之一：① 一个**纸层**（平剪的纸、单色、纤维纹、顶边一道暖光边、底边一道暗带；后层亮而半透、前层暗而不透——这条明度阶梯就是深度）；② **透纸的光**（暖、浑浊的半透，靠近光源最强；窗、灯笼、光带是孔 / 自发光窗，会烧、会 bloom）；③ **影子**（顶光从每层投下柔影到后面的层上——这是「真纸在真盒子里」的关键，永远不要关掉，`STYLE.md:12`）。**盒子就是画框；镜头是灯里的一支微距镜头**（`STYLE.md:3`）。每个镜头都是**一个实体物件**，不是一张平面图形。

**不是什么**（最容易做错的邻居风格）：不是**平面剪纸动画**（这里有深度、背光、投影）；不是**皮影戏**（没有单屏、没有杆、没有染色驴皮——本库另有 `shadow-puppet` 风格，两者不可混）；不是**红纸窗花**（本库另有 `papercut-red`，那是正面受光的红纸剪贴，没有背光透射与柔影）；不是 **3D 立体模型**（每个元素都是平行于盒前面的平面纸，纵深靠明度阶梯与虚焦，不靠透视体块）；也不是定格动画（纸不会弯折、不会挤压变形）。

**什么时候用它**：节庆 / 礼物品牌 / 文化故事（`style.json` uses: Festivals / Gift brands / Cultural stories）。最适合讲**「两个地方 + 一个共享的光」**——月亮、灯塔、一扇窗、一颗卫星（`DEMO.md:27`）。团圆与思念、迁徙与邮路、一条河的历史、一件被留着的物件，都是这个媒介的原生题材。

**一句话内核**：**盒子就是世界，光是唯一的主角——明度阶梯即深度，柔影即真实，灯亮即故事开始。**

**边界**：撑不起快节奏喜剧与信息密集的解说（微距镜头 + 慢推 + 烧入字幕，节奏天然是「一个说书人坐在桌边」）；撑不起需要**正面脸部表演**的题材（人物是**没有脸的黑色剪影**，只有少数带关节的部件，情绪靠头角度与身体倾斜，`DEMO.md:20`）；撑不起明亮的日间实景（光是暖的，是除一个强调色之外唯一饱和的元素）；也撑不起大量文字信息（画面里的字必须是**纸**，而且**同一批字不许既做纸又做字幕**，`STYLE.md:40`）。

## 2. 画面构图

- **镜头数与画幅**：样本 **19 段镜头**（`src/shots/index.js:21-45` 的 `SHOTS()` 实际列出 19 条：S01–S18 + S15b；`out/timeline.json` 的 `P` 表也是 19 条）。注意：`style-dna/paper-lantern.md:280` 写「切成 20 段」，与源码实际条数不符，**以源码 19 段为准**。输出 **1920×1080（16:9）**，`main.js:31,34` 把 renderer 与 Pipe 都硬写在 1920×1080。**★ 2026-10-04 已支持多比例**：能力声明落在 `demo/film.js`（`FILM_META.aspects = ['16:9','9:16','3:4','4:3','1:1']`），多比例靠 `demo/index.html` 的**页面外壳等比装入**实现（见本节末段）。
- **主体位置与占比**：主体在**盒内**，所以构图的第一条是「盒边完全出画」——盒内镜头里木框不许露边，外景镜头里盒边必须清晰入画，**绝不半在**（`STYLE.md:67`）。故事层永远在焦点上，占画面高度约 **55–70%**；f02（≈8.5 s，S01 夜村）里月亮占画面高约 **28%**、山脊带占下 1/3、村舍窗光是一条 1/10 高的暖线；f15（≈71.5 s，S11 城市）里天际线占下 55%、月亮只占约 **3%**（「月亮却很远」）。**主体占比随情绪走，但永远留出天**。
- **负空间 / 留白**：留白主要给**天空与月光**。f21/f22（≈104.5 / 108.5 s，S17 苏轼）上半幅几乎全空，只有一轮满月、几朵祥云和一条山脊；f14（≈68 s，S10 火车侧视）下半幅是一条亮窗列车、上半幅是深蓝天与山影。**「空天」本身就是这个风格的停顿**——不要用元素把天填满。
- **图层叠放顺序**（从底到顶，夜外景 S01 实测，`DEMO.md:68`）：天渐变（不受光 `skyPanel` + 星点，z −.135，`#0a1330 → #172a58 → #2e4478 → #43598a`）→ 月盘 + 加色光晕（z −.125，`#fffaf0 / #fff0cf / #f7dca4`）→ 祥云（z −.112，`#c3cbe8`，`trans .9`）→ 远喀斯特山（z −.098，`#6a86c2`，`trans .7`）→ 中山（z −.080，`#3f5a92`，`trans .45`）→ 村舍 + 自发光窗（z −.062，墙 `#5a70a6` / 顶 `#1b284f` / 窗光 `#ffb862`，`trans .25`）→ 河 + 月影（z −.046，`#22325e` / 影 `#e9cf96`，`trans .3`）→ 桂花树 + 桥 + 自发光花（z −.030，`#17224a` / 花 `#d9a24a`，`trans .12`）→ 前景岸 + 芦苇（z −.014，`#0e1532`，`trans .05`）→ 挂灯笼（z +.004，`#0d1328` / 光 `#ff8a48`，`trans .05`）。**这条 `trans` 从 .9 降到 .05 的阶梯就是深度本身**，不许打破。
- **安全区**（字幕 / 主体 / 边缘）：字幕是**烧入的 DOM 行**，居中，`bottom: 74px`（画面高 **6.85%**），左右各留约 7% 内边距（`index.html:10`；`dub-styles.json` 的 `marginLFactor 0.07037`）。主体不许压到字幕行——样本里字幕永远落在最暗的底部带（f02 的河岸、f15 的楼脚、f17 的桌面），**这是刻意的**：底部带被压暗到能托住一行暖白字。
- **本风格不能出现的构图**：① 盒边半在画内半在画外（`STYLE.md:67`）；② 比腔体大的满幅纸层（`demo` 用 `.558 × .328`，超了就会在外景镜头里戳穿木框，`DEMO.md:63`）；③ 把前层做成浅色（会把盒子压平，`STYLE.md:29`）；④ 用数字变焦或甩镜（`STYLE.md:67`）；⑤ 平面剪贴式的「正对着看一张图」——本风格每个镜头都必须读得出**层与层之间的空气**。

**★ 2026-10-04：已支持多比例（页面外壳等比装入）**。本风格是 three.js 管线 + 19 个镜头模块的绝对像素构图，逐处改成 `layout(W, H)` 代价过高、且漏一处会**静默错位**，所以采用库侧 `MAINTAINING.md` 的「页面外壳等比装入」范式：**影片本体一字未改**（仍按固定设计帧 1920×1080 画，`main.js:31,34` 的 renderer / Pipe 尺寸不变），只在 `demo/index.html` 里加一层外壳——当前帧（= 渲染视口）不是 1920×1080 时，把**整张设计帧**（含 `#sub` / `#credit` 两个 DOM 叠加层）等比装入（contain）并居中，留边露出本风格的**暖夜底色 `#0a1330`**（取自 palette 夜空最深一段；夜色调，不是纯黑）。`FILM_META.aspects = ['16:9','9:16','3:4','4:3','1:1']`。
- **16:9 逐字节不变**：1920×1080 时外壳**完全不碰 DOM**（不建包装层、不设 transform、不改底色）；改造前后三个时间点（18.27 / 60.90 / 103.53 s）**md5 逐字节相同**（跨进程，JPEG 亦一致 ⇒ 后处理确定）。
- **9:16 是装入不是裁切**：整幅画面（含居中字幕、片名纸带、两扇窗）都在框内。实测 SSIM：9:16 vs **16:9 中心裁切** = 0.570 / 0.613 / 0.700（三个时间点，**明显 < 1**）；9:16 vs **理想等比装入**（pad 色 = 留边色 `#0a1330`）= 0.988 / 0.994 / 0.994（**接近 1**）。作为对照，同一帧改用**黑色 pad** 的理想装入只得 **0.538** —— 留边占竖屏面积 68%，色差会主导 SSIM，所以参照图的 pad 色必须等于实现的留边色。
- **代价（如实说）**：① **是等比装入、不是竖幅重排**——竖屏下有效画面只占 **1080×607**（约占框高 32%），上下各 656 px 留边；纸纤维纹与柔影按紧轴缩小，细部可能摩尔纹。② **全屏层留在设计框内**——本风格的 bloom / 暗角 / 柔影只作用于设计帧，**不铺进留边**（留边是纯色、无颗粒）。③ 留边色是暖夜靛蓝 `#0a1330`，与多数夜景镜头的天 / 地同色系，接缝不明显；但暖内景镜头（木桌 / 堂屋）的上下留边会有可见的冷色对比。若将来要让竖屏有效画面提升到整屏，需要**重排**一版真正的竖幅构图（天空在上、前层在下，月亮移到中轴），而不是装入。

- **明度 / 对比规则**：**后层亮而半透、前层暗而不透**——这条阶梯就是深度，破坏它（把前层做浅）会把盒子压平（`STYLE.md:29`）。背光 shader 的 `trans` 每层从约 **.9（远）降到约 .05（前）**；亮度公式是 `emissive += albedo × lightCol × trans × lit × falloff × (base + cloud)`，`fall = mix(.22, 1, exp(−d²/R²))` 围绕每个镜头的灯点（通常是月亮）。**光永远是暖的（琥珀到金），而且是除一个强调色之外唯一的饱和元素**（`STYLE.md:31`）。**每一叠只用一种色温**——冷夜 / 暖内景 / 紫城市 / 绿别处，换阶梯就是「换一个地方」（`STYLE.md:30`）。
- **禁止出现的颜色**：冷光（除了天空本身，任何**被灯照亮后仍然冷**的元素都是错的）；第二个强调色（除非故事真的有两面，才允许一面一个）；纯白字幕（成片用的是暖白 `#fbf3e4`，纯白会从暖纸里跳出来）。
- **同一画面最多几个色相**：**一个温度 + 一个强调色**。实测成片的色相集合极小：夜空是靛蓝族四段，窗光是暖琥珀，再加一个印泥红（f03 的「中秋」印、f06 的卷轴印）。f15 的城市虽然窗光极密，但仍收在暖黄—近白两种之内，底色是单一紫（`#2a2456`）。
- **质感 / 颗粒规则（本风格是「纸艺」，这条与配色同级重要）**：本风格的颗粒**只有一层，而且在渲染期**——它是每张纸的**纤维纹**：`paper.js` 的 `GRAIN` 贴图（512²、α .9、用 `source-atop` 叠在每张纸层的画布上，`DEMO.md:83`、`style-dna/paper-lantern.md:26`），加上顶边暖光边 `rgba(255,236,200,.35)` 与底边暗影 `rgba(0,0,0,.28)`（各偏移 3 px）。**后期不要再叠一层成片颗粒**：本风格的构建链三处都写死「无 grain」——`DEMO.md:149` 的注释 `# 5. mux: two-pass loudnorm −14 LUFS, 30 fps, no grain`、`DEMO.md:150` 的 mux 命令第 5 参传 `0`、`style-dna/paper-lantern.md:219` 的 `sh core/render/mux.sh … 30 0  # 两遍 loudnorm −14 LUFS，30fps，无 grain`。理由：纸的质感必须来自**纸本身**（纤维、受光边、投影），一旦叠上全画面均匀的胶片颗粒，纸就不再读成纸，而读成「拍纸的胶片」——这会直接破坏本风格的媒介幻觉。**本次成片恰恰违反了这一条**（编排器落了 mux 脚本默认的 `grain 2`，见第 11 节）。★ **2026-10-08 更正**：此处「本次成片」指**编排器那条 24 fps 本地副本**的那次 run——该 run 的**参数偏离**（落默认 `grain 2`）属实；但**权威 artifact（已发布影片）无证据支持该扣分**，故第 11 节的 `palette −1` 已于 2026-10-08 **撤销**（详见第 11 节）。

## 4. 转场规则

- **镜头之间怎么切**：**以溶解为主**。`src/shots/index.js` 里 19 段镜头中，**16 段带 `in: { type: 'dissolve', dur }`**；只有 **S03**（`start: L('L04') - .1`）与 **S17**（`start: L('L22') - .6`）**没有 `in` 字段 = 硬切**；S01 是开场，本身从黑起。所以本风格**不是硬切风格**，它是「一直在融」的——只有两处刻意用硬切打断（压月饼那一下、苏轼那句诗起）。
- **有没有叠化 / 闪白 / 擦除 / 定格**：**溶解**（主）、**iris**（从 `center` 起的圆形擦除，`main.js:68` 的 `mode: tr.type === 'iris' ? 1 : 0`，本样本未启用）、**灯关 / 灯开**（灯灭时除房间底噪全部声音掉出，随灯一起回来，`STYLE.md:73`）、**近景祥云幕**（`cloudCurtain(S, .15)`，**定义在 `s17_sushi.js:9`，`s16_mutual.js:67` 与 `s17_sushi.js:63` 各用一次**——注意 `DEMO.md:46` 与 `DEMO.md:105` 对它的出处描述不一致，以源码为准）。**全片没有闪白、没有数字转场、没有定格。**
- **硬切点怎么定**：**镜头起点锚定到台词**，不是锚定到绝对秒数——`shots/index.js` 里写 `start: L('L06') - .5`，而 `L('L06')` 读的是 `C[id].at`（`main.js:22`）。所以**改一句配音的时长，整条时间线自动重排**。S03 之所以硬切，是因为「啪地一压」这一下需要**落在词上**（`DEMO.md:45` 的硬动作落在 whisper 逐词时间）。

## 10. 编排规则

- **内容文件字段契约**：`demo/script.json` 是唯一真值，每行 `{ id, text, rate?, say?, sub? }`（`script.json:1-110`，25 行）。派生数据：`vo/dur.json`（每句时长，键 = id）、`vo/words.json`（whisper 逐词时间戳，`E.word(id, k)` 的 `k` 是 **whisper token 索引，不是字符索引**——whisper 会把「我们」并成一个 token，必须打印出来数，`DEMO.md:53`）。镜头表在 `src/shots/index.js`，每段 `{ id, start, in?, build }`。
- **事件词汇表**：事件是每个镜头的 `s.sfx` 数组（`main.js:26`，本次样本为空 → `events 0`），由 `out/timeline.json`（台词起点）与 `vo/words.json`（逐词时间）驱动 `mix.py` 的 foley。转场词汇是 `in: { type: 'dissolve' | 'iris', dur, center }`。**镜头上下文 `E`** 含 `dur / T0 / C / env / W / cue(id) / cueEnd(id) / word(id, k)`（`main.js:41`）。
- **时间线契约**：`main.js` 是时间线（`GAP` 表 `main.js:15-16` + 台词锚定 `main.js:17-19`）。页面契约：`window.READY` / `window.DUR` / `window.render(t)`（**逐帧确定**）/ `window.CUES` / `window.PLAN` / `window.EV`（`main.js:20,25,26,81`）。`out/timeline.json` 由 `render/cues.mjs` 导出，供 `mix.py` 排 foley 与镜头表复用。**所有模块禁止各写一份时间。**
- **新增主体怎么接入**：一个新的镜头模块必须导出 `build(E) → { S, update(t), post(t), grade(t) }`。每个纸层用 `sheet({ U, w, h, draw, glowDraw?, glow, glowCol, trans, z, x, y, ax, ay, shadow, recv, finish, ppm, bumpDraw? })`（`paper.js:124-139`）——`draw(x, k)` 在**米制空间**作画（原点居中、y 向上），`glowDraw` 画自发光图（**白 = 光、黑 = 遮罩**），`ax/ay` 是关节枢轴。**三条必守**：① `trans` 必须按深度给（后大前小）；② 不该参与柔影的层（片名、前面的灯笼、光弧、幕布）必须**同时**给 `shadow: false` 和 `recv: false`；③ 每个镜头的 `grade()` 省略的键必须回落到 `GRADE0`，不许依赖上一镜的残留值。
- **换主题时要改哪些文件**：① `demo/script.json`（25 行台词，多音字写 `say`、画面内文字写 `sub: false`）；② 配音引擎 `demo/tts_local.py`（本地 Index-TTS，参考音 `voice_09`，逐句速度与 `say` 注音都在 `demo/lines.json`，由 `script.json` 派生）——改台词后要重跑它并重新对齐 `vo/dur.json`；英文场景可改走 `core/tts/tts.py` 的 Kokoro 口径 + `core/tts/asr_check.py`；③ `demo/src/main.js` 的 `GAP` 表（给片名与结尾留节拍，如 `L02: 4.2` / `L25: 5.0`）；④ `demo/src/shots/index.js` 的镜头表（每段 `start` 锚定到 `L('Lxx')`，转场用 `in: { type: 'dissolve', dur: .5–1.2 }`）；⑤ `demo/src/shots/sNN_*.js`（每个镜头一个模块，重写层清单与运动）；⑥ `demo/src/art.js` / `people.js` / `props.js`（母题、剪影、道具——**换主题必须重画纸层**）；⑦ `demo/src/room.js`（真实世界布景，不用就整段去掉）；⑧ `demo/mix.py` 的 foley 映射 + `demo/music/` 的配乐。**可整体换**：主题、地点、人物（或没有人）、明度阶梯、光源、真实世界是否出现、开场、结尾、镜头路径。**不变的是**：盒子即画框、后亮前暗的阶梯、柔影、暖光、一个强调色、纸在棍上的运动。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里能生效的参数是 `palette`（bg `#0a0806` / bg2 `#22325e` / fg `#FFFFFF` / accent `#e9b25c` / subtitle `#FFFFFF`）、`bgRecipe`（gradient 两段 + `paper-grain` 纹理 + vignette **0.35**）、`subtitle`（SimSun / `fontSizeFactor 0.03704` / `marginVFactor 0.06852` / `marginLFactor 0.07037` / `outlineFactor 0` / 不加粗 / `align 2`）、`title.fontSizeFactor 0.086`、`overlay` 全关（chapterCards / lowerThird / accentRule / progressBar 都 false）、`motion.subtitleFadeIn 0.12` + `chapterTransition: cut`。**注意**：`lib/dub-styles.json#paper-lantern` 是 `derived: true` 的**派生条目**（配色来自 `lib/dub-visual.json` 的代码抽取、字幕 px 取自 `STYLE.md §4` 的 px 值 ÷1080、字幕颜色由 WCAG 对比度规则从暗底反推得纯白），**且模板通路根本拿不到**纸层的背光 shader、`trans` 明度阶梯、自发光窗与 bloom、柔影、真实世界布景——**这些是本风格的命门**。走 dub 通路时还原度会显著低于走 `demo/` 的完整链路（详见第 11 节）。

## 11. 当前短板与避坑要点

### 已知缺陷

- **配音有两句非多音字性质的听感偏差（audio −2）**。修复 agent 的 whisper 校对结果是 **12 OK / 13 DIFF**。13 条 DIFF 里**绝大多数是预期**：`script.json` 的 `say` 字段**有意**把多音字/同音字喂给 TTS（字幕保留真字），whisper 听到的自然与字幕不同，属设计（如 L21「相思的香，是互相的香」）。**但 L03 与 L04 两条既不是多音字、也不是 `say` 设计，是真实误读**——L03「我是一块月饼，出生在外婆的厨房。」、L04「揉面，包馅，再用外公刻的木模子，啪地一压——」。**不能因为「多数 DIFF 是预期的」就把这两条淡化**：本风格的声音口径是「一个坐在桌边讲故事的人」（`STYLE.md:76`），旁白是主要叙事载体，两句误读是可听见的瑕疵；且 **L04 的「啪」正是 foley（木模闷响 + 扑的一下，`DEMO.md:59`）的对齐锚点**，读错会连带削弱那一下的同步感。按每句一处具体缺陷计 **−2**。

### 踩过的坑（本机实测）

- **首版静音的真正根因是「`mix.wav` 探测顺序 + `-s`」（已修复，值得全库警惕）**。编排器把候选路径硬编码成 `demo/mix.wav` → `demo/audio/mix.wav` → `demo/out/mix.wav`（`lemo-make.mjs` 的 `mixWavCands`；混流脚本里同一顺序见同文件的 `for c in "$D/mix.wav" …` 探测），并用 **`-s`（文件非空即通过）取第一个命中的**。而本风格 `mix.py` 的落点是 `out/mix.wav`（`demo/mix.py:7` 的 `OUT='out/mix.wav'`）——于是**一份位于 `demo/mix.wav` 的旧静音占位（23.5 MB，非空）把真正的 `demo/out/mix.wav` 遮住了**，成片因此吃了静音。首版命令行还带 `--skip-sync --no-preflight --skip-audio`（`logs/paper-lantern.log:1`），`--skip-audio` 让本次音频链整段没跑、更坐实了用占位。**修复方式**：重跑本地 TTS + 混音，让 `demo/mix.wav` 与 `demo/out/mix.wav` 都成为同一份真实混音（md5 `a7781d36…`）。
- **`--skip-sync` 会在日志里留下与本次无关的残留输出**：`[2]` 段虽跳过，日志却打了一行 `styles/paper-popup/demo/node_modules 已就位（junction → D:\lemo-opuscar\node_modules）`——**这是 paper-lantern 的日志里一条属于 paper-popup 的串台输出**，别被它误导。`--no-preflight` 则跳过了预检。
- **渲染是 Windows GPU 侧、24 fps、6 workers**：`2922 frames` 用了 **489 s**（日志 `[5]` 的 `done … 2922 frames 489s`），产物 `video_gpu.mp4` 103.5 MB。
- **混流在 WSL 侧跑 `core/render/mux.sh`**，用 nvenc。首版 `MUX_OK 55812383 src_frames=2922 out_frames=2922`（`logs/paper-lantern.log:104`，**帧数一致**、末帧没被切；成片 53.2 MB / 545.8 s 总耗时）。2026-10-03 重混后成片为 **59,657,832 B**（视频流与首版一致，多出约 3.9 MB 的 AAC 音轨，`121.750000 s`）。★ 该读数为 2026-10-03 版（**原记**）；2026-10-04 多比例重渲后那一版为 **59,360,035 B / 121.791667 s / 2923 帧**、真峰值 **−3.37 dBTP**（`loudnorm input_tp`，4× 过采样）——**那一版是用当时 `core/render/mux.sh` 的 `LN_TP` 默认值 −3.5 渲的**（2026-10-03 由 −1.7 改到 −3.5，2026-10-05 改回「−1.7 起步 + 编码后复核闭环」）。**当前入库成片是 2026-10-07 重渲版：59,348,253 B / 121.791667 s / 2923 帧，真峰值 −1.68 dBTP**（同一 `mux.sh`、`LN_TP=-1.7`，只编了 1 档）。 ★ **2026-10-08 口径说明**：上面 `MUX_OK … src_frames=2922` 是**那次本地 run** 的日志读数（**本地副本口径**，24 fps）；**已发布影片**（`films` release）实测为 **3653 帧 / 30 fps / 121.766667 s**（见第 9 节「帧数」行的对照）。按 `MAINTAINING.md:339-347`，本地副本的帧数 / 时长**不可当作成片口径**。
- **`destination-out` 挖孔前必须给不透明 fillStyle**：不给的话孔是半剪的（透明或发光白都会出问题）；`props.js` 的 `cut(x, fn)` 替你做了这件事（`DEMO.md:102`）。
- **VSM 柔影会漏光、会自阴影起光环**：不该参与柔影的层（片名、前面的灯笼、光弧、幕布）需要 **`shadow: false` 和 `recv: false` 两者都要**，只给一个不够（`DEMO.md:103`）。
- **加色光晕不要用透明径向渐变贴图**——会露出可见的方形边；必须用解析式 `ShaderMaterial` 衰减（`paper.js:198-205` 的 `burst()`），本样本用它做「从打开的盒子里溢出的光」（`DEMO.md:104`）。
- **比腔体大的纸层会在外景镜头里戳穿木框**——满幅纸层必须 ≤ `.558 × .328`（`DEMO.md:106`）。
- **grade uniform 曾经是「粘」的（2026-09-26 修复）**：`Pipe.final()` 只在镜头的 `grade()` 返回某个键时才写它，所以没有该键的镜头会继承上一镜的值，结果取决于渲染 worker 从哪一帧开始——v1 成片在 **60.9 s（S09）与 101.5 s（S16）** 的 worker 边界上有可见的 grade 跳变。现在每个缺失的键每帧回落到 `GRADE0`（lift `[0,.005,.018]` 冷夜默认 / gain `[1.03,1,.95]`），任何 worker 数都得到相同帧；**夜景靠默认值，内景必须显式返回自己的暖 lift**（S08 就是这么修的）（`DEMO.md:107`）。
- **whisper medium 会听错中文同音字**（八月 → 8月、她 → 他、婵娟 → 禅绢）：DIFF 要用耳朵判，不能拿字符串比对（`DEMO.md:108`）。**多音字**要用 `say` 字段喂同音字、字幕保留真字（`script.json` 的 L21）。
- **`E.word(id, k)` 的 `k` 是 whisper token 索引，不是字符索引**——whisper 会把「我们」并成一个 token，写硬动作的时间点之前必须把 token 列表打印出来数（`DEMO.md:53`）。
