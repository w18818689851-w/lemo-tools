# 1930s 橡皮管卡通（`rubber-hose`）· 风格制作 Skill

## 1. 风格说明

**是什么**：早期有声时代的手绘黑白动画。角色有**橡皮管四肢**（等宽软管、没有肘、没有膝）、**白色四指手套**、**饼状眼**（黑色椭圆瞳孔挖掉一个楔形）、巨大的圆鞋，身体像气球一样挤压拉伸。背景是柔和的灰色水彩画；角色是平涂的白、灰与墨。**一切**（家具、机器、植物、墙壁）**都跟着音乐呼吸**。画面像一卷磨损的 35mm 拷贝投在 4:3 片门里：闪烁、划痕、灰尘、片门抖动、晕影（`STYLE.md:6-10`）。

**不是什么**（最容易做错的邻居风格）：不是 1950 年代的平面卡通（没有有限动画、没有彩色、没有图形化背景）；不是默片（同步的音乐才是引擎）；不是盖在现代动画上的「复古滤镜」（没有关节、没有渲染明暗）。**绝不**使用既有卡通角色的名字、剪影、设计、旋律或 logo；尤其**不要**用「人头杯 + 吸管」那类设计——若主角是个物件，**整个物件就是身体**（`STYLE.md:4,10`）。

**什么时候用它**：食品饮料、复古广告、儿童题材；适合把任何主题改编成**「一个热闹地点里的一场追逐或一场表演」**，配角是 5–8 个活着的物件（`DEMO.md` Story & structure）。

**一句话内核**：**万物随拍呼吸，每一步都是一个音符。**

**边界**：撑不起安静写实的题材、撑不起需要细读文字信息的长讲解（字幕只是年代字卡，承载不了长句）、撑不起任何彩色的诉求。也撑不起「远景群像」——远景会把角色变小、Mickey-mousing 读不出来，这是本风格的硬伤而不是偏好。

## 2. 画面构图

- **镜头数与画幅**：样本 **14 个镜头**（`story.js:24-40` SHOTS），原生输出 **1920×1080 / 16:9**（**已适配 9:16**，见下方子段），画面里有 **4:3 片门**：`GATE = {x:240, y:0, w:1440, h:1080, r:28}`——1440×1080 居中、左右各 240 px 黑边（各占宽 12.5%），片门四角圆角 r≈28 px，边缘一圈柔和内阴影（`film.js:4,58`；帧 f01/f06/f11 左右黑边清晰可见）。
- **主体位置与占比**：剧场式构图——多数镜头**舞台全景、锁定、平视**，布景像镜框舞台，道具沿台面排开（f06/f03：闹钟、壶、锅沿台面一字排开）。中景跟拍时角色占屏高 **1/4–1/3**；高潮用**拥挤的中全景**（不是远景）：主角居中，身后台面站着活道具，前景另有一排更大的舞者（`DEMO.md` Shots｜Climax；帧 f21）。
- **负空间 / 留白**：几乎没有——1930 年代卡通是「填满」的。片名卡用旋转放射线填满整个片门（f01/f24），其余镜头靠台面/墙纸/瓷砖的重复图案把画面塞满。
- **图层叠放顺序**（从底到顶）：黑底（1920×1080）→ 片门裁剪 + 片门抖动位移 → 缓存的水彩背景画布（厨房 / 碗柜+水槽）→ 会呼吸的活道具 → 角色（平涂 + 一条硬边明暗带 + 屏幕空间恒定线宽的墨描边）→ 片名字 / 播音员字卡（画在场景层里，所以跟着胶片一起抖）→ 胶片损伤合成层（闪烁 / 划痕 / 灰尘 / 毛发 / 晕影）（`film.js:13-59`；`ui.js`）。
- **安全区**：片门内四边各留约 4% 不放关键形状（片门抖动 ±1.2 px + 剪接处 3–6 px 跳 + 圆弧运动都可能把内容推出片门，`film.js:17-18`）。字幕字卡默认在片门底部 y≈986 px（画面高 91.3%），**动作靠下时改到顶部**（`story.js:15-22` 的 `'b'` / `'t'` 标记）。脸必须读得清——**不为笑点用远景**。
- **本风格不能出现的构图**：远景讲笑点（角色变小、Mickey-mousing 读不出，`STYLE.md:89`）；让角色在某些机位与背景道具穿帮（必须检查每个镜头的最后一帧，`STYLE.md:92`）；任何关节弯曲或渲染式明暗；任何色彩。

**在 9:16（产品默认）下的表现**：**已适配**（`FILM_META.aspects = ['16:9','9:16']`，`film.js:23`）。本风格天然抗 9:16——内容本来就锁在居中的 4:3 片门里，所以改造走的是**「片门等比装入 + 同色留白」**这一档（**不是真重排，也不是相机重取景**）：`setFrame()`（`film.js:18-22`）从实际帧派生紧轴缩放 `S = min(W/1440, H/1080)` 与居中偏移 `OX/OY`，`post()` 首行（`film.js:36`）把**整张设计帧（可见区 = 4:3 片门 1440×1080）等比装入当前帧**、设计帧外填黑；片门、圆角、内阴影、晕影、划痕、灰尘、毛发、闪烁全部随之缩放，胶片质感完整。1080×1920 实测（`S = 0.75`）：片门内容 1080×810 居中，**上下各留 555 px 黑边**（实测非黑区 y = 555–1365、宽满 1080），**不裁切、不变形、主体完整**；字幕字卡（设计帧 y≈986）落在当前帧 y≈1294，**完整可见**——实测 t=7.5s 底部卡「Seven A.M., folks! And Boy, is this coffee bitter!」与 t=25.0s 顶部卡「Look out, folks... the drain!」两帧字幕都在框内。代价：竖屏读起来是**「横带 + 上下大留白」**，不是真竖版构图；若产品要求竖屏填满，需要重写 `scenes.js` 的构图（本风格 14 个镜头全是绝对坐标的舞台机位，工作量大）。

## 3. 配色体系

| 角色 | 色值 | 用途 | 来源 |
|---|---|---|---|
| 纸（底） | `#F1EEE6` | 背景水彩底、字卡文字 | `DEMO.md` Palette；`lib/dub-styles.json#rubber-hose` bg |
| 浅 | `#C8C5BC` | 背景第二级 | 同上 |
| 中 | `#9A978F` | 背景主体灰阶 | 同上 |
| 深中 | `#6B6963` | 家具、台面 | 同上 |
| 深 | `#3B3A37` | 暗部 | 同上 |
| 墨（角色描边） | `#0E0D0C` | 角色描边、瞳孔、鞋、字卡底 | 同上 fg / subtitle |
| 角色白 | `#FCFBF7` | 角色平涂（比任何背景都亮） | 同上 |
| 墙 / 砖 | `#8C8981` / `#A29F97` | 墙面、瓷砖 | `DEMO.md` Palette（对比修正） |
| 柜 | `#66635D`–`#7C7972` | 橱柜 | 同上 |

- **明度 / 对比规则**：**严格灰阶**——约 6 级灰 + 一个独立的角色白，**任何地方都不许有色相**（连胶片损伤也不许）。**角色占住两端**：角色白与墨黑比背景里任何东西都更亮/更暗；背景住在中灰区（墙在中灰、家具深一两级）。最终合成加一次 **contrast ≈ 1.1–1.15**（demo 用 `contrast(1.14)`）——1930 年代拷贝是浓黑亮白，**从不是平灰**（`STYLE.md:27-29`；`film.js:23`）。
- **明暗带只有一条**：角色身上一条硬边浅灰明暗带（背对左上光源的那一侧），**绝不用渐变**。
- **禁止出现的颜色**：任何色相、任何饱和色、纯白 `#FFFFFF`（角色白是 `#FCFBF7`）、任何彩色化的胶片损伤。**同一画面最多几个色相：0 个**（灰阶 + 角色白，共 6–7 级明度）。
- **灰阶温度可选但要统一**：暖纸灰（demo 用的这套）/ 冷银盐灰 / 微棕；选一套，全片不许换（`STYLE.md:30`）。

## 4. 转场规则

- **镜头之间怎么切**：**按拍硬切**。144 BPM、4/4、1 拍 = 10 帧，切点落在小节/拍上（`story.js:24-40` 的 SHOTS 全部用 `bar(b,beat)` 表达）。**剪接处片门跳一下**（`jump = 3`，`main.js:49`）——这条是风格的一部分，不是瑕疵。
- **允许的转场**：① **iris 收 / 放**，而且**可以被角色抓住**——样本结尾是一只戴手套的手把 iris 拉上（`DEMO.md` Ending；`STYLE.md:61`）；② **字卡像窗帘一样卷起 / 放下**——样本片名卡在 bar 3.4 像窗帘一样卷上去，露出布景（`DEMO.md` Opening；`story.js:24` 的 `K.roll = [bar(3,4), bar(4)]`）；③ **按拍硬切**；④ **拉远**——从近景拉成拥挤的中全景，表达「一种情绪扩散给所有人」（样本高潮，`DEMO.md` Climax）。
- **转场时长与缓动**：iris 收放与窗帘卷起都按拍走；硬切是 0 帧过渡（一帧换场），只靠片门那一跳提供「胶片接上了」的触感。
- **绝对不要的转场**：**溶解 / 叠化**（`STYLE.md:63` 明确「no dissolves」）；现代动画式的关节弯曲或渲染明暗；彩色。

## 5. 字幕样式

| 项 | 值 |
|---|---|
| 字体 | **IM Fell English SC**（旧式铅字小型大写，`demo/fonts/IMFeENsc28P.ttf`）；dub 通路回退 **SimSun** |
| 字号（相对画面高） | **36 px ≈ 3.33% 画面高**（`STYLE.md:34`；dub 通路 `fontSizeFactor 0.03333` → 36 px，与 demo 一致） |
| 颜色 / 描边 / 阴影 | 字是**纸白** `#F1EEE6`，印在**近黑字牌** `rgba(12,11,10,.92)` 上；牌上有一圈**白色双线框**（外框 2.2 px、内框 1 px）、四角「圆点 + 圆环」花饰、左侧一枚 1930 年代**丝带话筒**小图标。**无描边、无阴影**（`ui.js:30-48`） |
| 位置 / 安全边距 | 片门内居中，**默认底部 y≈986 px（画面高 91.3%）**，动作靠下时改到顶部；dub 通路 `marginVFactor 0.14537`（距底 14.5%）、`marginLFactor 0.06019` |
| 单行字数上限 / 最多行数 | 字牌高 = 字号 × 1.9（单行）；文本 24–56 字符（≈5–12 个英文词），**一行到两行，绝不折成三行**；中文 12–26 字。牌宽 = 文字实测宽 + 2×字号 + 1.05×字号（话筒位） |
| 出现与消失方式 | **硬上硬下、无淡入淡出**（`subtitleFadeIn: 0`）。字卡画在**场景层**里，所以跟着片门一起抖、一起闪。停留 ≥ `max(1.8 s, 语音时长 + 0.6 s)`；**一张卡可以覆盖两条短语音** |

- **字幕与旁白的关系**：旁白是一位**电台体育解说员**在解说这场追逐，第三人称、现在时、广播腔。样本 7 条语音被**合并成 6 张卡**（`v1a` + `v1b` 合成第一张，因为 `v1a` 只有 1.856 s，单独出卡会闪）（`story.js:15-22`；`rubber-hose.srt`）。6 张卡落在 5.15 / 11.67 / 17.08 / 23.75 / 37.50 / 43.75 s。
- **本风格特有的字幕禁忌**：**短语音必须合并成一张卡**，否则字幕闪（`STYLE.md:94`）；不许抽象内心独白（这是广播解说，不是意识流）；不许现代口语、网络梗、emoji；一句不许塞两个以上并列信息点；**绝不许照抄任何真实卡通角色的名字、剪影或台词**。

**文案+风格通路的底衬落地**：STYLE.md §4 声明「a small near-black plate with a white double-rule border」，但「文案+风格」通路原先只走 `BorderStyle=1`（只画描边与阴影、不画底盒；盒填充字段 `OutlineColour` 被当作描边色用），这层底衬从未画出来。现已切到 `BorderStyle=3`（不透明底盒：盒填充色改用 `OutlineColour`、`Outline` 变为盒内边距，`BackColour` 仍只作阴影色——box 模式下 `Shadow=0`，故该阴影不绘制），渲染参数固定为 `BorderStyle=3`、盒内边距 `Outline=10`（1080 高基准）、`Shadow=0`、盒填充色 `OutlineColour=#140C0B0A`（AARRGGBB，落盘 ASS 为 `&H140A0B0C`）。`Shadow=0`：`BorderStyle=3` 下 ASS 的阴影是一份与底盒几乎完全重叠的整盒副本，会把半透明底衬二次压暗（实测 `hd-2d` 的对比度由 6.00 掉到 3.18）；置 0 后底衬的不透明度如实生效，也与检查器的单层合成模型一致。**底衬色与字色取自 demo 的真实实现**：该风格 `STYLE.md §4` 明确规定了底衬与字色的深浅取向（见上方原句），而此前配置正好相反；现已把 `palette.subtitle` 与 `subtitle.plateColor` 一起换成 demo 那一对。字色 `#F1EEE6` 与该底衬 `#140C0B0A` 的 WCAG 对比度 **14.53**。

## 6. BGM / 音效特征

- **配乐**：原创 **1930 年代热舞乐队 / ragtime 大乐队**（`music/score.py`，VSCO 2 CE / VCSL 采样经 `core/audio/sampler.py`，班卓琴走 `pluck.py`）。乐器：跨步钢琴、单簧管、小号（开号 + plunger 弱音「哇哇」）、长号（滑音）、大号 oom-pah、2 & 4 拍班卓、刷子军鼓与滚奏、木琴、木鱼、滑哨、镲、卡祖笛、搓衣板、剧场管风琴。**不要弦乐垫、不要现代合成器**。**144 BPM、4/4、28 小节**（`DEMO.md` Score structure 写作 28 小节；`story.js:3-4` 与实测是 **30 小节 = 50.0 s**，见第 11 节）。一段 4 小节原创切分主题在全片重现四次：片名 → 追逐 → 温柔的慢速单簧管独奏 → 高潮的转调全乐队齐奏。
- **Mickey-mousing（可选项）**：乐队成员「回答」角色（长号咧嘴、小号大笑）；笑点前/凝视时**硬停**（连混响尾一起切）；每个笑点一个 stinger；每次拉伸/滑落/坠落一声滑哨；**一个道具就是一件乐器**（样本里盘子阶梯就是木琴）；温柔段落给独奏；上升段转调。
- **拟音（按材料合成）**：瓷器 = 高硬非谐分音（≈2.7 / 4.2 / 6.3 kHz）+ 极短瞬态；厚马克杯 = 更低更闷的分音；方糖 = 高木鱼 + 稀疏脆响；闹钟 = 18 Hz 锤击两只铃；烤面包机 = 咔哒、八分音符 tick、铃 + 弹簧「啵嘤」；水 = 滤波噪声 + 上升 blip、下水口呼噜、气泡床；橡胶 = 锯齿波「吱呀」过带通（`mix.py:22-64`；`DEMO.md` Foley）。
- **旁白处理**：Kokoro `bm_lewis`，speed 1.0，电台播音腔；**电台链**：HP ≈260 Hz / LP ≈4.6 kHz、tanh 饱和、短房间、压缩。**音乐在人声下闪避**：代码是 `mus * (1 - 0.62 * duck)` ⇒ **≈ −8.4 dB**（`mix.py:163-164`；实测 `VO RMS −14.8 dB / music-under-VO −20.2 dB / music-alone −15.4 dB / FX −23.1 dB`）。
- **光学声轨老化**：拟音 + 配乐之后过一遍带限 **110 Hz–6.2 kHz**、轻微抖晃（wow ≈0.6 Hz、flutter ≈7 Hz）、柔和饱和；再垫 hiss、crackle 与 **24 Hz** 放映机片门咔哒——**静音里唯一允许的声音**（`mix.py:167-184`）。
- **响度目标**：`−14 LUFS`（两遍 loudnorm）；真峰值上限 `−1.2 dBTP`。**实测成片 `−13.9 LUFS / LRA 9.5 LU / Peak −2.9 dBFS`**（`_distill/logs/rubber-hose.log:95-98`）。★ 口径更正：上述 `Peak −2.9 dBFS` 是 `ebur128` 的 1 位小数读数、口径不同，不能当真峰值引用；**成片真峰值 = `loudnorm` 的 `input_tp`，4× 过采样 = −2.94 dBTP**。
- **静音策略**：乐队一停，**一切冻结**（连背景呼吸也停），混响尾一起切掉。实测静音区间（`logs/rubber-hose.log:81`）：**10.577–10.828 s**（≈0.25 s，笑点前的悬念）、**15.020–15.829 s**（≈0.81 s = 2 拍，「对上眼神」）、**28.333–29.165 s**（≈0.83 s = 2 拍，大拉伸之后）、**36.687–37.497 s**（≈0.81 s = 2 拍）。静音里只剩放映机底噪。

## 7. 素材偏好

- **需要什么素材**：① 用「矩阵栈 + 形状原语」画出来的角色与活道具（`toon.js` / `chars.js` / `cast.js`）；② **缓存的水彩背景画布**（1.25–1.5× 分辨率，平涂 + 柔和斑块 ±5% + 内缘变暗 + 细深灰轮廓 + 纸纹，**永不 boil**）——样本两张：厨房、碗柜+水槽（`bg.js`）；③ 三套字体（`demo/fonts/` 里的 IM Fell English SC / Shrikhand / Limelight，均有 OFL 授权）；④ 一段原创切分主题 + 大乐队采样库（VSCO 2 CE / VCSL，CC0）+ 鼓组（MuldjordKit，CC BY 4.0）；⑤ 5–8 条电台腔短旁白。
- **不需要什么素材**：实拍视频、照片贴图、任何彩色的东西、任何现代合成器音色、任何既有卡通角色的设计/剪影/旋律/logo。
- **取景 / 质感偏好**：4:3 片门里的剧场式构图；质感来自**屏幕空间恒定线宽**（1080p 约 6–7 px，先把点变换到屏幕坐标再描边）+ **line boil**（±1.2 px，12 fps 在 3 张画间循环）+ **胶片损伤**（片门抖动 ±1.2 px + 偶发 3–6 px 跳、闪烁 ±4%、0–3 条漂移竖划痕、每帧 3–8 粒灰尘、偶尔一根毛发、四角 62% 黑晕影、0.55 px 模糊、contrast 1.14）。**颗粒在 ffmpeg 的 mux 阶段加（grain 3），不在页面里**（`STYLE.md:23`；`film.js:17-59`；`toon.js:83-97`）。
- **可替代方案**（缺素材时怎么降级而不破风格）：缺字体就用任何**旧式衬线小型大写**做字卡、任何**胖圆 retro script** 做片名（dub 通路就是这么退到 SimSun 的）；缺采样库就用**纯合成**的跨步钢琴 + 木琴 + 刷子鼓把编制补齐，**只要避开弦乐垫和现代合成器**；背景缺一张就**复用同一张缓存背景 + 换机位**（剧场风格本来就靠同一布景演全场）；角色少就**减少配角数量**，但**至少保留 1 个会呼吸的活道具**——「万物随拍呼吸」这条不能省。

## 8. 镜头节奏

| 项 | 值 |
|---|---|
| 单镜时长 | 1.67–6.67 s（最短 `bitterCU` 1 小节 = 1.67 s，最长 `cupboard` / `sink` / `dance` 各 4 小节 = 6.67 s） |
| 全片时长 | **50.0 s**（`story.js:5` `DUR = bar(NBARS+1)`，NBARS 30；`style.json` dur 50.0；日志 1200 帧） |
| 镜头数 | **14**（title / wide1 / bitterCU / wide2 / chase / toaster / cupboard / sink / twoShot / leaving / sweetCU / dance / iris / end） |
| 信息投放节拍 | **144 BPM、4/4；1 拍 = 10 帧 = 5/12 s，1 小节 = 5/3 s**。角色**拍两格（on twos，12 fps）**，相机**拍一格（24 fps）**——步进相机读起来会抖。选速度的硬规则：**1 拍必须是 24 fps 下的偶数帧（8 / 10 / 12 / 16 / 20）**，这样每个拍点都落在两格画上 |

- **加速 / 减速点**：钩子在第 1 帧（片名卡上字母按拍波浪式蹦跳 + 乐队一记重击）→ 3 s 内卷起字卡、露出布景 → 小愿望（苦！近景反应，1.67 s 的短镜做加速度）→ 追逐三段升级（台面横移 → 烤面包机 → 盘子木琴/勺子滑梯/下摇）→ 危险（水槽漩涡，略高机位、**一个不切的长镜**穿过大拉伸）→ **2 拍死静**（28.333–29.165 s）→ 温柔转折（中景双人、然后主角背影变小）→ 释放：**拉远成拥挤中全景，全厨房起舞**（每个镜头 2–3 步：摇摆 → 踢腿 → 集体下蹲弹起，最后一拍全体定格成「ta-da」姿势并保持进 iris）→ iris 被拉上。
- **呼吸（全片的底层节拍）**：每个空闲物件用 `cos(2π·拍数)` 挤压拉伸，**每拍一个极端**（拍点拉长、反拍压扁），幅度 **5–7%**，**所有道具同相**。极乐时刻幅度可放大 **×3**，并把整张背景画布绕地线压扁 ≈2.5%（`STYLE.md:41`；`cast.js:8`）。
- **留白与静音的位置**：见第 6 节的四个静音区间；**乐队一停就全场冻结**，连背景呼吸也停（`STYLE.md:45`）。另外「停顿也是表演」：一串停顿 + 每个眼神落在八分音符上配一声木鱼，读起来就是在思考（样本跳跃前的犹豫段：下蹲 → 看对方背影 → 看目标 → 回头 → 咧嘴 → 小跳 → 跃出，镜头缓慢推近，`DEMO.md` Shots 末段）。

## 10. 编排规则

- **内容文件字段契约**（`story.js` 是唯一真值）：`BPM/BEAT/BAR`（144 / 5/12 / 5/3）、`bar(b, beat)` 1 起算的时间换算、`NBARS/DUR`（30 / 50.0）、`ANIM_FPS`（12）与 `q(t)`（拍两格）、`breath(t)`（呼吸相位 cos）、`VO{}`（旁白起点）、`SUBS[]`（字卡 `[t0, t1, 文本, 'b'|'t']`）、`SHOTS[]`（`[起, 止, 名]`）、`K{}`（关键时刻）、`CUES[]`（配乐 cue）。页面契约：`window.render(t)` / `window.DUR` / `window.SUBS` / `window.EV` / `window.READY`（`main.js:52-59`）。
- **事件词汇表**（`events.js` → `mix.py`）：`porcelain` / `ceramic_low`（瓷器 / 厚陶瓷）、`woodblock`、`sugar_crunch`、`slide_whistle`、`boing`、`bell_ring`、`water_splash` / `bubble_bed`、`rubber_creak`、`china_crash`、`whoosh` / `zip_up` / `smack` / `ratchet`、`plip` / `twirl` / `creak` / `zipBack`、`vo{id}`、`projector`（`style-dna/rubber-hose.md:202-219`）。
- **时间线契约**：`story.js` 是唯一时间真相——画面、字幕、拟音、配乐 cue 全从它导出；**时间一律用 `bar(b, beat)` 计算**（1 起算，beat 可带小数）。剪接处片门跳一下：`cutAt` 命中该帧时 `jump = 3`（`main.js:49`）。
- **新增主体怎么接入**：用 `toon.js` 的矩阵栈（push / translate / rotate / scale）+ 形状原语（ell / arc / spline / rr / rect / quad / noodle / ribbon）画，脸用 `chars.js` 的 `pieEye` / `mouth` / `brow`，脚用 `shoe`，手用 `glove`，肢体用 `hose`，并在 draw 开头调用 `breathe(b)` 让它随拍呼吸（`cast.js:1-8,11-32`；`chars.js:59-154`）。**新增一个镜头** = 在 `SHOTS` 加一行 + 在 `scenes.js` 加 `shotXxx(t)` + 在 `main.js` 的 `FN` 表登记（`main.js:35`）。
- **换主题时要改哪些文件**：① `demo/lines.json`（5–8 条电台腔短旁白，**必须过 whisper 校对**）；② `demo/story.js` 的 `BPM/NBARS/VO/SUBS/SHOTS/K/CUES`（**先写小节网格，再写 cue 表**，这是官方推荐顺序）；③ `demo/scenes.js`（每个镜头的机位、道具、表演）；④ `demo/chars.js` / `cast.js`（主角与活道具的 rig——记住「若主角是个物件，整个物件就是身体」）；⑤ `demo/bg.js`（换地点就重画缓存水彩背景，1.25–1.5×）；⑥ `demo/music/score.py`（换主题，但保留「一段短切分主题在四种编排里重现」的结构）；⑦ `demo/mix.py` 的材料拟音映射。**不可换**的三件事：**橡皮管四肢 + 饼眼 + 四指手套的解剖套件、万物随拍呼吸、4:3 片门里的磨损胶片质感**。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里能生效的参数是 `palette`（bg `#F1EEE6` / bg2 `#C8C5BC` / fg `#0E0D0C` / accent `null`）、`bgRecipe`（gradient + `scanlines` 纹理 + `film-grain` + vignette 0.08）、`subtitle`（SimSun / 0.03333 / marginV 0.14537 / marginL 0.06019 / 无描边 / 不加粗 / 居中）、`title.fontSizeFactor 0.09`、`overlay` 全部关闭、`motion.subtitleFadeIn = 0` + `chapterTransition = cut`。**注意**：`lib/dub-styles.json#rubber-hose` 是 `derived: true` 的**派生条目**（配色来自 `lib/dub-visual.json` 的代码抽取，字幕 px 来自 STYLE.md §4，字幕色由 WCAG 规则反推），并且模板通路**拿不到** 4:3 片门、片门抖动、划痕、灰尘、毛发与 line boil——它只能用 `scanlines` + `film-grain` 近似。走 dub 通路时本风格的还原度会明显低于走 `demo/build.sh`。

## 11. 当前短板与避坑要点

### 已知缺陷
- **水槽镜头接近「平灰」坑**：f14（≈29.2 s，`sink` 镜）是一大片中灰椭圆水槽 + 几道细螺旋线，对比明显低于其余镜头，最接近 `STYLE.md:88` 点名的「flat grey frames」；同一帧里主角贴在片门左缘、脸占比偏小，也擦到 `STYLE.md:89`「远景杀笑点」的边。
- **字牌尺寸与文档不符**：`STYLE.md:34` 说字卡是「a small near-black plate」，但长句（如第一张 51 字符）在 36 px IM Fell SC 下牌宽约 1136 px，占 1440 片门宽的 **79%**，不算「small」。
- **dub 通路会丢掉字卡的一半形态**：`lib/dub-styles.json#rubber-hose` 的 `subtitleOutline` 是 `#00000000`（全透明）、`fontFamily` 回退 **SimSun**；而 demo 的字卡是「白双线框 + 四角圆点圆环花饰 + 丝带话筒图标 + IM Fell English SC」，模板通路只剩黑底牌。
- **`bgRecipe` 与 demo 的材质不是一回事**：dub 通路用 `gradient` + `scanlines` + `film-grain` + `vignette 0.08`，而 demo 是**缓存的水彩背景**（平涂 + 斑块 + 内缘变暗 + 纸纹）加**四角 62% 黑的晕影**——模板通路的「旧胶片感」会明显偏轻。
- **响度与动态范围**：实测 `−13.9 LUFS`（目标 `−14`，偏 0.1 LU，可接受）；`LRA 9.5 LU` 低于 loudnorm 目标 11 LU；`Peak −2.9 dBFS` 比真峰值上限 `−1.2 dBTP` 还低 1.7 dB，说明线性增益留了余量。（口径更正：`Peak −2.9 dBFS` 是 `ebur128` 的 1 位小数读数，真峰值以 `loudnorm` 的 `input_tp`、4× 过采样 **−2.94 dBTP** 为准）
- **文档内部不一致**：`DEMO.md` Score structure 写「28 bars」，但 `story.js:5` 是 `NBARS = 30`，`_distill/logs/rubber-hose.log:80` 的 `rms_per_bar_db` 数组正好 30 项，1200 帧 ÷ 24 fps = 50.0 s = 30 小节 × 5/3 s。**以 30 小节为准**。

### 素材缺口
- 本机 demo 自带 IM Fell English SC / Shrikhand / Limelight 三套字体（`demo/fonts/`），但 **dub 通路未接**，模板化时回退 SimSun，片名的胖 retro script 气质会掉。
- 大乐队音色依赖外部采样库（VSCO 2 CE / VCSL / MuldjordKit），**不在仓库里**；换机器或断网重跑 `music/score.py` 有失败风险。
- 没有任何可复用的角色库：主角与 5–8 个活道具全是代码画的 rig，**换主题必须重画**。
- 没有真实 35mm 拷贝的扫描素材：划痕、灰尘、毛发全是程序化生成，密集观看时会比真拷贝「规律」。

### 能力限制
- **【已修】4:3 片门 + 1920×1080 母版曾不适配 9:16**：原记「内容锁在居中 1440×1080 里，9:16 导出会丢右侧 43.75%、字卡落进黑区（详见第 2 节子段；**未实渲复核**，按既有 1:1 左上角塞入口径推导）」。**2026-10-04 已修**：`film.js` 导出 `NATIVE` 并声明 `FILM_META.aspects = ['16:9','9:16']`（`film.js:23`）、`setFrame(W,H)` 派生紧轴缩放 `S` 与居中偏移 `OX/OY`（`film.js:18-22`）、`post()` 首行从实际帧把**片门等比装入**当前帧（`film.js:36`）；`main.js` 的 canvas 跟视口走。**16:9 逐字节未变**（3 帧 md5 全同），9:16 实测不裁切、不变形、主体与字幕完整（落在「等比装入 + 同色留白」这一档，见第 2 节子段）。
- **无色彩能力**：风格定义就是严格灰阶，任何彩色诉求都不该选本风格。
- **GPU / TTS 独占**：渲染与 Index-TTS 都是独占资源，不能并发。
- **whisper 校对的已知误听**：`DEMO.md` 记录 Kokoro 曾把省略号后的 `is... bitter!` 听成 `is... better!`；`v1a` 的 `Seven a.m., folks!` 在 ASR 里会被写成 `7 a.m. Folks.`（日志实测）。**每条旁白都要过 whisper，并且要归一化数字与缩略形式后再比对**。

### 踩过的坑（本机实测）
- **本风格不走自带 mux 副本，不受 2026-10-03 那次回灌影响**：日志 `[6]` 明写「混流脚本 core/render/mux.sh」，`grain 3`，`MUX_OK 40095404 src_frames=1200 out_frames=1200`——帧数一致。项目里另外 9 个风格（含同批的 risograph / shadow-puppet）因为硬写 `libx264` 且缺补静音，被 `scripts/patch-style-mux.mjs` 回灌修过；**rubber-hose 不在那 9 个之列**。
- **本次成片走 `--skip-sync --no-preflight`**（日志第 1 行 `node lemo-make.mjs rubber-hose --skip-sync --no-preflight --ratio 16:9`），配音是**本次现场跑的 TTS**（7 条语音全部输出），whisper 校对 `mismatches: 0 (lang=en, model=base.en)`。渲染走 `core/render/video.mjs` + `h264_nvenc` + 6 workers（1200 帧 19 s），音频链在 WSL 跑，两路并行 32.5 s，混流 54.2 s。**无告警**。
- **远景杀笑点（实测两次）**：盘子木琴与高潮群舞**各被重拍过一次**——远景让角色变小、Mickey-mousing 读不出，最终都改成中景 / 中全景（`DEMO.md` 坑）。
- **踢腿画在身体剪影之后会被把手挡住**：要向外踢、踢出剪影（`STYLE.md:91`）。
- **某个机位下锅从马克杯头上「长」出来**：必须检查每个镜头的最后一帧（`STYLE.md:92`）。
- **跃起弧线太高会出画**：弧线与跳跃必须留在当前缩放下片门内（`STYLE.md:63`）。
- **方糖在纯正面视图下读成高箱子**：仰角 ≈0.26 rad + 轻微 3/4 转身才能读出「方块 + 脸」（`DEMO.md` 坑）。
- **不同长度的音效片段直接相加会 numpy 广播报错**：要把片段放进定长缓冲（`mix.py` 的 `seq()`）。
- **一排烟雾读成思考气泡**：要散开、放大（`STYLE.md:93`）。
- **把「悲伤」的眉毛画成「生气」**：眉毛要按**内端 / 外端**定义（内端 = 靠近鼻子），不是按左右（`STYLE.md:90`）。
- **JS 语法**：`-x ** 6` 是语法错误，要写 `-(x ** 6)`；zsh 下 `echo =====` 会失败（`=word` 展开）。
