# 油画厚涂（`impasto`）· 风格制作 Skill

> **用途**：选定本风格后，**优先读这份文档**作为核心参考。

## 1. 风格说明

**是什么**：一幅用调色刀笔触画出来、并且在动的油画。**每一笔都是一个真实的物体**——一片斜的颜料面，刀压下去留下一道脊、抬起来留下一道唇、颜料将尽处拖出断续的条、两种颜色被互相拖进对方。世界每帧都从笔触重画一遍，但**静止的颜料永远不动**，只有故事里在动的东西才动；光以掠射角扫过高度场，所以颜料有厚度（`STYLE.md:8`、`style-dna:11`）。

**不是什么**（最容易做错的邻居风格）：不是梵高式的漩涡滤镜（笔触到处沸腾）、不是盖在扁平矢量上的笔刷贴图、不是水彩（颜料必须**不透明**）、不是把噪声采样出来的「绘画感」照片滤镜（`STYLE.md:12`）。判据：如果笔触不是**被设计出来的**，而是从噪声里采样的，就不是本风格。

**什么时候用它**：音乐短片、文化艺术、情感广告（`style.json` 的 `uses`）。任何「颜色本身就能讲故事」的题材。

**一句话内核**：**颜色就是故事，而刀可以把任意一笔重新铺成新的颜色**（`style-dna:69`）。demo 把「孤独（灰）→ 一点颜色（红伞）→ 被听见（圆舞曲）→ 人群 → 回声」这条弧线全部交给颜色。

**边界**：它需要**有明度结构的场景**——`STYLE.md:16` 的硬规则是「先画成一张扁平的、按明度规划的插画（至少 3 个明度），再转成笔触」；参考图在 480px 宽下读不出来，再多笔触也救不回来。所以撑不起：需要精细文字阅读的题材（刀触托不住小字母）、需要大量 UI / 数据表的题材、快速蒙太奇式剪辑（转场只能覆盖式换景与拍上硬切）。

## 2. 画面构图

- **镜头数与画幅**：原生 **16:9 / 1920×1080**；**已适配 9:16**（`FILM_META.aspects = ['16:9','9:16']`，`film.js:21`）。demo 9 个镜位（`DEMO.md:20-30`），从 CU 到大全景到俯瞰，全片 39.7s。
- **相机必须待在画出的画板内部**（`half = W/2/zoom`），否则会**露出画布边**（`STYLE.md:61`）。这是本风格第一条构图铁律。
- **主体位置与占比**：**主体拿到硬边和最小的笔触，其余一切待在大而平静的色块里**（`STYLE.md:61`）。笔触尺寸按重要性与纵深分级：天空和墙面用 40–60px 大色块，只有边缘和脸用 3–6px 的小笔（`style-dna:25`）。
- **负空间 / 留白**：大量。构图按明度规划，至少 3 个明度层级（`STYLE.md:16`）；demo 的灰色广场段几乎整幅是同一明度的平面，只靠几个人物的剪影与湿倒影撑结构。
- **图层叠放顺序**（从底到顶）：① 薄底画（参考图本身，模糊 ~1.5px，防止画布从笔触缝隙透成描边）；② 静态笔触层（`E.batch()` → `E.draw(batch, o)`，按 `group` 分形状组，笔触绝不跨组）；③ 运动笔触层（`E.drawNow()`：人物、天气、颜料飘带）；④ 掠射光 + 调色（`E.finish(post)`）；⑤ 标题（被刀画进画面，是世界的一部分）；⑥ **DOM 小字**（署名、数据、图注，必须留在清晰的 DOM 文本里）。
- **安全区**：小字走 DOM，不受笔触影响；标题要留出「被雨带走」的空间。
- **本风格**不能**出现的构图**：相机跑出画板（会露出画布边）；**画顺序搞错**——在建筑之后才画地面会盖住它们的脚（`DEMO.md:107`）；扁平矩形不加锥度/亮边/定义性刀点（会读成柱子或方块，`STYLE.md:86`）。

### 在 9:16（产品默认）下的表现

产品导出默认是 9:16（1080×1920）。本风格**已适配 9:16**——`FILM_META.aspects = ['16:9','9:16']`（`film.js:21`），`frame()` 首行从实际帧调 `setFrame()`（`film.js:342`；`film.js:18-20` 导出 `NATIVE` 与活绑定 `FX/FY/S = min(fx,fy)`），相机 `zoom × S`（`film.js:72,109,127,161,200,245,290,318`）把整块画板按紧轴等比缩小、居中；屏幕空间的家什按当前帧铺满——屏幕雨把帧宽高传给 `rain()`（`film.js:79,122,195,256`），暗角横轴权重 `vigA = 1.78*FX/FY`（`film.js:346` → `engine/impasto.js:154,185,317`），署名板 `top = H/2 + (640-540)*S` 且字号/阴影 ×S（`film.js:45-46`）；画布跟视口走并把帧尺寸透给影片模块（`main.js:4-6`）。1080×1920 实测（`S = 0.5625`）：**不裁切**，主体与文字完整——灰广场段的街道纵深、俯瞰的圆形编排都在画面里。代价：画板只有 2112×1188（约 1.1× 设计帧），按紧轴缩到 0.5625× 后是一条**竖向中段的横带**，上下各留大片空白（空白其实是画布底色 `[.46,.4,.33]`，与笔触缝隙里露出的画布色同色，读起来像未上色的画布边）——与 `dataviz` 的竖屏表现同一类：等比装入、不裁切、版面更空。**例外**：俯瞰万花筒段（`P.top` 是 3600×3600 的大画板）画板够大，9:16 下**铺满整屏、无空白**（实测 25.0s 帧）。相机仍待在画板内部：`half = W/2/zoom`（`film.js:318`，zoom 已含 S，故两种比例下 world 半宽都等于 `960/zoom`）。

## 3. 配色体系

| 角色 | 色值 | 用途 | 来源 |
|---|---|---|---|
| 天空（雨后黄昏） | 钴蓝 `#34507e` → 桃 `#d99a78` → 金 `#f7dca0` | 渐变**由笔触逐级铺出**，不是像素混合 | `DEMO.md:71` |
| 立面 | 赭石 `#dca064`、玫瑰 `#c98d7e` | 建筑 | `DEMO.md:71` |
| 立面点缀 | 百叶绿 `#3f7a6c`、雨棚红 `#b8342a` | 门窗、雨棚 | `DEMO.md:71` |
| 全彩道具（伞） | 镉红 `#dc2f28`、黄 `#f4bc2a`、钴蓝 `#2f62c0`、铬绿 `#23906c`、洋红 `#cc3a82`、橙 `#ee7a2a`、青绿 `#26aab4`、紫 `#6e4cc0` | **最亮最纯的彩度留给故事主体** | `DEMO.md:72` |
| 灰世界 | 同一批笔触的**明度**版，略偏冷，**留 5% 颜色残余** | 前半段的「孤独」 | `DEMO.md:73` |
| 标题 | 金（刀画衬线） | 标题被画进画面 | 帧 f04 / f23 |
| 小字 | DOM 文本，清晰可读 | 署名、数据、图注 | `STYLE.md:35` |

- **明度 / 对比规则**：**暖光对着冷影**是默认的温度结构；**最亮最纯的彩度留给故事的主体**（一个道具、一群人、一个光源），不是背景（`STYLE.md:28`）。**渐变不是靠混合像素做出来的，是靠笔触与笔触之间的台阶做出来的**（`STYLE.md:27`）。
- **颜色可以是一个事件**：每一笔都能同时持有一个灰版与一个彩版——「单色世界里只有一个例外」或「世界从灰被逐笔重铺成彩」是本媒介的原生手法（`STYLE.md:29`）。demo 把这条用满了：红伞是前半段唯一有颜色的东西，之后伞一把把变彩，最后整个广场填满颜色。
- **禁止出现的颜色 / 用法**：像素混合做的渐变（必须靠笔触台阶）；把全彩用在大面积背景上（背景应待在明度结构里）。
- **同一画面最多几个色相**：灰世界段是 **0 个色相**（只有明度 + 5% 残余）；彩色段是 **1 个主色相族 + 若干全彩道具色**，且全彩只出现在主体上。demo 的伞有 8 个色相，但它们是**逐个登场**的，不是同时塞满画面。

## 4. 转场规则

- **镜头之间怎么切**：两种，都**必须来自媒介本身**——① **覆盖式换景（paint-over）**：下一镜的笔触以约 **0.5s 的 `appear`** 扫过上一镜，音轨配一声**调色刀刮过湿颜料**；② **在节拍上硬切**（`STYLE.md:61`、`style-dna:103`）。
- **有没有叠化 / 闪白 / 擦除 / 定格**：**没有叠化**（两层刀的脊会糊成泥，`STYLE.md:61` 明确禁止）。有第三种手法：**用同一个大全景做「押韵」的回到**——demo 的镜 2（2.65–7.15s，灰色大全景）与镜 8（31.66–35.75s，同一套机位、已变成全彩）就是这种「同一个大全景，重复」的镜头语法（`STYLE.md:56`、`DEMO.md:32`）。
- **硬切点怎么定**：全部挂在音乐网格上。demo 有两张网格：Part A = D 小调 3/4 @ **80 BPM**（从 0.4s 起），Part B = D 大调 3/4 @ **132 BPM**（从 15.3s 起）（`DEMO.md:38-40`）。切点表在 `timeline.js` 的 `T`（`hook`/`cutWide`/`title`/`cutMed`/`stop`/`steps`/`splash`/`pop`/`react`/`bowIn`/`cutStreet`/`cutTop`/`gp`/`chord`/`last`/`end`）。
- **转场时长与缓动**：覆盖式换景 **~0.5s `appear`**；标题的刀画扫入 **~1s**（`STYLE.md:34`）。
- **绝对不要的转场**：溶解 / 叠化（`style-dna:105`）；相机跑出画板；无来由的运镜。

## 5. 字幕样式

| 项 | 值 |
|---|---|
| 字体 | 标题用**衬线展示体**（demo 用 Cormorant Garamond / Cormorant SC，OFL，见 `demo/CREDITS`）；dub 通路回退 `SimSun`（宋体） |
| 字号（相对画面宽 / 高） | demo 标题为大号衬线；dub 通路 `subtitle.fontSizeFactor: 0.03519`（≈38px @1080）、`title.fontSizeFactor: 0.1` |
| 颜色 / 描边 / 阴影 | 字 `#FFFFFF`；描边 `#090402`（近乎黑）；底板 `#00000000`（**全透明，不加底板**——画面本身就是颜料） |
| 位置 / 安全边距 | 居中（`align: 2`），下边距 `marginVFactor 0.14537`、左边距 `marginLFactor 0.07037` |
| 单行字数上限 / 最多行数 | `STYLE.md:36` 要求 **≤ 2 行**；demo 无旁白故无字幕行 |
| 出现与消失方式 | dub 通路 `subtitleFadeIn: 0`（**不淡入**）、`chapterTransition: "cut"`（硬切）；若配旁白，停留 ≥ `max(1.8s, 语音 + 0.6s)` |

- **本风格独有的字幕形态**：**标题是被刀一笔笔「画」进画面的**（约 1 秒的 `appear` 扫入），而且**会随世界一起被带走**——demo 的标题被雨冲走（向下漂移并淡出），`film.js:108-111` 是这段实现（`STYLE.md:34`、`DEMO.md:14`）。**标题是画面里的一个物件，不是叠加层。**
- **小字必须留在 DOM**：署名、数据、图注保持清晰 DOM 文本叠在画面上，**刀触托不住小字母**（`STYLE.md:35`）。
- **字幕与旁白的关系**：本 demo **完全没有旁白**——音乐 + 拟音独立成片（`style-dna:39`）。若确实要配旁白，走朴素衬线、≤2 行、放在一块平静的色块上，且**音乐与环境让到人声下约 8 dB**（`STYLE.md:36,69`）。
- **本风格特有的字幕禁忌**：把标题/文字做成淡入滑入的**叠加层**（文字必须跟着颜料走）；用刀笔触去写小字；旁白抢戏（若有人声，音乐必须让位）；网络口播腔、感叹号堆叠、营销话术（`style-dna:49-52`）。

## 6. BGM / 音效特征

- **配乐**：**有手作质感的原声乐器**——独奏弦乐、手风琴、拨弦、竖琴琶音、钢片琴 / 钟琴（用于 POP）、钢琴、吉他、木管。**孤独的世界用一件独奏乐器，共享的世界用合奏**（`STYLE.md:67`）。demo 是采样器合成（CC0 音源：VS Chamber Orchestra Community Edition + Versilian Community Sample Library + FreePats，见 `demo/CREDITS`），通过 `core/audio/sampler.py` 渲染。两段结构：**Part A** 独奏大提琴、D 小调、3/4 @ 80 BPM，从 0.4s 起，乐句在 **10.15s 停在未解决的 E3** 上，弓 0.3s 后离弦；**Part B** 街头圆舞曲（musette）、D 大调、3/4 @ **132 BPM**——15.3s POP（弱起，钢片琴 + 上行竖琴滑奏）→ 16.66s 伴奏进（拨弦贝斯 + 手风琴 oom-pah-pah）→ 18.03s 大提琴旋律进 → 19.39–23.03s **九把伞一拍一把**（钢片琴音高 G→B→D / A→C#→E / D→F#→A）→ 23.48–31.21s 俯瞰六小节（手风琴高八度重复旋律，每小节一个竖琴琶音）→ **31.21s 大停顿（真数字零）** → 31.66s 终止和弦（tutti + 定音鼓 + 吊镲）→ 尾声 F#→E→D **解决开头断掉的那句** → 35.75s 末拨弦（`DEMO.md:38-49`）。
- **拟音（foley）**：**跟随颜料与世界**（`STYLE.md:65`）——每一次重画或覆盖换景都有一声**调色刀刮过湿颜料**（带通 900–4200 Hz + 30–120 Hz 颗粒 + 湿底）；湿的刀点；以及场景本身的材料（湿石、尼龙伞布、木头、织物、玻璃）。demo 逐段设计：CU 段 = 弓的松香 + 雨点打清漆木；灰色广场 = 满雨 + 排水沟细流 + 湿石板脚步（按行走算法摆位、带声像）+ **标题处的刀刮声**；中景 = 拱廊下的低通雨 + 行人近距脚步 + 伞布擦过；静默 = 一滴水 + 两声小脚步（J-cut）+ 一大下水声；女孩 = 尼龙窸窣 + 伞骨咔哒 + 伞的「fwump」+ 颜料落点；反应 = 闷住的雨 + 抬弓的气声；街道 = 每把伞一声「fwump」+ 颜料飘带抵达时的一声轻嘶；俯瞰 = 人群的水步踩在圆舞曲上（第 1 拍重）；大停顿 = 数字零；结尾 = 雨停、水滴、收伞、鸟鸣（`DEMO.md:52-65`）。
- **床（beds）**：**分层**（一层嘶声、近处颗粒、一个明确的细节），相机进入遮蔽处时做低通（`STYLE.md:66`）。demo 是三层雨床 + 逐镜电平自动化（`mix.py:66-85`）。
- **旁白处理**：**本 demo 没有旁白**（`style-dna:39`）。若配旁白，音乐与环境让到人声下约 **8 dB**（`STYLE.md:69`）。
- **响度目标**：`−14 LUFS`；**真峰值上限**：`−1.2 dBTP`（**项目级交付线**，判据见 `core/render/mux.sh`；本风格 `STYLE.md:69` 未额外声明更严上限）。出片实测 **−13.6 LUFS / LRA 8.6**（`ebur128`）、**真峰值 −0.74 dBTP**（`loudnorm` `input_tp`，4× 过采样）——**超 −1.2 dBTP 交付线 0.46 dB（未达标）**，但真峰值为负、**未削波**；`astats` 另报采样峰值 `−1.237667 dBFS`（它低于交付线是假象——采样峰值不是真峰值，不能据此宣称达标）。 ★ **2026-10-03 已修**：成片已用 `scripts/fix-truepeak.mjs` 音频重混（`-c:v copy`，视频流逐字节未变），真峰值 −0.74 dBTP → **−2.06 dBTP**、已在 −1.2 dBTP 交付线内（达标）；原 −0.74 dBTP 记录保留为历史。
- **静默策略**：**静默是真的数字零**——demo 有**两处**：① **10.45–12.4s** 的「几乎什么都没有」（雨几乎停；11.15s 一滴水；11.5s / 11.95s 两声小脚步**先于画面**进入（J-cut）；12.4s 一大下水声是静默后第一个声音）；② **31.21s 的大停顿**，`score.py` 与 `mix.py` **在同一窗口把样本置零**（连混响尾都剪掉），里面最多只放一个声音（`style-dna:81`）。**静默是给颜色出现让路。**

## 7. 素材偏好

- **需要什么素材**：**零外部图像素材**。`demo/CREDITS` 明确写：All pictures painted in code (engine/impasto.js + engine/plate.js). No generated images, no photos. 需要的是：① 每个场景的**参考插画**（用 `new Ref(w,h,scale)` + `.fill/.line/.text/.tint` 代码画出的扁平明度稿）；② 配乐用的 CC0 采样（VS Chamber Orchestra / Versilian / FreePats）；③ 字体 Cormorant Garamond / Cormorant SC（OFL，在 `demo/fonts`）。
- **不需要什么素材**：不需要实拍、不需要照片、不需要生成图像、不需要 HDRI。
- **取景 / 质感 / 偏好**：超采样 **2×**；**绝对没有胶片颗粒**（颗粒 + 压缩会吃掉刀口），高码率（`STYLE.md:23`、`style-dna:31`）。刀触参数：长大于宽（≈ 半径的 1.7–3.1 倍长、0.95–1.45 倍宽），两端斜切，角度抖动 **±13°**、明度抖动 **±6%**，斜切 `skew ±0.55`；要读成剪影的实体（人物、道具）**只给很少或不给破碎拖尾**（`run ≈ 0–0.25`）。灯光：`light [-.55,-.6,.7]`、`norm 3.2`、`amb .8`、`dif .28`、`spec .16–.3`、`ao 1.2`（`DEMO.md:74-75`）。
- **可替代方案**（缺素材时怎么降级而不破风格）：**没有参考插画就什么都画不出来**——本风格的降级路径是**降低场景复杂度**（更少的形状组、更少的明度层级），而不是跳过「明度优先」这一步。人物/道具降级时也**不能**省掉「锥度 + 一道亮边 + 一两笔定义性刀点」这三件套，否则剪影会读成柱子或方块（`STYLE.md:86`、`DEMO.md:105`）。倒影必须是**成叠的短横刀点**，绝不是一个画出来的矩形（`STYLE.md:22`）。

## 10. 编排规则

> **本节是本风格与其它风格差别最大的地方**——impasto **没有 `lines.json`**，也没有 `voices/` 目录、没有 TTS 环节。它走的是自己那套「音乐 + 拟音独立成片」的音频架构。下面把内容入口与音频入口写清楚。

- **内容/画面入口（换主题时要改的核心文件）**：
  1. **`demo/timeline.js`** —— **画面与声音共用的唯一网格源**（`style-dna:165`）。导出：`A` / `B` 两张节拍网格 `{t0, bpm, beats}`（demo A = 80 BPM / 从 0.4s，B = 132 BPM / 从 15.3s）、取拍点助手 `at` / `TA` / `TB` / `BEAT_A` / `BEAT_B`、**切点与事件时间表 `T`**（`hook`/`cutWide`/`title`/`cutMed`/`stop`/`steps`/`splash`/`pop`/`react`/`bowIn`/`cutStreet`/`cutTop`/`gp`/`chord`/`last`/`end`）、总时长 `DUR`、音符表 `MEL_A` / `MEL_B`、和声表 `CHORDS_B`、逐拍事件 `POPS`、弓位函数 `bowPos()`。**先改这个文件。**
  2. **`demo/scenes/*.js`**（`wide.js` / `medium.js` / `ecu.js` / `cellist.js` / `girl.js` / `figures.js` / `top.js` / `cards.js` / `common.js`）—— 每个场景用 `new Ref(w,h,scale)` + `.fill(path, fill, props)` / `.line` / `.text` / `.tint` 画出一张**扁平的、按明度规划的参考插画**，每个形状的 props 给 `{dir, maxR, detail, group, type, hgt, jit, len, wid, aj, fallback}`；再交给 `paintRef(ref, {R:[radii], T, rev(x,y), app(x,y,level)})` 从粗到细铺刀触（Hertzmann 式：先大色块，只在画还没追上参考图的地方——边缘与细节——用更小的笔）。
  3. **`demo/film.js`** —— 镜头、相机、`EDIT` 表（切点）、转场、后期 look（`POST[look]` 的 `grey` / `warm`）、结尾掠射光、片尾卡。人物/道具用 `Strokes().push({x,y,ang,len,wid,c,c2,type,taper,bend,skew,alpha,hgt,rev,app,seed})` 建笔（`type`: `KNIFE`/`BRUSH`/`DAB`/`LINE`），运动物体每帧重建但**必须用固定 seed**。
- **音频入口（换主题时要改的音频文件）**：
  1. **`demo/tools/dump_timeline.mjs`** —— 把 `timeline.js` 导出成 `out/timeline.json`，**这是 Python 侧唯一的网格来源**（日志实测「dump_timeline.mjs → ok，out/timeline.json 回传 OK」）。
  2. **`demo/music/score.py`** —— 采样器配乐（CC0 音源，经 `core/audio/sampler.py`），读 `out/timeline.json` 排段落。demo 参数：A 段 D 小调 80 BPM、B 段 D 大调 132 BPM；10.15s 的未解决 E 被弓离弦硬门切掉；31.21s 大停顿做真数字静默（`style-dna:285-288`）。
  3. **`demo/mix.py`** —— 声设计 + 混音：拟音库（`mix.py:20-64`）、三层雨床与逐镜电平自动化（`mix.py:66-85`）、覆盖换景与标题处的调色刀刮声（`mix.py:91-92`）、音乐优先 / 环境避让 / 大停顿真零 / limit（`mix.py:135-141`）。
- **内容文件字段契约**：见上。**本风格没有 `content.json`，也没有 `lines.json`**——所有内容都写在 `timeline.js`（时间与音乐）与 `scenes/*.js`（画面）里。**换主题时要改的文件就是上面这 5 个**（`timeline.js` + `scenes/*.js` + `film.js` + `music/score.py` + `mix.py`）；`engine/impasto.js` 与 `engine/plate.js` 是通用引擎，不用改。
- **事件词汇表**（画面事件 `T` → 声音 `mix.py`，`style-dna:194-206`）：`cutWide` / `cutMed` / `cutStreet` / `cutTop` / `last` → `knife`（覆盖换景的调色刀刮声）；`title` → 一声长 `knife`（标题被画进画面）；`hook` → `rosin` + 雨点打琴 `woodtap`；`stop` → `rosin`（弓离弦）；`steps` → `splish`（静默里的小脚步，J-cut）；`splash` → `big_splash`（静默后第一个声音）；`pop` → `fwump`（伞布）+ `fabric`（尼龙）+ 颜料落点 `splish`；`bowIn` → `whoosh`（弓抬起）；每个 `POPS` → `whoosh` + `fwump`（伞变彩）；`gp` → 真数字零（大停顿）；`chord` → 雨停、伞收 `fabric`、鸟鸣 `chirp`。
- **时间线契约**：页面契约（`demo/main.js`）暴露 `window.render(t)` / `window.READY`。`film.js` 的 `setup(canvas)` 返回 `draw(t)`：按 `EDIT` 选镜 → 若在转场里则上一镜与当前镜**同时绘制**（`appear`）→ 从 `POST[look]` 取后期 look（`grey` / `warm`）→ 按需覆盖（结尾掠射光 `post.light/norm/expo`、大停顿 `post.expo/sat`）→ `E.finish(post)`。
- **与 `dub.mjs` 通路的关系**：`dub-styles.json#impasto` 也是**派生条目**（`derived: true`），能生效的参数有：`palette`（bg `#1a0a06` / bg2 `#2a2224` / fg `#FFFFFF` / accent `#f8c850` / subtitle `#FFFFFF` / 描边 `#090402` / 底板透明）、`bgRecipe`（`gradient`，stops `[#1a0a06, #2a2224]`，`texture: none`（★ 2026-10-03 更正：原记 `grain`，与「颗粒 0」铁律冲突；当前配置已是 `none`），vignette 0.35）、`subtitle`（SimSun、字号因子 0.03519、marginV 0.14537、marginL 0.07037、无描边、居中）、`title.fontSizeFactor 0.1`、`overlay` 全 false、`motion.subtitleFadeIn 0` / `chapterTransition: "cut"`。**注意两点**：① 这是派生值，字幕字号/位置取自**分类别默认（paper-ink）**，因为 `STYLE.md §4` 只给了字幕形态、没给 px；② `bgRecipe.texture` 与**本风格「颗粒 0」的铁律**（`STYLE.md:23`：颗粒 + 压缩会吃掉刀口）——**★ 2026-10-03 已修**：该字段原为 `grain`（派生条目的自动生成瑕疵），现已是 `none`，与铁律一致，走 dub 通路不再加颗粒。

### 已知缺陷

- **音频比画面长约 0.4–0.5s**：日志实测 `score 40.1545s`、`mix 40.0545s`，而画面 `DUR = 39.65454545454545`、`952 frames`。混流后音频尾部被截掉约 0.4–0.5s。demo 自己没告警，但这是一个真实的对不齐。

### 素材缺口
- **无外部图像素材缺口**：`demo/CREDITS` 明确「All pictures painted in code. No generated images, no photos.」——场景、人物、道具、雨、倒影全部由 `engine/impasto.js` + `engine/plate.js` 程序化绘制。
- **配乐采样缺口**：配乐依赖 CC0 采样库（VS Chamber Orchestra Community Edition、Versilian Community Sample Library、FreePats）+ `core/audio/sampler.py`。**缺这些采样或采样器模块，独奏大提琴 / 手风琴 / 钢片琴的音色会退化**，本风格「手作质感的原声乐器」这一层会明显掉档。
- **字体缺口**：demo 自带 Cormorant Garamond / Cormorant SC（OFL，在 `demo/fonts`，`CREDITS` 提到 `fonts/OFL.txt`）；dub 通路回退 `SimSun`（宋体），衬线展示气质会明显不同。
- **参考插画需自制**：每个新场景都是一张用代码画的扁平明度插画（`scenes/*.js`），**没有现成的插画素材可以直接用**，这是本风格换主题时最大的工作量。

### 能力限制
- 撑不起需要精细文字阅读的题材（刀触托不住小字母，小字必须走 DOM）；撑不起数据表 / UI 密集的题材；撑不起快速蒙太奇（转场只有覆盖式换景与拍上硬切，没有叠化）。
