## 1. 风格说明

**是什么**：一部「剪出来的」纸片动画——**每一个可见之物都是一张被剪刀剪过、平铺在另一张纸上的纸**。没有绘画、没有渐变阴影、没有描边线；细节、体积和表情全部来自**剪掉了什么**。红纸是主角材料，底纸也是纸（白天是浅色纸、夜里是深染纸）。人物是**关节剪纸**（头、躯干、上下肢用铆钉铰接），以 **12 fps 硬步进**表演（`STYLE.md:8`）。

**不是什么**（最容易做错的邻居风格）：不是**皮影**——没有背光幕布、没有半透明驴皮、没有签子，这里的纸是**正面受光且不透明**的，背光是留给关键时刻的**特殊事件**；不是**平面矢量插画**（没有描边、没有渐变）；不是**纯剪影片**（每个形状内部都是镂空的）（`STYLE.md:10`）。

**什么时候用它**：内容本身**能用手艺讲**——折一次剪一刀变出很多、一物照见万物、对称增殖、纸屑回场；以及一切要「年味、团圆、喜庆、被保存」的题材。适合春节、节庆祝福、民俗故事（`style.json#uses`）。

**一句话内核**：折—剪—展就是情节本身——一刀在折缝里，展开成八扇窗；孔就是光，光把纹样投到世界上。

**边界**：撑不起**当代都市职场**内容（纸的语汇与它无话可说）、**数据/图表**内容（没有图表位，纹样不等于信息图）、**快节奏口播**（12 fps 角色步进撑不住密集话术）、**需要写实质感或人物特写情绪**的内容（脸永不变形，表情只能靠换脸片）。

## 2. 画面构图

- **镜头数与画幅**：12 个镜头（S1–S12，`DEMO.md:24-37`），全片 49.00s / 1176 帧 / 1920×1080（16:9），24 fps；**已适配 9:16**（`FILM_META.aspects = ['16:9','9:16']`，**字面量**落在新建的 `styles/papercut-red/demo/film.js:41`，见下）。
- **主体位置与占比**：主体是**层**，不是物体。所有纸层**必须平行于屏幕**——纵深只能来自**视差 + 纸的深浅档**，绝不能用透视（`STYLE.md:63`）。近景人物常偏左或偏中，右侧留给被照亮的东西（样片 f16 女孩在左、发光团花在右）。
- **负空间 / 留白**：留白由**底纸**承担，量中等——夜戏（f06/f09/f18）是大片靛蓝底纸加少量暖光孔，昼戏（f20）是米色纸底加红色剪影层。真正的「空」出现在桌面俯拍段（f13：米色纸上只有一块红方纸）。
- **图层叠放顺序**（从底到顶）：底纸（纸族决定昼夜）→ 远/中/近纸层（每层一步纸档）→ 每片自身的纸纹（`soft-light`，再用 `destination-in` 还原 alpha，保证孔仍是孔）→ 纸影 → 内刻线 → 光（夜景光照图 + 暖光池）→ 自发光背光片 + 辉光 → 投影纹样 → 剪刀/纸屑 → 字幕横批。参考 `paper.js:165-187`、`light.js`。
- **安全区**：字幕横批居中、距底 **70px**（≈6.5% 画面高）、条宽 = 文字实测宽度 + 150px、最多两行（`DEMO.md:90`）。人物近肢要保持在脸的前方，否则举起的近臂会横穿面部（`STYLE.md:42`）。
- **本风格不能出现的构图**：**红压红**（底与主角同一纸族会让剪影不再跳出来，`STYLE.md:28`）；灰色色块或渐变阴影（「填灰」是硬禁忌）；等宽描边线；任何用透视造出来的纵深；任何悬空孤岛（真纸剪不出掉心的环，镂空必须有桥，`STYLE.md:19`）。

**在 9:16（产品默认）下的表现**：本风格**已适配 9:16**（★ 2026-10-04 改造）——`FILM_META.aspects = ['16:9','9:16']`（`film.js:41`）。`main.js` 首行读 `window.innerWidth/Height` 设 `cv.width/height` 再 `setFrame()`（`main.js:20-22`）；`film.js` 的 `setFrame(w,h)` 派生 `W/H/FX/FY/S = min(fx,fy)`（`film.js:20-26`），并把**模块加载期建的常驻画布**（`fcanvas()`，`film.js:15-19`）按当前帧重设尺寸。本风格有**两类家什**（`film.js:2-8` 写明）：

- **设计帧里的东西**（相机里的世界、片名卡、片尾揭示与片尾卡、海报）走**设计帧 → 当前帧的等比装入**：相机 `cam()` 把 `S` 折进 zoom（`main.js:35`：`[z*FS,0,0,z*FS, W/2−x·z·FS, H/2−y·z·FS]`），其余走 `frX/frY/fitM`（`film.js:29-34`）。世界与家什**同一套映射**，剪纸的圆不会被压成椭圆。
- **当前帧的家什**（字幕横批 / 全屏叠加：淡入淡出 / 揭纸 / 光斑）按「位置 ×FX/×FY、尺寸 ×S」**铺满视口**（`ctxX/ctxY`，`film.js:36`；字幕 `hud.js:44`：`x = W/2 − s.w·FS/2`、`y = H − (70+s.h)·FS`）。这一条与上一条**不能混**：走等比装入会让全屏叠加只覆盖中间一条。

**实测（1080×1920，`S = 0.5625`）**：**不裁切、无黑边、无字幕被切**。整幅设计帧按 0.5625 等比缩入并居中；因为 `W·S = 1080 = W`，**横向构图与 16:9 逐点同比例**（`frX` 保持横向比例，右侧 43.75% 一分不少），纵向内容落在画面中段（设计帧上下边缘 → `frY(0) ≈ 0.342`、`frY(1080) ≈ 0.658`），上下由底纸（夜戏靛蓝 / 昼戏米色）自然填满，无黑边。字幕横批居中贴底：实测条宽 **880–920 px**（x 80–999，`< 1080`、左右各留 ≥ 80px）、条底距帧底约 43 px（`hud.js:44`）。**真重排证据**：9:16 与「16:9 中心裁切」的 SSIM = **0.703 / 0.868 / 0.661**（7.35s / 24.5s / 41.65s；`crop=607:1080:656:0` 后 `scale=1080:1920`），明显 < 1 ⇒ **不是裁切**。**代价（如实写明）**：这是**等比装入 + 底纸留白**，不是重构图——主体缩到 0.5625×、竖屏上下各留大片底纸，画面密度低于 16:9（夜戏的雪地/天空分界在 9:16 里读成一条横向色带）。本风格按 1920×1080 绝对像素构图的老结论（右侧丢 43.75%、下方整片黑、横批右半被切）**已作废**。

## 4. 转场规则

- **镜头之间怎么切**：转场**必须来自剪纸工艺本身**——折、翻页 / 揭纸、一张纸飞走、一刀切穿画面（`STYLE.md:63`）。样片里 S2 出画靠 title sheet 沿中线折过去、S10 黎明靠**夜纸从右上角揭起**露出昼纸、S1 冷开场靠**剪过的纸飞走**露出宣纸。
- **有没有叠化 / 闪白 / 擦除 / 定格**：**没有溶解、没有叠化**（`STYLE.md:63`、`style-dna/papercut-red.md:115`）。没有元素淡入或滑入——字幕是「落」下来的：**两步 12 fps 落下**，像贴一副对联（`STYLE.md:34`）。
- **硬切点怎么定**：切点挂在 **120 BPM、2/4 网格**上——1 拍 = 0.5s、1 小节 = 1.0s；关键时刻写死在 `story.js` 的 `T` 表里（snips .25/1.0/1.75、title 3.0、village 7.0、rise 12.0、room 17.0、folds 24/25/26、cut0 26.5→cut1 29.4、unfolds 30/30.25/30.5、bloom 31.0）。**一剪 = 一个八分音符**。
- **转场时长与缓动**：折约 **0.55s 一次**（落在一次木鱼上）；展开三次各间隔 0.25s、每瓣 ease-out 的「啪」；剪的揭示沿剪刀路径一串圆蒙版展开（半径 r≈62 单位）。镜头、光、天气、火焰、飞纸**逐格动（24 fps）**，角色**硬步进（12 fps）**。
- **绝对不要的转场**：溶解/叠化等 UI 式转场；淡入/滑入；镜头之间留出空帧（要用出画与入画的纸动作**交叠**，`STYLE.md:91`）。

## 5. 字幕样式

| 项 | 值 |
|---|---|
| 字体 | 结实的 OFL 衬线（STYLE.md 点名 Fraunces SemiBold；本机没有，dub 通路退到 SimHei）；片名用 Fraunces 800 剪字 |
| 字号（相对画面宽 / 高） | 字幕 44px @1920 宽 ≈ **2.29% 画面宽**（dub 条目 `fontSizeFactor: 0.041` 与之一致）；片名标题 `fontSizeFactor 0.09` |
| 颜色 / 描边 / 阴影 | 奶油字 `#fff1d6` 压在同色族更暗的红横批 `#a8111f` 上，带一层纸影；**没有描边**（剪纸是叠层，不是描边） |
| 位置 / 安全边距 | 居中，**距底 70px**（≈6.5% 画面高）；横批条宽 = 文字实测宽度 + 150px |
| 单行字数上限 / 最多行数 | 最多 **2 行**；样片单句 32–74 字符（最短 `Crackle, bang! And away ran Nian.` 32，最长是「三怕」清单句 74） |
| 出现与消失方式 | **落下**：两步 12 fps 落到位，像贴对联；停留 ≥ `max(1.8s, 语音时长 + 0.7s)`；两条字幕**绝不重叠**（`subs.py`：`t1 = min(下一句−0.15, 起点+max(1.8, dur+0.7))`） |

- **字幕与旁白的关系**：字幕是**画面里的一条纸横批**，不是浮层——它有锯齿边、燕尾端、带纸影，属于这个世界。本次出片 5 条字幕（srt 5 cues），时间落在 19.55–24.75 / 35.15–38.13 / 38.55–43.65 等窗口（`logs/papercut-red.log`）。
- **本风格特有的字幕禁忌**：不许淡入、不许滑入、不许重叠；不许用无衬线现代字体（会读成 UI）；横批的红**必须比画面里的红更暗**，否则奶油字立不住；不许用第一人称抒情或营销话术式的句子（`style-dna/papercut-red.md:52-56`）。

**文案+风格通路的底衬落地**：STYLE.md §4 声明「Subtitles are a paper strip in the world, e.g. a red banner」，但「文案+风格」通路原先只走 `BorderStyle=1`（只画描边与阴影、不画底盒；盒填充字段 `OutlineColour` 被当作描边色用），这层底衬从未画出来。现已切到 `BorderStyle=3`（不透明底盒：盒填充色改用 `OutlineColour`、`Outline` 变为盒内边距，`BackColour` 仍只作阴影色——box 模式下 `Shadow=0`，故该阴影不绘制），渲染参数固定为 `BorderStyle=3`、盒内边距 `Outline=10`（1080 高基准）、`Shadow=0`、盒填充色 `OutlineColour=#00A8111F`（AARRGGBB，落盘 ASS 为 `&H001F11A8`）。`Shadow=0`：`BorderStyle=3` 下 ASS 的阴影是一份与底盒几乎完全重叠的整盒副本，会把半透明底衬二次压暗（实测 `hd-2d` 的对比度由 6.00 掉到 3.18）；置 0 后底衬的不透明度如实生效，也与检查器的单层合成模型一致。该色值取自 demo 的 band 真实实现（demo band rgba(168,17,31,1)）；字色 #f2e8d0 与该底衬的 WCAG 对比度 **6.23**。

## 6. BGM / 音效特征

- **配乐**：**明亮的中式室内小合奏**——琵琶（长音轮指）、筝（`dan_tranh`：琶音/刮奏/轮指）、二胡（滑音）、笛子、笙或扬琴音色、木鱼、小锣与大锣、手鼓；**五声音阶**（样片是 D 宫五声 D E F# A B），120 BPM、2/4、4 小节原创主题（`DEMO.md:41`）。**明确排除**钢琴、弦乐组、戏曲锣鼓与唢呐——为了避开皮影戏与水墨（`DEMO.md:41`）。
- **拟音（foley）清单**：**按材料分层**——剪刀 = 金属擦切（2.5–9kHz 带通）+ 短铃 + 纤维断裂的「咔」；折 = swish + 折痕轻拍；展开 = 清脆「啪」；重步 = **厚纸板闷「嘭」（55Hz）**，每步约 6px 画面抖动；揭纸 = 细碎撕拉；贴纸 = 手掌轻拍；火柴擦燃与「噗」；爆竹 = 20–60ms 间隔密集噼啪 + 远处闷响。**一剪 = 一拍细分**，上行筝音一音符对应一出现之物，一记大锣只留一个重音（31.0 bloom 处）。
- **旁白处理**：温暖的奶奶、除夕夜讲故事，Kokoro `af_sarah`、speed 0.9、五句；近、暖、小屋子混响（`room_ir .8` 混 .12）；人声窗口内**不放撞击声**。本次出片 ASR 校对 5/5 全 OK、mismatches 0（`logs/papercut-red.log`）；「Nian」被 whisper 听成 Nion/Nyan，已在 `lines.json` 注册 `asr` 别名。
- **响度目标**：`−14 LUFS`；**真峰值上限**：`−1.2 dBTP`。本次成片实测 **−14.1 LUFS / LRA 5.1 LU / 真峰值 +1.73 dBTP**（口径 = `loudnorm` 的 `input_tp`，4× 过采样；mux 告警里印的 `peak 0.328200 dB` 是 `astats` 的**采样峰值**、不是真峰值，同一行括号里的 ebur128 1 位小数读值 `1.7` 才接近真峰值）——**超出 −1.2 dBTP 交付线 2.93 dB，真峰值为正即已实际削波**，mux.sh 明确告警（`logs/papercut-red.log:137-140`）。**不加胶片颗粒**（纸纤维本身就是质感）。 ★ **2026-10-03 已修**：成片已用 `scripts/fix-truepeak.mjs` 音频重混（`-c:v copy`，视频流逐字节未变），真峰值 +1.73 dBTP → **−1.69 dBTP**、已在 −1.2 dBTP 交付线内（达标）；原 +1.73 dBTP 记录保留为历史。
- **静音策略**：静默是**真实存在的一段**，是「奖赏之前的清场」：17.0–19.5（年兽眼睛段）整段无音乐、只留风声雪声与沉重呼吸（实测 peak −74.6 dB）；29.5–30.0（剪完、展开前）所有声音停住留一拍屏息（实测 peak −211.1 dB，即数字静音），然后 31.0 才爆出大锣与 tutti（实测 30.6–30.99 为 −29.2 dB、31.0–31.4 跳到 −14.9 dB）。

## 7. 素材偏好

- **需要什么素材**：几乎**不需要外部素材**——一切由代码生成。真正要产出的是：`story.js`（唯一真值：`DUR`/`BEAT`/`T`/`VO`/`SHOTS`）、关节片模块（一组 `piece` + `rig` parts 表 + 可换脸片）、纸族配色（昼纸 / 夜染纸 / 靛蓝 / 玉绿 / 黑纸，按主题选）、五声配乐（`music/score.py` 原创）。纹样全部来自 `motifs.js` 的民俗剪纹库（锯齿、月牙、旋涡、云、团花、梅花孔、铜钱孔、锥形刻线）。
- **不需要什么素材**：不需要照片、不需要实拍视频、不需要矢量素材包、不需要描边/渐变资源、**不需要任何真实的窗花纹样或团花版式**（`STYLE.md:4` 明确要求「generate every pattern from code」，且**不许在片子里点名参考对象**）。
- **取景 / 质感 / 比例偏好**：16:9（1920×1080）；质感全部来自「纸」——纸纹 `soft-light` 斑驳 ±7% @约 130px、刀口低频抖动 `edge wobble ≈0.35` 单位 + 左上 1px 亮边/右下 1px 暗边、纸厚阴影、内刻线；**建筑与机械用直线段 + 抖动，绝不圆滑**（平滑会把房子变成面包，`DEMO.md:115`）。
- **可替代方案**（缺素材时怎么降级而不破风格）：没有团花生成器就退到 **2×/4× 折**（更简单的对称仍然成立），但**不能**改成「一个不规则形状」；没有中式民乐样本就用任何**单件拨弦/弓弦 + 木鱼**的合成音色，**绝不能**换成钢琴+弦乐组或电子鼓；角色部件太复杂就**减少部件数、把动作压到 12 fps 的 3–4 个姿势**，但**不能**把角色改成「渐变插画人物」——那会直接破风格。

## 10. 编排规则

- **内容文件字段契约**：`story.js` 是**唯一真值**（`style-dna/papercut-red.md:174-183`）——`DUR`（总时长秒，demo 49.0）、`BEAT`（一拍秒数 0.5）、`T`（关键时刻秒数表：snips/lift/title/titleFold/village/rise/lightsOut/room/blink/decide/red/light/noise/nod/folds/cut0/cut1/unfolds/bloom/paste/outside/lanterns/nianClose/flinch/flee/fireworks/dawn/sunUp/asleep/reveal/cadence/end/endTicks）、`VO[]`（`{id,t,text}`，同音词写 `asr` 别名）、`SHOTS[]`（`[起,止,名]`，用 `shotAt(t)` 查表）、`lines.json`（`{id,text,voice,speed,asr?}`）。
- **事件词汇表**（本次导出 **81** 条，`type` → `mix.py` 里的声音）：`snip`（剪刀，可 `big`）、`paperwhoosh`、`place`/`stamp`/`pat`（贴/印/拍纸）、`pageturn`、`windbed`、`thud`（年兽脚步，厚纸板闷响 55Hz）、`growl`、`puff`（烛火熄）、`breath`、`blink`、`match`、`fold`/`unfold`、`bloom`、`glowon`、`lanternarrive`、`crackers`/`firework`、`yelp`、`peel`、`bird`、`roomtone`、`vo{id}`。
- **时间线契约**：页面契约（`main.js`）暴露 `window.READY` / `window.render(t)` / `window.DUR` / `window.EV`；`story.js` 导出 `DUR/BEAT/T/VO/SHOTS/shotAt`；`fold.js` 导出 `drawFold(g,t)`、`camFold(t)`；`light.js` 导出 `beginLight/pool/glowWindow/bloom/rays/applyLight`；`events.mjs` 读 `window.EV` 生成 `events.json` 驱动声音。
- **新增主体怎么接入**：一个新人物/新物 = 一个「**关节片模块**」——(1) 一组 `piece`（用 `paper.js` 的 `piece(box,draw,opt)` 预渲染，走完整工序 `fill → cut → inset → finishPaper`）；(2) `rig` parts 表（`rig.js` 的 `{name,parent,at,piece,ang,z}`，由 `solveRig` 解出各部件矩阵）；(3) 可换的脸片/表情片。造型规则：红块 + 内刻线、孔用月牙 + 瞳孔孔、不留孤岛、对称物用 D4 变换（`tuanhua.js`）。
- **换主题时要改哪些文件**：**改 3 组**——(1) `story.js`（时间线 + `T` + `VO` + `SHOTS`）、`lines.json`（旁白脚本）；(2) 主体模块（人物/物件的 `piece` + `rig` + 脸片）与 `village.js` 一类场景布局（含昼/夜纸族）；(3) `music/score.py` 的主题音高与 cue 表（它读 `events.json`，所以**任意折/剪/展次数都能自动配到乐**）。`paper.js` / `motifs.js` / `rig.js` / `tuanhua.js` / `light.js` / `fold.js` / `hud.js` / `mix.py` **不需要动**——这是本风格最关键的复用机制：**换主体与时间线，工艺层不变**。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里是 `derived:false`、`derivedFrom:["stylerule","demo-code"]` 的条目。**能生效的参数**：`palette`（bg/bg2/fg/accent/subtitle/subtitleOutline/subtitleBack）、`bgRecipe`（type=**solid**、stops `["#f2e8d0"]`、`texture:"paper"`、vignette 0.08）、`subtitle`（fontFamily `SimHei`（本机无 Fraunces SemiBold）、fontSizeFactor 0.041≈44px、marginVFactor 0.12、marginLFactor 0.06、outlineFactor 0.0037、bold true、align 2）、`title`（fontSizeFactor 0.09、showRole false）、`overlay`（chapterCards **true**、lowerThird **true**）、`motion`（subtitleFadeIn **0**＝「落」不是淡入、chapterTransition **cut**）。★ 2026-10-03 已修：该条目的 `palette` **字段值曾与它自己的 `notes` 打架**（字段为 bg `#D2201F` / fg `#f2e8d0` / accent `#FCF9F2`，notes 说「修正后」应为 bg `#f2e8d0` / fg `#d2201f` / accent `#d9a93f`），现已按 notes 校正为 bg `#f2e8d0` / fg `#d2201f` / accent `#d9a93f`、`bgRecipe.stops = ["#f2e8d0"]`，不再红压红（原观察保留为历史）。

- 12 fps 角色步进撑不住密集话术与快节奏口播；脸永不变形，表情只能靠换脸片，做不了细腻情绪特写。

### 踩过的坑（本机实测）
- 本次出片**完整跑通但有告警**：`node lemo-make.mjs papercut-red --skip-sync --no-preflight --ratio 16:9`，1920×1080、nvenc、24fps、6 workers；渲染 1176 帧用 20s，成片 35.2MB、总耗时 57.0s；**唯一告警是音频峰值超限（见上）**。
