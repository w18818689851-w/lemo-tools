## 1. 风格说明

**是什么**：一个用**正交等距**镜头看的**微缩世界**。画面里的一切都由平面着色的低多边形几何块构成——尖顶六边形地块柱、箱体房子、三棱柱双坡屋顶、锥体松树与二十面体阔叶树——浮在一片带面片反光的海面上。没有透视、没有地平线，远处直接溶进屏幕纵向的天空渐变，所以整个世界看起来像一块**悬在颜色里的模型**（`STYLE.md:8`）。**光就是唯一的时钟**：太阳移动时每个面片重新上色，暗处只剩自发光的窗与灯还保留颜色。

**不是什么**（最容易做错的邻居风格）：不是**体素游戏**（没有方块的方块、没有像素贴图）；不是**真实景物的移轴摄影**（没有透视、没有照片细节）；不是**平滑着色的 3D 卡通**（没有圆滑法线、没有次表面散射）（`STYLE.md:10`）。

**什么时候用它**：适合讲「一件东西被一块块造出来」的内容——产品从零装配、团队把一件事拼起来、一座城/一个果园/一片珊瑚礁的成长、一个网络逐节点亮起、一次施工的完整过程。也适合只想交付「安静、可爱、大量留白」观感的治愈向内容。

**一句话内核**：**建岛即作曲**——每一块落地的东西都带一次弹跳和一个音符，画面自己写出旋律（`DEMO.md:18`）。

**边界**：这个风格**撑不起**强冲突、快节奏、密集信息或真实人物。它不能出现人脸特写、不能靠对白推进、不能做数据密集的信息图；抽象概念当主语会让它立刻失焦（`style-dna/lowpoly-island.md:55`）。它也不能承载「危险、紧迫、脏乱」的气质——夜里唯一的暗是阴影与 AO，没有纯黑（`STYLE.md:27`）。

## 2. 画面构图

- **镜头数与画幅**：原生画幅 **1920×1080（16:9）**，`--ratio 16:9` 渲染（`_distill/logs/lowpoly-island.log:1-2`）。全片 12 个镜头段（`SHOTS`，`story.js:64-79`）；**已适配 9:16**（`FILM_META.aspects = ['16:9','9:16']`，`demo/film.js`），见下方子段。
- **主体位置与占比**：世界本体在画面中央偏下，开场与结尾刻意让它变小。开场近景只有**一个浮标**（frustum 7.5），结尾纯正交拉远 ×25 让整岛缩成一个亮点（`DEMO.md:24,31`；帧 f01/f22）。
- **负空间 / 留白**：大量。天空渐变带永远停在**画面上三分之一**（`main.js:82-84`；帧 f02/f04），夜里天空占掉约七成画面（帧 f19/f20/f22）。
- **图层叠放顺序**（从底到顶）：远处粗海面（5000 单位，y −0.55）→ 近处 220×220 面片海面 → 浅水泻湖图与浪花环 → 地块柱 → 道具（房/树/码头/船）→ 发光件（窗、灯室玻璃）→ 光束 ribbon + halo → 屏幕天空渐变与星 → HUD（片名/字幕/片尾卡）（`sea.js:64-66`、`post.js:33-49`、`main.js:131-158`）。
- **安全区**（字幕 / 主体 / 边缘）：字幕居中、距底 **118px**（≈10.9% 画面高），无底框；主体不下沉到画面下缘——相机永远离目标 **≥ 3× frustum 高度**，否则会看到海面以下（`main.js:78`）。片尾卡刻意在文字块之间留出缝隙，让那颗亮着的小岛仍然可见（`DEMO.md:61`）。
- **本风格**不能**出现的构图**：任何带消失点的透视构图、任何有真实地平线的构图、任何俯拍实景、任何把主体压在画面最下沿的构图。

**在 9:16（产品默认）下的表现**：**已适配**（`FILM_META.aspects = ['16:9','9:16']`，`demo/film.js`）。本风格是 **WebGL + 正交等距**，改造走的是「**正交相机重取景**」这一档：页面把渲染画布与 `#ov` 设成**视口尺寸**（`main.js:14-19`、`:101`），`cam()` 的 frustum 改为「**水平世界范围恒等于设计帧**」——`fw = fh × 1920/1080`（与画幅无关）、竖直范围 `fhh = fw × H/W` 随画幅变（`main.js:85-92`）⇒ 竖屏在**上下多看到天空与海**，世界内容恰好等于「设计帧等比装入并居中」（`hz0/hz1` 是世界空间量、用设计帧的 `fh`，不随画幅变，地平线的落点自动落在等比装入后的位置）。HUD（片名 / 字幕 / 片尾卡）贴**当前帧**：位置 ×FX/×FY、字号与尺寸 ×S（`main.js:124-170`）。1080×1920 实测：**水平方向与 16:9 完全同幅**（岛、灯塔、风车、码头、小船、浮标全部完整），上下各多出天空与海面；字幕「Then, the ground began to sing.」/「By evening, every house knew its part.」/「Far away, another island hears its first note.」与片尾卡（标题 + 副题 + 署名 + 版权行）都在帧内、未被裁；9:16 与「16:9 中心裁切」的 SSIM 仅 **0.84–0.93**（≠ 裁切），而 9:16 的**中央设计带**与「16:9 等比装入 ×0.5625」的 SSIM 达 **0.94–0.98**（确认是重取景而非裁切）。**16:9 无回归**：`fhh = fh`，每个表达式退化成它替换掉的那个数字；3 帧「改造前 vs 改造后」PSNR **62.7 / 55.6 / 61.5 dB**，与「同帧渲两次」的噪声地板（62.9 / 55.6 / 61.2 dB）同量级（本风格 WebGL 渲染非逐字节确定，md5 判据不可用，故用 PSNR 判定）。代价：主体像素尺寸 = 16:9 的 **0.5625 倍**（等比装入的必然结果），**本轮没有做「真竖版重排」**（重排主体与字幕、重算安全区）。另修一处**只有竖屏才暴露**的缺陷：正交拉远段（t ≳ 47s）竖直范围会伸到相机背后 ⇒ 画面下缘一条天空色带；判据用整数比较 `H·1920 > W·1080`（16:9 恒为假 ⇒ 16:9 逐位不变），只在该情形把相机距离 `D` 加大（`main.js:87-89`）。

## 4. 转场规则

- **镜头之间怎么切**：**硬切**，且切点落在**拍点**上（96 BPM 网格，1 拍 = 0.625s，`story.js:3`）。全片 12 段（帧 f04→f05→f07→f08→f10→f11→f13→f16→f18→f19→f21→f22 均为硬切）。
- **有没有叠化 / 闪白 / 擦除 / 定格**：没有。允许的第三种转场是**穿过天空的缩放**（zoom through the sky），以及**同机位的时间跳档**（天色变化）（`STYLE.md:63`）。
- **硬切点怎么定**：跟拍点走——生长事件的密度变化（2 分→4 分→8 分格）本身就是剪辑节奏，宽景与近景在拍点上交错（`DEMO.md:25`）。
- **转场时长与缓动**：硬切即 0 帧过渡。若用天色跳档，靠 `skyAt()` 插值关键帧（`main.js:32-41`），不靠叠加特效。
- **绝对不要的转场**：溶解/叠化（dissolve）、划像（wipe）等 UI 式转场；透视甩镜（perspective whip-pan）；任何改变 fov 或透视的操作——**投影永不变**（`STYLE.md:46,63`）。

| 颜色 / 描边 / 阴影 | 暖白 `#fffdf8`，**无描边**，藏蓝投影（blur 14） |
| 位置 / 安全边距 | 居中，距底 **118px**（≈10.9% 画面高），无底框 |
| 单行字数上限 / 最多行数 | 单行 ≤ ~50 字符；**永远单行**，不折行 |
| 出现与消失方式 | 比旁白**提前 0.05s** 出现；停留 ≥ `max(1.8s, 语音时长 + 0.6s)`，不得与下一句或片名重叠 |

- **字幕与旁白的关系**：字幕是旁白的逐字稿，不做二次改写；字幕旁附一个**小六边形地块图标**（顶面 + 两个侧面），图标顶色随时间变化——黎明的粉、白天的草绿、黄昏的橙、夜里的窗黄（`main.js:94-105`、`DEMO.md:56`）。
- **本风格特有的字幕禁忌**：不许加底框或半透明色板（`STYLE.md:34`）；不许与片名同屏；不许折成两行；片名字幕是**逐字从一条细水线下升起**、过冲后回落，不是淡入（`main.js:112-130`）。

## 6. BGM / 音效特征

- **配乐**：**事件驱动**——页面导出的每条生长事件都带 MIDI 音高，`music/score.py` 在它的**精确时刻**合成这个音（本次实测合成了 **332 个音**，`logs/lowpoly-island.log:74`）。乐器只用**音高打击乐**：marimba、kalimba、woodblock、bells、vibraphone、celesta、steel drum；底下垫一层软 pad、一条温柔的 marimba ostinato、白天与高潮段加轻 shaker / 软 kick。**96 BPM，D 大调五声**（`DEMO.md:37`）。**无钢琴、无弦乐**（`STYLE.md:67`）。
- **拟音（foley）清单**：升起地块 = 气泡扫掠 + 水花 + 14 颗水滴嗒（越大越低）；楼层 = 木块敲 + 更轻的回弹敲（**第二次敲在首次后 0.21s**）；屋顶 = 陶瓷咔嗒；码头木板 = 空敲；灯塔环 = 石块闷响；灯室玻璃 = 叮；点亮 = 低频 whump + 电流嗡。环境床：低通棕噪海浪、海鸥（下滑 FM 啾声）、风车吱呀、黄昏起的蟋蟀（`DEMO.md:42`）。
- **旁白处理**：Kokoro `af_sky`（清晰温柔女声），speed 0.86–0.92，5 句短句（`DEMO.md:43`）。人声压缩、**比音乐高约 10 dB**；音乐在人声下 **duck −8 dB**（`STYLE.md:73`）。
- **响度目标**：`-14 LUFS`；**交付真峰值上限**：`-1.2 dBTP`（项目级交付线；本风格 `STYLE.md:73` 只写 −14 LUFS，未额外声明更严上限）。本次成片实测 **I = −14.0 LUFS / LRA 4.6 LU（`ebur128`）/ 真峰值 −1.48 dBTP（`loudnorm` `input_tp`，4× 过采样）—— 真峰值在交付线内，余量 0.28 dB、未削波**（`logs/lowpoly-island.log:107-110` 只印了 `ebur128` 的 `Peak -1.5 dBFS`——那是 1 位小数读数，`astats` 采样峰值 −1.525210 是下界，两者都不能当真峰值用）。
- **静音策略**：夜晚段降到一层低 pad 长音 + 海浪 + 蟋蟀，音乐几乎只剩持续音；高潮重拍之前，音乐总线最后半拍被压到**数字零**（`DEMO.md:39`）。静默不是停止，而是把节奏交给世界自己的事件。**grain 0**——平坦色块会因颗粒闪烁（`STYLE.md:73`）。

## 7. 素材偏好

- **需要什么素材**：**几乎不需要外部素材**——世界、道具、音乐、拟音全部程序化生成（几何图元 + WebGL shader + 合成音频）。真正要人写的是：片名/副题/片尾卡文字、5 行左右旁白、世界参数（岛形/道具清单/调色板）、生长日程（事件时刻 + MIDI 音高）、天色关键帧、镜头段表（`style-dna/lowpoly-island.json:93`）。
- **不需要什么素材**：**不需要任何贴图、位图纹理、实拍照片或视频**（`STYLE.md:16`）；不需要字体文件以外的设计资产（字幕字体是 OFL 的 Quicksand / Josefin Sans）。
- **取景 / 质感 / 比例偏好**：正交等距（默认方位角 45°、俯角 30°），frustum 高度 5–7 做近景、12–16 看全岛、最高 420 做尺度揭示（`DEMO.md:33`）。
- **可替代方案**（缺素材时怎么降级而不破风格）：若没有音频合成链路，可退化为**纯环境床 + 少量拟音**，但**不能**用钢琴/弦乐素材顶替——那会直接破坏风格（`STYLE.md:67`）。若无法做 GTAO，可用更暗的环境光 + 地块缝隙加大来近似接缝，但会丢失屋檐下的暗（见第 11 节）。

## 8. 镜头节奏

| 项 | 值 |
|---|---|
| 单镜时长 | 约 2.5–6.25s（对齐 1 小节 = 2.5s 的网格，`story.js:3`） |
| 全片时长 | **53.00s**（实测；`style.json dur=53.0`、`logs/lowpoly-island.log:26`） |
| 镜头数 | 12 段（`SHOTS`，`story.js:64-79`） |
| 信息投放节拍 | 生长事件按最小格排、**一块一格**：地块 2 分→4 分→8 分音符，房子部件占 16 分格，细节从下一个 16 分格接上（`world.js:217-221,248-252`） |

- **加速 / 减速点**：**靠密度加速，不靠提速**（`STYLE.md:45`）。开场极慢（0–6.25s 只有一个浮标，帧 f01/f02）；6.25s 起第一块地升起进入加速生长（帧 f04→f08）；21–26s 生活化的一天（帧 f10/f11）；26s 后黄昏（帧 f13）；31–36s 夜晚减速到几乎静止（帧 f16，只剩一盏灯与浮动的屋顶部件）；36.25s 灯塔点亮进入高潮（帧 f17/f18）；43.95s 起纯正交拉远（帧 f21/f22）。
- **留白与静音的位置**：开场 6.25s 的空海（f01/f02）与结尾 46.25–53s 的星空拉远（f22/f23）是全片两处最大留白；夜晚段 31.25–33.75s 是音乐 RMS 最低点（**−32.6 dBFS**，`logs/lowpoly-island.log:68`）。

## 10. 编排规则

- **内容文件字段契约**：`story.js` 必须导出 `DUR`、`BPM/BEAT/BAR`、`bar(n)/beat(n)`、`G0`、`T`（段落秒表）、`VO`、`SHOTS`、`shotAt(t)`；`world.js` 导出 `EVS`（生长日程）；旁白在 `lines.json`（`{id, text, voice, speed}`）。页面契约：`main.js` 暴露 `window.render(t)` / `window.DUR` / `window.EV` / `window.READY`（`story.js:2-79`、`main.js:201-207`）。
- **事件词汇表**：`rise`（地块升起，带 note）/ `pop`（树/灯弹出）/ `floor` `roof`（楼层/屋顶落定）/ `plank`（码头木板）/ `splash`（小船落水）/ `window`（窗点亮）/ `ring` `lamproom`（灯塔环/灯室）/ `ignite`（灯塔点亮）/ `beamhit`（光束命中一格）/ `boatbell` `bell`（船答铃/浮标钟）/ `chord` `sparkle`（和弦/点缀）；另加 `vo` / `amb{what,d}` / `title` / `endcard` / `cue{name}`（`main.js:184-194`）。
- **时间线契约**：一切挂在 **96 BPM** 网格（1 拍 0.625s / 1 小节 2.5s）；律动第 0 小节从第一块地升起（`G0 = 6.25s`）开始计；片尾卡在 48.75s，总长 53.0s（`story.js:2-28`）。
- **新增主体怎么接入**：一个新的「世界/主体」模块必须提供三样——① **布局函数**返回地块数组 `{q, r, x, z, h, type}`（对照 `buildLayout`）；② **道具工厂**返回 `{root, parts[]}`，每个 part 带 `t0` 与 `kind`（对照 `makeHouse`）；③ **生长日程 `EVS`**，每条 `{t, type, note?, ...}`，每件可动件必须有 `t0` 与到位曲线（`dropY`/`popS`）（`world.js:38-53,78-101,389-394`）。
- **换主题时要改哪些文件**：只需改 `story.js`（片名/旁白/和弦/天色/镜头段表）、`world.js` 的 `PAL` 与 `buildLayout`/道具工厂/`EVS`、`lines.json`。**引擎四件（`sea.js` / `post.js` / `main.js` / `music/score.py`）通常不动**——因为配乐读的是页面导出的 `EV`，换世界自动得到匹配的新配乐（`style-dna/lowpoly-island.md:233`）。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里可生效的参数是 `palette`（`bg #eef6fb` / `bg2 #3aa3b8` / `fg #141414` / `accent #ffc676`）、`bgRecipe`（gradient、vignette 0.08、texture flat-shaded-3d）、`subtitle`（字号因子 0.03889、下边距 0.14537、描边 0、align 2）、`title`（字号因子 0.086）与 `tags`（主题 游戏/儿童/旅行，情绪 轻松/童心，节奏 慢，场景 故事/教学）。**注意**：该条目是 `derived:true` 的派生值，字幕字体写的是 `DengXian` 而非 Quicksand（见第 11 节）。

## 11. 当前短板与避坑要点

### 已知缺陷
- **【已修】9:16 曾丢画面**：原记「本风格无 `aspects` 声明、按 1920×1080 绝对像素构图。产品默认 9:16 导出时画面 1:1 塞左上角、右侧约 43.75% 丢失、下方整片黑。要出竖版必须改构图常量重渲，不能靠裁切」。**2026-10-04 已修**：新增 `demo/film.js` 声明 `FILM_META.aspects = ['16:9','9:16']`；页面把画布与 `#ov` 设成视口尺寸；`cam()` 的正交 frustum 改为「水平世界范围恒等于设计帧、竖直范围随画幅」（16:9 时 `fhh = fh` ⇒ 逐位不变）；HUD 按 FX/FY/S 重排。1080×1920 实测不裁切、不变形，主体与字幕完整（见第 2 节子段）。
- **「文案+风格」通路的字幕字形不对**：`dub-styles.json#lowpoly-island` 的 `subtitle.fontFamily` 是 `DengXian`（分类默认派生值），而风格原生字幕是 **Quicksand 600 / 44px**；走 `dub.mjs` 通路时字形会偏离（见 `dub-styles.json#lowpoly-island` 条目的 `subtitle.fontFamily`）。同理 `subtitleOutline:0` 与原生「无描边 + 藏蓝投影」一致，但投影会被通路丢掉。
- **本次渲染有一条 GLSL 告警**：`THREE.WebGLProgram: warning X3595: gradient instruction used in a loop with varying iteration`（`logs/lowpoly-island.log:42`）——非致命，但说明某个循环里用了渐变指令，画面无可见异常。
- **细纹理 `textureRaw: flat-shaded-3d` 声明了但渲染未实现**：`lib/dub-styles.json#lowpoly-island.bgRecipe.textureRaw` 是 `flat-shaded-3d`，而渲染侧（`lib/dub-core.mjs` 的 `bgFilters()`）**只把粗粒度 `bgRecipe.texture` 当主权威源**（本风格是 `none` ⇒ 落空（该风格粗粒度没有纹理层）），**不读** `textureRaw` ⇒ `flat-shaded-3d` 这一层质感在「文案 + 风格」通路上**从未画出来过**。为什么没实现：`bgFilters()` 里没有 `flat-shaded-3d` 对应的滤镜分支，按「只复用已有分支、不发明无数据依据的参数」的口径**只如实标注、不猜参数**（已集中登记在 `lib/dub-styles.json` 的 `_notes` 未实现清单里）。

### 素材缺口
- 无外部素材缺口（全程序化）。真正的缺口是**字体文件**：若运行环境没有 Quicksand / Josefin Sans，字幕与片名会 fallback，字形立刻不像本风格。
- 本风格 9:16 走**正交重取景**（水平世界范围不变、竖直范围随画幅），**没有**单独的竖版地块布局参数；只有要做「真竖版重排」（重排主体与字幕、重算安全区）才需要重新调 frustum 与俯角。

### 能力限制
- 依赖 **WebGL + GTAO + 2× SSAA**：本次 6 workers 渲 1272 帧耗时 207s（`logs/lowpoly-island.log:97`），对 GPU 要求不低。
- 事件驱动配乐要求页面能导出 `EV`；若走纯 `dub.mjs` 通路（无页面事件），**建岛即作曲这条核心机制会失效**。
- 相机距离必须 ≥ 3× frustum 高度，否则画面下缘露出海面以下（`STYLE.md:92`）。

### 踩过的坑（本机实测）
- 一个不可见的 glow sprite 在 GTAO pass 里被当成实心方块，渲染成漂在海面上的**黑色平行四边形**——必须在 AO pass 里隐藏 sprite 与半透明物体（`DEMO.md:85`）。
- 小船原本在 21 单位外，光束找到它时已经出画；解法是**由光束角速度反推小船位置**，让光束在选定的那一拍命中它（那一拍是旋律的休止，船答铃正好填上）（`DEMO.md:86`）。
- 低太阳角下海面接收阴影会拉出一道**长黑斑**——海面**不接收阴影**（`DEMO.md:87`）。
- 共享 post 代码里用 `perspectiveDepthToViewZ` 对正交相机不成立，必须换 `orthographicDepthToViewZ`（`post.js:2`）。

### 下次迭代优先补什么
- 给 `dub-styles.json#lowpoly-island` 补一个 **9:16 构图变体**（改 frustum/俯角），并把手抽的 Quicksand 字号与投影写回该条目，替换 `DengXian` 派生值。★ 注意：影片侧 9:16 **已完成**（正交重取景，见第 2 节子段）；这里说的是「文案+风格」通路的**派生条目**还没有竖版参数，两者是两条通路。
