# 中国水墨（`ink-wash`）· 风格制作 Skill

> **用途**：选定本风格后，**优先读这份文档**作为核心参考。
> **目标不是逐帧复刻样本**，而是**对齐风格特质、复用它的制作思路 / 视觉元素 / 编排手法**。

## 1. 风格说明

**是什么**：一幅在你眼前展开的写意水墨画。暖白宣纸是空间，墨以五种浓淡**乘算**在纸上，形体靠没骨的墨块（笔腹深色的一侧本身就是轮廓）与湿墨晕开、干墨飞白；留白占大半画面，画面里的东西是**被画出来**的，不是被切进来的。全片唯一彩色是朱红印章（`STYLE.md:6-13`）。

**不是什么**（最容易做错的邻居风格）：不是水彩（没有彩色晕染、没有彩色色块）；不是「加了笔刷纹理的矢量图」（没有平涂、没有闭合轮廓线）；不是书法片头（书法只是骨架，字要按笔顺一笔笔写出来）。

**什么时候用它**：文化品牌、武侠、诗词、节气、人生哲思、非遗与匠人题材。适合讲「一个动作 / 一个决定 / 一段过程」，适合把抽象的过程具象成一次落笔。

**一句话内核**：**一笔就是全部**——纸上的每一次落墨都是一个事件，笔顺即编舞。

**边界**：撑不起信息密度高的内容。数据表格、多栏文字、快速切换的清单式讲解、热闹的多人对话、需要精确图表的内容都不适合；它一次只承载**一个**主体、**一个**动作、**一次**转场。

## 2. 画面构图

- **镜头数与画幅**：样片 48s / 约 8 段镜头；原生 **16:9（1920×1080）**；**已适配 9:16**（`FILM_META.aspects = ['16:9','9:16']`，`film.js:6-11`）。抽帧即 16:9，是权威证据。
- **主体位置与占比**：主体**极小**。人物在大全镜里只有 150–180 px 高（约占画面高 14–17%），常偏在画面一侧或一角；近景只在「静默里的唯一硬切」时出现（帧 f14 的斗笠大特写）。
- **负空间 / 留白**：**60–80% 是空纸**（`STYLE.md:73`）。留白不是「背景」而是实体：水、天、雾、沉默都靠留白表示；删墨比加墨更符合本风格。
- **图层叠放顺序**（从底到顶）：程序化宣纸底（`#F2ECDE` + 云状斑驳 + 三向纤维 + 纸浆暗斑 + 暗角）→ 墨的湿层（晕开 / 边缘积墨 / 颗粒）→ 墨的干层（纤维抖动 / 纸纹咬边）→ 朱红印章与极小点缀 → 题跋字幕（屏幕空间，重置相机变换）。
- **安全区**：字幕手写进每个镜头的留白处（`shots.js` 的 `subPos(id,t)`），因此**位置逐镜不同**——帧 f07 在左下、f10/f19 在左上、f13 在右上、f21 在右中。主体安全区靠留白自然保证；暗前景（芦苇）允许沿画面底边通过。
- **本风格不能出现的构图**：居中对称的信息面板；多栏文字块；平涂色块压住湿墨；满画幅塞满元素（>40% 覆盖）；把字幕放进有墨的区域。

**在 9:16（产品默认）下的表现**：本风格**已适配 9:16**，落档 **「等比装入 + 同色留白」**（不裁、不变形、主体完整）。`comp.js` 导出 `NATIVE`（`comp.js:10`）与 `setFrame(w,h)`（`comp.js:12`），由 `main.js` 按视口尺寸调用（`main.js:10-11`）派生 `W/H/FX/FY/S = min(fx,fy)` 与居中偏移 `OX/OY`（`comp.js:13-14`）。两条独立的路：① **手卷世界走相机**——`world.js` 的 `camXf` 把「设计帧 → 当前帧」的等比装入折进相机矩阵：`s = cam.z × S`、`tx = OX + S·(960 − cam.x·cam.z)`（`world.js:53-56`），世界坐标**只走这一次**，不再单独乘 FX/FY；`cross.js` / `climax.js` / `passage.js` 里按设计帧屏幕坐标直接画的两镜与切浪、片尾卷轴，则在开画前套一层 `setTransform(S,0,0,S,OX,OY)` 的 `fit()`（`cross.js:12`、`climax.js:14`、`passage.js:13`），坐标与线宽/字号一起 ×S；② **屏幕空间家什**——题跋字幕的位置与字号都走同一套 fit（`main.js:38` 的 `pos×S+OX/OY`、`size×S`），片尾卡的「CHINESE INK WASH」与署名行也套 fit（`passage.js:148`）；离屏画布（`layerSet`、`TMP`、`WV`、`BG`）全部改取当前帧的 `W/H`（`main.js:13`、`world.js:8`、`passage.js:9`）。1080×1920 实测（`S = 0.5625`、`OX = 0`、`OY = 656.25`）：整幅 1920×1080 构图**等比缩到 1080×607.5、水平居中、垂直居中**，上下多出的 656px 是**宣纸色留白**（着色器的程序化纸纹铺满整帧，天然接得上，正合本风格「留白是实体」的内核）——**不裁切、无黑区、主体完整**。与「16:9 中心裁切」的 SSIM 实测 **0.47–0.92**（`≈1` 才说明是裁切）⇒ 确为等比装入而非裁切（偏高的 0.92 出现在几乎全空白的镜头上：画面 60–80% 是纸，裁切与留白版都大面积是纸，SSIM 自然高；内容密的镜头 0.47–0.78 区分明显）。**字幕**：题跋随画面一起等比装入，落在画面留白处的相对位置不变，实测 t=24.0 的「Halfway over, / the river rose to meet him.」与 t=40.8 的「…and the water only flows on.」整句可读、未被裁。代价是画面在竖屏里只占中间约 32% 高（横向 FOV 与 16:9 完全一致），竖屏观看时主体偏小；本风格是**横向手卷**、山水的宽构图不能裁，等比装入是这一档里唯一不破坏构图的解。

## 3. 配色体系

| 角色 | 色值 | 用途 | 来源 |
|---|---|---|---|
| 底（宣纸） | `#F2ECDE`（`rgb(.95,.925,.87)`，实测 `#F2ECDE`–`#F3EBDD`） | 全片背景、水、天、雾、沉默 | `STYLE.md:16`、`DEMO.md:42` |
| 墨·焦 | 不透明度 `.96` | 书法、最锐的线、剑、斗笠沿、苔点 | `ink.js:6` |
| 墨·浓 | 不透明度 `.82` | 轮廓、没骨笔的深边 | `ink.js:6` |
| 墨·重 | 不透明度 `.60` | 次级线、衣褶 | `ink.js:6` |
| 墨·淡 | 不透明度 `.34` | 山体、袍身与身体晕染 | `ink.js:6` |
| 墨·清 | 不透明度 `.16` | 远山、面部、雾 | `ink.js:6` |
| 强调 | `#B02E22`（`VERM=[176,46,34]`） | **只有**印章 + 至多一处极小点缀（样片是剑穗） | `STYLE.md:39`、`hero.js:6` |
| 字幕 | 墨色（`dub-styles` 给 `#2f2b27`，取自 `passage.js:135-137`） | 题跋文字，无描边无底 | `dub-styles.json#ink-wash` |

- **明度 / 对比规则**：墨不是一种黑，是**从冷灰 `rgb(.52,.55,.58)` 到暖黑 `rgb(.075,.068,.062)`** 的连续体（`comp.js:73`）；深度靠明度不靠色相——远 = 淡而软，近 = 深而有纹理。画面一挤，**减墨**而不是加调子。
- **禁止出现的颜色**：任何第二种彩色（除朱印与一处极小点缀）；红色做大面积晕染或做字；给纸面或文字上色；平涂的灰（浓淡必须由墨与笔毫构成）。
- **同一画面最多几个色相**：**一个**（墨，含其明度梯级）+ 至多一点朱红。

## 4. 转场规则

- **镜头之间怎么切**：默认**不硬切**，靠运镜把镜头缝起来——手卷式右向左平移、立轴式竖直俯仰、极慢远景视差；镜头之间用**墨晕**、沿卷轴平移、雾来过渡（`STYLE.md:73`）。
- **有没有叠化 / 闪白 / 擦除 / 定格**：**有墨晕**（带深色水线的前沿，`d·(0.62+0.8·fbm)` 噪声径向蒙版，元素锚世界空间、整场在合成器里）；**有雾**（推进墨晕/雾 = 在两种状态间穿过）；**有定格**（决定性的笔之前是静止，最多缓慢推近 5%）。**没有**通用溶解、没有划像、没有闪白。
- **硬切点怎么定**：全片**只允许一次硬切**，切到**极大特写**，用来表示「流动被打断」（`STYLE.md:68`）。样片把它放在 26.8s 的第一段静默处，切到斗笠沿（帧 f14）。硬切必须落在静默里。
- **转场时长与缓动**：样片墨晕转场锚点 `leap 14.2 → x3a 14.45 → x3b 15.3`，即约 0.25s 起晕、1.1s 完成（`story.js`）。决定性的笔只用 **0.17s** 横过画面（28.5→30.5 段），笔完成之后后果才开始。
- **绝对不要的转场**：通用溶解 / 划像；矢量式补间（东西不能被 tween，只能被画出来、晕开或溶进雾）；无来由的运镜。

## 5. 字幕样式

| 项 | 值 |
|---|---|
| 字体 | 样片：Cormorant Garamond italic 500（古典斜体衬线，`STYLE.md:44`）；dub 通路本机无此字体，回退 **KaiTi 楷体** |
| 字号（相对画面宽 / 高） | 样片 46 px @1920 宽 ≈ **2.4% 画面宽**；dub 通路 `fontSizeFactor` **0.042**（≈4.2% 宽） |
| 颜色 / 描边 / 阴影 | 墨色（`#2f2b27`）／**无描边**（`outlineFactor:0`）／无阴影 |
| 位置 / 安全边距 | 逐镜写在留白里（`subPos`）；dub 通路 `marginVFactor 0.145` / `marginLFactor 0.08`，`align:2` |
| 单行字数上限 / 最多行数 | 单句 **28–45 字符**（约 5–9 英文词）；**最多 2 行**，用 `\n` 显式断行 |
| 出现与消失方式 | **湿墨→干墨**在零点几秒内出现（`subtitleFadeIn:0`，无渐入）；`drying in ~0.35s`（`DEMO.md:58`） |

- **字幕与旁白的关系**：字幕是**题跋**——一段写在画边上的说明，不是口播的复读。停留 ≥ `max(1.8s, 语音时长 + 0.6s)`（`STYLE.md:44`）。**每行行首有一个朱红小方块**标记起笔。
- **本风格特有的字幕禁忌**：不要加底框（`subtitleBack:#00000000`）；不要用红字；不要居中大标题式字幕；不要超过 2 行；不要压在墨上——必须落在留白。

## 6. BGM / 音效特征

- **配乐**：**古琴领奏**（`core/audio/pluck.py` 的 `guqin`：散音、按音滑音、吟猱、泛音、扫弦），配低而带气声的**箫**、大鼓与定音鼓（表现重量）、框鼓（脚步）、小锣（印章）；**中国五声音阶**，样片是 **F 宫五声（F G A C D）**（`STYLE.md:77`、`score.py:1-5`）。节奏按段落 cue，**不循环**：散板开场 / 60 BPM 山水 / 90 BPM 行走 / 鼓滚表现威胁 / 静默 / 三记泛音对应三笔 / 再静默 / 断流用鼓 + 七弦扫。
- **拟音（foley）清单**（`mix.py:19-77`）：墨滴（1300→380Hz 下滑「叮」+ 湿软噗）、毛笔破空（1200–6500Hz 带通 + 毛刷颗粒，**绝不是金属 whoosh**）、点水（水花 + 小咚 + 5 颗水珠）、溅墨（70 颗短湿点）、印章（木印闷「咚」+ 纸面细响）、拔剑（鞘摩擦 + 五音叠加金属清鸣）、断流（撕裂气流 + 江水轰响 + 低频冲击）、袍角（带通）。
- **旁白处理**：样片 Kokoro `bm_george`、`en-gb`、speed `.82–.86`，4–6 句，平静、不解释画面。音乐在语音下**闪避 −6~−8 dB**（`.5s` 平滑），环境同步压到 30%；每句都用 whisper 在最终混音上复核过（样片因江水轰响把 `Halfway` 听成 `This way`，所以环境也压）。
- **响度目标**：样片实测 **I = −13.8 LUFS / LRA 8.0 LU（`ebur128`）**（mux 目标 −14 LUFS）；**交付真峰值上限 −1.2 dBTP**（项目级交付线，本风格 `STYLE.md` 未额外声明更严上限）。**成片真峰值实测 −1.62 dBTP**（`loudnorm` `input_tp`，4× 过采样）—— 在交付线内（余量 0.42 dB）、未削波。此前本节写的「真峰值 −1.6 dBFS」是 `ebur128` 的 1 位小数读数（口径不对），已改为 `input_tp` 口径；`astats` 采样峰值 −1.630804 是下界。
- **静音策略**：**静默是字面意义的零**——`mix.py:128-132` 把**整个总线**（音乐 + 环境 + 混响尾）清零，只用 20ms 淡入淡出，静默里最多留一个声音（一滴水 / 一声剑鸣）。样片两段：`26.8–28.5` 与 `30.5–32.4`，日志实测两段 `silence_max_abs` 都是 **0.0**。最长那段（1.9s）之后才是断流的剑。

## 7. 素材偏好

- **需要什么素材**：**几乎不需要外部素材**——这是本风格的最大优势。纸、墨、山、水、浪、人物、字、印章全部由 `demo/` 里的引擎程序化生成（`ink.js` / `comp.js` / `land.js` / `wave.js` / `glyph.js` / `seal.js` / `hero.js`）。唯一「素材」是**一支 OFL 毛笔字体**，且只当**骨架**用（描中心线、压力取自字形粗细）。
- **不需要什么素材**：不要照片、不要视频素材、不要贴图（纸是程序化的，**不能是 texture 文件**，`STYLE.md:16`）、不要彩色插画、不要 3D 模型。
- **取景 / 质感 / 比例偏好**：主体永远小、留白永远大；质感靠「湿墨晕开 + 边缘积墨 + 干笔飞白 + 纸纹咬边」四件套；比例固定 16:9。
- **可替代方案**（缺素材时怎么降级而不破风格）：缺字体 → 用任何楷 / 宋体做骨架，只要坚持「描中心线 + 藏锋起笔 + 出锋收笔」，不要直接描字体轮廓（会缺口，`STYLE.md:101`）。缺古琴音源 → 用任何拨弦 + 长衰减的拨弦音色近似，但**不能换成钢琴 + 弦乐**（那是另一个风格）。人物不会画 → 只画「一块淡身体底 + 两笔没骨 + 焦墨四肢」，宁可更简，不要加细节。

## 8. 镜头节奏

| 项 | 值 |
|---|---|
| 单镜时长 | 约 4–8 s（样片 8 段覆盖 48s） |
| 全片时长 | **48.0 s**（`style.json:17`）；适合 40–60s 单场景短片 |
| 镜头数 | 约 8 段（开场纸 / 手卷平移 / 行走 / 威胁 / 静默硬切 / 释放 / 收束 / 印章片尾） |
| 信息投放节拍 | 「一笔 = 一件事」：虚白空纸 → 一滴墨（creation）→ 留白里的小人 → 轻快（踏水）→ 障碍被画成一块湿墨 → 静默 → 决定性一笔 → 释放 → 尺度揭示 → 印章 |

- **加速 / 减速点**：两段静默（26.8–28.5 / 30.5–32.4）是最强的减速；之后的断流是唯一的高速点（笔 **0.17s** 横过画面）。人物 **12fps（on twos）**，镜头 / 墨晕 / 涟漪 / 溅墨 **24fps（on ones）**（`STYLE.md:48-50`）。
- **留白与静音的位置**：静音要放在「故事屏住呼吸」的地方（`STYLE.md:79`）；样片两段静默分别对应「决定之前」与「断流之前」，且**硬切只允许落在静默里**。留白同理：越关键的决定，画面越空。

## 10. 编排规则

- **内容文件字段契约**：`demo/story.js` 是**唯一真值**，导出 `DUR`、`T`（`dropFall/dropHit/bloomEnd/titleIn/panA/panB/paint[]/leap/x3a/x3b/step0/beat/nSteps/darken/shot4/cut5/draw/w1..w3/hush/cut/cutEnd/x7a/x7b/close/bow/scrollA/seal/endCard`）、`VO[]`（`{id, t, sub:[t0,t1], text}`，text 用 `\n` 显式断行）、`stepTimes()`。语音文本另存 `demo/lines.json`：`[{id, text, voice, speed, lang}]`。
- **事件词汇表**（`type` → 消费者，全部由 `shots.js` 的 `events()` 产生）：`vo{id}`、`drip{gain}`、`brush{gain,dur}`、`whoosh{gain,k}`、`step{gain,k}`、`splash{gain}`、`skid{gain}`、`sword{gain}`、`cut{gain}`、`splatter{gain}`、`collapse{gain}`、`waterclose{gain}`、`cloth{gain}`、`seal{gain}`、`silence{t0,t1}`、`amb{kind,t0,t1}`。
- **时间线契约**：`story.js` → `shots.js` 的 `frame(t,A,B,TMP)` 返回该帧合成参数（含 A/B 两套画面的墨晕蒙版 `[cx,cy,R,on]`）；`subPos(id,t)` 给字幕位置；`events()` 给事件数组。`comp.js` 的 `makeComp(canvas)` → `composite(A,B,o)`；`layerSet(W,H)` 造 `{wet, dry, col}` 三张画布。页面契约：`window.READY` / `window.render(t)` / `window.DUR` / `window.EV`。
- **新增主体怎么接入**：用 `ink.js` 的笔触库搭——`mk(pts,o)` 建一笔、`draw(L,s,p,am)` 逐帧画、`drawSeq` 按书写顺序、`blot` 点苔/溅墨、`mass` 湿墨块、`qpts` 二次贝塞尔；`TONE`（五色）与 `PROF`（`brush/tip/nail/lens/fan/rise/robe/even`）可复用。参考：人物 `hero.js`、山石 `land.js`、浪 `wave.js`、书法 `glyph.js`。
- **换主题时要改哪些文件**：① `demo/story.js`（时间线 + VO 文本，改一行语音时长全片自动重排）；② `demo/lines.json`（语音文本与声线）；③ `demo/shots.js` 的 `subPos()`（按新镜头留白重写字幕位置）；④ 画面层：`world.js` / `cross.js` / `climax.js` / `passage.js` 换主体与镜头；⑤ `demo/music/score.py` 重写配乐；⑥ 若要保留朱红点缀，改 `hero.js:6` 的 `VERM` 使用点。**不要**改 `core/`。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里生效的参数是 `dub-styles.json#ink-wash`——`palette`（`bg #F2ECDE` / `fg #2f2b27` / `accent #B02E22` / `subtitle #2f2b27`）、`bgRecipe`（solid + `rice-paper` 纹理 + `vignette 0.1`）、`subtitle`（`KaiTi` / `fontSizeFactor 0.042` / `marginVFactor 0.145` / `outlineFactor 0` / `align 2`）、`title.fontSizeFactor 0.055`、`motion.chapterTransition = bloom`、`overlay` 全关（无章节卡 / 无下三分之一 / 无进度条）。
