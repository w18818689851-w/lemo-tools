# 蜡笔儿童绘本（`crayon-book`）· 风格制作 Skill

## 1. 风格说明

**是什么**：**一页绘本在你眼前被现画出来**——蜡笔在暖白粗纹纸上，一盒十来支蜡笔，孩子式透视，颜色总是**涂出轮廓**，而每条线因为**每帧都是一张新画**而轻轻**沸腾**（boil）。语气是绘本讲故事：温柔、不着急、由音乐领着走，只有几行**就是印在纸上的那些字**的旁白。**任何主题都变成「一本绘本里正在被完成的那一页」——画与涂色本身就是剧情**（`STYLE.md:8`）。

**不是什么**（最容易做错的邻居风格）：不是「**加了蜡笔滤镜的可爱矢量图**」——观感来自**材质物理**（蜡只粘在纸纹的凸点上、笔压决定它压进凹处多深、水彩被蜡排斥，`STYLE.md:10`）；不是**白板讲解**（没有马克笔、没有手、没有手写字幕框）；不是**水彩画**（水彩是客、蜡笔是主）；不是**黑板画**。

**什么时候用它**：绘本、睡前故事、儿童教学、情感类温情短片、产品「先画轮廓、再用水彩揭示隐藏特性」的说明。`style.json:11-15` 给的适用面是 Picture books / Bedtime stories / Kids' learning。

**一句话内核**：**耐心、温柔、值得被贴在冰箱上**——不是精致，也不是戏剧化（`style-dna/crayon-book.md:124`）。

**边界**：这个风格**撑不起**快节奏、强冲突、密集信息量、以及任何需要「清晰可读的图表/数据/长文案」的内容。它也不适合第一人称抒情或长复合句旁白（旁白是**印在书页上的文字**：第三人称、过去时、短句，`style-dna/crayon-book.md:36`）。样片的故事弧是 **45–55s**（`DEMO.md:14`）。

## 2. 画面构图

- **镜头数与画幅**：样片 52.0s / **1248 帧 @24fps**，**整片一镜到底横跨一页**（world 3200×1800，整页 = scale 0.6），最后才拉出去揭示「这是一本书」（`DEMO.md:31`）。画幅 16:9（1920×1080）。
- **主体位置与占比**：**关键人物在近景镜里不小于画面高的 1/4**（`STYLE.md:58`）；**画面下方保留空白纸面**给「印上去的字」（`STYLE.md:58`）。孩子式透视是构图的一部分：**山墙正面 + 斜侧墙**、**人比门大**（`STYLE.md:20`）。
- **负空间 / 留白**：**大量裸露的纸面**——饱和蜡笔铺在「很多空白纸上」，明度靠**笔压**而不是加色相（`STYLE.md:26`）。空白的纸也是「画之前」的证据：开场**锁死整页**，让观众先看到纸（`DEMO.md:35`）。
- **图层叠放顺序**（从底到顶，**顺序固定**，`film.js:210-221`）：纸（paper）→ knock-out（角色身后保留纸白）→ 蜡笔 fill/lines → **水彩**（wash）→ **角色（在水彩之后合成）** → 字幕底 knock-out → 字幕 → finish（浮雕 / 暗角 / 台灯）。
- **本风格**不能**出现的构图**：**屏幕固定的纸纹**（必须锚定在页面上随镜头平移，否则文件膨胀，`STYLE.md:90`）；把「印上去的字」放在水彩会经过的地方（蜡会挡住水彩，字会幸存下来，`STYLE.md:84`）；字幕放在无旁白段落（`style-dna/crayon-book.md:105`）。

**在 9:16（产品默认）下的表现**：本风格**已适配 9:16**——`FILM_META.aspects = ['16:9','9:16']`（`film.js:20`），`crayon.js` 加 `NATIVE` / `setFrame(W,H)` 派生 `FX/FY/S = min(FX,FY)`（含 `fitX/fitY` 辅助），`renderFilm` 首行 `setFrame(w ?? NATIVE.W, h ?? NATIVE.H)`（`film.js:162`）按视口重排页面。1080×1920 实测：**不裁切**，月亮脸 / 字幕 / 房子 / 草地全部落在画面内；与「16:9 中心裁切」的 SSIM 仅 **0.376**（裁切会 ≈1）⇒ 确为**重排**而非裁切。**16:9 逐字节零回归**（去掉高频后 PSNR 44.5 dB，原始差来自混流 `grain`）。旧文档「本风格无 `aspects` 声明、9:16 会裁掉右侧约 43.75%」的说法来自**改造前**，已作废（详见第 11 节）。

## 3. 配色体系

样片的**一盒 12 支蜡笔**（`DEMO.md:67`，`pal.js:2-19`）：

| 角色 | 色值 | 用途 |
|---|---|---|
| 纸 | `#f4efe3` | 暖白画纸底 |
| 轮廓（靛蓝） | `#2d3263` | **全部轮廓线**、字幕字色 |
| 黄 | `#f5c63c` | 月亮主体 |
| 橙 | `#ec8a3c` | 月亮斑纹 |
| 红 | `#d4483c` | 屋顶、树上的点 |
| 粉 | `#ee8ea4` | 腮红、衣物 |
| 桃 | `#f4c7a4` | 皮肤 |
| 棕 | `#7a4b31` | 树干、烟囱 |
| 赭 | `#e7b867` | 墙、木色 |
| 绿 | `#62a24c` | 草地 |
| 天蓝 | `#79acd9` | 窗、水 |
| 紫 | `#6a5aa6` | 被子、夜色 |
| 白 | `#fbfaf4` | **蜡笔抵抗（wax resist）专用** |
| 水彩 | 群青，透射 `(0.15, 0.19, 0.44)` | 全片**唯一**一道水彩 |

- **明度 / 对比规则**：**一盒约十来支蜡笔，绝不超过**；轮廓只用**一种深色**（靛蓝 / 深棕 / 梅子色），**绝不用纯黑**；一支白蜡笔专门留给蜡抵抗（`STYLE.md:24`）。**明度来自笔压，不是加色相**。
- **水彩规则**：**全片最多一道水彩**，按「它揭示什么」来选（群青 = 夜、玫瑰 = 黎明、树汁绿 = 雨），而且**从不画在角色身上**（`STYLE.md:25`）。
- **禁止出现的颜色**：纯黑轮廓（`style-dna/crayon-book.md:154`）；在角色身上使用水彩；超出蜡笔盒的额外色相。
- **同一画面最多几个色相**：蜡笔盒内任意组合，但**角色强调色只有一个**——样片是女孩发夹上的**黄色星星**，与天空的星星呼应（`DEMO.md:68`）。

## 4. 转场规则

- **镜头之间怎么切**：本风格**整片一镜到底**（`DEMO.md:31`），没有「切」——靠**画出来**、**涂上去**、**水彩刷过**、**横移**或**翻页**推进（`STYLE.md:58`）。
- **有没有叠化 / 闪白 / 擦除 / 定格**：**没有溶解/叠化等非手绘转场**（`style-dna/crayon-book.md:105`）。允许的转场必须**来自手绘本身**：①**画出来（drawing on）**——线条沿长度 reveal 0.4–0.9s，涂色逐行出现，文字逐字出现；②**涂上去（colouring over）**；③**水彩刷过**；④**横移**；⑤**翻页**。
- **硬切点怎么定**：没有硬切；节奏挂在 **3/4 拍、72 BPM 网格**上——1 拍 = 0.833s、1 小节 = 2.5s（`film.js:12`、`style-dna/crayon-book.md:67`）。
- **转场时长与缓动**：线条 reveal **0.4–0.9s**；文字**逐字写出约 0.35s**；水彩是**三道刷痕 27.9–34.7s**（`world.js:132-136`）；片名**逐字写出**（2.6s 起）。**相机缓动是「世界中心 + 缩放」的单调三次插值**（`camT`，`style-dna/crayon-book.md:179`）。
- **绝对不要的转场**：**让蜡笔淡入淡出**——「你没法让蜡笔淡出」：片名只能靠**镜头移开、翻页或被涂掉**来离开（`STYLE.md:32`、`style-dna/crayon-book.md:105`）；溶解 / 叠化；无来由的运镜。

## 5. 字幕样式

| 项 | 值 |
|---|---|
| 字体 | **Patrick Hand**（手写体，OFL）——「书页上印着的字」；片名另用 **Gaegu Bold** 或同类手写体（`STYLE.md:31-32`） |
| 字号（相对画面宽 / 高） | **54 px**（1080p 下；归一化约画面宽 2.81%） |
| 颜色 / 描边 / 阴影 | **靛蓝蜡笔色**（样片即轮廓色 `#2d3263`），**无描边、无阴影**；写在**一块边缘毛糙的空白纸片（ragged knock-out patch）**上，**绝不用深色字幕框**（`STYLE.md:31`） |
| 位置 / 安全边距 | **底部居中**；画面下方保留空白纸面 |
| 单行字数上限 / 最多行数 | **一次一行**；样片单句 **13–47 字符**（最短 `Night, night.` 13 字符；最长数羊句 47 字符，`style-dna/crayon-book.md:38`） |
| 出现与消失方式 | **逐字写出约 0.35s**（不是淡入）；每个字形**带倾斜与偏移**、**以两格（twos）沸腾**；提前 0.1s 上、至少停 **1.8s**、下一行到来前 **0.25s** 收；停留 ≥ max(1.8s, 语音 + 0.6s) |

- **字幕与旁白的关系**：字幕**就是旁白本身**——「the book's printed words」。时间由 `LINES` 生成：`t0 = 语音起点 − 0.1s`，`t1 = max(t0+1.8, t+时长+0.7)` 且不晚于下一行前 0.25s（`film.js:24`、`style-dna/crayon-book.md:165`）。
- **本风格特有的字幕禁忌**：①**无旁白的唱歌/水彩段落不排字幕**（`style-dna/crayon-book.md:105`）——样片 27.5–37.5s 的人声 RMS 实测 **−114.5 dB**（即无人声），这一段全靠音乐与刷子；②不许用深色字幕框；③**字不能写在水彩会经过的地方**——蜡会挡住水彩，字会「幸存」下来而破坏画面（`STYLE.md:84`），样片为此把片名放进了广角镜不会展示的**角落**（`DEMO.md:102`）。

## 6. BGM / 音效特征

- **配乐**：**3/4 拍、72 BPM、F 大调、52.0s**（`music/score.py:1-2`）。**小件木质与金属齿乐器，不用弦乐、不用三角钢琴**（`STYLE.md:62`）：音乐盒（主音）、玩具钢琴（喜剧圆舞曲，**每数一只羊 / 每爬一级横档一个音**）、长笛当**歌唱的嗓音**、单簧管做低音与幽默、钟琴**每颗被水彩揭示的星星一个音**（由 `glint` 事件驱动，样片 **29 个 glint**，`logs/crayon-book.log:90`）。摇篮曲主题**全片只完整出现一次**，就在水彩那一段；开场音乐盒动机就是它的第一句；结尾**音乐盒发条松掉**（ritardando + 轻微音高下沉，`DEMO.md:51`）。
- **拟音（foley）清单**（`STYLE.md:64`、`mix.py:22-28`）：**蜡笔** = 粘滑摩擦（带通噪声 × 不规则颗粒调制，颗粒随笔画速度变密变亮；**涂色 = 每趟一个短刮擦**）；**湿刷子** = 柔软低通噪声 + 鬃毛颗粒，**随笔画声像移动**；毡子噗（羊落地）、布料嗖声（翻身）、卷笔刀、蜡笔放下、**翻页**（提起 / 呼啸 / 扑动）；**底噪** = 极轻蟋蟀 / 鸟、房间底噪、远处钟声。
- **旁白处理**：**温柔、温暖的讲故事者**（Kokoro `af_heart`，speed 0.86–0.90；v3 曾用 `bf_emma` 但**读起来太亮太硬**而换回，`DEMO.md:59`），6–8 行短句、带呼吸。人声链（`DEMO.md:59`）：高通 75 Hz → **先压缩**（thr 0.2、2.5:1、8 ms / 140 ms）→ 低架 +1.5 dB @220 Hz、−2 dB 陷波 @3.2 kHz、**高架 −4 dB @6 kHz** → 分频去齿音（4.8–10 kHz、4:1）→ 逐行 RMS 匹配 → 暖近场混响（12 ms 预延迟、0.7s 低通尾巴、**湿声约 −17 dB**；`STYLE.md:91` 记「湿声约比干声低 18 dB」）。**人声比底噪高 7–10 dB，绝不更响**。本次实测每行 vo/bed 差 6.6–17.9 dB（`logs/crayon-book.log:113-119`），去齿音最大衰减 −4.2 ~ −4.4 dB（`logs:93-99`）。
- **响度目标**：`−14 LUFS`（`STYLE.md:65`）。本次成片实测 **I = −14.1 LUFS、LRA 7.5 LU**（`logs/crayon-book.log:136-137`）；混音实测 mix RMS −23.5 dB / peak −3.1 dB（`logs:105`）。**真峰值 −1.02 dBTP**（判据 = `loudnorm` 的 `input_tp`，4× 过采样；2026-10-03 离线复测）——**超 −1.2 dBTP 交付线 0.18 dB**，真峰值为负、**未削波**（详见第 11 节）。 ★ **2026-10-03 已修**：成片已用 `scripts/fix-truepeak.mjs` 音频重混（`-c:v copy`，视频流逐字节未变），真峰值 −1.02 dBTP → **−2.08 dBTP**、已在 −1.2 dBTP 交付线内（达标）；原 −1.02 dBTP 记录保留为历史。
  ★ 2026-10-07 复测当前入库成片真峰值 **−1.57 dBTP**（`loudnorm` 的 `input_tp`，4× 过采样；核法见 `_distill.json` 的 `selfCheck.loudness.truePeakDbtp`）。
- **静音策略**：**静默是一个真实的拍子，不是空**——数羊失败后留**整整一拍**（13.95–15.00s，实测 RMS **−240.0 dB**，`logs:77`），唱歌前再留 **0.3s 呼吸**（27.20–27.50s，同样 −240.0 dB，`logs:80`）。**音乐在人声下压 −7 dB、在无词段落抬 +4 dB**（`DEMO.md:57`）；实测无词段（27.5–37.5s）music −20.6 dB，明显高于其它段（`logs:110`）。

## 7. 素材偏好

- **需要什么素材**：不需要任何实拍或现成素材——**全部由代码生成**。需要的是：①**一张纸**（暖白 `#f4efe3` + 锚定在页面上的纸纹）；②**一盒 12 支蜡笔**（`pal.js` 里 12 支色 + 1 道水彩透射色）；③**角色的 model sheet**——**先画人设表再进任何镜头**（`STYLE.md:95`、`DEMO.md:89`）；④**6–8 行短旁白**；⑤配乐 cues（A–G 段落）、片名 / 结束卡文案。
- **不需要什么素材**：不需要照片、实拍、3D、贴图；**不需要 ffmpeg 加颗粒**（**纸本身就是颗粒**，`style-dna/crayon-book.md:209`）；不需要弦乐与三角钢琴音源；不需要描边字幕框。
- **取景 / 质感 / 比例偏好**：**纸纹锚定在页面上**（随镜头平移；缩放时两个八度交叉淡变，让颗粒在屏幕上始终 ~1 px），三个八度值噪声（**1.35 / 2.9 / 6.3 px**）+ 横向纤维项（x/10、y/1.9），对比 `smoothstep(.16,.86)`，浮雕强度 **~0.55**，低频斑驳 ±2%、暖暗角（`STYLE.md:14`、`DEMO.md:63`）。**蜡的附着是核心规则**：每层 RGB = 颜色、**A = 笔压**，着色器在 `tooth > 1 − 1.22·pressure`（软边 ±0.07）处沉积蜡，重压再 `×(1 − 0.10·p²)` 变深（`STYLE.md:15`、`DEMO.md:64`）。笔触带低频手抖 **~1.7 px**、宽度 ±15%、两端收尖；角色轮廓 **~7 px**、建筑 **8 px**、精细物件 **4–5 px**（`DEMO.md:65`）。涂色是**来回之字排线**：行距 **~10.5 px**、笔宽 **~11 px**、每趟笔压 0.72–1.14×、**越界 0–7 px**，大面积再补交叉排线 40–50%（`DEMO.md:65`）。
- **可替代方案**（缺素材时怎么降级而不破风格）：缺复杂场景时，**减少道具但保留「画出来」的过程**——画与涂色是剧情，只要 reveal 还在，风格就成立。缺水彩时，**整片可以没有水彩**（`STYLE.md:99` 明说「有没有水彩」由你决定），但那就放弃了最强的蜡抵抗手法。缺音源时用玩具钢琴 / 音乐盒合成替代，但**保留 72 BPM 3/4 网格与「每数一样东西一个音」的写法**。

## 8. 镜头节奏

| 项 | 值 |
|---|---|
| 单镜时长 | **整片一镜到底**（无剪切），由 `camT`（世界中心 + 缩放的单调三次插值）驱动（`style-dna/crayon-book.md:179`） |
| 全片时长 | **52.0s**（`style.json` 记 dur 52.0 / 1248 帧 @24fps）；`DEMO.md:14` 给的故事弧是 **45–55s** |
| 镜头数 | **1**（一页一镜到底），但相机路径有 9 个明确段落：锁死整页 → 推向月亮（片名让位）→ 锁死中近景（喜剧）→ 沿视线俯仰（发现）→ 双人镜 → 紧跟随爬梯 → **保持大远景（水彩揭示）** → 缓推入睡 → 拉出成书 + 翻页（`DEMO.md:33-43`） |
| 信息投放节拍 | 挂在 **3/4 拍、72 BPM**：1 拍 = 0.833s、1 小节 = 2.5s（`film.js:12`） |

- **动画步进（本风格最核心的节奏规则）**：**一切被画出来的东西都以 12 fps 步进**（线条、涂色、角色、沸腾种子）；**相机、水彩的湿前沿、闪烁以 24 fps 运行**（`STYLE.md:36`）。
- **沸腾（boil）的量化值**：每 2 帧重新抖动一次偏移（**±0.8 px**）与手抖（**±0.9 px**）以及排线行；**角色全量、背景线 ×0.6、背景涂色保持静止**（也顺便把码率减半）；**片子安静下来时把沸腾降到约一半**——样片在角色睡着后降到 **×0.5**（`DEMO.md:66`；`style-dna/crayon-book.md:114` 记 0.55 倍，两处口径略有差异）。
- **加速 / 减速点与关键节拍**：数羊 **5 拍**（10.0s 起每拍一只，`film.js:47`）；失败后**整拍静默**（13.95–14.95s）；爬梯 **8 级横档**从 20.3s 起每 **0.45s** 一级（`film.js:52`，实测横档时刻 20.3/20.75/21.2/21.65/22.1/22.55/23.0/23.45，`logs:90`）；水彩三道刷痕 **27.9–34.7s**；拉出成书 **46.0s**、翻页 **47.6s**；片名 2.6s 起逐字写出。
- **留白与静音的位置**：数羊失败后的**一整拍静默**；唱歌前的 **0.3s 呼吸**；**水彩揭示段无旁白**（实测 vo −114.5 dB，`logs:110`），让刷子与音乐自己讲；**保持大远景**让「材质本身即运动」（`STYLE.md:53`）。
- **表演规则**：**替换式（substitution）表演**——每个姿势一张新画，落在拍上；重复动作**两张关键画交替**；**孩子的画不做 in-between**；大而简单的姿势（`STYLE.md:39`）。**涂色即动作**：被涂上颜色「就是」在做那件事（涂上外套 = 穿上、粉色乱涂 = 脸红、水彩 = 夜幕降临，`STYLE.md:40`）。

## 10. 编排规则

- **内容文件字段契约**（`style-dna/crayon-book.md:162-167`）：①`lines.json`——每行 `{id, text, voice, speed}`，样片用 `af_heart`、speed 0.80–0.90，共 **6–8 短行**；②字幕由 `LINES` 生成（`t0 = 语音起点 − 0.1s`，`t1 = max(t0+1.8, t+时长+0.7)`，不晚于下一行前 0.25s）；③事件表 `events.json`——`{dur, ev[]}`，由 `film.js` 的 `EV.push` 产生；④配乐 cues（A–G 段落）、蜡笔盒（`pal.js` 12 支色）、水彩透射色、片名 / 结束卡文案。
- **事件词汇表**（`style-dna/crayon-book.md:185-195`）：`voice{id}`/`scratch{dur,pan}`/`write{dur}`/`scribble{dur}`/`pop`/`paper`/`toss`/`hop{i}`/`baa{i}`/`number{i}`/`silence{dur}`/`cricket`/`wave`/`rung{i}`/`hopout`/`climbover`/`step`/`sit`/`brush{dur,dir}`/`dip`/`glint{pan}`/`cap`/`yawn{who}`/`quilt`/`tuck`/`liedown`/`room`/`page{dur}`/`cue{id}`。全部由 `film.js` 里 `EV.push` 产生，再由 `core/render/events.mjs` 序列化成 `events.json`——所以**换内容时配乐与拟音会跟着新事件重排**（`glint` 事件直接驱动钟琴）。
- **时间线契约**：`film.js` 导出 `DUR` / `frame(comp,t)`（**≥46.0s 交给 `end.js`**）/ `drawPage(comp,t,cam,{subs,vig})` / `LINES` / `SUBS` / `EV` / `camT`。页面契约（`main.js`）：`window.READY` / `window.render(t)` / `window.DUR`。**合成顺序固定**：paper → knock → crayon(f/l) → wash → **角色（水彩之后）** → knock 字幕底 → 字幕 → finish（`film.js:210-221`）。
- **新增主体怎么接入**：用蜡笔引擎画（`style-dna/crayon-book.md:171-176`）：线 `line(L, pts, {col,w,p,seed,wob,boil,taper,draw,streak})`（飘带 + 收尖 + 条纹 + 沸腾）；面 `fill(L, poly, {col,p,ang,gap,w,over,draw,cross})`（之字排线 + 出界 + 可选交叉）；小面积 `dab`；形状 `ellipse / handCircle / bez / smooth / xf`；字 `text(L,str,x,y,{size,font,reveal})`。角色用 `rig.js` 的 `part/group` 做**遮挡 + knock-out**、管状四肢。**先画角色的 model sheet（`sheet.js`）再进任何镜头。**
- **换主题时要改哪些文件**：①`lines.json`（新旁白）；②`film.js`（`DUR`、时间线、`camT` 镜头表、`EV`、`LINES`/`SUBS`）；③`world.js`（新页面：道具、水彩 BANDS）；④`chars.js`（新角色，先出 model sheet）；⑤`pal.js`（新蜡笔盒与透射色）；⑥`music/score.py` 的 A–G 段落结构（须与新节拍对齐）；⑦`end.js`（成书 / 翻页 / 结束卡文案）。**注意**：`style-dna/crayon-book.md:186` 的口径是「换 `lines.json` 重跑只是验证引擎能重排的技术检查，不是做片子的方式」。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里走 `lib/dub-styles.json#crayon-book`，该条目**标记为派生条目**（`derived:true`，`derivedFrom: palette@lib/dub-visual.json / subtitle-px@STYLE.md §4 / contrast-rule(WCAG)`）。生效参数：`palette.bg #f4efe3`（= 纸色，**与样片一致**）/ `fg #2d3263`（= 靛蓝轮廓色，**与样片一致**）/ `accent #d4483c`（= 红色蜡笔，**与样片一致**）/ `subtitle #2d3263` + `subtitleOutline #FFFFFF` / `subtitleBack #00000000`、`bgRecipe.type solid` + `texture crayon` + `vignette 0.08`、`subtitle.fontFamily KaiTi` / `fontSizeFactor 0.04907` / `marginVFactor 0.14537` / `marginLFactor 0.07037` / `outlineFactor 0` / `bold false` / `align 2`、`title.fontSizeFactor 0.086` / `showRole false`、`overlay.chapterCards false` / `accentRule false`、`motion.subtitleFadeIn 0` / `chapterTransition cut`。**本条的配色三项与样片完全对得上**（不像同批的 cel-anime-80s 派生条目那样跑偏）；但 `subtitle.fontFamily` 退回 `KaiTi`，与样片的 **Patrick Hand** 不同。

### 踩过的坑（本机实测）
- **水彩带之间留白条纹、天空在地面之上就停住** → 最后一道水彩带必须**下探到草地线**；**只要有纸的地方天空就存在**（`DEMO.md:100`）。
- **墙在轻笔压下涂色，被水彩一过就发浑变蓝** → 水彩经过的地方笔压 ≥ 0.8 或补交叉排线（`STYLE.md:83`、`DEMO.md:101`）。
- **写在天空里的片名与数字在水彩后幸存**（蜡抵抗）→ 片名挪到广角镜不会展示的**角落**（`DEMO.md:102`）。
- **在女孩头发上画的轮廓读起来像发箍** → 头发体块的轮廓只画**外缘**（`STYLE.md:86`、`DEMO.md:103`）。
- **被子画成一块平的紫色半圆，读成月亮的暗面** → 必须有被子特征：拼布方格、缝线、星星贴花、翻下来的一道亮边、**溢出圆盘的下摆**、以及一只把被子拉上去的手（`DEMO.md:104`）。
- **成书转场处暗角 / 浮雕叠加两次** → 桌面那套的 vignette、emboss、台灯从 **0 渐入**（`STYLE.md:89`、`DEMO.md:105`）。
- **女主角消失在夜里**（水彩渗进她涂色的缝里）→ **角色在水彩之后合成**（`STYLE.md:85`、`DEMO.md:106`）。
- **翻页用矩形条带会露出阶梯** → 每条带用**仿射变换**（`STYLE.md:88`）。
- **knock-out 画在普通图层上会显示成灰蜡笔** → 用**哑画布（dummy canvas）**（`STYLE.md:87`）。
- **水彩刷痕的波浪边缘 + 宽亮条纹读成山丘** → 用**小尺度高频波纹**、条纹要细要淡（α ≤ 0.12）（`STYLE.md:82`）。
- **屏幕固定纸纹让文件膨胀到 190 MB** → 锚定纸纹 + 背景涂色不沸腾 + 不加颗粒 + CRF 26 → **74 MB 且无可见损失**（`DEMO.md:96`）。
- **用单位方差噪声做的混响 IR 响得离谱** → 湿声压到比干声低约 17–18 dB（`STYLE.md:91`、`DEMO.md:59`）。
