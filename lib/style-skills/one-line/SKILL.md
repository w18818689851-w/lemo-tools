# 一笔画（`one-line`）· 风格制作 Skill

> **用途**：选定本风格后，**优先读这份文档**作为核心参考。
> **目标不是逐帧复刻样本**，而是**对齐风格特质、复用它的制作思路 / 视觉元素 / 编排手法**。
> **资料源**：`styles/one-line/STYLE.md` · `styles/one-line/DEMO.md` · `styles/one-line/demo/build.sh` ·
> `lib/style-dna/one-line.json` · `lib/style-dna/one-line.md` · `lib/dub-styles.json#one-line` ·
> `styles/one-line/style.json` · demo 源码 · **成片逐帧拆解**（见文末「蒸馏证据」）。

## 1. 风格说明

**是什么**：一根**从不离纸**的墨线。屏幕上的一切——角色、地点、物件，甚至时间——都是那根线正在被画出来的过程；在代码里整部片子真的就是一条点数组，从笔尖第一次触纸到最后一帧（`style-dna/one-line.json#essence`）。除了墨只有两样东西：暖白纸，以及一支笔的柔和影子（纸之上的真实世界）。最多一个强调色，且**只用一次**（`STYLE.md:8-11`）。

**不是什么**（最容易做错的邻居风格）：不是**白板讲解**（没有手、没有马克笔、没有擦除、没有文字堆满的板）；不是**水墨**（没有调子、没有把笔晕当外观）；不是**有剪切、有多笔的线稿动画**（`STYLE.md:13`）。参考语汇只借语法、不借形象：La Linea 的「一条线既是世界也是角色」、Gjon Mili 1949 年拍毕加索光画的「一个手势的自信与速度」、McLaren 的「线是画给音乐听的」（`STYLE.md:4`）。

**什么时候用它**：内容本身是**连续的一件事**——一段旅程、一条产线、一个人的一生、一个品牌从第一张桌子到 logo；或者你需要一次「原来全都是同一幅画」的揭示。适合品牌故事、人生里程碑、极简广告（`style.json#uses`）。

**一句话内核**：线的连续性就是意义——笔不抬、场景不切、转场是变形，最后一笔之前的一切都是同一幅画的局部。

**边界**：撑不起**并列清单式**内容（N 个互不相干的要点）、**数据密集**内容（没有图表位、没有表格位）、**多人对话**（没有对话镜头语言）和**需要解说板/箭头标注**的内容。它的甜点区是 30–60 秒（`DEMO.md:8`）；再长，连续作画的专注感会变成疲劳。

## 2. 画面构图

- **镜头数与画幅**：**全片只有一个镜头**——没有剪切，一个连续运动从第 1 帧到最后一帧。样片 47.50s / 1140 帧 / 1920×1080（16:9），24 fps（`logs/one-line.log`）。★ **2026-10-04 已适配 9:16**：影片模块 `film.js` 声明字面量 `FILM_META.aspects = ['16:9','9:16']`，从 `opts.W/opts.H` 经 `frame.js` 的 `setFrame()` 派生 `FX/FY/S` 重排版面（原先无声明、按 1920×1080 绝对像素构图）。
- **主体位置与占比**：主体就是那根线本身。笔尖被一个软约束锁在画面中央约 **72%×66%** 的区域内（`DEMO.md:34`、`style-dna/one-line.json#shot_logic`）。跟拍点是笔尖在 **−0.55…+0.4s** 的加权平均，所以笔尖永远「稍微落后、稍微提前」地待在构图里，从不贴边。
- **负空间 / 留白**：纸就是留白，**留白量极大**。微距段（如开场 f01、跟笔段 f05）画面里只有一条线，其余 95% 以上是空纸；只有揭示帧（f20）才把纸「用满」。片尾卡也刻意写在**空纸**上、避开最终画面（f24）。
- **图层叠放顺序**（从底到顶）：纸（斑驳 + 纤维 + 暗角）→ 墨线（填充多边形）→ 墨点 / 泪滴墨点 → 纸齿斑点（近景时叠在墨上）→ 笔影与手影 → 字幕 / 标题 / 片尾卡（`main.js:41-75` 的 render 顺序）。所有纹理**锚定在纸上、随镜头移动**（`STYLE.md:17`）。
- **安全区**：字幕基线距底 100px（≈9.3% 画面高），居中；标题写在当前小品的空纸上，**标题窗口内每一帧都要检查它有没有被镜头推进去的画面撞上**（`DEMO.md:101`）。
- **本风格不能出现的构图**：任何**填充**、任何**阴影**（除笔影/手影）、**第二种线重**、**背景美术**、画进画面的手 / 马克笔 / 橡皮（`STYLE.md:9`、`style-dna/one-line.json#shot_logic.forbidden`）。也不许出现「两个独立物件同时在场」——因为只有一根线，同一时刻只能有一个位置被画。

**在 9:16（产品默认 1080×1920）下的表现**：★ **2026-10-04 已适配**——`film.js` 从 `opts.W/opts.H` 经 `setFrame()`（`frame.js`）派生 `FX/FY/S`，相机把紧轴缩放 S 折进 zoom（`cam.js` 的 `k = BASE·z·S`），世界（那条线）按 S 整体缩小、**主体不被裁**；屏幕空间家什（纸纹 / 暗角 / 纸齿 / 笔影手影 / 字幕 / 标题 / 片尾卡）位置按轴 ×FX/×FY、尺寸按 ×S（`subs.js`）。1080×1920 实测（S = 0.5625）：揭示帧（40.38s）里**老人的整张脸、圆眼镜、红嘴、风筝都在画面内、居中**；片尾卡与标题落在画面右上、完整可见；字幕帧（3.5s `Everyone begins by holding on.`）贴底居中、未溢出。代价是整幅画按 0.5625× 缩小、四周留大片纸色空白——**版面更空、密度更低**，与 `dataviz` / `whiteboard` 的竖屏代价一致。

## 3. 配色体系

| 角色 | 色值 | 用途 | 来源 |
|---|---|---|---|
| 底（纸） | `#F4EFE4` | 暖白纸面，程序化斑驳（1400 单位图块、soft-light）+ 长纤维（260 单位图块，拉远时淡出免得闪烁）+ 暗角 0.13 乘算 | `DEMO.md:69`、`style-dna/one-line.md:24` |
| 主（墨） | `#1D1A17` | 暖黑，围绕路径的**填充多边形**（不是 `ctx.stroke`），逐点与纸色混合成不透明色调 | `DEMO.md:71`、`ink.js:4-6` |
| 强调（红） | `#B3332B` | **全片唯一的强调色**，从嘴角开始、到法令纹渐回墨色，最后留在老人的微笑上 | `DEMO.md:80`、`ink.js:27-34` |
| 字幕 | 墨 `#1D1A17` @ 84% 不透明 | 无框、底部居中，背后一层柔和**纸色光晕** | `DEMO.md:86` |

- **明度 / 对比规则**：整片是「暖白纸 + 暖近黑墨」的**极高对比、极低色数**体系。除了纸、墨、一处红，画面上**不允许第四种颜色**。红在最终画面里必须**留在有意义的位置**（样片是嘴），否则强调色白用。
- **禁止出现的颜色**：任何第二个强调色（`STYLE.md:33`「Never a second accent」）；任何灰阶调子（会读成水墨/铅笔稿）；任何饱和底色或渐变背景（背景必须就是纸）。
- **同一画面最多几个色相**：**1 个**（暖白纸不计为色相）；全片只有 1 个彩色章节允许第 2 个色相出现。

## 4. 转场规则

- **镜头之间怎么切**：**不切。** 全片一个镜头、一根线。转场就是**变形**——上一幅图像的最后一笔，就是下一幅图像的第一笔（`STYLE.md:63`、`style-dna/one-line.json#shot_logic.transitions`）。样片里风筝线变自行车架、微笑变道路、房子变鼻子。
- **有没有叠化 / 闪白 / 擦除 / 定格**：**全都没有**。没有淡入淡出、没有溶解、没有擦除、没有定格（`style-dna/one-line.json#shot_logic.forbidden`）。唯一接近「定格」的是**停笔**：笔尖停下、墨洇成一个泪滴形墨点、音乐切成静默 1.5–3s——但画面并没有停，墨还在洇（`STYLE.md:81`）。
- **硬切点怎么定**：不存在硬切点。**章节边界只由笔的位置决定**，不由时间决定：每个章节是一段 SVG path，章节之间的连接器必须落在最终画面的**自然线**上（镜框、法令纹、鱼尾纹、下颌线、一根头发），否则那条多余线在揭示时会读成皱纹、胡子或面具（`DEMO.md:62`）。
- **转场时长与缓动**：没有固定时长，**长度就是那段连接器的弧长**；时间按 `1 + K·turn` 加权（急转弯分到更多时间，平滑处理保证速度不跳变），行进线 300–700 单位/s、小细节 50–150 单位/s（`DEMO.md:47-49`）。速度本身要**平滑**，绝不能跳变。
- **绝对不要的转场**：任何 cut、fade、dissolve、wipe、zoom-blur；任何「两个画面同时存在」的叠化（因为只有一根线）。

## 5. 字幕样式

| 项 | 值 |
|---|---|
| 字体 | Caveat 500（手写体）；标题用 Sacramento（单线连笔——本身就是一幅一笔画），片尾卡另加 Caveat 600 宽字距的 `ONE-LINE DRAWING` |
| 字号（相对画面宽 / 高） | 字幕 46px @1920 宽 ≈ **2.4% 画面宽**；标题 76px ≈ **4.0% 画面宽** |
| 颜色 / 描边 / 阴影 | 墨 `#1D1A17` @ 84%，**无描边、无阴影、无框**；背后一层柔和纸色光晕，保证经过的墨线永远不穿过字母 |
| 位置 / 安全边距 | 居中，**基线距底 100px**（≈9.3% 画面高）；标题写在当前小品之外的空纸上 |
| 单行字数上限 / 最多行数 | 1 行；样片最长 37 字符（`For a while, one line was enough for two.`）、最短 16 字符（`Your turn now.`），实际出片时 37 字符那行在 f09 里被折成两段显示 |
| 出现与消失方式 | **写出来**：从左到右，约 `0.2s + 每字符 17ms`；淡出约 0.45s；停留 ≥ `max(1.8s, 语音 + 0.6s)` |

- **字幕与旁白的关系**：字幕**逐字写出**、与旁白的 whisper 逐词时间戳对齐；关键词必须落在画面拍点上（样片把「holding **on**」落在抓握的那一笔、「**goes** on」落在笔重新起跑的那一帧，`DEMO.md:57`）。
- **本风格特有的字幕禁忌**：不许有框、不许有底色块、不许遮住正在画的线（靠纸色光晕实现）；不许长句、不许从句、不许一句塞两个信息点（`style-dna/one-line.json#sentence_patterns.forbidden`）；不许把关键词落在没有画面事件的时刻。

## 6. BGM / 音效特征

- **配乐**：**一件独奏乐器、一条不间断的旋律线**——作画的听觉等价物。样片用大提琴（`cellos` 低力度、单声道、略偏左、legato 0.14s 叠接），童年段换 `cellos_pizz`，下一代开始处用**一声** `hand_chimes`（`DEMO.md:53`）。**没有钢琴、没有弦乐 pad。** 谱是**写给画**的：关键音落在 mark 与拐角上；线快 = 短音；线停 = 一个长音淡入静默；最高的音落在最重要的一次触碰上。
- **拟音（foley）清单**：**笔在纸上是全片最重要的声音**，从 200Hz 的笔速轨迹合成——带通噪声（快时亮 2.2–7.5kHz、慢时暗 0.7–2.4kHz）、随机纸纤维 tick（密度 ∝ 速度）、振幅 ∝ √速度、随笔尖的屏幕 x 位置 pan、被干笔空隙打断；另加第一触的一声木嗒（`tap`）、墨点几乎听不见的湿涨（`blot`）、交接的一声小摩擦（`handoff`）、一次翻页。事件词汇见第 10 节。
- **旁白处理**：Kokoro `am_liam`，speed 0.84；高通 85Hz、低通 7.2kHz 让声音变暖变软（`DEMO.md:57`）。本次出片 ASR 校对 6/6 全对、mismatches 0（`logs/one-line.log`）。
- **响度目标**：`−14 LUFS`；**交付真峰值上限**：`−1.2 dBTP`（项目级交付线；本风格 `STYLE.md:71` 只写 −14 LUFS，未额外声明更严上限）。本次成片实测 **I = −14.2 LUFS / LRA 7.0 LU（`ebur128`）/ 真峰值 −1.62 dBTP（`loudnorm` `input_tp`，4× 过采样）—— 真峰值在交付线内，余量 0.42 dB、未削波**（`logs/one-line.log` 混流段只印了 `ebur128` 的 1 位小数 Peak；`astats` 采样峰值 −1.620590 是下界，两者都不能当真峰值用）。**grain 0**——纸纹在渲染里、不在后期。
- **静音策略**：**静默是字面的**：停笔时把**音乐总线归零（含混响尾巴）**，房间底噪降到 15%（`DEMO.md:55`）。本次出片 score.py 报出的静默窗口是 **24.6–26.85s**（`logs/one-line.log`），画面里对应泪滴墨点在 f13（≈25.7s）仍在洇。人声下 duck：音乐 ≈5 dB、笔 ≈4 dB。

## 7. 素材偏好

- **需要什么素材**：**一幅最终画面**（写成 SVG path 字符串）+ **章节表**（时间窗、marks、holds、线的年龄）+ **旁白行** + **标题** + **强调色区间** + **交接时刻**（`style-dna/one-line.json#asset_contract`）。字体要 Caveat（手写）与 Sacramento（单线连笔）——demo 自带 `fonts/`。配乐样本是 CC0 的 VS Chamber Orchestra（`logs/one-line.log` 的 Samples 行）。
- **不需要什么素材**：**不需要任何照片、视频素材、贴图、图标库**。这个风格几乎不吃外部素材——它的画面是纯程序化几何。
- **取景 / 质感 / 比例偏好**：16:9（1920×1080）；质感全部来自「纸」的程序化纹理（斑驳 / 纤维 / 纸齿 / 暗角）与「墨」的物理（笔压、墨渗、积墨、飞白、泪滴）；线宽是**纸单位**，随缩放变化，但拉远时必须 clamp 到 ≥1.3 以免最终画面像铅笔稿（`ink.js:84`）。
- **可替代方案**（缺素材时怎么降级而不破风格）：没有 Sacramento 就只用 Caveat（仍是手写体，破风格程度最小）；没有独奏样本库就换成**任何单件乐器 + 单声部**的合成音色（切忌换成 pad 或鼓组，那会直接破风格）；最终画面画不出来时**宁可缩短片长到 30s、减少章节数**，也**不要**改成多笔线稿或加填充——线的连续性一旦破，风格就不存在了。

## 8. 镜头节奏

| 项 | 值 |
|---|---|
| 单镜时长 | 全片 1 个镜头（连续运动，无切点）；内部由 `shots.js` 的镜头关键帧（t/x/y/z/r/f）分段 |
| 全片时长 | 47.50s（`style.json` dur=47.5、frame_sec=39.9）；甜点区 30–60s |
| 镜头数 | 1（无剪切） |
| 信息投放节拍 | 9 个章节段（`face.js:119-131` 的 SEGS）；旁白 6 行，落在 4.09s（grip）/ 16.11s、18.42s（nose1/nose2）/ 24.6–26.85s（静默）/ 38.8s（final）/ 41.7s（chime） |

- **加速 / 减速点**：**全部 on ones（24 fps）**——吸引力来自连续的作画动作，步进会破坏它（`STYLE.md:43`）。速度：行进线 300–700 单位/s，小细节（手指、睫毛）50–150 单位/s；**全片最重要的一笔通常最慢**。镜头侧：开场是 z≈4.3 的微距、跟拍权重 f≈0.1；行进段 f 0.6–0.85、z 拉到 ≈2.4；每个小品用 f 0.15–0.35 的构图帧；停顿时 z 从 4.6 缓慢推到 5.4；揭示是一次 5 秒的连续拉远（z 从 ≈3 到 1），再保持 ≈1s（`DEMO.md:36-44`）。
- **留白与静音的位置**：静音落在**停笔**那一刻（本次 24.6–26.85s），持续 1.5–3s，是全片最强的节拍（失去、怀疑、一个决定）。开场前 3 秒也是「留白」——纸上还没有线，只有笔影。

## 10. 编排规则

- **内容文件字段契约**：需要产出最终画面（SVG path 字符串）、章节表（时间窗、marks、holds、`style` 年龄）、旁白行、标题、强调色区间、交接时刻。demo 里分别由 `face.js` 的 `SEGS`、`story.js` 的 `DUR/VO/TITLE/HAND/END`、`lines.json` 提供（`style-dna/one-line.json#asset_contract.content_fields`）。
- **事件词汇表**：`track`（笔速轨迹，200Hz，含速度 / 屏幕 x / 风格 / 干度 → 笔声合成）、`corners`（拐角 = 高转角 + 局部速度最低 → 候选音符起音）、`tap`（第一触 → 木嗒）、`blot`（停笔墨点 → 湿涨）、`chime`（新线开始 → 钟声）、`handoff`（交接 → 摩擦）、`vo`（人声 → 加载 `voices/<id>.wav`）、`seg`（段落起止与标记时刻 → 配乐 cue）（`main.js:77-104`）。
- **时间线契约**：`story.js` 是时间线**唯一真值**，导出 `DUR`、`VO`、`TITLE`、`HAND`、`END`（`story.js:2-13`）。页面契约由 `main.js` 暴露 `window.render(t)` / `window.DUR` / `window.EV` / `window.SUBS` / `window.READY`；几何层 `geom.js` 导出 `buildPath`/`headAt`/`posAt`；镜头层 `cam.js` 导出 `camAt`/`worldToScreen`/`BASE`（`BASE=0.85`，z=1 时整张脸入画）。
- **新增主体怎么接入**：新的「画」模块必须导出 `SEGS`——每段 `{id, style, t:[t0,t1], parts:[{d, tf}], slowK, marks?, holds?}`，`d` 是 SVG path 字符串、`tf` 是可选变换、`style` 是线的年龄（`child`/`teen`/`adult`/`love`/`old`/`kid`，各有基准宽 2.4/2.5/2.9/2.8/2.7/2.0）、`marks` 是音乐卡点（按弧长分数 `f` 或位置 `at:[x,y]`）、`holds` 是停顿墨点。**接入方式就是替换 `face.js` 这一个文件。**
- **换主题时要改哪些文件**：**只改 3 个**——`face.js`（新的最终画面 + 章节表）、`story.js`（时间线真值：DUR / VO / TITLE / HAND / END）、`lines.json`（旁白脚本）。`ink.js` / `paper.js` / `cam.js` / `geom.js` / `subs.js` / `music/score.py` / `mix.py` **全部自动跟着走**，不需要动。这是本风格最关键的复用机制：**换一幅画，其余不变**（`style-dna/one-line.md:227`）。
- **与 `dub.mjs` 通路的关系**：本风格在「文案 + 风格」通路里的条目是**派生条目**（`derived:true`），配色来自 `lib/dub-visual.json`（demo 代码抽取），字幕字号/位置取自类别默认（`paper-ink` 类：字号 40px、下边距 157px、左边距 76px、描边 3px），字幕颜色由 WCAG 对比度规则从底色推得。**能生效的参数**：`palette`（bg/bg2/fg/accent/subtitle/subtitleOutline/subtitleBack）、`bgRecipe`（type=**solid**、`texture:"rice-paper"`、vignette 0.35、`textureRaw:"ink"`）、`subtitle`（fontFamily `KaiTi`、fontSizeFactor 0.03704、marginVFactor 0.14537、marginLFactor 0.07037、outlineFactor 0.003、align 2）、`motion`（subtitleFadeIn 0、chapterTransition **bloom**）。⚠ 该条目的 `palette.bg` **曾**缺失、被 `plain-dark` 的 `#0C1016` 兜底（`bgSameAsDefault: true`）；★ **2026-10-03 已修**：现已改为 `palette.bg = #F4EFE4` / `fg = #1D1A17`、`bgSameAsDefault: false`——文案通路现在能拿到纸底（原「与默认底几乎同色」的观察保留为历史）。

## 11. 当前短板与避坑要点

### 已知缺陷
- **9:16 曾不适配（★ 2026-10-04 已修）**：原记「按 1920×1080 绝对像素构图、无 `aspects` 声明，硬渲 9:16 时画面 1:1 塞在左上角、右侧约 43.75% 丢失，老人右半张脸与右侧片尾卡会被切」。**2026-10-04** 已改造 `styles/one-line/demo/`：新建 `frame.js`（`NATIVE` / `setFrame(W,H)` / `FX,FY,S`）、把影片逻辑从 `main.js` 拆到 `film.js` 并声明 `FILM_META.aspects = ['16:9','9:16']`、`main.js` 改为页面契约读视口（`cv.width = innerWidth`）、相机 `zoom × S`（`cam.js`）、屏幕家什 ×FX/×FY/×S（`subs.js`）。**16:9 逐字节未变**（`FX=FY=S=1` 时每个表达式退化成它替换掉的那个数字；三个采样帧 md5 相同）；9:16 实测不裁切、主体完整（见第 2 节）。
- **「文案 + 风格」通路里底色退化**：`dub-styles.json#one-line` 是派生条目、`bg` 缺失、兜底成 `#0C1016` 深底（`bgSameAsDefault: true`），拿不到 `#F4EFE4` 的纸感；该条目的 notes 也明确写了「知识库更新时应优先用代码抽取值替换本条的派生值」。★ **2026-10-03 已修**：`dub-styles.json#one-line` 的 `palette.bg` 已改为 `#F4EFE4`、`fg` 改为 `#1D1A17`、`bgSameAsDefault: false`，文案通路已能拿到纸底。（原观察保留如上。）
- **字幕折行未受控**：样片 37 字符那行在 f09 里已折成两段显示，而 `STYLE.md`/`DEMO.md` 声明的是「单行、基线距底 100px、写出来」；长行折行后的第二行位置与写出节奏没有规范可依。
- **细纹理 `textureRaw: ink` 声明了但渲染未实现**：`lib/dub-styles.json#one-line.bgRecipe.textureRaw` 是 `ink`，而渲染侧（`lib/dub-core.mjs` 的 `bgFilters()`）**只把粗粒度 `bgRecipe.texture` 当主权威源**（本风格是 `rice-paper` ⇒ 宣纸噪点（`noise=alls=6:allf=t+u`）），**不读** `textureRaw` ⇒ `ink` 这一层质感在「文案 + 风格」通路上**从未画出来过**。为什么没实现：`bgFilters()` 里没有 `ink` 对应的滤镜分支，按「只复用已有分支、不发明无数据依据的参数」的口径**只如实标注、不猜参数**（已集中登记在 `lib/dub-styles.json` 的 `_notes` 未实现清单里）。

### 素材缺口
- **最终画面（SVG path）必须为每个主题重画**，这是本风格最大的人力成本；仓库里只有 demo 那一幅「老人的脸」。
- **字体依赖**：Caveat 与 Sacramento 在 demo 的 `fonts/` 里，脱离 demo 环境（如 dub 通路）本机没有这两个字面，只能退到系统手写体或楷体。
- **独奏配乐样本**：demo 用 CC0 的 VS Chamber Orchestra；换成别的素材库时很难保证「单件乐器 + 单条不间断旋律」的音色统一。

### 能力限制
- 不适合并列清单、数据密集、多人对话、需要标注板的内容（第 1 节「边界」）。
- 片长甜点区 30–60s；超出后专注感转为疲劳（`DEMO.md:8`）。
- 拓扑是硬约束：最终画面的每个区域**只能被画一次**，连接器必须落在自然线上，规划得像**欧拉路径**；一次改画往往要重排章节顺序。

### 踩过的坑（本机实测）
- 本次出片**完整跑通**：`node lemo-make.mjs one-line --skip-sync --no-preflight --ratio 16:9`，1920×1080、nvenc、24fps、6 workers；渲染 1140 帧用 28s，成片 18.6MB、总耗时 67.1s，**无告警**（`logs/one-line.log`）。
- **走的是 `--skip-sync`**（`[2] 同步两份库` 段显示「（--skip-sync）」），`--no-preflight` 也开着；TTS **是现跑的**（`[配音 1/1]` 段），不是预生成配音；ASR 校对 6/6 全对、mismatches 0；混流走 **nvenc（GPU）**。
- **音频与渲染是并行跑的**（`[5]` 段末尾注「音频与渲染并行完成 · 49.0s」），mix.py 在 WSL 里 6 workers 跑 190 块。
- 实测坑（来自 `DEMO.md:92-103`，本次出片未复现但换主题会撞上）：杂散连接器会把揭示读成胡子/面具/围兜；风筝从头顶直直画上去会变成一个尖洋葱顶；手从太阳穴横伸出去会读成螺栓；两张侧脸被头顶一条弧封口会读成高脚杯（鲁宾花瓶）；侧脸贴太近加宽后会编成辫子（**留 ≥5 单位缝**）；圆墨点会读成一颗痣（要做成**下垂的泪滴**）；拉远时线太细（**clamp 线宽缩放**）；半透明手影重叠处会加倍变暗（**每只手合成一层**）；标题会随镜头推进撞上画（**检查标题窗口的每一帧**）；whisper 会误听短句（改句子，不硬刚）。
- `still.mjs` 在机器负载高时很慢，要用 `?cams=`/`?camt=` 在一次浏览器会话里渲多视图。
