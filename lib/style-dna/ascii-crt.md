# ASCII / CRT 终端（ascii-crt）· 风格创作逻辑档案

> 面向：要**从零原创**一部该风格片子的人 / 下游智能体。
> 本文只收录**风格逻辑**（换主题仍成立的规则），不收录示例《TRANQUILITY.LOG》的具体内容。
> 证据见文末，格式 `file:line`。

---

## 0. 一句话

一块单色终端屏幕：**P3 琥珀磷光**在暗玻璃上发光，边缘弯曲、带扫描线；画面里的一切都是**真实字符排在字符网格上**、按墨量密度挑出来的。全片只有一个镜头——屏幕本身——它只靠**改变网格字号**来运动。

**它不是**：加了「ASCII 滤镜」的图片（字符必须作为字符画在网格上）、黑客电影的绿雨、像素游戏（无精灵、无自由像素）、科幻 HUD（无矢量线、无悬浮面板）。
（`STYLE.md:12`）

## 1. 材料与渲染的硬规则

| 规则 | 具体值（实测/文档） |
|---|---|
| **字体** | VT323（OFL）；格 0.4em 宽 × 0.8em 高（1:2）；160px 图集 + 2.2px 描边（电子束扩散），`drawImage` 缩放。 |
| **网格** | 每镜列数不同：标题 ~20 列、终端 80 列、画面 200+ 列。 |
| **密度表** | 字形墨量 × dim/normal/bold（0.42/0.7/1.0）→ 约 20 级；4×4 有序抖动 + hash；亮度 <0.05 留白。 |
| **底片管线** | 灰度先画进与网格严格对齐的离屏画布（R=琥珀，G=第二色，B=标志位）；按格取平均；局部对比 `m + 0.9·(m − mean)`。 |
| **剪影优先** | 可辨识主体靠剪影（多边形/几块面）；暗=稀疏暗字，亮=密集粗字，暗面只用稀疏 `.`。 |
| **深度** | 远=更暗更稀，近=更亮更密；面之间一条细亮边。 |
| **CRT post** | 磷光色映射（暗深橙→琥珀→过曝近白）、多级 bloom + 淡光晕、扫描线（亮处暗缝变窄）、桶形畸变、圆角遮罩、暖近黑玻璃、淡反光、~1% 闪烁、细噪声。**无 RGB 荫罩。** |
| **余辉** | τ ≈ 0.12s 解析式衰减；移动字形带一段极淡拖尾（t−35ms × 0.3）。 |

**关键取向**：`STYLE.md:18` 强调**负空间才让 ASCII 画读得出来**；`STYLE.md:16` 强调网格缩放的连续性靠预渲染图集。

## 2. 句式（字幕 / 旁白怎么写）

**谁来写**：一台被留在月球、孤独运行了 40 年的机器（或一个远程操作者）。第一人称、现在时。冷静克制，不抒情。

**长度（实测）**：单句 **4–11 个英文词**（约 20–60 字符），且**行数极少**（demo 全片只有 5 行）。硬规则：每条 ≤ 4.5s（语速 0.8）；LOG 字幕条一行 ≤ 80 列，停留 = `max(1.4s, 说完 + 0.6s)`。屏幕上「故事展示的文本」是画面不是字幕，在 `.srt` 里记为 `[SCREEN] …`。

**句首类型**（示例性，不是抄原文）：
- 日志式开场：`Log resumed.` / 时间戳 + 状态
- 状态/事实起句再落到意图：`A message from Earth. I should show them I am here.`
- 否定式坦白约束：`I have no camera. Only words.`
- 数字做钩子：`Forty years of logs.`
- 新条目收束：`New entry. Signal received.`

**这个风格里不会出现的句式**：
- 第一人称抒情与感叹（机器只报告状态）
- 网络口播腔、营销话术、感叹号堆叠
- 长句与从句嵌套（句子必须能被逐字敲出来）
- 抽象概念当主语（只说能被网格画出来的东西）

## 3. 叙事节奏

**信息投放顺序**：

```
CRT 从点→线→整幅开机（空屏上一个巨大光标闪 3 次）
  → 标题作为「机器打开的文件」在 20 列打字
  → 拉远到 80 列，变成启动日志第 1 行
  → 静态 80 列终端（唯一的运动是文字与光标）
  → 打扰（握手噪声冲刷屏幕）
  → 屏息（光标闪）
  → 挫折（NOT FOUND ×3）
  → 决定（推近，回信被巨大地打出）
  → 近静默 1–1.5s
  → 高潮（回信字母掉落、按墨量重排成地球升起的字符画，第二色在重拍出现）
  → 尺度揭示（推进到单个字形，内部是 40 年的日志子网格）
  → 等待 → 一句小回复 → 回声（退出屏幕、关机收成一点）→ 片尾卡
```

**时间挂在 100 BPM 网格上**：1 拍 = 0.6s，1 小节 = 2.4s。

| 锚点（秒） | 值 |
|---|---|
| 开机 / 标题 / 拉远 | on0=0.35 / title=3.0 / zoom0,zoom1=7.2,8.4 |
| 握手 / 消息 | carrier=16.2 / msg=17.6 |
| 推镜 / 回信 | push0,push1=29.6,30.2 / reply=30.2 |
| 字母掉落 / 变色重拍 | fall0=33.6 / bloom=37.2 |
| 分形推进 | fr0..fr5 = 40.2→47.6 |
| 发送 / 退出屏幕 | tx0,tx1=48.0,49.8 / out0,out1=52.6,54.8 |
| 片尾卡 / 关机 / 总长 | card=55.2 / off0,off1=58.6,59.2 / dur=59.8 |
| 打字速度 | 启动行 12ms/字、命令 38ms、标题与回信 120–150ms（=100 BPM 十六分音符） |
| 落地闪 | 1.9× 亮度、0.12s 衰减 |

**总时长**：主 demo 59.8s（`style.json`）；简报区间 30–60s。分形推进：先从 8px 格推到 300px 格并**停 1s**，再推到 450px（子文本约 28px 可读）。

**静默怎么用**：静默是**主要乐器**。握手、消息、光标闪烁都只在房间底噪上播放；画面成形前有 1.5s 静默。需要「数字归零」时（含混响尾巴）必须真的归零（demo 在硬切上把整条配乐归零 5s）。

## 4. 镜头逻辑

**镜头是什么**：就是**屏幕本身**——唯一能动的「镜头」是网格字号，外加 CRT 的开/关机状态与一个可能的「屏幕之外」的镜头。它表达的是一台机器的时间与注意力。

**词汇表**（用法由主题决定，没有固定路线）：

| 运动 | 表达 | 可服务 |
|---|---|---|
| 静态 80 列终端 | 等待、流程、机器时间 | 倒计时；队列；被阅读的日志 |
| 推进（格子变大） | 注意力、亲密 | 一句对白；一个名字；被敲下的决定 |
| 拉远（格子变小） | 语境、尺度 | 标题变成列表第 1 行；成千条目中的一条 |
| 推进到单个字形内部 | 隐藏的深度；一个符号由什么构成 | 由消息构成的一个字母；由人构成的一个像素 |
| 滚动（缓冲移动） | 累积、时间流逝 | 多年的记录；变更日志；信息流 |
| 清屏 / 硬重绘 | 一次切；一个新状态 | 重启；新章节；崩溃 |
| 文本变成图像（网格缩小、字形坠落） | 字变成世界 | 一封信变成一张脸；数据变成地图 |
| 开机 / 关机、消磁 | 生、死、睡眠、电击 | 机器苏醒；结局；一次抽搐 |
| 从玻璃上退出到画出来的房间 | 屏幕是世界里的一个物件 | 谁在读；机器在哪 |

**允许的转场**（必须发生在屏幕内）：清屏/硬重绘、滚动、开机/关机、消磁。

**禁止**：两块屏幕之间的交叉溶解；让字符离开网格（除声明的变换时刻）；把画面当成「图片 + ASCII 滤镜」；彩色装饰。

## 5. 表达习惯（idioms）

1. **画面由词构成**：一句话散开，字母按墨量密度排序后变成一幅只含这些字母的图像。
2. **字号即镜头**：推进到一个字占满屏幕，那个字本身又由更小的文字组成。
3. **打字节奏即剪辑节奏**：机器均匀而快，人不匀、有停顿与爆发；一个闪烁的光标就是最重要的表演。
4. **CRT 物理**：开机点→线→整幅、关机收成一点；余辉、bloom、弯曲玻璃。
5. **一次颜色变化**：一个柔和的第二色只出现一次，在重拍上开启，不轻易收回。
6. **日志文件**：时间戳、错误码、进度条讲故事。
7. **LOG 条作为字幕**：底部保留区，反白 `LOG` 标签 + 提示符，按语音逐词打出，在缩放网格之外。

## 6. 氛围

一间深夜的机房 / 一座远程中继站：房间底噪（风扇、低鸣、极轻的行输出啸叫）、磷光的暖、玻璃的冷；只有屏幕亮着。整体是**冷、耐心、机器般平静，但有一次暖的意外**的气质。

---

## 7. 声音

- **乐器**：原创模拟合成器配乐，用代码（numpy/numba）渲染——PolyBLEP 锯齿/方波、带移动截止的共振 4 极点梯形低通、滤波包络、方波音序器、慢磁带 wow（±几音分）、pad 长混响、重击门限混响；可选 sub-bass 无人机、采样保持噪声、失谐齐奏主音。**绝不 chiptune。** demo：D 小调、100 BPM。
- **动作声（全部合成）**：继电器咔哒、消磁嗡（60Hz 及谐波 + 闷咚）、屈曲弹簧键（塑料咔 + 3.4kHz 弹簧叮 + 键帽回弹低嗒；空格更闷、回车更重）、对面字符的电传滴答、调制解调器与电话线音（应答音 2100Hz 带两次相位翻转、双音、1200/2400 FSK、限带噪声）、方波错误音与 BEL、粒子落地的成簇细小高频滴答、房间底噪（风扇 + 低鸣 + **极轻**的 15.7kHz 行输出啸叫，约 −50 dBFS）。
- **混音规则**：音乐在人声下 duck 约 −8 dB；母版 −14 LUFS，mux 不加颗粒（噪声活在画面里）。机器说话时处理人声（轻环形调制 16%@52Hz、6ms 梳状、140–7000Hz 带通、软饱和），并用 whisper 复检每行仍可读。静默是主要乐器。

## 8. 变化空间（可自由发挥）

谁在打字、屏幕是干什么用的、网格列数、开场、结尾、镜头（网格）路径、节奏、以及**第二色是否出现**。

`STYLE.md:107-109` 给了远离 demo 的方向：
- **结构**：一段聊天记录（两个用户隔一夜互相打字，时间戳当场景标题）；一本系统手册（章节标题、ASCII 图表、有一页开始出错）；一台机器从开机到关机的一天（一串计划任务，每个任务画出它在做的事）。
- **开场**：从滚动中途开始（缓冲已经在飞，它停在某一行）；一张打印纸（点阵纸向上喂入，然后屏幕接管）；先来一个错误（崩溃转储，然后倒回原因）。
- **结尾**：缓冲填满（故事的文本向上滚走只剩提示符）；屏幕保护（最后一行之后，一个缓慢漂移的图案接管空闲屏幕）；光标停止闪烁（不断电，只留一个最终状态）。

## 9. 禁忌清单

- 用「图片 + ASCII 滤镜」造假。
- 黑客电影的绿雨。
- 像素游戏（无精灵、无自由像素）。
- 科幻 HUD（无矢量线、无悬浮面板）。
- 彩色装饰（单色磷光 + 最多一个第二色）。
- 两块屏幕之间的交叉溶解。
- chiptune 配乐。
- 让字符离开网格（除声明的变换时刻）。

## 10. 素材契约（要新做一部片，需要产出什么）

### 10.1 内容要素

| 要素 | 说明 |
|---|---|
| 台词 `lines.json` | `{id, t, text, voice, speed, asr?}`；demo 用 `am_echo` speed 0.8，4–6 条短句 |
| 逐词时间戳 `voices/words.json` | 字幕逐词打出用 |
| 语音时长 `voices/dur.json` | 停留计算 |
| 时间线 `main.js` 的 `T` | 开机/标题/握手/消息/回信/掉落/变色/分形/发送/退出/关机 |
| 网格与密度表 | 列数、格子尺寸、字符集（如 `' .:-=+*#%@'` 或回信字母集） |
| 第二色 | 与其开启时刻 |

> ⚠️ `DEMO.md:3` 明确：不要复用 demo 的故事、叙事弧、镜头、道具或时长。

### 10.2 新画面元素的契约

一个「底片函数」：先把灰度画进与网格**严格对齐**的离屏画布（R=琥珀亮度，G=第二色亮度，B=标志位如夜面），再交给 `term.js` 的 `cellsFromImage` 按格取平均、`makeRamp`+`pick` 选字。可辨识主体必须靠剪影。参考实现：`art.js` 的 `paintEarthrise` / `makeCraters` / `horizonY`。

### 10.3 时间线契约

`main.js` 是全片时间线：导出 `window.DUR`、`window.EV`、`window.SUBS`、`window.render(t)`、`window.READY`；`tools/subs.mjs` 导出 `window.SUBS`。**关键**：懒构建的数据（粒子计划与它们的落地声事件）必须在 `window.EV` 导出**之前**建好（`main.js:598` 先 `buildFall()`）。

### 10.4 事件词汇（`type` → 消费者）

| type | 含义 | 消费者（mix.py 的合成拟音） |
|---|---|---|
| `vo{id}` | 人声 | 从 `voices/<id>.wav` 读 |
| `key/space/enter/keyLight{ch}` | 打字 | 弹簧屈曲键 |
| `remote{ch}` | 对面来的字符 | 电传滴答 |
| `relay` / `degauss` | 继电器 / 消磁 | 咔哒 / 60Hz 嗡 + 闷咚 |
| `bootline` / `ratchet{k}` / `clunk` | 启动行 / 走字 / 落定 | 数据啾声 / 棘轮 / 继电器 |
| `modem{d}` / `modemUp{d}` | 握手 / 发送 | 电话线限带握手 |
| `err` / `err2` / `bel` | 错误音 / BEL | 方波错误音 |
| `zoomIn{d,soft?}` / `zoomOut{d}` | 缩放呼啸 | 上行/下行扫 |
| `poweroff` | 关机 | 闷咚 + 崩裂 |
| `land{n}` | 粒子落地 | n 个一簇的细小高频滴答 |

## 11. 构建链（复用机制）

```
sh styles/ascii-crt/demo/build.sh
  # 1. TTS → voice_fx.py（机器声）→ whisper 复检
  # 2. music/score.py（原创模拟合成器）→ score.wav + stems + score.json
  # 3. events → mix.py（合成拟音 + ducking + 配乐）→ SRT
  # 4. core/render/video.mjs 出帧（1435 帧 ≈50s）→ mux（−14 LUFS, 无颗粒）→ styleframe + poster
```

**关键机制**：画面、拟音、字幕、配乐全部读 `main.js` 里同一份时间线 `T` 与 `window.EV`；粒子计划必须在导出前建好（`DEMO.md:110`）。
