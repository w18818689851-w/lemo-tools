# 铜版画（engraving）· 风格创作逻辑档案

> 面向：要**从零原创**一部该风格片子的人 / 下游智能体。
> 本文只收录**风格逻辑**（换主题仍成立的规则），不收录示例《The Honeybee, Plate VII》的具体内容。
> 证据见文末，格式 `file:line`。

---

## 0. 一句话

一部「雕版自己刻出来」的凹版印刷片：**线条是雕刀在铜上刻出的沟槽里兜住的墨**，明暗全靠线密度，颜色是印完后手工罩上去的透明水彩。

**它不是**：木刻（白底黑块 + 白色凿痕）、钢笔速写（松散断线）、工程图（blueprint）、褐色滤镜老照片。
（`STYLE.md:14`）

## 1. 材料与渲染的硬规则

这是这个风格最不可让步的部分。任何画面元素都必须能被解释成「凹版印刷工艺的某个环节」。

| 规则 | 具体值（实测/文档） |
|---|---|
| **纸即世界** | 1920×1080 世界单位的手工帘纹纸，米黄 `#f1e8d2`；纸纹（纤维、帘纹、霉斑 `#9a6a34`）在**世界空间**里，随镜头缩放。压印版痕 + 双线边框框住画面。 |
| **墨只有一种** | 暖近黑 `#1c1510`，全片唯一墨色。 |
| **色调 = 线密度，不是填色** | 亮 = 露白纸；半调 = 一族平行线；暗 = 第二族交叉；最深 = 第三族组成菱形。**任何地方都没有灰块**。 |
| **线宽分级** | 轮廓最重（起伏 ×0.45–1.35，世界宽 1.8–2.4px）；第一层排线 0.18–2.0px；交叉层 ×0.78；第三层 ×0.6；发丝与点刻 0.6–0.9px。 |
| **鼓胀律** | 每条线 `width × (0.2 + 0.8·sin(πu)^0.7)`，首尾各 ~22% 收尖。等宽线 = 失败（读起来像钢笔/矢量）。 |
| **三族阈值** | 0–1 色调上，第一族从 0.14 起、交叉从 0.46–0.5、第三族从 0.74–0.78。 |
| **单光源** | 全片一个光向，惯例左上（demo：`{x:-0.55, y:-0.62, z:0.56}`）。背光轮廓更重。 |
| **几何遮挡** | 线条遇到前景形体直接断掉（传 `excl`，逐环相减；不能用 even-odd，否则重叠处会互相抵消）。 |
| **圆形放大图** | 双线圆环（2px + 0.75px，内缩 4px）+ 水平排线底纹（每 11 局部单位一条）+ 主体周围留白晕。内容按 **500 单位半径**绘制再缩进（demo 实际半径 120）。 |
| **引线** | 0.95px 发丝线，从部件上的点（半径 1.7px 圆点）到圆环边缘，绕开遮挡物留 **≥34px** 余量（最多一个折点），根部一个小号斜体图号。 |
| **手工上色** | 乘算，纸之上、墨之下：外溢 3.5px、套色错位 2/1.5px、湿边水痕、低频密度抬升 0.55、大区 1–2 次回渗、颗粒感。每块从画笔落点晕开。 |
| **铜版（仅开场）** | 抛光暖金属 `#5e2a12 → #94502c → #4e220e` + 抛光发丝痕 + 模糊 14px 的四格窗反射；沟槽 = 暗槽 `#240c05` + 朝光亮毛刺 `rgba(255,226,186)`。 |
| **雕刀** | 菱形钢身、倒角面、蘑菇木柄；**偏线 ≤15°**（0.22 rad；30° 会读成「在旁边戳」）。卷屑是收窄的铜飘带，缠距不规则，一条边受光。 |

**关键取向**：`STYLE.md:19` 强调排线间距是**相对主体高度**的（约 1/180），这样小图形不会糊灰。

## 2. 句式（字幕 / 旁白怎么写）

**谁来写**：一位安静的策展人 / 博物学家。第三人称、现在时。克制，不煽情，不设悬念。

**长度（实测）**：单句 **44–80 字符**（约 8–15 英文词）。示例里最短是标题句（44 字符），最长是第一条细节（80 字符）。字幕排布宽上限 860px（38px 字），最多两行。

**句首类型**（示例性，不是抄原文）：
- 版号 / 版次式开场：`Plate seven.` → 版号 + 主体名
- 以部件为主语的陈述：`Each eye is built from …`
- 以环境状语起句再落到主体：`In flight, …`
- 一个具体数字/量词做钩子：`some six thousand facets`
- 结尾用反差量词收束：`a twelfth of a teaspoon`

**这个风格里不会出现的句式**：
- 第一人称抒情（`I feel…`）
- 网络口播腔、感叹号堆叠、营销话术
- 抽象概念当主语（只谈可被画出来的实物、部件、位置）
- 一句塞两个以上并列信息点（每句只承担一层）

## 3. 叙事节奏

**信息投放顺序**（博物馆标签式）：

```
版号 + 系列
  → 标题（罗马大写）+ 斜体学名
  → 主体成形（轮廓 → 第一层排线 → 交叉 → 暗部）
  → N 条放大细节（每条：在哪[部件] → 是什么[名称/学名] → 一句注解）
  → 采集完成（自然尺寸对照）
  → 静默
  → 手工上色
  → 锁定终版（图注 = 行动号召 + 版画家签名）
  → 衬纸结尾卡
```

**时间挂在 96 BPM 网格上**：1 拍 = 0.625s，1 小节 = 2.5s。

| 层 | 停留规则 |
|---|---|
| 首条细节 | **9 拍 = 5.625s**（长签名镜头） |
| 其后每条细节 | **7 拍 = 4.375s** |
| 细节结束后固定段 | gather 2 拍 → silence 2 拍 → colour 8 拍 → landing 7 拍 → end 7 拍 |
| 细节总数 | 1–4 条自动重排（`film.js:35`） |
| 刻字停留 | ≥ `max(1.8s, 语音时长 + 0.6s)` |
| 刻写注解停留 | `字符数 ÷ 12 + 1 s`（`STYLE.md:37`、`film.js:230` 用同一规则） |
| 字幕 | 提前 0.1s 上、滞后 0.6s 下（`subs.py:9`） |
| 色块 | 每块晕开 1.25–1.6s，彼此间隔 0.42s |

**总时长**：主 demo 40.0s（`style.json`），alt 内容 35.6s；文档给 20–60s 区间（教材图 20–45s，博物馆标签 30–40s，一分钟讲 35–60s）。

**静默怎么用**：静默是**真实存在**的一段，不是空。在采集完成与上色之间保留整整 2 拍（demo 实测 25.0–26.25s），此时连房间底噪都压到 0.25 倍，全片只留一个极小的声音。上色一定发生在静默**之后**——这样它读起来是奖赏，而不是新信息。

## 4. 镜头逻辑

**镜头是什么**：一枚压在图版上的**放大镜**（loupe over a sheet）。它不制造情绪，只负责「看」——把视线引到一处，再让位给信息。

**词汇表**（用法由主题决定，没有固定路线）：

| 运动 | 表达 | 可服务 |
|---|---|---|
| 跟随雕刀刀尖 | 注意力集中一处；正在制作 | 第一道刻痕；签名 |
| 对数拉远 | 这条线属于更大的整体 | 尺度揭示；语境 |
| 推向部件 + 随圆形图飞行 | 「在哪」与「是什么」一镜完成 | 不可见细节；机制 |
| 以阅读倍率沿纸面平移/俯仰 | 标签按序读出 | 零件表；海岸线 |
| 一边拉远一边有东西飞过 | 元素就位后的相互关系 | 加速；总结 |
| 锁死，或 ≤2% 呼吸轻推 | 图版作为文献 | 阅读时间；颜色在动 |
| 沿铜面掠射 | 沟槽即深度 | 工艺的代价 |
| 镜像铜版 → 真实印张 | 反转 | 隐藏的真相；前后对比 |

**允许的转场**（必须来自印刷工艺本身）：揭起印张、盖下衬纸、局部擦掉重刻、换新纸上机。

**禁止**：溶解/划像等 UI 式转场；任何元素淡入/滑入（文字要么被**刻**出来，要么被**写**出来）；无来由的运镜。

## 5. 表达习惯（idioms）

1. **刻制顺序即动画**：轮廓 → 排线扫过形体 → 交叉 → 暗部/发丝/点刻，一帧帧「长」出来。
2. **三趟法**：形体靠一趟趟叠出体积感。
3. **圆形放大图作信息载体**：刻环 → 擦净 → 放大重刻 → 带引线飞到页边 → 落地时标签才刻上。
4. **手工上色是高潮**，且一定在「所有信息就位」之后。
5. **终版图版 = 海报**：所有标签、图注、签名一次锁定。
6. **长笔画由镜头跟随**：首条轮廓 5.4s，第 0 帧就已刻了约 1/3，保证没有空帧（`DEMO.md:47`）。
7. **自然尺寸对照**：空槽位放真实比例小图，交代实物多大。

## 6. 氛围

一间安静的老式工作室 / 博物馆库房：纸的味道、铜的冷、墨的干；光从左上斜进来，尘埃在光柱里。整体是**耐心、精确、值得被保存**的气质，而不是戏剧性。

## 7. 声音

- **乐器**：羽管键琴 + 弦乐四重奏；可选独奏大提琴/维奥尔琴、鲁特琴、室内管风琴、玻璃琴（冷调主题）。
- **动作声（按材料分层）**：纸（揭纸噼啪、衬纸轻拍、薄纸沙沙、整纸呼啦）；压印机（滚筒低鸣、闷响）；铜与钢（2.6–9kHz 带通雕刀嘶声 + 颤振 + 1.18/2.31/3.47kHz 版材共振，卷屑 5–9kHz 小叮，抬刀金属嗒，画圆刻划，擦亮摩擦）；墨与水（笔尖刮擦、刻字点状嗒声、水滴 plip、湿笔唰声）。排线 = 每一趟更密的微刮擦。
- **混音规则**：旋律比人声高一个八度；音乐在人声下压到 ~50%（弓弦压得最少）；整体 −14 LUFS。刻制段落**全用拨弦**（对应雕刀小而准的切），密度随趟数递增；每个圆形图 = 刻环高音「叮」+ 飞行上行线 + 落地低拨弦；上色前跑动戛然而止 → 真静默 1.25s → 上色是弓弦第一次上弓；终版图版落 V–I 终止式。

## 8. 变化空间（可自由发挥）

主题、细节条目与数量（1–4，时间轴自动重排）、信息顺序、开场、结尾、镜头路径、颜色（上哪块 / 上什么色 / 或完全不上）、节奏、配乐。

`STYLE.md:111-115` 给了远离 demo 的方向：
- **结构**：同一版的多重状态（一个地方三次重刻）；一册图版（四张小版像翻页，每张一个事实，无圆形图）；一堂解剖课（按教学顺序标部件，只给正在讲的那块上色）。
- **开场**：从终版擦回第一条线；1× 纸面上先刻标题、图在下方长出；掠过空白铜面时设计被描出。
- **结尾**：版与印张并置；单独的自然尺寸小图；一张空白新纸落上纸堆。

## 9. 禁忌清单

- 任何「填灰」——色调必须由线构成。
- 等宽线（读起来像钢笔或矢量图）。
- 文字或图形淡入、滑入。
- 溶解/划像等非印刷工艺的转场。
- 不透明色；给文字/边框/纸面上色。
- 照抄任何真实图版、姿势、边框或标题。
- 复用示例的故事、叙事弧、镜头、道具或时长（`DEMO.md:3`）。

## 10. 素材契约（要新做一部片，需要产出什么）

### 10.1 内容文件字段（`content.json`）

| 字段 | 类型 | 范围 | 越界后果 |
|---|---|---|---|
| `title` | string | ≤22 字符 | 顶破学名行宽；需在 `film.js` 降到 44px |
| `latin` | string | ≤30 字符 | 读时间变长（须在 9.4s 首次推镜前满足 chars/12+1s） |
| `plate_no` / `series` | string | ≤10 / ≤48 | series 超 ~48 会与标题相撞 |
| `subject` | `"bee"` \| `"scallop"` | 内置主体 | 未知 → 回退 `bee` |
| `details[]` | `{name,latin,note,focus}` 数组 | 1–4 条 | >4 被忽略；不足则空槽位显示自然尺寸图 |
| `details[].focus` | string | 该主体的 focus 键 | 无对应放大图 → 对主体本身实时放大 |
| `details[].note` | string | ≤60 字符（2 行 29px） | 第 3 行会碰到下一个圆形图 |
| `colors[]` | `{region,color}` | 主体 region | 未知 region 跳过；顺序即上色顺序 |
| `caption` | string | ≤50 字符 | 须在 4.4s 终版里满足 chars/12+1s |
| `signature.left/right` | string | 短 | — |
| `nat_size_label` | string | ≤16 | — |
| `voice.voice/speed/lines[]` | Kokoro 音色 / 0.8–1.0 / `{id,text,asr?}` | id: `title`/`d1..dN`/`close` | 单行超其段落会与下一段重叠；d 行 ≤4.5s |
| `end.film_title/style_name/credits[]` | string | credits ≤3 行 × ≤35 字符 | 超长破坏结尾卡阅读时间 |

> ⚠️ `DEMO.md:136` 明确：换 `content.json` 重跑只是「验证引擎能重排的技术检查，**不是做片子的方式**」。真正的做法是写 treatment，再据此产出素材。

### 10.2 新画面主体的契约

一个主体模块必须导出 **`{ink, regions, focus}`**：
- `ink`：`B.Ink` 描边库，**必须以一条名为 `ol0` 的首笔画打头**（镜头跟随的就是它）。
- `regions`：`{regionName: {path, polys, bbox}}`，供上色与引线避让使用。
- `focus`：`{focusKey: {x,y,r}}`，供放大圆形图取景。

参考实现：`demo/subjects/scallop.js`。

### 10.3 时间线契约

`makeFilm(C, voiceDur)` 必须返回 **`{render, DUR, T, EV, subs, dets, cam}`**：
- `render(ctx, t)` 逐帧绘制；`DUR` 总时长；`T` 各段秒数表。
- `EV` 按时间排序的事件数组（由 `tools/events.mjs` 序列化成 `events.json` 驱动声音）。
- `subs` 字幕条；`dets` 细节实例。
- 页面契约（`main.js`）：`window.READY` / `window.render(t)` / `window.DUR` / `window.EV`。

## 11. 构建链（复用机制）

```
sh styles/engraving/demo/build.sh [content.json]
  # 1. content → lines.json → Kokoro TTS → whisper 检查
  # 2. music/score.py（读 events.json，任何细节数都能配到乐）
  # 3. tools/events.mjs → events.json → mix.py → tools/cuecheck.py
  # 4. tools/subs.py → srt
  # 5. core/render/video.mjs 出帧 → mux 到 −14 LUFS（grain 4）
  # 6. still.mjs 出剧照与海报
```
（`build.sh:1-25`）

**关键机制**：配乐脚本 `score.py` **读 events.json**——每个细节段落（A 长 / B 俯仰 / C 拉远再推）写一次、放在片子放它的位置；outro 跟着细节结尾平移，所以**任意数量的细节都能得到匹配的配乐**（`DEMO.md:53`）。这是「可换内容重跑」在音乐层的实现方式。
