# 后室 / 新怪谈（backrooms）· 风格创作逻辑档案

> 面向：要**从零原创**一部该风格片子的人 / 下游智能体。
> 本文只收录**风格逻辑**（换主题仍成立的规则），不收录示例《Night Shift Orientation》的具体内容。
> 证据见文末，格式 `file:line`。
> ⚠️ 片子里**不能出现**「Backrooms」这个词、wiki 的「Level」编号、社区实体名、任何现有组织或 logo——一切都要原创（`STYLE.md:4`）。

## 0. 一句话

一段从空荡、无尽、荧光灯照明的空间里回收的**摄像机磁带**：一台 1990 年代手持 VHS 摄像机（4:3）连续拍下一个个「熟悉但不对劲」的室内，没有人；恐怖来自**空、重复、官僚式的规则、以及摄像机本身在最不该出错的时刻出错**。

**它不是**：恐怖片（没有怪物特写、没有血、没有 jump scare、没有配乐 sting）、ASCII/CRT 终端片（伪影是磁带与镜头，不是磷光与扫描线）、废墟（干净是这个风格的一部分）。
（`STYLE.md:15`）

## 1. 材料与渲染的硬规则

| 规则 | 具体值（实测/文档） |
|---|---|
| **画幅** | 4:3 加黑边嵌在 1920×1080；3D 用 720×540 渲染，让 VHS 通道放大（低分辨率藏住 CG 的干净感）。 |
| **空间** | 2.4m 网格上轴对齐的隔断墙（厚 0.16m）、随机缺口与短桩、柱子；吊顶 2.7m；手工路线穿过程序化填充的空间。 |
| **光照 = 上千盏灯、无阴影** | 每块灯板的颜色/强度存进 128×128 浮点 DataTexture；每片元把最近 5×5 灯板求和（发光体余弦 × Lambert / (d²+0.3)）+ 反弹光。无遮挡。每盏 ±8% 暖/冷、+0–7% 绿、3.5% 死、2.5% 闪烁。 |
| **雾跟着当地光照走** | 雾色 ×（当地光 / 平均）。灯死处雾也暗，剪影读成**光里的一个洞**。背景 = 雾 × 0.15。 |
| **克制的衰败** | 部分墙根水渍潮痕、吊顶下烟黄带、~7% 翘边接缝、~4% 发黄板、~2% 回风口、<1% 缺板（黑洞）、扩散板里的死虫。**个位数百分比。** |
| **印刷品** | 办公激光打印在发黄纸上，压缩体表头、表单号与修订号、编号规则、「管理层」礼貌结尾。钉在软木板上或胶带贴墙。 |
| **VHS 通道（不是 CRT）** | 逐行抖动（≤0.25px）、磁头切换条（底部 8 行）、按需跟踪撕裂、桶形畸变 0.07 + 暗角 0.42（**不作用于 OSD**）、亮度窄/宽高斯 + 边缘振铃、色度向右渗开 1.6px、高光拖尾、白平衡漂移、暗部 AGC 噪声、0–2 条掉磁白线、黑电平抬升 0.045、高光软削。噪声按 30fps。**无扫描线、无 RGB 荫罩。** |
| **OSD** | 手工 5×7 点阵字体 + 黑描边：`● REC` 左上、电量右上、`PM 11:58` / `SEP.27.1996` 右下；字幕机用同一套字体 ×2。 |

**关键取向**：`DEMO.md:73` 强调**背景 = 雾 × 0.15**，走廊溶进黑暗而不是一堵亮墙。

## 2. 句式（字幕 / 旁白怎么写）

**谁来写**：两类说话者。**PA（广播）**——第三人称/祈使的规则口吻，平静的公司腔，字幕加 `[PA]` 前缀；**操作者**——第一人称、现在时、低声（字幕斜体、首行标 `(whispering)`）。环境声用方括号 SDH 描述（`[LIGHTS FLICKER]`、`[SILENCE]`）。

**长度（实测）**：极短。PA 规则句 6–13 个英文词（最长一条 71 字符）；操作者的话更短（`Okay. First night.` / `Hello?` / `That's an exit.`）。字幕硬规则：CEA-608 风格，**每行 ≤ 32 字符**，一行一条黑底块，IBM Plex Mono 600 42px。

**句首类型**（示例性，不是抄原文）：
- 欢迎/入职式开场：`Good evening, and welcome to the night shift.`
- 编号规则句：`Rule one. …` / `Rule three. If …, do not …`
- 操作者短反应/自语：`Okay. First night.` / `Hello?`
- 用时间差制造不对：`It was midnight a second ago.`
- 平铺直叙点名异常：`That's an exit.`

**这个风格里不会出现的句式**：
- 血腥/暴力/惊吓式台词（恐怖来自空与规则，不来自怪物）
- 网络口播腔、感叹号堆叠、营销话术
- 解释性长句（规则必须像印在墙上的制度：短、冷、有编号）
- 把规则写成字幕（规则是**画面**，要能读出来，不能被旁白念完代替）

## 3. 叙事节奏

**信息投放顺序**：

```
磁带滚入（AWB 蓝→黄摆动，AF 找到墙上告示，字幕机打片名）
  → 慢慢摇离告示露出走廊（隔断与灯退进雾里）
  → 例行（行走 POV，低头看湿地毯上的鞋尖；约 20s 几乎无事）
  → 矛盾（蹲下看一张重复出现的告示，保持 ≥4s 不被遮挡）
  → 遵守规则（猛地低头看鞋；让地毯上的光变化而不是抬头看天花板）
  → 峰值（变焦 + 自动对焦在走廊里找，那东西只在约 0.5s 的合焦里存在）
  → 时间被拿走（跟踪撕裂，随后完全相同的构图，只有 OSD 变了）
  → 打破规则（转角看到红色 EXIT；在完全静默里保持不动；推近；门自己开了）
  → 最后一条规则转向观众 → REC 熄灭（定格、撕裂、黑）→ 片尾卡
```

**时间挂在「原始时间」上**，再经分段线性 warp `W()` 映射到成片时间（只压走路段）。

| 锚点（原始秒） | 值 |
|---|---|
| 滚入 / 第一次对焦成功 | rollIn .55 / afLock 1.55 |
| 摇镜 / 第一次低头 | pan 6.0–7.3 / lookDown1 11.3–13.4 |
| 第二张告示 | notice2 16.2–21.2 |
| 三次灯闪 | flick 27.45 / 27.95 / 28.45 |
| 变焦 / 那东西在画面里 | zoom 32.2–33.4 / figOn 32.2–33.95 |
| **它只有这 ~0.5s 是清楚的** | afFig 33.15–33.65 |
| 第二次对上焦已不在 | afEmpty 35.15 |
| 跟踪撕裂（时间码 +3 小时） | tear 36.35–37.0 |
| 转角 / 全片 1s 数字静音 | turn 42.7–44.5 / hush 47.35–48.35 |
| 门 / REC 熄灭 / 片尾卡 | door 51.0–52.3 / recOff 57.7 / endCard 58.1–61.0 |
| 总时长 | DUR = W(61.0) = 59.7s |
| 字幕停留 | ≥ `max(1.9s, 说完 + 0.65s)` |

**总时长**：主 demo 59.7s（`style.json`）；STYLE.md 明确「适合 45–60s 的片子」。

**静默怎么用**：静默是**高潮**——出口出现时整整一秒数字归零（连混响尾巴一起），字幕写 `[SILENCE]`。允许的唯一惊吓是柔和的：声音回来时所有镇流器同时重启的一声低闷「咚」。另外每次灯闪是一段 0.1s 的黑（三次一组），AE 之后约 0.45s 才追上、增益噪声随之泵动。

## 4. 镜头逻辑

**镜头是什么**：一台手持的家用摄像机——它是一段**连续的长镜头**，剪辑只发生在磁带断掉的地方（开机滚入、跟踪撕裂、REC 熄灭）。它表达的是「一个人在照着一份程序走」，它的机械故障就是情节。

**词汇表**（用法由主题决定，没有固定路线）：

| 运动 | 表达 | 可服务 |
|---|---|---|
| 沿走廊行走 POV | 例行、无尽 | 建立空间；时间流逝 |
| 从细节慢慢摇到空间 | 尺度；空间还在延伸 | 一次揭示；第一眼 |
| 低头看脚 | 服从、回避 | 遵守一条规则；不去看 |
| 蹲下保持不动看印刷文字 | 阅读；官僚 | 一条规则；一处矛盾 |
| 变焦 + 对焦在远处搜寻 | 看见 / 看不见 | 一个存在；一份怀疑 |
| 撕裂后完全相同的构图，只有 OSD 变了 | 时间被拿走 | 一次跳跃；一份失去 |
| 转过一个角，保持不动 | 一道门槛 | 一个出口；一个选择 |
| 无声的缓慢推近 | 某物的牵引 | 一扇门；一个标志 |
| 一边拍一边后退 | 撤退、恐惧 | 离开一个房间；一条被打破的规则 |
| 把摄像机放在平面上、静止、独自录制 | 被遗弃 | 操作者不在了；一段长等待 |
| 朝一个声音猛甩过去，然后什么都没有 | 期待落空 | 一个没有来源的噪声 |

**允许的转场**（只有磁带事件）：开机滚入、跟踪撕裂、REC 熄灭。

**禁止**：怪物特写/血/jump scare/配乐 sting；在磁带不断的情况下剪辑；废墟化；让印刷文字被遮挡或不可读。

## 5. 表达习惯（idioms）

1. **自动对焦 / 自动曝光搜寻**：某物只在合焦正确时存在（第一次对上焦它在，第二次对上焦它不在）。
2. **磁带跟踪损伤**：一次撕裂是宇宙做的剪辑；相同构图之后，时钟跳了几小时、电量掉了一格、一盏灯灭了。
3. **OSD 就是情节**：REC、电量、日期与时间码是画内证据（不在场证明、倒计时、带日期的巡检）。
4. **规则作为画面里的文字**：告示与 PA 广播从普通开始，逐渐出错、互相矛盾，最后转向观众。
5. **空与重复**：同一张告示出现在另一个地方；同一个房间少了一个细节；一条走廊通进雾里。空本身就是威胁。
6. **那个「几乎是人」的东西**：一个远处的剪影，偏差 15–40%（小头、长颈、窄而高的肩、长到膝的手臂），画成有机曲线贴在朝向相机的广告牌上，缓慢移动。目标：**你看得出它在挥手，你数不清手指。**
7. **唯一的饱和色**：一个信号色（红色警报灯/绿色应急标志/琥珀警示灯）是唯一会 bloom 的东西。

## 6. 氛围

一片空荡、熟悉但不对劲的室内：芥末黄墙纸、潮湿的地毯、嗡嗡响的荧光吊顶、重复到永远。没有人。整体是**官僚、疲惫、后颈发凉**的气质——不是血腥的恐怖，而是「你在一个不该还在运转的地方值班」的不安。

## 7. 声音

- **没有配乐。** 只有磁带会录下的东西。音乐只存在于画内（隔墙传来的电梯音乐、收音机、天花板喇叭里一段走调的叮咚），被过滤、混响、可能随磁带 wow 走调。demo 的电梯音乐：原创 easy-listening 循环（88 BPM F 大调），读一条逐渐变慢的带速曲线（1.00→0.97→0.89）。
- **日光灯床**：120Hz + 谐波（1/.55/.42/.22/.16/.06）、带通方波的「滋」、约 9kHz 镇流器细啸、坏灯管随机「滋滋」爆发；与画面同一套光照曲线门控；小房间 +3dB。
- **PA**：平静的公司腔（`af_bella` 0.82–0.84）过「天花板喇叭」（限带约 310–3500Hz、纸盆共振 ~1.3kHz、tanh 饱和、房间混响），干到 whisper 仍能转写；每条规则前一段原创两音叮咚（颤音琴 E5→C5），时间跳跃后叮咚与人声一起走调。
- **操作者**：3–4 句短台词（`am_michael`），低电平、近讲低频、随人声包络的气流层、压缩；近讲呼吸，速率跟着恐惧曲线；屏息后一口长呼气。
- **按材料拟音**：湿地毯脚步（60–85Hz 闷击 + 0.9–2.6kHz 小湿黏）、转身布料摩擦、REC 开关的摄像机咔哒 + 马达、变焦伺服啸、AF 马达细咔哒、每次灯闪的镇流器「叮」+ 电弧「滋」、头顶极轻的拖曳、门闩 + 粘滑合页吱呀 + 气压呼声。
- **混音规则**：铺底与画内音乐在人声下约 −8 dB；−14 LUFS；不加颗粒（噪声活在画面里）。静默是高潮：整整一秒数字归零（含尾巴），随后所有镇流器同时重启的低闷「咚」是全片唯一的声音惊吓，且克制。撕裂处整条混音被切碎 + 噪声爆发。低频底噪（35–55Hz 布朗噪声 + 41/43.5Hz 拍频）从时间跳跃升起、到静默处切断。

## 8. 变化空间（可自由发挥）

地点与其材质、拍摄的程序/理由、规则、路线、那个存在（或没有）、信号色、开场、结尾与长度。

`STYLE.md:117-119` 给了远离 demo 的方向：
- **结构**：两盘磁带（同一条路线相隔一年各拍一次，第二盘发现变了什么）；一次真实的房产看房（操作者兴高采烈地介绍每个房间，而房子在不停加房间）；一份逐条念出的清单（每条在画面里的写字板上打勾，直到出现一条不在清单上的）。
- **开场**：半句话开始（操作者已经在说话，跟踪还在滚入）；测试卡与日期板在摄像机被拿起之前；镜头盖没摘（只有声音，直到盖子取下）。
- **结尾**：电池耗尽（图标闪烁，画面定格在耗尽的那格）；摄像机被放下继续录一个空房间；磁带循环回第一镜（现在里面有了操作者的鞋）。

**改编套路**：把主题变成**一次入职、一个程序、或一份清单**，由某人在磁带上录下来——新工作的第一班、一次建筑巡检、一次搬家看房、一所学校的安全演练、一家酒店的夜审。写 5–6 条规则，让媒介背叛规则（`DEMO.md:26`）。

## 10. 素材契约（要新做一部片，需要产出什么）

### 10.1 内容要素

| 要素 | 说明 |
|---|---|
| 台词 `lines.json` | `{id, voice, speed, text, asr?}`；分 PA（`af_bella`）与操作者（`am_michael`） |
| 时间线 `story.js` 的 `T0` | 关键时刻（原始时间）+ 分段线性 warp `W()` |
| 机位曲线 | `POS`/`YAW`/`PITCH`/`CAMH`/`FOV`/`FOCUS`/`APER`/`FEAR`/`HOLD` |
| OSD | `clock(t)` / `battery(t)`（撕裂后时间码跳 +3 小时、电量掉到 1 格） |
| 告示与规则文本 | `tex.js` 的 `notice()` |
| 那个存在的剪影 | `thing2d.js` 的有机曲线设计 |

> ⚠️ `DEMO.md:3` 明确：不要复用 demo 的故事、叙事弧、镜头、道具或时长。

### 10.2 新画面元素的契约

走 `world.js` 的材质工厂：`paint({map,color,shin,spec,emit})` 画任意贴图/纯色漫反射物体；`silhouetteMat(map)` 画几乎不受光的剪影（alpha 测试）；贴图由 `tex.js` 程序化生成（确定性 mulberry 种子，不依赖外部图片）。剪影**必须用有机曲线画在朝向相机的广告牌上**（原始几何体会读成玩具）。

### 10.3 时间线契约

`story.js` 是**唯一真值**：导出 `DUR`（= W(61.0)）、`T`（已 warp 的关键时刻）、`LINES`、`CHIMES`、机位曲线与 OSD 曲线。**所有时间按「原始时间」写、经 `W()` 映射；任何别处的硬编码时间也要一起 warp。** `main.js` 组装渲染链（GTAO + DOF + bloom → VHS）并导出事件；`subs.js` 生成 608 字幕。

### 10.4 事件词汇（`type` → 消费者）

| type | 含义 | 消费者（mix.py） |
|---|---|---|
| `recOn` / `recOff` | 开关机 | 摄像机咔哒 + 马达 |
| `line{id,who}` | 台词 | PA 过天花板喇叭 / 操作者小声说话 |
| `chime` | 两音叮咚 | 颤音琴 E5→C5 过同一喇叭 |
| `step{v}` | 脚步 | 湿地毯闷击 + 湿黏 |
| `rustle{v}` | 布料摩擦 | 带通噪声 |
| `zoom{d}` | 变焦 | 伺服啸 |
| `af` | 对焦 | 马达细咔哒 |
| `flick` | 灯闪 | 镇流器「叮」+ 电弧「滋」（与画面 gLight 同一公式） |
| `overhead{d}` | 头顶掠过 | 极轻拖曳 |

## 11. 构建链（复用机制）

```
sh styles/backrooms/demo/build.sh
  # 1. TTS → whisper
  # 2. music/muzak.py（画内电梯音乐）→ events → mix.py（全部声音 → mix.wav）
  # 3. whisper 复检处理后的人声

```
